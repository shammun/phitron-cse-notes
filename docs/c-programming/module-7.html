    Introduction to Programming · Module 7

    Arrays: input, sum, search, min/max

    Arrays store many values under one name, indexed from 0. This module reads arrays and prints them back, then uses one loop over the array to sum, average, search, replace values and find the minimum or maximum with its position. These single-pass patterns come up in almost every later problem.

    8 programs5 practice linksFolder on GitHub ↗

    🧭 Start here

    You have to read the marks of five students and print them back. With what you know so far, you would write five variables:

    int a1, a2, a3, a4, a5;
scanf("%d %d %d %d %d", &a1, &a2, &a3, &a4, &a5);

    Five is annoying but bearable. Now the problem says the first line contains N, and N can be 1000. You are not going to type a thousand names, and it is worse than that: you do not know N while you are writing the program, so you cannot type them even if you wanted to. Separate names simply run out.

    What you want is what a hotel does with rooms. One name for the building, a number for each room. That is an array. int a[5]; makes five boxes that share the single name a, and you choose one by putting a number in square brackets. The numbering starts at 0, so those boxes are a[0] to a[4], and in an array of n values the last one is a[n-1], never a[n].

    value:    7    2    9    2    5
box:    a[0] a[1] a[2] a[3] a[4]
         ^                   ^
      first box          last box, n = 5

    Now see what that buys you. The number in the brackets can be a variable, and a loop counter is a variable. So the counter that used to only count can now also point at a box:

    int a[n];
for(int i = 0; i < n; i++){
    scanf("%d", &a[i]);       // i chooses the box
}
for(int i = 0; i < n; i++){
    printf("%d ", a[i]);
}

    That is the new idea of this module. Until now i was only a count of repetitions; here i is also the address of the value you are working on, so one short loop can visit every value however many there are.

    First use: adding them up. Keep one extra variable, start it at 0, and add each box as you walk past it. Nothing is stored except the running total.

    i     a[i]    sum after this step
0      7               7
1      2               9
2      9              18
3      2              20
4      5              25

    For the average, divide that sum by n, but make one of them a real number first with (double) sum / n. Divide two integers and C throws the fraction away, so 25 over 4 becomes 6 rather than 6.25.

    Second use: searching. To find where a value x sits, walk from box 0 upwards and stop at the first box that equals x. Set pos = -1 before the loop starts; if nothing matches it stays -1, which is exactly what these problems want printed.

    Third use: the smallest. Start min at a[0] and remember its position, then compare every later box and replace only when a[i] < min. Strictly less, not less-or-equal, so that when the smallest value appears twice you keep the earlier position.

    And why store the values at all? Because you can walk over them more than once. Find the largest in one pass, then in a second pass print how far each value falls below it. That is impossible if you only ever held one number at a time, and it is the reason arrays turn up in nearly every problem from here on.

    One trap worth marking now: the boxes are numbered from 0, but a problem may ask for positions counted from 1. Keep the 0-based index inside the program and add 1 only when you print. The programs below do each of these one at a time, with the array drawn out at every step.

    💡 Key ideas

    Array basics

    int a[n]; holds n ints, from a[0] to a[n-1]. Read and print them with a for loop.

    for (int i = 0; i < n; i++) scanf("%d", &a[i]);

    Accumulator

    Start sum = 0 and add each element. Use long long when the total can go past about 2×10^9.

    Real average

    (double) sum / n converts to double before dividing. Otherwise the division is integer division and the fraction is lost.

    Linear search

    Scan from the left and break at the first match. Start pos = -1 to mean 'not found'.

    Min/max tracking

    Start from a[0] (or INT_MAX/INT_MIN) and update whenever you see a smaller or bigger value. Using strict < keeps the first position when values tie.

    0-indexed vs 1-indexed output

    Arrays in C start at 0, but some tasks ask for positions starting at 1. Add 1 only when printing.

    #include <stdio.h>
#include <limits.h>

int main()
{
    int n;
    
    scanf("%d", &n);
    
    int a[n];
    
    for (int i = 0; i < n; i++) {
        scanf("%d", &a[i]);
    }
    
    int min = INT_MAX, max = INT_MIN;
    
    for (int i = 0; i < n; i++) {
        if (a[i] < min) {
            min = a[i];
        }

    Minimum = -2, Maximum = 9

    Reading the output. The output is Minimum = -2, Maximum = 9.

    How it works, step by step
    1. min = INT_MAX and max = INT_MIN (from <limits.h>), so the first element always replaces them.
    2. For each a[i]: if it is smaller than min, update min; if it is bigger than max, update max.
    3. Print both values.
    ✅ Check yourself: Why start min at INT_MAX rather than 0?
    If every element were positive, a starting value of 0 would never be replaced, and the answer would be wrong.

    /*
===============================================================================
  Problem A: Summation
  Source: https://codeforces.com/group/MWSDmqGsZm/contest/219774/problem/A
===============================================================================

  Problem Statement
  -----------------
  Given a number N and an array A of N numbers, print the absolute summation
  of these numbers.

  Absolute value means to remove any negative sign in front of a number.

  Input Format
  ------------
  First line contains a number N (1 <= N <= 10^5), the number of elements.
  Second line contains N numbers (-10^9 <= A[i] <= 10^9).

  Output Format
  ------------
  Print the absolute value of the summation of these numbers.

  Constraints
  -----------
    1 <= N <= 10^5
    -10^9 <= A[i] <= 10^9

  Worst-case sum magnitude:
    |sum| <= N * max(|A[i]|) = 10^5 * 10^9 = 10^14
  This overflows a 32-bit int (~2.1 * 10^9), so we MUST use long long.

  Sample Input 0     Sample Output 0
  --------------     ---------------
  4                  13
  7 2 1 3

  Explanation: 7 + 2 + 1 + 3 = 13, |13| = 13.

  Sample Input 1     Sample Output 1
  --------------     ---------------
  3                  2
  -1 2 -3

  Explanation: (-1) + 2 + (-3) = -2, |-2| = 2.
===============================================================================
*/

#include <stdio.h>
#include <stdlib.h>

int main() {
    int n;
    scanf("%d", &n);

    long long sum = 0;
    long long x;

    for (int i = 0; i < n; i++) {
        scanf("%lld", &x);
        sum += x;
    }

    /* llabs() from <stdlib.h> returns |sum| as a long long.
       Using abs() here would be wrong because abs() takes int,
       silently truncating a long long value. */
    printf("%lld\n", llabs(sum));

    return 0;
}
    Input (stdin)
    3
-1 2 -3

    n, then n integers.

    Output 
    2

    Reading the output. -1 + 2 - 3 = -2, and its absolute value is 2, which matches the task's sample.

    How it works, step by step
    1. Keep a long long sum = 0.
    2. Read each value into a long long x and add it to sum. The array does not need to be stored.
    3. Print llabs(sum).
    ✅ Check yourself: Why llabs and not abs?
    abs works on int, so a large long long sum would be cut off. llabs works on long long.

    /*
===============================================================================
  Problem B: Searching
  Source: https://codeforces.com/group/MWSDmqGsZm/contest/219774/problem/B
===============================================================================

  Problem Statement
  -----------------
  Given a number N and an array A of N numbers, determine if the number X
  exists in array A or not, and print its position (0-indexed).

  Note: X may be found once, more than once, or not at all.

  Input Format
  ------------
  First line contains a number N (1 <= N <= 10^5), the number of elements.
  Second line contains N numbers (0 <= A[i] <= 10^9).
  Third line contains a number X (0 <= X <= 10^9).

  Output Format
  ------------
  Print the position of X the FIRST time you find it (0-indexed).
  If it does not exist, print -1.

  Constraints
  -----------
    1 <= N <= 10^5
    0 <= A[i] <= 10^9
    0 <= X <= 10^9

  A[i] and X fit in a 32-bit int (max 10^9 < 2.1 * 10^9), so int is fine.

  Sample Input 0     Sample Output 0
  --------------     ---------------
  3                  1
  3 0 1
  0

  Explanation: Array = [3, 0, 1]. X = 0 is at 0-indexed position 1.

  Sample Input 1     Sample Output 1
  --------------     ---------------
  5                  -1
  1 3 0 4 5
  10

  Explanation: X = 10 is not in the array, so print -1.

  Sample Input 2     Sample Output 2
  --------------     ---------------
  4                  0
  2 3 2 1
  2

  Explanation: Array = [2, 3, 2, 1]. X = 2 appears twice; the first
  occurrence is at 0-indexed position 0.
===============================================================================
*/

#include <stdio.h>

int main() {
    int n;
    scanf("%d", &n);

    int a[n];   /* variable-length array, C99 */

    for (int i = 0; i < n; i++) {
        scanf("%d", &a[i]);
    }

    int x;
    scanf("%d", &x);

    /* Linear search. Stop at the first match so we get the earliest index. */
    int pos = -1;
    for (int i = 0; i < n; i++) {
        if (a[i] == x) {
            pos = i;
            break;
        }
    }

    printf("%d\n", pos);

    return 0;
}
    Input (stdin)
    4
2 3 2 1
2

    n, the array, then x.

    Output 
    0

    Reading the output. 2 appears at indexes 0 and 2. The break stops at the first one, so the output is 0.

    How it works, step by step
    1. Read the array and then x.
    2. Start with pos = -1.
    3. At the first a[i] == x, set pos = i and break.
    4. Print pos.
    ✅ Check yourself: What would print without the break?
    2, the last matching index, which is not what the task asks for.

    /*
===============================================================================
  Problem C: Replacement
  Source: https://codeforces.com/group/MWSDmqGsZm/contest/219774/problem/C
===============================================================================

  Problem Statement
  -----------------
  Given a number N and an array A of N numbers, print the array after doing
  the following operations:
    - Replace every positive number by 1.
    - Replace every negative number by 2.
  (Zero stays as zero.)

  Input Format
  ------------
  First line contains a number N (2 <= N <= 1000), the number of elements.
  Second line contains N numbers (-10^5 <= A[i] <= 10^5).

  Output Format
  ------------
  Print the array after the replacement, values separated by space.

  Constraints
  -----------
    2 <= N <= 1000
    -10^5 <= A[i] <= 10^5

  A[i] fits comfortably in a 32-bit int.

  Sample Input 0         Sample Output 0
  --------------         ---------------
  5                      1 2 0 1 1
  1 -2 0 3 4

  Explanation:
       1 > 0   -> 1
      -2 < 0   -> 2
       0 == 0  -> 0
       3 > 0   -> 1
       4 > 0   -> 1
  Result: "1 2 0 1 1"
===============================================================================
*/

#include <stdio.h>

int main() {
    int n;
    scanf("%d", &n);

    int a[n];

    for (int i = 0; i < n; i++) {
        scanf("%d", &a[i]);
    }

    /* Transform each element in place */
    for (int i = 0; i < n; i++) {
        if (a[i] > 0) {
            a[i] = 1;
        } else if (a[i] < 0) {
            a[i] = 2;
        }
        /* if a[i] == 0, leave it unchanged */
    }

    /* Print space-separated. To avoid a trailing space before the newline,
       print the first element alone, then " %d" for each subsequent one. */
    for (int i = 0; i < n; i++) {
        if (i == 0) {
            printf("%d", a[i]);
        } else {
            printf(" %d", a[i]);
        }
    }
    printf("\n");

    return 0;
}
    Input (stdin)
    5
1 -2 0 3 4

    n, then n integers.

    Output 
    1 2 0 1 1

    Reading the output. The output is 1 2 0 1 1, the same as the task's sample.

    How it works, step by step
    1. Read the array.
    2. For each element: if it is > 0, set it to 1; else if it is < 0, set it to 2.
    3. Print the first element on its own, then print " %d" for each of the rest, so there is no trailing space.
    ✅ Check yourself: Why print " %d" for every element after the first?
    The space comes before each number, so there is never an extra space at the end of the line.

  Problem Statement
  -----------------
  Given a number N and an array A of N numbers, print all array positions
  that store a number less than or equal to 10, along with the number stored

  Input Format
  ------------
  First line contains a number N (2 <= N <= 1000), the number of elements.
  Second line contains N numbers (-10^5 <= A[i] <= 10^5).

  Output Format
  ------------
  For each number in the array that is less than or equal to 10, print a

  -----------

    -10^5 <= A[i] <= 10^5
    At least one A[i] satisfies A[i] <= 10.

  A[i] fits comfortably in a 32-bit int.

  Sample Input 0         Sample Output 0
  --------------         ---------------
  5                      A[0] = 1
  1 2 100 0 30           A[1] = 2
                         A[3] = 0

  Explanation:
    Position 0: value 1   <= 10  -> print "A[0] = 1"
    Position 1: value 2   <= 10  -> print "A[1] = 2"
    Position 2: value 100 >  10  -> skip

#include <stdio.h>

int main() {
    int n;
    scanf("%d", &n);

    int a[n];

    for (int i = 0; i < n; i++) {
        scanf("%d", &a[i]);
    }

    for (int i = 0; i < n; i++) {
        if (a[i] <= 10) {
            printf("A[%d] = %d\n", i, a[i]);
        }
    }

    return 0;
}

    /*
===============================================================================
  Problem E: Lowest Number
  Source: https://codeforces.com/group/MWSDmqGsZm/contest/219774/problem/E
===============================================================================

  Problem Statement
  -----------------
  Given a number N and an array A of N numbers, print the lowest number and
  its position.

  Note: If there is more than one occurrence of the lowest number, print the
  position of the FIRST one.

  Input Format
  ------------
  First line contains a number N (2 <= N <= 1000), the number of elements.
  Second line contains N numbers (the problem guarantees typical int ranges).

  Output Format
  ------------
  Print two numbers separated by a space on a single line:
    <lowest value> <position of its first occurrence>
  Position is 1-indexed (see samples).

  Constraints
  -----------
    2 <= N <= 1000

  Sample Input 0         Sample Output 0
  --------------         ---------------
  3                      1 1
  1 2 3

  Explanation: Array = [1, 2, 3]. Lowest = 1, at 1-indexed position 1.

  Sample Input 1         Sample Output 1
  --------------         ---------------
  5                      2 3
  5 6 2 3 2

  Explanation: Array = [5, 6, 2, 3, 2]. Lowest = 2. It appears at 1-indexed
  positions 3 and 5; we print the FIRST occurrence, so position = 3.
===============================================================================
*/

#include <stdio.h>

int main() {
    int n;
    scanf("%d", &n);

    int a[n];

    for (int i = 0; i < n; i++) {
        scanf("%d", &a[i]);
    }

    /* Initialize with the first element. This is cleaner and safer than
       using INT_MAX because it works no matter what integer range the
       problem uses, and it guarantees the position we record is a real
       index into the array. */
    int min_val = a[0];
    int min_pos = 0;   /* 0-indexed internally; we'll +1 when printing */

    /* Scan from index 1 onward. Use strict '<' (not '<=') so that on ties
       we keep the EARLIEST position, which is what the problem asks for. */
    for (int i = 1; i < n; i++) {
        if (a[i] < min_val) {
            min_val = a[i];
            min_pos = i;
        }
    }

    /* Convert to 1-indexed position for output */
    printf("%d %d\n", min_val, min_pos + 1);

    return 0;
}
    Input (stdin)
    5
5 6 2 3 2

    n, then n integers.

    Output 
    2 3

    Reading the output. The minimum 2 appears at positions 3 and 5 (counting from 1). The first is kept, so the output is 2 3.

    How it works, step by step
    1. Set min_val = a[0] and min_pos = 0.
    2. For i from 1, if a[i] < min_val, update both. The strict < keeps the first position when values tie.
    3. Print min_val and min_pos + 1.

    📌 Remember

    • Arrays run from index 0 to n-1, so loop with i < n.
    • Accumulate into long long when the total can be large.
    • Cast to double before dividing to get a real average.
    • Search with pos = -1 and break at the first match.
    • Use strict < to keep the first minimum; add 1 only when printing 1-based positions.
