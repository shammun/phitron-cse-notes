Module 13 adds one new idea: use the number itself as the index. Make a counting array f filled with zeros. Whenever you read a number x, do f[x]++. After one loop, f[x] tells you how many times x appeared, with no searching. This is called a frequency array. If that sounds abstract, start with the tally-sheet story just below; the worked examples then trace the same idea step by step, with numbers, letters and a yes/no version.3 programsModule 142D arrays and matricesModule 14 moves from rows of values to grids.
