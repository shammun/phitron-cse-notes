    Strings: length and <string.h> functions

    Module 11 goes deeper into C strings. A string is a char array ending in the null character '\0', and most string work is built on that one fact. You count a string's length by hand, then with strlen, and you meet the other <string.h> helpers: strcpy, strcat and strcmp.

    💡 Key ideas

    Null terminator '\0'

    Every C string ends with a hidden '\0' character. Functions stop reading when they reach it, not when the array ends.

    char s[10] = "abcd"; // stores a b c d \0 and 5 unused slots

    Counting length by hand

    Loop until you hit '\0' and count the steps. This is what strlen does for you.

    int len = 0;
while(s[len] != '\0') len++;

    strlen

    Found in <string.h>. It returns how many characters come before the first '\0'. Spaces and punctuation count too.

    strcpy and strcat

    strcpy(dst, src) overwrites dst with src. strcat(dst, src) adds src to the end of dst. Either way, dst must be big enough to hold the result.

    strcpy(b, a); // b now holds the same text as a

    strcmp and dictionary order

    strcmp(x, y) compares the strings letter by letter. It returns a negative number if x comes first in dictionary (lexicographic) order, 0 if the strings are equal, and a positive number if x comes later.

    strcmp("apple", "apply") < 0  // 'e' < 'y'

    String length with a loop

    Counts the characters in "abcd" without any library function. The loop walks the array until it reaches the null terminator.

    #include <stdio.h>

int main() {
    char str[10] = "abcd";

    int length = 0;

    for(int i=0; str[i] != '\0'; i++){
        length++;
    }

    printf("%d", length);

    return 0;
}
    Input

    This program reads no input.

    Output 
    4

    Reading the output. It prints 4: the number of letters, not the array size 10. There is no newline after it.

    How it works, step by step
    1. char str[10] = "abcd"; sets aside 10 slots but uses only 5: four letters and '\0'.
    2. length starts at 0.
    3. The for loop runs while str[i] != '\0', so it visits indexes 0, 1, 2 and 3.
    4. Each pass adds 1 to length. At index 4 the loop finds '\0' and stops.
    5. printf("%d", length) prints the count.
    Watch out. Don't loop up to the array size (i < 10). The slots after '\0' are not part of the string.
    ✅ Check yourself: What would this program print if the string were "hi there"?
    8, because the space counts as a character.

    #include <stdio.h>
#include <string.h>

int main() {
    char str[10] = "abcd ab?";

    int length = strlen(str);
    printf("%d", length);

    return 0;
}
    Input

    This program reads no input.

    Output 
    8

    Reading the output. It prints 8: a, b, c, d, the space, a, b and ?.

    How it works, step by step
    1. #include <string.h> makes strlen available.
    2. char str[10] = "abcd ab?"; holds 8 characters plus '\0', so 9 of the 10 slots are used.
    3. strlen(str) counts characters until the first '\0'.
    4. The result goes into length and is printed.
    Watch out. If a string has '\0' in the middle (for example "hi\0there"), strlen stops at the first one and returns 2.
    ✅ Check yourself: What is the longest string that fits in char str[10]?
    9 characters, because one slot must hold '\0'.

    📌 Remember

    • A C string is a char array that ends with '\0'.
    • The length is the number of characters before '\0', including spaces.
    • strlen, strcpy, strcat and strcmp all live in <string.h>.
    • strcmp returns a negative number, zero or a positive number depending on dictionary order.
    • Always leave one extra slot for the terminator.
