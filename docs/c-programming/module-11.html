    Strings: length, <string.h> and practice day 2

    Module 11 goes deeper into C strings. A string is a char array ending in the null character '\0', and most string work is built on that one fact. You count a string's length by hand, then with strlen, and you meet the other <string.h> helpers: strcpy, strcat and strcmp. The practice day (11.5) then uses them on five judge problems: comparing words, joining strings, adding up digits, weaving two strings together and finding a hidden word. The solutions use only what the course has covered up to this module: loops, conditions, char arrays, scanf/printf and <string.h>.

    🧭 Start here

    By the end of the last module you had written the same four lines three times: walk a word one character at a time, stop at the hidden '\0', count the steps.

    Module 11 says: you have done it by hand, here is the ready-made helper. Put #include <string.h> at the top of the file and those four lines become one, int length = strlen(s);. Below is the walk strlen makes on the word abcd.

    int length = 0;
for(int i = 0; s[i] != '\0'; i++){
    length++;
}
    s:   a     b     c     d    \0
i:   0     1     2     3     4
    +1    +1    +1    +1    stop

length is 4, and strlen(s) is 4 too

    Nothing magic happened, so the rules you know still hold. Every character counts, spaces and punctuation included, so strlen("abcd ab?") is 8. It stops at the first '\0', not at the end of the array, so char str[10] = "abcd"; still gives 4.

    One habit comes with it. strlen walks the whole string on every call, so work the length out once before a loop and use that variable inside. for(int i = 0; i < strlen(s); i++) re-walks the string on every pass, and with a million digits that is a million walks instead of one.

    Three more helpers arrive with the same header, and each replaces a loop you could write yourself. strcpy(dst, src) copies a string into dst; you may want to write dst = src, but that does not compile for arrays. strcat(dst, src) sticks src onto the end of what dst already holds. Both write the closing '\0' for you.

    Two things follow. strcat starts writing where the current '\0' sits, so the target must already hold a proper string; on a fresh array full of junk that is why strcpy comes first. And nothing checks sizes, so joined must be big enough for both words plus the slot for the terminator.

    char joined[25];

strcpy(joined, "abcd")  ->  a b c d \0
strcat(joined, "ef")    ->  a b c d e f \0

    The most useful of the four is strcmp, because it answers a question you could not ask before. Two numbers are compared with x < y. Two words cannot be: x < y on char arrays compares where the arrays sit in memory, not the letters inside them.

    strcmp(x, y) does what a dictionary does. It looks at the first letters; if they are equal it looks at the second, and so on, and the first difference decides everything after it. Here it is on acm and acpc.

    A negative result means the first word comes earlier, 0 means they are identical, and a positive result means it comes later. Only the sign matters. Two cases are worth remembering: when one word is the start of the other the shorter one comes first, so strcmp("ab", "a") is positive; and dictionary order is not length order, so strcmp("b", "abc") is positive too.

    position    0     1     2
x = acm     a     c     m
y = acpc    a     c     p
            =     =    m < p   decided here

strcmp(x, y) is negative, so acm comes first

    One more small fact comes back in the practice problems: a digit read as text is not a number. '3' is stored as its ASCII code, 51. The digits sit next to each other in the table, so s[i] - '0' gives the value. That is how a number with a million digits, far too long for any long long, can still have its digits added up: read it as a string and walk it.

    Why bother with the header? Each helper is a loop you no longer write and no longer get wrong, so the length, the copy, the join and the comparison are one line each. The cost is that none of them checks that your array is big enough, which is now your job.

    The five practice problems below use exactly these: strcmp to print the word that comes first, strlen with strcpy and strcat to report and join two words, - '0' to add up digits, and two lengths side by side to weave two words together or to find hello hidden inside a longer string.

    💡 Key ideas

    Null terminator '\0'

    Every C string ends with a hidden '\0' character. Functions stop reading when they reach it, not when the array ends.

    char s[10] = "abcd"; // stores a b c d \0 and 5 unused slots

    Counting length by hand

    Loop until you hit '\0' and count the steps. This is what strlen does for you.

    int len = 0;
while(s[len] != '\0') len++;

    strlen

    Found in <string.h>. It returns how many characters come before the first '\0'. Spaces and punctuation count too.

    strcpy and strcat

    strcpy(dst, src) overwrites dst with src. strcat(dst, src) adds src to the end of dst. Either way, dst must be big enough to hold the result.

    strcpy(b, a); // b now holds the same text as a

    strcmp and dictionary order

    strcmp(x, y) compares the strings letter by letter. It returns a negative number if x comes first in dictionary (lexicographic) order, 0 if the strings are equal, and a positive number if x comes later.

    strcmp("apple", "apply") < 0  // 'e' < 'y'

    Digit characters are not numbers

    '3' is stored as its ASCII code 51, not as 3. The digits '0' to '9' come one after another in the table, so c - '0' gives the digit's value.

    int value = s[i] - '0'; // '7' - '0' = 7

    Walking two strings together

    One index i can walk two strings at once. Guard every access with i < length, so the shorter string stops while the longer one continues.

    if(i < length_s) printf("%c", s[i]);
if(i < length_t) printf("%c", t[i]);

    Subsequence check

    A subsequence keeps the order but may skip letters. To see if "hello" hides inside S, walk S once and move to the next wanted letter whenever you meet the current one.

    if(s[i] == target[j]) j++;

    #include <stdio.h>

int main() {
    char str[10] = "abcd";

    int length = 0;

    for(int i=0; str[i] != '\0'; i++){
        length++;
    }

    printf("%d", length);

    return 0;

    Input

    This program reads no input.

    Output 
    4

    Reading the output. It prints 4: the number of letters, not the array size 10. There is no newline after it.

    How it works, step by step
    1. char str[10] = "abcd"; sets aside 10 slots but uses only 5: four letters and '\0'.
    2. length starts at 0.
    3. The for loop runs while str[i] != '\0', so it visits indexes 0, 1, 2 and 3.
    4. Each pass adds 1 to length. At index 4 the loop finds '\0' and stops.
    5. printf("%d", length) prints the count.
    Watch out. Don't loop up to the array size (i < 10). The slots after '\0' are not part of the string.

    /*

C. Compare
time limit per test: 1 second
memory limit per test: 256 megabytes

Given two strings X and Y. Print the smallest lexicographical one.

Note: Lexicographical is the way of ordering the words based on the alphabetical order
of their component letters.

Input
Only one line contains two strings X, Y (1 <= |X|, |Y| <= 20) consists of lowercase English letters.

Output
Print the smallest lexicographical string.

Note: If both of X and Y are equal, print any of them.

Example

input
acm
acpc

output
acm

*/

# include <stdio.h>
# include <string.h>

int main() {
    /* Each string has at most 20 letters, so 25 slots hold the letters and the '\0'. */
    char x[25];
    char y[25];

    scanf("%s %s", x, y);

    /* strcmp compares the two strings letter by letter, the way a dictionary does.
       It gives a negative number when x comes first, 0 when they are equal
       and a positive number when y comes first. */
    if(strcmp(x, y) <= 0){
        printf("%s", x);
    }
    else {
        printf("%s", y);
    }

    return 0;
}
    Input (stdin)
    acm
acpc

    The example from the statement: two words.

    Output 
    acm

    Reading the output. acm. Both words start with ac. Then m meets p, and m comes first in the alphabet, so acm is the smaller word.

    How it works, step by step
    1. Read both words with scanf("%s %s", x, y). Each is at most 20 letters, so char x[25] is enough.
    2. strcmp(x, y) compares letter by letter from the left and stops at the first difference.
    3. It returns a negative number when x comes first, 0 when the words are equal and a positive number when y comes first.
    4. if(strcmp(x, y) <= 0) prints x. The = part covers equal words, where the statement allows printing either one.
    5. Otherwise y comes first, so print y.
    Watch out. Dictionary order is not length order. strcmp("b", "abc") is positive, so abc is printed even though it is longer. And when one word is the start of the other (ab and a), the shorter one comes first.
    ✅ Check yourself: Which word does the program print for ab a, and why?
    a. The first letters match, then a runs out. A word that is the start of another comes first, so strcmp("ab", "a") is positive.

    /*

D. Strings
time limit per test: 2 seconds
memory limit per test: 64 megabytes

Given two strings A and B. Print three lines contain the following:

- The size of the string A and size of the string B separated by a space
- The string produced by concatenating A and B (A + B).
- The two strings separated by a single space respectively, after swapping their first character.

For more clarification see the example below.

Input
The first line contains a string A (1 <= |A| <= 10) where |A| is the length of A.
The second line contains a string B (1 <= |B| <= 10) where |B| is the length of B.

Output
Print the answer required above.

Example

input
abcd
ef

output
4 2
abcdef
ebcd af

*/

/* Module 10 solved this problem by counting the lengths by hand.
   Here the same job is done with the <string.h> functions from Module 11. */

# include <stdio.h>
# include <string.h>

int main() {
    /* Each string is at most 10 characters, so 15 slots are enough. */
    char a[15];
    char b[15];

    scanf("%s", a);
    scanf("%s", b);

    /* Line 1: strlen counts the characters before the '\0'.
       Its result is stored in an int first, so that %d prints an int. */
    int length_a = strlen(a);
    int length_b = strlen(b);
    printf("%d %d\n", length_a, length_b);

    /* Line 2: build A + B in a third array.
       It must hold up to 10 + 10 = 20 characters plus the '\0', so 25 slots.
       strcpy puts a copy of A into it, then strcat adds B to its end. */
    char joined[25];
    strcpy(joined, a);
    strcat(joined, b);
    printf("%s\n", joined);

    /* Line 3: swap the two first characters through a temporary box. */
    char temp = a[0];
    a[0] = b[0];
    b[0] = temp;

    printf("%s %s", a, b);

    return 0;
}
    Input (stdin)
    abcd
ef

    The example from the statement: A on the first line, B on the second.

    Output 
    4 2
abcdef
ebcd af

    Reading the output. 4 2, then abcdef, then ebcd af. On line 3 the first letters a and e have traded places.

    How it works, step by step
    1. Read a and b. Each is at most 10 characters, so char a[15] is enough.
    2. strlen(a) and strlen(b) replace the two counting loops from Module 10. The results go into int variables and are printed on line 1.
    3. char joined[25] must hold up to 20 characters plus '\0'.
    4. strcpy(joined, a) copies a into it, then strcat(joined, b) adds b to the end. Printing joined gives line 2.
    5. Line 3 swaps a[0] and b[0] through a temporary char, then prints both strings with a space between them.
    Watch out. strcat does not check the size of its target. If joined were char joined[15], two 10-letter strings would write past its end. Make the target big enough for both strings and the '\0'.
    ✅ Check yourself: Why is strcpy(joined, a) needed before strcat(joined, b)?
    strcat adds to whatever joined already holds, and a new array holds leftover junk with no '\0'. strcpy gives it a proper starting string.

    /*

E. Count
time limit per test: 2 seconds
memory limit per test: 64 megabytes

Given a string S. Print the summation of its digits.

Input
Only one line contains a string S (1 <= |S| <= 10^6) where |S| is the length of the string.

It's guaranteed that S contains only digits from 0 to 9.

Output
Print the answer required above.

Example

input
351

output
9

Note
First Test: 3 + 5 + 1 = 9.

*/

# include <stdio.h>
# include <string.h>

int main() {
    /* |S| can be 10^6, so the array needs 10^6 slots plus room for the '\0'. */
    char s[1000005];
    scanf("%s", s);

    /* Find the length once, before the loop, instead of calling strlen
       again on every pass: strlen walks the whole string each time. */
    int length = strlen(s);

    /* A digit character is not its number: '3' is stored as 51, not 3.
       The digits '0' to '9' sit next to each other in the ASCII table,
       so s[i] - '0' turns the character into its value ('3' - '0' = 3). */
    int sum = 0;
    for(int i = 0; i < length; i++){
        sum = sum + (s[i] - '0');
    }

    /* The biggest possible sum is 9 * 10^6 = 9000000, which fits in an int. */
    printf("%d", sum);

    return 0;
}
    Input (stdin)
    351

    The example from the statement.

    Output 
    9

    Reading the output. 9, because 3 + 5 + 1 = 9.

    How it works, step by step
    1. char s[1000005] holds up to 10^6 digits plus '\0'.
    2. scanf("%s", s) reads the digits as text.
    3. int length = strlen(s); is worked out once, before the loop. Writing i < strlen(s) would walk the whole string again on every pass.
    4. For each character, s[i] - '0' gives its value ('5' - '0' is 5), and that value is added to sum.
    5. Print sum. The largest possible answer is 9 × 10^6 = 9,000,000, which fits in an int.
    Watch out. Writing sum = sum + s[i] without - '0' adds the ASCII codes: for 351 you would get 51 + 53 + 49 = 153 instead of 9.
    ✅ Check yourself: Why read the input as a string instead of with scanf("%lld", ...)?
    It can have a million digits. Even long long holds only about 19 digits.

    /*

K. I Love strings
time limit per test: 2 seconds
memory limit per test: 64 megabytes

Given two strings S and T. Print a new string that contains the following:

- The first letter of the string S followed by the first letter of the string T.
- The second letter of the string S followed by the second letter of the string T.
- and so on...

In other words, the new string should be ( S0 + T0 + S1 + T1 + .... ).

Note: If the length of S is greater than the length of T then you have to add the rest of
S letters at the end of the new string and vice versa.

Input
The first line contains a number N (1 <= N <= 50) the number of test cases.

Each of the N following lines contains two string S, T (1 <= |S|, |T| <= 50) consists of
lower and upper English letters.

Output
For each test case, print the required string.

Example

input
2
ipAsu ccsit
ey gpt

output
icpcAssiut
egypt

*/

# include <stdio.h>
# include <string.h>

int main() {
    int n;
    scanf("%d", &n);

    for(int k = 0; k < n; k++){
        /* Each string has at most 50 letters, so 55 slots are enough. */
        char s[55];
        char t[55];
        scanf("%s %s", s, t);

        int length_s = strlen(s);
        int length_t = strlen(t);

        /* Run i up to the longer length. On each step print S's letter at i
           and then T's letter at i, but only if that string still has a letter there.
           When the shorter string runs out, the longer one simply keeps printing,
           which adds "the rest of the letters" at the end. */
        int longer = length_s;
        if(length_t > longer){
            longer = length_t;
        }

        for(int i = 0; i < longer; i++){
            if(i < length_s){
                printf("%c", s[i]);
            }
            if(i < length_t){
                printf("%c", t[i]);
            }
        }

        /* Each test case goes on its own line. */
        printf("\n");
    }

    return 0;
}
    Input (stdin)
    2
ipAsu ccsit
ey gpt

    The example from the statement: 2 test cases, each with two strings on one line.

    Output 
    icpcAssiut
egypt

    Reading the output. icpcAssiut: i+c, p+c, A+s, s+i, u+t. egypt: e+g, y+p, and then t is left over from the longer string.

    How it works, step by step
    1. Read the number of test cases n, then repeat the job n times.
    2. Read s and t, and get their lengths with strlen.
    3. Find longer, the bigger of the two lengths, with one if.
    4. Loop i from 0 to longer - 1. Print s[i] only when i < length_s, then t[i] only when i < length_t.
    5. Once the shorter string is used up, its if stops firing and only the longer string keeps printing. That adds its leftover letters at the end without a separate loop.
    6. Print \n after each test case.
    Watch out. Without the i < length checks, the loop would read past the end of the shorter string and print its '\0' and whatever junk follows it.
    ✅ Check yourself: What does the program print for S = ab and T = xyz?
    axbyz: a, x, b, y, and then the leftover z.

    /*

M. Subsequence String
time limit per test: 1 second
memory limit per test: 256 megabytes

Given String S. Determine if there is a Subsequence in S that is equal to "hello" or not.

Note: A subsequence is a sequence that can be derived from another sequence by deleting some
elements without changing the order of the remaining elements.

For example: The list of all subsequence for the word "apple" would be "a", "ap", "al", "ae",
"app", "apl", "ape", "ale", "appl", "appe", "aple", "apple", "p", "pp", "pl", "pe", "ppl",
"ppe", "ple", "pple", "l", "le", "e".

Input
Only one line contains a string S (5 <= |S| <= 10^4) where |S| is the length of the string
and it consists of lowercase English letters.

Output
Print "YES" if there exists an Subsequence equal to "hello" otherwise, print "NO".

Examples

input
ahhellllloou

output
YES


input
hlelo

output
NO

*/

# include <stdio.h>
# include <string.h>

int main() {
    /* |S| can be 10^4, so 10005 slots hold the letters and the '\0'. */
    char s[10005];
    scanf("%s", s);

    char target[10] = "hello";

    int length = strlen(s);

    /* j points at the letter of "hello" we are still looking for.
       Walk S from left to right. Whenever the current letter of S is the
       one we need, move j to the next letter of "hello".
       Taking the earliest match is always safe: it leaves the most of S
       for the letters that are still needed. */
    int j = 0;
    for(int i = 0; i < length; i++){
        if(j < 5 && s[i] == target[j]){
            j++;
        }
    }

    /* j reaches 5 only if all five letters h, e, l, l, o were found, in order. */
    if(j == 5){
        printf("YES");
    }
    else {
        printf("NO");
    }

    return 0;
}
    Input (stdin)
    ahhellllloou

    The first example. The second example, hlelo, prints NO.

    Output 
    YES

    Reading the output. YES. The program uses the first h, the e after it, two of the ls and then an o.

    How it works, step by step
    1. Read s (up to 10^4 letters) and set up char target[10] = "hello".
    2. j is the position in target of the letter we still need. It starts at 0, meaning we are looking for h.
    3. Walk s from left to right. When s[i] == target[j], that letter is found, so j++ moves on to the next one.
    4. The check j < 5 stops the program from comparing past the end of hello once all five letters are found.
    5. Taking the first match every time is safe: it leaves as much of S as possible for the letters still needed.
    6. At the end, j == 5 means all of h, e, l, l, o were found in order, so print YES, otherwise NO.
    Watch out. The two ls must be two different letters of S. Because j moves forward after each match, one l in S can never be counted twice, so helo correctly gives NO.
    ✅ Check yourself: Why does hlelo give NO even though it contains every letter of hello?
    The order is wrong. After h and e, only one l is left before the o, so j stops at 4.

    📌 Remember

    • A C string is a char array that ends with '\0'.
    • The length is the number of characters before '\0', including spaces.
    • strlen, strcpy, strcat and strcmp all live in <string.h>.
    • strcmp returns a negative number, zero or a positive number depending on dictionary order.
    • Always leave one extra slot for the terminator, and make a strcat target big enough for both strings.
    • c - '0' turns a digit character into its value.
    • Call strlen once before a loop, not in the loop condition.

    It is overwritten. b now holds a copy of a.

    ace is: delete b and d. eca is not, because the letters appear in the other order.
