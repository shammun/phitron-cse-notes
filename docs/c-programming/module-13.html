    Frequency arrays

    Module 13 teaches the frequency array. It is an array where the index is the value you care about, and the element stores how many times that value appeared, or just whether it appeared. After one pass over the data, you can answer "is x there?" or "how many x?" instantly, with no searching. This trick comes up again and again in later problems.

    💡 Key ideas

    Index = value

    freq[x] belongs to the number x. When you see x, you update freq[x] directly. No loop is needed to find its place.

    freq[a[i]]++;

    Start at zero

    The array must start with all zeros. Write int freq[N] = {0}; inside a function. Global arrays start at zero on their own.

    Presence vs count

    freq[x] = 1 only marks that x was seen. freq[x]++ counts how many times it was seen. Pick the one the problem needs.

    Letters as indexes

    For lowercase letters, ch - 'a' maps a..z to 0..25, so a 26-slot array is enough. Add 'a' to turn an index back into a letter.

    f[ch - 'a'] = 1;
printf("%c", i + 'a');

    Answer queries in O(1)

    Once the array is built, each question is a single lookup: freq[x].

    Size limit

    The array must be bigger than the largest possible value. Values up to 10^5 need about 100001 slots.

    #include <stdio.h>

/* This program checks for presence of numbers in an array
 * It uses a frequency array approach where:
 * - Index represents the number
 * - Value at index represents if number exists (1) or not (0)
 */

int main(){
    /* Get size of input array from user
     * n represents how many numbers we'll read
     */
    int n;
    scanf("%d", &n);

    /* Create array to store input numbers
     * Size is n+5 to have some buffer space
     * Note: Variable length arrays are a C99 feature
     * and may not work in all compilers
     */
    int a[n + 5];
    for(int i=0; i<n; i++){
        scanf("%d", &a[i]);
    }

    /* Create frequency array initialized to all zeros
     * Size 100000 assumes no number > 99999
     * Each index i will store:
     * - 1 if number i exists in input array
     * - 0 if number i does not exist
     */
    int freq[100000] = {0};

    /* Mark presence of each number from input array
     * For each number x in array a:
     * Set freq[x] = 1 to show x exists
     */
    for(int i=0; i<n; i++){
        freq[a[i]] = 1;
    }

    /* Print first 10 entries of frequency array
     * Shows presence/absence of numbers 0-9
     * Format: "number presence_value"
     */
    for(int i=0; i<10; i++){
        printf("%d %d\n", i, freq[i]);
    }

    /* Get number of queries from user
     * Each query will ask if a number exists
     */
    int m;
    scanf("%d", &m);

    /* Process each query
     * For each query:
     * 1. Read number x to check
     * 2. Print the number
     * 3. Check freq[x]:
     *    - If 1, number exists -> print YES
     *    - If 0, number absent -> print NO
     */
    for(int i=0; i<m; i++){
        int x;
        scanf("%d", &x);
        printf("%d ", x);

        if (freq[x] == 1){
            printf("YES\n");
        } else{
            printf("NO\n");
        }
    }
}

    How it works, step by step
    1. Read n and the n numbers into a.
    2. int freq[100000] = {0}; starts every mark at 0.
    3. For each a[i], set freq[a[i]] = 1 to mark it as present.
    4. Print i and freq[i] for i from 0 to 9, so you can see the marks.
    5. Read m queries. For each x, print YES if freq[x] == 1, otherwise NO.
    Watch out. A value of 100000 or more would write past the end of freq. Always check the limits before choosing the array size.
    ✅ Check yourself: Why does 4 show 1 and not 2, even though it appears twice?
    The code sets freq[x] = 1 instead of adding 1, so it only records presence.

#include <stdio.h>

/* 

In C, global arrays are automatically initialized to 0. This means that all elements of the array f 
are initially set to 0.

This automatic initialization happens because f is declared globally (outside the main function).

*/
// Array to store frequency of each number (initialized to 0 globally)
int f[100000];

int main(){
    // n: size of input array, m: range of numbers (1 to m)
    int n, m;
    scanf("%d %d", &n, &m);

    // Array to store input numbers with some buffer space
    int a[n];

    // Read n numbers and count their frequencies
    for(int i=0; i<n; i++){
        scanf("%d", &a[i]);
        // Increment frequency counter for number a[i]
        f[a[i]] += 1;
    }

    // Print frequency of each number from 1 to m
    for(int i=1; i<=m; i++){
        printf("%d\n", f[i]);
    }

    return 0;
}

    8 4
1 3 3 2 4 3 1 4

    8 numbers, each between 1 and 4.

    2

2

    Reading the output. Line i is the count of i: 2 (two 1s), 1 (one 2), 3 (three 3s), 2 (two 4s).

    How it works, step by step
    1. int f[100000]; is global, so every slot starts at 0.
    2. Read n and m.
    3. Read each number and do f[a[i]] += 1 in the same loop.
    4. Print f[1], f[2], and so on up to f[m], one per line.
    Watch out. The array a isn't really needed. You could read into a temporary x and do f[x]++.
    ✅ Check yourself: What would line 5 show if M were 5 with the same numbers?
    0, because 5 never appears and global arrays start at zero.

    #include <stdio.h>
#include <string.h>

/* This program finds unique characters in a string and counts them
 * For example, if input is "aaaaaagggggccjcc"
 * Output will show which letters appear (regardless of frequency)
 * and total count of unique letters
 */

int main() {
    /* Declare a string with max size 100000 and initialize with test value
     * In real applications, you may want to get input from user instead
     */
    char str[100000] = "aaaaaagggggccjcc";
    
    /* Create an array of size 26 (one for each lowercase letter)
     * Initialize all elements to 0 using {0}
     * This array will act as a presence checker for each letter
     */
    int f[26] = {0};
    
    /* Get length of string to know how many characters to process */
    int len = strlen(str);

    /* First loop: Mark presence of each character
     * For each character in string:
     * 1. Get the character and store in ch
     * 2. Convert character to array index (0-25) by subtracting 'a'
     *    For example: 'a'-'a'=0, 'b'-'a'=1, etc.
     * 3. Set corresponding array position to 1 to mark presence
     */
    for (int i=0; i<len; i++){
        char ch = str[i];
        int index = ch - 'a';
        f[index] = 1;
    }

    /* Initialize counter for unique characters */
    int cnt = 0;
    
    /* Second loop: Count and print unique characters
     * For each position in frequency array (0-25):
     * 1. If f[i]=1, that letter exists in string
     * 2. Add 1 to total count
     * 3. Print the letter (convert index back to char by adding 'a')
     *    and its presence value
     */
    for(int i=0; i < 26; i++){
        cnt += f[i];
        if(f[i] == 1){
            printf("%c %d\n", i + 'a', f[i]);
        }
    }

    /* Print total count of unique characters found */
    printf("%d\n", cnt);

    return 0;
}
    Input

    This program reads no input.

    Output 
    a 1
c 1
g 1
j 1
4

    Reading the output. a 1, c 1, g 1 and j 1 come out in alphabetical order, even though g comes before c in the string. The last line is 4.

    How it works, step by step
    1. The string is hard-coded as "aaaaaagggggccjcc", and f[26] starts at zeros.
    2. For each character, ch - 'a' gives its slot, and that slot is set to 1.
    3. Loop over the 26 slots. Add each f[i] to cnt, and if f[i] is 1, print the letter i + 'a'.
    4. Print cnt, the number of different letters.
    Watch out. Only lowercase letters are safe. An uppercase letter or a digit would give a negative index or one above 25.
    ✅ Check yourself: Why do the letters come out sorted?
    The second loop goes through the slots in order from 0 (a) to 25 (z), not in string order.

    📌 Remember

    • A frequency array uses the value as the index: freq[x].
    • Set it to 1 to record presence, or use ++ to count.
    • It must start at zero, and it must be bigger than the largest value.
    • Letters map to 0..25 with ch - 'a'.
    • Looping over the frequency array gives the values in sorted order for free.

    ✅ Check yourself

    After counting 2, 4, 3, 4, 5 into freq, what are freq[4] and freq[0]?
    freq[4] is 2 and freq[0] is 0.
    In a letter-count array, which letter does index 7 belong to?
    h, because 'a' + 7 is 'h'.
    When is a frequency array a bad idea?
    When values can be huge (for example up to 10^9) or negative. The array would be too big, or the index would be invalid.
