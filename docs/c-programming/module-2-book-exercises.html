    Short exercises from the textbook chapter on decisions and repetition. They cover if / else, for, while and do-while loops, and the idea that a char is really a small number (its ASCII code). Together these let a program choose what to do and repeat work.

    💡 Key ideas

    if / else

    Runs one block when a condition is true and the other block when it is false.

    if (n % 2 == 0) { /* even */ } else { /* odd */ }

    else-if ladder

    Checks conditions from top to bottom and runs only the first block whose condition is true.

    Logical AND &&

    a<=b && a<=c is true only when both parts are true. This is how you test 'a is the smallest of three'.

    Characters are numbers

    'a' is stored as 97 and 'A' as 65. Lowercase and uppercase letters are exactly 32 apart, so ch - 32 turns 'g' into 'G'.

    Range test on characters

    ch >= '0' && ch <= '9' checks whether a character is a digit. Use >= and <= so both ends of the range count.

    for / while / do-while

    for suits a known number of repeats. while checks its condition before each round. do-while checks after each round, so its body always runs at least once.

    Reads a number and says whether it is even or odd, using the remainder after dividing by 2.

    #include<stdio.h>

int main() {
    int n;
    scanf("%d", &n);
    if (n % 2 == 0){
        printf("Even number \n");
    } else {
        printf("Odd number \n");
    }
}
    Input (stdin)
    7

    One integer.

    Output 
    Odd number

    Reading the output. 7 % 2 = 1, so the program prints Odd number.

    How it works, step by step
    1. Read n with scanf.
    2. n % 2 is the remainder after dividing by 2: 0 for even numbers, 1 for odd numbers.
    3. If the remainder is 0, print Even number. Otherwise print Odd number.
    ✅ Check yourself: What is -7 % 2 in C, and does this program still work for negative odd numbers?
    It is -1. The program only checks == 0, so -7 is still correctly called odd.

    #include<stdio.h>

int main() {
    int a, b, c;
    scanf("%d %d %d", &a, &b, &c);

    // minimum
    if(a<=b && a<=c){
        printf("%d\n", a);
    } else if (b<=a && b<=c) {
        printf("%d\n", b);
    } else {
        printf("%d\n", c);
    }

    // maximum
    if(a>=b && a>=c){
        printf("%d\n", a);
    } else if (b>=a && b>=c) {
        printf("%d\n", b);
    } else {
        printf("%d\n", c);
    }
}
    Input (stdin)
    8 3 5

    Three integers on one line.

    Output 
    3
8

    Reading the output. First line 3 (the minimum), second line 8 (the maximum).

    How it works, step by step
    1. Read a, b, c.
    2. If a is less than or equal to both others, it is the minimum. Otherwise test b the same way. If neither passes, c must be the minimum.
    3. Repeat the same idea with >= to find the maximum.
    4. Using <= (not <) means ties are still handled: with 5 5 9, a counts as the minimum.
    ✅ Check yourself: Why does the last branch simply print c without checking anything?
    If neither a nor b is the smallest, the only one left is c.

    Swap a letter's case

    ascii_letters.cLessonTime O(1) · Space O(1)

    Reads one letter and prints it in the opposite case by adding or subtracting 32 from its ASCII code.

    #include <stdio.h>

int main() {
    char a;
    scanf("%c", &a);

    if (a >= 'a' && a <= 'z'){
        printf("%c", a - 32);
    } else {
        printf("%c", a + 32);
    }
    return 0;
}
    Input (stdin)
    g

    A single letter.

    Output 
    G

    Reading the output. Input g gives G.

    How it works, step by step
    1. Read one character into a with %c.
    2. If a is between 'a' and 'z', it is lowercase, so print a - 32 (for example, 'g' = 103 becomes 71 = 'G').
    3. Otherwise the program assumes it is uppercase and prints a + 32.
    Watch out. The else branch adds 32 to anything that is not lowercase. A digit or symbol turns into some other character. A safer version checks a >= 'A' && a <= 'Z' before adding.
    ✅ Check yourself: What is the ASCII gap between 'a' and 'A', and why is it the same for every letter?
    32. Both alphabets are laid out in the same order, so every lowercase letter is exactly 32 above its uppercase letter.

    #include <stdio.h>

int main() {
    char x;
    scanf("%c", &x);
    if (x >= '0' && x <= '9') {
        printf("IS DIGIT\n");
    } else {
        printf("ALPHA\n");
        if (x > 'a' && x < 'z'){
            printf("IS SMALL\n");
        } else {
            printf("IS CAPITAL\n");
        }
    }

    return 0;
}
    Input (stdin)
    b

    A single character.

    Output 
    ALPHA
IS SMALL

    Reading the output. For b you get two lines: ALPHA, then IS SMALL.

    How it works, step by step
    1. Read one character x.
    2. If x is between '0' and '9', print IS DIGIT.
    3. Otherwise print ALPHA, then use an inner if to decide between IS SMALL and IS CAPITAL.
    Watch out. The inner test is x > 'a' && x < 'z', so a and z are reported as capital letters. Fix: use x >= 'a' && x <= 'z'. Module 5's version gets this right.
    ✅ Check yourself: Which two lowercase letters does this program misclassify, and why?
    a and z. The strict > and < leave out both ends of the range, so they are reported as IS CAPITAL.

    while vs do-while

    while_do_while.cLessonTime O(n) · Space O(1)

    Counts i up from 1 to 5 with a while loop, then counts j down from 10 to 1 with a do-while loop.

    #include <stdio.h>

int main() {
    int i;
    int j;
    i = 1;
    j = 10;
    while(i <= 5) {
        printf("i = %d\n", i);
        i+=1;
    }

    do {
        printf("j = %d\n", j);
        j -= 1;
    } while(j > 0);

    return 0;
}
    Input

    This program reads no input.

    Output

    Reading the output. The output shows i = 1 to i = 5, then j = 10 down to j = 1.

    How it works, step by step
    1. while (i <= 5) checks the condition first, prints i, then does i += 1.
    2. do { ... } while (j > 0); prints j and does j -= 1 first, then checks whether to repeat.
    3. The loop stops once j reaches 0.
    ✅ Check yourself: If j started at 0, how many lines would the do-while print?
    One line (j = 0), because the body runs before the condition is checked.

    📌 Remember

    • % gives the remainder; n % 2 == 0 means n is even.
    • In an else-if ladder, only the first true branch runs.
    • Characters are numbers: lowercase = uppercase + 32.
    • Use >= and <= for ranges so both ends are included.
    • A do-while body always runs at least once; a while body might not run at all.

    ✅ Check yourself

    Write a condition that is true only when ch is an uppercase letter.
    ch >= 'A' && ch <= 'Z'
    What is the difference between a while loop and a do-while loop?
    A while loop checks its condition before each round, so it can run zero times. A do-while loop checks after each round, so it runs at least once.
    With a=4, b=4, c=9, which branch of min_max.c prints the minimum?
    The first one. a<=b and a<=c are both true, so it prints 4.
