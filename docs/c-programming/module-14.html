    2D arrays and matrices

    Module 14 moves from rows of values to grids. A 2D array a[n][m] is an array of rows, and each element is reached with two indexes: a[i][j]. With nested loops you can read, change and print a matrix, and test for special shapes such as scalar matrices or diagonals. The practice files also bring back the frequency-array trick.

    🧭 Start here

    A list of numbers is something you can already handle. int a[5] is a line of five boxes, and a[2] picks the third one. This module is about what happens when the numbers do not lie in a line but sit in a grid.

    The everyday version is a marks sheet. Three students down the side, three subjects across the top, and one mark in every box:

                 Bangla  English  Maths
student 0       7        8       9
student 1       4        5       6
student 2       1        2       3

    With one index only, you can still store this, but it gets ugly. You could keep three separate arrays, s0, s1 and s2, one per student. Then you cannot loop over the students at all, because a loop can change a number but not the name of a variable.

    Or you could put all nine marks in one long array of nine boxes, and work out by hand that the mark of student i in subject j sits at position 3*i + j. That works, but you redo that little sum every single time, and it changes the moment the number of subjects changes.

    C gives you the grid directly. int a[3][3] is three rows, and each row is an array of three ints. You reach one box with two indexes: a[i][j] is row i, column j, and both start counting at 0.

            j=0  j=1  j=2
i=0      7    8    9
i=1      4    5    6
i=2      1    2    3

a[0][2] = 9   (row 0, column 2)
a[2][0] = 1   (row 2, column 0)
a[1][1] = 5   (the middle box)

    That is the new thing here: until now an index was one number picking one box; now the first number picks the row and the second picks the box inside that row. Nothing else about arrays changes.

    Two indexes means two loops, one inside the other. The outer loop holds a row still while the inner loop walks across it:

    for(int i = 0; i < n; i++){        // i picks the row
    for(int j = 0; j < m; j++){    // j walks the columns
        printf("%d ", a[i][j]);
    }
    printf("\n");                  // that row is done
}

    Read that again slowly. For one value of i the whole inner loop runs from start to finish, so the boxes are visited row by row:

    Swap the two loops and the same nine boxes come out column by column instead. The printf("\n") belongs to the outer loop, because a row ends when the inner loop has finished; move it inside and every single number lands on its own line. Reading a grid is the same shape, with scanf("%d", &a[i][j]) in place of the printf.

    i=0:  (0,0) (0,1) (0,2)   newline
i=1:  (1,0) (1,1) (1,2)   newline
i=2:  (2,0) (2,1) (2,2)   newline

    A second example. On a square grid the boxes where i == j, that is (0,0), (1,1) and (2,2), form the line from the top-left corner to the bottom-right one. That is the main diagonal, and one loop adding a[i][i] totals it. The other diagonal is the boxes where i + j == n - 1: in a 3×3 grid, (0,2), (1,1) and (2,0).

    A third example. To answer "is every box off the diagonal a zero?" you need no new tool. Start with flag = 1, meaning "true so far", walk every box, and set flag = 0 the moment one box breaks the rule. It is the same flag you have used with ordinary loops.

    Why bother. A great many things are shaped like a grid: a chessboard, a picture made of pixels, a table of distances between cities, a class timetable. Writing a[i][j] with two loops is short enough that you can spend your thinking on the actual question instead of on where the numbers live.

    💡 Key ideas

    Array of arrays

    int a[3][4] is 3 rows, each holding 4 ints, for 12 cells in total. a[i][j] is row i, column j, and both start at 0.

    Nested loops

    The outer loop picks the row i and the inner loop walks the columns j. For output, print a newline after each row.

    for(int i=0;i<n;i++){
  for(int j=0;j<m;j++) printf("%d ", a[i][j]);
  printf("\n");
}

    Row-major storage

    In memory the rows sit one after another. That is why scanf fills the grid the same way whether the input has 12 numbers on one line or 4 numbers on each of 3 lines.

    Primary diagonal

    The cells where i == j, running from top-left to bottom-right. Only a square matrix has diagonals.

    Secondary diagonal

    The cells where i + j == n - 1, running from top-right to bottom-left.

    Scalar and unit matrices

    A diagonal matrix has zeros everywhere off the diagonal. A scalar matrix also has the same value everywhere on the diagonal. A unit matrix is a scalar matrix with 1s on the diagonal.

    Flag pattern

    Start with flag = 1, meaning "yes so far". Set it to 0 on the first cell that breaks the rule, then print based on flag.

    #include <stdio.h>

/* This is a C program that demonstrates the use of 2D arrays and memory addressing */

int main() {
    /* Declaring and initializing a 2D array of size 3x5
     * - First dimension (3) represents rows
     * - Second dimension (5) represents columns
     * The array is initialized with values in a structured format:
     * Row 1: 1,2,3,4,5
     * Row 2: 6,7,8,9,10 
     * Row 3: 11,12,14,14,15
     */
    int arr[3][5] = {
        {1, 2, 3, 4, 5},    /* Row 0 values */
        {6, 7, 8, 9, 10},   /* Row 1 values */
        {11, 12, 14, 14, 15} /* Row 2 values */
    };

    /* Using nested loops to iterate through the 2D array
     * - Outer loop (i) iterates through rows (0 to 2)
     * - Inner loop (j) iterates through columns (0 to 4)
     */
    for(int i=0; i < 3; i++){
        for(int j=0; j<5; j++){
            /* For each element, we print:
             * i = current row index
             * j = current column index
             * &arr[i][j] = memory address of current element
             * arr[i][j] = value stored at current element
             * The %p formatter is used for printing memory addresses
             * The %d formatter is used for printing integer values
             */
            printf("%i = %d, j = %d, address = %p, value = %d || ", i, j, &arr[i][j], arr[i][j]);
        }
        /* Print newline after each row for better formatting */
        printf("\n");
    }
}

    #include <stdio.h>

/* This program demonstrates reading, modifying and printing a 2D array */
int main(){
    /* Declare variables to store dimensions of 2D array
     * n = number of rows
     * m = number of columns 
     */
    int n, m;
    
    /* Read dimensions from user input using scanf
     * %d format specifier is used for reading integers
     * &n, &m are addresses where the input values will be stored
     * Space between %d %d means we expect user to input two numbers separated by space
     */
    scanf("%d %d", &n, &m);

    /* Declare 2D array with extra buffer space
     * Size is (n+5)x(m+5) to avoid any potential buffer overflow
     * Array indices will go from 0 to n-1 for rows and 0 to m-1 for columns
     */
    int a[n+5][m+5];

    /* Read array elements using nested loops
     * Outer loop (i) iterates through rows (0 to n-1)
     * Inner loop (j) iterates through columns (0 to m-1)
     */
    for(int i=0; i<n; i++){
        for(int j=0; j<m; j++){
            /* Read each element using scanf
             * %d format specifier for reading integer
             * &a[i][j] gives address where element will be stored
             */
            scanf("%d", &a[i][j]);
        }
    }

    /* Modify specific elements in the array
     * a[1][2] = element at row 1, column 2 (0-based indexing)
     * a[2][3] = element at row 2, column 3 
     */
    a[1][2] = 100;
    a[2][3] = 200;

    /* Print the modified array using nested loops
     * Outer loop (i) iterates through rows
     * Inner loop (j) iterates through columns
     */
    for(int i=0; i<n; i++){
        for(int j=0; j<m; j++){
            /* Print each element using printf
             * %d format specifier for printing integer
             * Space after %d creates gap between elements
             */
            printf("%d ", a[i][j]);
        }
        /* Print newline after each row for matrix-like output */
        printf("\n");
    }
}

    #include <stdio.h>

int main(){
    /* Declare variable n to store the dimension of square matrix
     * A scalar matrix must be a square matrix (same number of rows and columns)
     */
    int n;
    
    /* Read the dimension from user input using scanf
     * %d format specifier is used for reading integer value
     * &n gives the address where the input value will be stored
     */
    scanf("%d", &n);

    /* Declare a 2D array m of size nxn to store the matrix elements
     * This creates a square matrix with n rows and n columns
     * Array indices will go from 0 to n-1 for both rows and columns
     */
    int m[n][n];

    /* Read matrix elements using nested loops
     * Outer loop (i) iterates through rows (0 to n-1)
     * Inner loop (j) iterates through columns (0 to n-1)
     * scanf("%d", &m[i][j]) reads each element into matrix position [i][j]
     */
    for(int i=0; i<n; i++){
        for(int j=0; j<n; j++){
            scanf("%d", &m[i][j]);
        }
    }

    /* Store the first diagonal element (m[0][0]) as reference
     * In a scalar matrix, all diagonal elements must be equal
     * Initialize flag as 1 (assuming matrix is scalar until proven otherwise)
     */
    int element = m[0][0];
    int flag = 1;

    /* Check if matrix is scalar using nested loops
     * A scalar matrix has two properties:
     * 1. All diagonal elements (i==j) must be equal
     * 2. All non-diagonal elements (i!=j) must be zero
     */
    for(int i=0; i<n; i++){
        for(int j=0; j<n; j++){
            if(i == j){
                /* Check diagonal elements
                 * If any diagonal element doesn't match the first element,
                 * matrix is not scalar - set flag to 0 and break
                 */
                if(m[i][j] != element){
                    flag = 0;
                    break;
                }
            } else{
                /* Check non-diagonal elements
                 * If any non-diagonal element is not zero,
                 * matrix is not scalar - set flag to 0 and break
                 */
                if(m[i][j] != 0){
                    flag = 0;
                    break;
                }
            }
        }
    }

    /* Print result based on flag value
     * If flag is still 1, matrix satisfies scalar matrix properties
     * If flag is 0, matrix failed one of the scalar matrix tests
     */
    if(flag == 1){
        printf("Scaler");
    } else {
        printf("Not Scaler");
    }

    return 0;
}
    Input (stdin)
    3
5 0 0
0 5 0
0 0 5

    A 3×3 matrix with 5s on the diagonal.

    Output 
    Scaler

    Reading the output. Scaler: every diagonal cell is 5 and every other cell is 0.

    How it works, step by step
    1. Read n and the n×n matrix m.
    2. Save element = m[0][0] and set flag = 1.
    3. Go through every cell. If i == j, the cell must equal element. Otherwise it must be 0.
    4. On a failure, set flag = 0 and break. This only leaves the inner loop.
    5. Print Scaler or Not Scaler depending on flag.
    Watch out. break only leaves the inner loop, so the outer loop keeps going. The answer is still right, but it wastes time. You could also add if(!flag) break; to the outer loop.

    #include <stdio.h>  /* For input/output functions like scanf, printf */
#include <math.h>   /* For mathematical functions */
#include <stdlib.h> /* For abs() function to get absolute value */

int main(){
    /* Declare variable n to store the dimension of square matrix
     * The matrix will have n rows and n columns
     */
    int n;
    /* Read matrix dimension from user using scanf
     * %d format specifier is used for reading integer value
     * &n gives the address where the input value will be stored
     */
    scanf("%d", &n);

    /* Declare a 2D array m of size nxn to store matrix elements
     * This creates a square matrix with n rows and n columns
     * Array indices will go from 0 to n-1 for both rows and columns
     */
    int m[n][n];

    /* Read matrix elements using nested loops
     * Outer loop (i) iterates through rows (0 to n-1)
     * Inner loop (j) iterates through columns (0 to n-1)
     * scanf("%d", &m[i][j]) reads each element into matrix position [i][j]
     */
    for(int i=0; i<n; i++){
        for(int j=0; j<n; j++){
            scanf("%d", &m[i][j]);
        }
    }

    /* Initialize variables to store sum of diagonals
     * main_diagonal: stores sum of elements where row index equals column index (i==j)
     * sec_diagonal: stores sum of elements where row + column = n-1 (i+j==n-1)
     */
    int main_diagonal = 0, sec_diagonal = 0;

    /* Calculate sums of both diagonals using nested loops
     * Main diagonal: elements where row index equals column index (i==j)
     * Secondary diagonal: elements where row index + column index = n-1 (i+j==n-1)
     */
    for(int i=0; i<n; i++){
        for(int j=0; j<n; j++){
            /* Add element to main diagonal sum if it's on main diagonal */
            if(i == j){
                main_diagonal += m[i][j];
            }
            /* Add element to secondary diagonal sum if it's on secondary diagonal */
            if(i+j == n-1){
                sec_diagonal += m[i][j];
            }
        }
    }

    /* Calculate absolute difference between diagonal sums
     * abs() function from stdlib.h is used to get positive difference
     * printf with %d format specifier prints the integer result
     */
    int diff = abs(main_diagonal - sec_diagonal);
    printf("%d", diff);

    return 0;
}
    Input (stdin)
    3
1 2 3
4 5 6
9 8 10

    A 3×3 matrix.

    Output 
    1

    Reading the output. 1: the main diagonal is 1+5+10 = 16, the secondary diagonal is 3+5+9 = 17, and |16−17| = 1.

    How it works, step by step
    1. Read n and the n×n matrix.
    2. In one pass over the cells: if i == j, add the cell to main_diagonal. If i + j == n - 1, add it to sec_diagonal.
    3. Both checks are plain ifs, not if / else if, so the centre cell of an odd-sized matrix goes into both sums.
    4. Print abs(main_diagonal - sec_diagonal).
    Watch out. You don't need two loops. for i: main += m[i][i]; sec += m[i][n-1-i]; does the same work in O(n).
    ✅ Check yourself: In a 4×4 matrix, which column holds the secondary-diagonal cell of row 1?
    Column 2, since 1 + j = 3.

    /*
  How many different values does the array hold?

  This is the frequency array again, in its simplest form. The idea from
  Module 13 was: keep one box per possible value, and use the value itself as
  the index, so `freq[v]` is where everything about v is recorded. Here we do
  not even need a count - a yes/no is enough:

      freq[v] == 0   ->  v has not been seen before: count it, mark the box
      freq[v] == 1   ->  v has already been counted: skip it

  Using the value as the index is what makes this fast. There is no searching
  and no comparing of elements with each other; one direct look-up per
  element settles it, so the whole job is a single pass over the array.

  unique_characters.c did the same thing for letters, where the index was
  str[i] - 'a'. Here the numbers are already small enough to be indexes
  themselves, so no conversion is needed.
*/

#include<stdio.h>

int main(){
    int n;
    scanf("%d", &n);

    int arr[n];
    /* One box per possible value, 0 to 100000, which matches the task's
       limit A[i] <= 10^5. Note what decides the size: the LARGEST value the
       input may contain, not n. A thousand numbers still need a hundred
       thousand boxes if that is how far the values can reach.
       `= {0}` fills every box with 0. Without it the boxes would hold
       leftover rubbish and the "is it still 0?" test below would be
       meaningless.
       The limits of the trick: a negative value, or one above 100000, would
       index outside this array. A frequency array only works when the values
       are small whole numbers with a known range. */
    int freq[100001] = {0};
    /* The answer, built up as the second loop goes along. */
    int unique_count = 0;

    for(int i=0; i<n; i++){
        scanf("%d", &arr[i]);
    }

    /* The counting pass. The first time a value turns up its box is still 0:
       mark it with 1 and add one to the answer. Every later copy of that
       value finds the 1 already there and changes nothing, so each distinct
       value is counted exactly once, however often it appears. */
    for(int i=0; i<n; i++){
        if(freq[arr[i]] == 0){
            freq[arr[i]] = 1;
            unique_count++;
        }
    }

    /* No "\n" after the number. */
    printf("%d", unique_count);

    return 0;

}
    Input (stdin)
    7
1 1 2 3 2 3 7

    7 numbers, and several of them repeat.

    Output 
    4

    Reading the output. 4: the different values are 1, 2, 3 and 7.

    How it works, step by step
    1. Read n and the array.
    2. freq[100001] starts at zeros, and unique_count starts at 0.
    3. For each arr[i]: if freq[arr[i]] is still 0, set it to 1 and add 1 to unique_count.
    4. Print unique_count.
    Watch out. freq[100001] covers values up to 100000, which matches the limit A[i] <= 10^5.
    ✅ Check yourself: How many distinct values are there in 5 5 5 5?

    /*

J. Count Letters
time limit per test: 2 seconds
memory limit per test: 64 megabytes

Given a string S. Determine how many times does each letter occurred in S.

Input
Only one line contains the string S (1 <= |S| <= 10^7) where |S| is the length
of the string and it consists of only lowercase English letters.

Output
For each character that appears in S, print a single line that contains the
following format: "X : Y" where X is the letter and Y is the number of times
that letter X occurred in S.

Note: you must print letters in ascending order.

Examples

input
aaabbc

output
a : 3
b : 2
c : 1

input
regff

output
e : 1
f : 2
g : 1
r : 1

*/

# include <stdio.h>
# include <string.h>

/* |S| can be 10^7, which is far too big for a local array: a local array lives
   in the small stack area. Declared here, above main, the array is global, so
   it has room, and a global array also starts filled with zeros. */
char s[10000005];

int main() {
    scanf("%s", s);

    /* One box per lowercase letter. Box 0 belongs to 'a', box 25 to 'z'. */
    int freq[26] = {0};

    /* Count the length once, before the loop. */
    int length = strlen(s);

    for(int i = 0; i < length; i++) {
        /* s[i] - 'a' turns the letter into its box number:
           'a' - 'a' is 0, 'b' - 'a' is 1, and so on. */
        freq[s[i] - 'a']++;
    }

    /* Walking the boxes from 0 to 25 prints the letters in alphabetical order
       on its own, whatever order they came in inside S. A letter that never
       appeared still holds 0, so it is skipped. */
    for(int i = 0; i < 26; i++) {
        if(freq[i] > 0) {
            printf("%c : %d\n", i + 'a', freq[i]);
        }
    }

    return 0;
}
    Input (stdin)
    aaabbc

    The first sample from the statement.

    Output 
    a : 3
b : 2
c : 1

    Reading the output. Three lines, a : 3, b : 2 and c : 1, which is what the statement expects.

    How it works, step by step
    1. The string can hold 10^7 characters, so s is declared above main. A local array that big would not fit in the stack, and a global array also starts at zero.
    2. int freq[26] = {0}; keeps one box per letter: box 0 for a, box 25 for z.
    3. strlen is called once, before the loop, because it walks the whole string every time it is called.
    4. For each character, s[i] - 'a' gives its box number, and freq[...]++ adds one to that box.
    5. The last loop walks the boxes from 0 to 25 and prints letter : count for every box above zero.
    Watch out. The letters come out sorted because the boxes are walked in order, not because anything was sorted. Only lowercase letters are safe here: an uppercase letter would give a box number above 25.
    ✅ Check yourself: Why is strlen called once into length instead of being used in the loop condition?
    strlen walks the string to find the '\0'. Inside the condition it would do that on every pass, turning one walk into 10^7 walks.

    /*

S. Search in matrix

Aladdin has a matrix of N rows and M columns, and one more number X. He will
take the number X only if X is not inside the matrix. Tell him what he will do.

Input
First line contains two numbers N and M (1 <= N, M <= 100).
Next N lines contain M numbers each: the matrix.
The last line contains the number X.

Output
Print "will not take number" if X is inside the matrix, otherwise print
"will take number".

Example

input
3 3
1 4 5
2 5 6
7 8 9
5

output
will not take number

Note
5 sits in the first row and also in the second row, so the number is already
inside the matrix.

*/

# include <stdio.h>

int main() {
    int n, m;
    scanf("%d %d", &n, &m);

    int a[n][m];
    for(int i = 0; i < n; i++) {
        for(int j = 0; j < m; j++) {
            scanf("%d", &a[i][j]);
        }
    }

    int x;
    scanf("%d", &x);

    /* found stays 0 until the number is seen somewhere in the grid. One flag
       is enough: we do not care how many times x appears, only whether it is
       there at all. */
    int found = 0;
    for(int i = 0; i < n; i++) {
        for(int j = 0; j < m; j++) {
            if(a[i][j] == x) {
                found = 1;
                break;      /* stop this row: the answer cannot change any more */
            }
        }
        if(found == 1) {
            break;          /* break only leaves the inner loop, so break again */
        }
    }

    if(found == 1) {
        printf("will not take number\n");
    } else {
        printf("will take number\n");
    }

    return 0;
}
    Input (stdin)
    3 3
1 4 5
2 5 6
7 8 9
5

    The sample from the statement: a 3 × 3 grid and the number 5.

    Output 
    will not take number

    Reading the output. will not take number, because 5 is in the grid (first row and second row).

    How it works, step by step
    1. Read n and m, then fill a[n][m] with two nested loops.
    2. Read the number x that is being looked for.
    3. found starts at 0 and becomes 1 the moment a cell equals x.
    4. The inner break leaves the current row only, so a second if(found == 1) break; is needed to leave the outer loop as well.
    5. Print will not take number when found is 1, otherwise will take number.
    Watch out. One break only leaves the loop it sits in. Without the second check the outer loop would keep walking the remaining rows.
    ✅ Check yourself: Why is a single found flag enough, even when x appears more than once?
    The question is only whether x is there at all, so the first match already decides the answer.

    📌 Remember

    • a[i][j] means row i, column j, both starting at 0. Use nested loops to visit every cell.
    • Main diagonal: i == j. Secondary diagonal: i + j == n - 1.
    • A matrix is diagonal, scalar or unit depending on its off-diagonal zeros and diagonal values.
    • Use a flag to record "the rule broke somewhere".
    • Rows are stored one after another, so input line breaks don't matter to scanf.
