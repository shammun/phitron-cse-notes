    Introduction to Programming · Module 5

    Practice: min/max of three & character classes

    Two classic beginner problems, solved cleanly with if / else-if ladders: find the smallest and largest of three numbers, and decide whether a character is a digit, a capital letter or a small letter. These are improved versions of the Book/Module2 exercises.

    2 programs2 practice linksFolder on GitHub ↗

    🧭 Start here

    Two old friends today, done properly. Put three cards face up on a table - say 10, 20 and -5 - and you see the smallest and the largest in one glance. A computer cannot glance. It can only ask one yes/no question at a time, and each question compares two values.

    So the job is to turn one glance into a short list of comparisons, using nothing but the if / else if ladder from Module 02.

    The clumsy way is to work out which of the six possible orders you are in and print inside each branch. Six branches, six printfs, and if the task later wants the two numbers on separate lines you have to edit all six.

    The tidy way is to decide what to remember, not what to print. Set a variable, then print once at the end:

    int min, max;
if (a >= b && a >= c)      max = a;
else if (b >= a && b >= c) max = b;
else                       max = c;

if (a <= b && a <= c)      min = a;
else if (b <= a && b <= c) min = b;
else                       min = c;

printf("%d %d", min, max);

    This is the small shift compared with the earlier modules. Until now an if chose which line to print; here it chooses which value to keep, and the printing is one line at the very end. Change the output format later and you change that one line.

    Follow the cards 10, 20 and -5 through both ladders:

    a = 10    b = 20    c = -5
max:  a>=b ?  10>=20  no   -> try b
      b>=a and b>=c ?  yes -> max = 20
min:  a<=b and a<=c ?  no  -> try b
      b<=a ?  20<=10  no   -> else, min = -5
prints:  -5 20

    Watch the >= rather than >. Suppose the values are 5, 5 and 1. With a > b && a > c the first test fails because 5 is not greater than 5, the second fails for the same reason, and the else hands you c, which is 1. The answer would be plainly wrong. Ties are normal in test data, so write the comparisons so that a tie still picks a correct value. A shorter form avoids the trap altogether: max = a; if (b > max) max = b; if (c > max) max = c;

    The second problem, from another angle. You are handed one character and must say whether it is a digit, a capital letter or a small letter. A char is really a small number - '0' is 48, 'A' is 65, 'a' is 97 - and the three groups sit in unbroken blocks, so "is it a digit" is just "is it inside the block": ch >= '0' && ch <= '9'. Write the characters, not the numbers, and the compiler fills in 48 and 57 for you. Both ends are included, so '0' and '9' are digits, and 'a' and 'z' are small letters.

    ch    digit?   capital?   small?   output
'7'    yes        -         -      IS DIGIT
'K'     no       yes        -      ALPHA
                                   IS CAPITAL
'a'     no        no       yes     ALPHA
                                   IS SMALL

    Why practise such small problems? Because picking one value out of several, and sorting a character into a class, turn up inside almost every larger program you will write, and both are places where a careless boundary quietly costs you a correct answer. The edge cases here are exactly the boundaries: equal values, and the first and last letter of a block.

    The last thing to get right is the output itself. A judge compares your text character by character, so min comes first, one space between the two numbers, and ALPHA sits on its own line above IS CAPITAL. The two programs below show both, with the boundary cases handled.

    💡 Key ideas

    Store the answer in a variable

    Set min and max inside the ladders, then print once at the end. This is cleaner than printing inside every branch.

    ASCII ranges

    Digits are 48–57, capital letters 65–90 and small letters 97–122. Compare against the character literals ('0', 'A', 'a') instead of memorising the numbers.

    Inclusive ranges

    ch >= 'A' && ch <= 'Z' includes both 'A' and 'Z'.

    Exact output format

    Judges compare output character by character, so match the task's spaces and line breaks exactly.

    /* 

Given 3 numbers A, B and C, Print the minimum and the maximum numbers.

Input
Only one line containing 3 numbers A, B and C ( - 105 ≤ A, B, C ≤ 105)

Output
Print the minimum number followed by a single space then print the maximum number.

Examples

1 2 3

Output

1 3

Input

-1 -2 -3

Output

-3 -1

Input

10 20 -5

Output

-5 20


*/

#include <stdio.h>

int main()
{
    int a, b, c;
    scanf("%d %d %d", &a, &b, &c);
    int min, max;

    if (a >= b && a >= c)
    {
        max = a;
    }
    else if (b >= a && b >= c)
    {
        max = b;
    }
    else {
        max = c;
    }

    if (a <= b && a <= c)
    {
        min = a;
    }
    else if (b <= a && b <= c)
    {
        min = b;
    }
    else
    {
        min = c;
    }
    
    printf("%d %d", min, max);
    return 0;
}
    Input (stdin)
    10 20 -5

    Three integers.

    Output 
    -5 20

    Reading the output. The smallest value is -5 and the largest is 20, so it prints -5 20.

    How it works, step by step
    1. Read a, b, c.
    2. Maximum: if a is at least as big as both others, max = a. Otherwise check b. Otherwise max = c.
    3. Minimum: the same idea with <=.
    4. Print min max separated by one space.
    ✅ Check yourself: Using the variable names a, b, c, how could you shorten the max ladder?
    Start with max = a;, then if (b > max) max = b; if (c > max) max = c;.

    /* 

Given a letter X. Determine whether X is Digit or Alphabet and if it is Alphabet determine if it is Capital Case or Small Case.

Note:

Digits in ASCII '0' = 48,'1' = 49 ....etc
Capital letters in ASCII 'A' = 65, 'B' = 66 ....etc
Small letters in ASCII 'a' = 97,'b' = 98 ....etc
Input
Only one line containing a character X which will be a capital or small letter or digit.

Output
Print a single line contains "IS DIGIT" if X is digit otherwise, print "ALPHA" in the first line followed by a new line that contains "IS CAPITAL" if X is a capital letter and "IS SMALL" if X is a small letter.

Examples

Input
A

Output
ALPHA
IS CAPITAL


Input
9

Output
IS DIGIT


Input
a

Output
ALPHA

*/

#include <stdio.h>

int main()
{
    char ch;
    scanf("%c", &ch);

    if (ch >= '0' && ch <= '9')
    {
        printf("IS DIGIT");
    }
    else if (ch >= 'A' && ch <= 'Z')
    {
        printf("ALPHA\nIS CAPITAL");
    }
    else if (ch >= 'a' && ch <= 'z')
    {
        printf("ALPHA\nIS SMALL");
    }

    return 0;
}
    Input (stdin)
    a

    One character.

    Output 
    ALPHA
IS SMALL

    Reading the output. For a it prints ALPHA and then IS SMALL. Unlike the Book version, the edge letter a is handled correctly.

    How it works, step by step
    1. Read one character ch.
    2. If ch is between '0' and '9', print IS DIGIT.
    3. Else if it is between 'A' and 'Z', print ALPHA and IS CAPITAL on two lines.
    4. Else if it is between 'a' and 'z', print ALPHA and IS SMALL.
    ✅ Check yourself: What is the ASCII value of '0', and why don't we need to remember it?
    48. Writing '0' in the code means the compiler fills in the number for us.

    Convert a digit character ch to its number value.

    Is 'Z' < 'a' true?
