    Introduction to Programming · Module 10

    Practice day: arrays and strings

    Module 10 is a practice day that brings together the two tools you have just learned, arrays and strings, and puts them to work on small judge problems. The six solutions here walk an array from both ends, treat a string as a plain character array, and check characters one by one. Everything uses only what the course has taught so far: loops, conditions, arrays and scanf/printf — no <string.h>, no functions of your own.

    🧭 Start here

    Put four cards on a table with a number on each, and write the positions underneath. That row is an array: a[0] is the first card, a[3] the last one.

    The problems on this day ask two plain things about such a row. Read it out backwards. And say whether it reads the same in both directions. Neither needs you to move a single card.

    position   0   1   2   3
card       5   1   3   2

    Take the first question. You might think of rebuilding the row, swapping the first card with the last and so on. You do not have to. Nothing about the row changes, only the order in which you say the cards out loud, so the loop counts down instead of up.

    It starts at the last filled position, n - 1, and runs while i is at least 0. Four cards sit at positions 0 to 3, which is why it starts at n - 1 and not n: a[4] is past the end.

    for(int i = n - 1; i >= 0; i--){
    printf("%d ", a[i]);
}
    i = 3  ->  print a[3] = 2
i = 2  ->  print a[2] = 3
i = 1  ->  print a[1] = 1
i = 0  ->  print a[0] = 5

printed:  2 3 1 5

    The second question is a two-finger check. Put one finger on the first card and one on the last. If they differ, stop there: nothing in the middle can repair it. If they match, move both fingers one step inwards and look again. Here are the fingers on the row 1 3 2 3 1.

    In code the left finger is i and the right one is n - 1 - i. They meet after n / 2 steps, so that is where the loop stops. With an odd n the middle card is never compared, which is right: it is its own mirror. One mismatch settles the answer, so keep a flag that starts at 1, clear it on the first bad pair and break.

    1   3   2   3   1
^               ^    1 and 1 match
    ^       ^        3 and 3 match
        ^            middle: no partner

    Now the new part of the day. Rub out the numbers and write a letter on each card, and the row becomes a string. In C a string is nothing more than a char array: s[0] is the first letter, s[1] the second, and the same loops walk it.

    One thing is different, and the whole day rests on it. With numbers you read n first, so you know how many there are. With a word nobody tells you. Instead scanf("%s", s) writes the letters into the array and adds one extra character you never see, the null character '\0'. That marker is the word saying where it ends.

    So you find a length by walking until the marker and counting the steps: int length = 0; then for(int i = 0; s[i] != '\0'; i++) length++;. The library has a ready-made version of that loop, strlen, but it lives in <string.h>, which is the next module.

    position  0    1    2    3     4
s[i]      a    b    b    a    \0
                               ^
                    the hidden end marker

    Once you can walk a word, the rest of the day is that same loop wearing different clothes. Is the word a palindrome? The two-finger check, now on s[i] and s[length - 1 - i], so abba gives YES and icpcassiut gives NO. Is it too long? Print s[0], then length - 2, then s[length - 1], turning localization into l10n. Swap upper and lower case? Letters are stored as numbers, and a capital sits exactly 32 below its small twin, so s[i] - 32 makes a letter capital and s[i] + 32 makes it small.

    Each of these reads the word once from left to right, so even a 100000-character line costs about 100000 steps and finishes instantly, with no second array and no trick. Two things trip people up: the array needs one slot more than the longest possible word, for the '\0', so size it from the constraint and not from the sample; and scanf("%s", s) stops at the first space, so it reads one word, never a whole line.

    The six programs below apply these patterns to the judge problems, each with its input and its output explained.

    💡 Key ideas

    Walking an array backwards

    To print an array in reverse, start the loop at the last index n-1 and go down to 0. Nothing needs to move in memory.

    for(int i = n - 1; i >= 0; i--) printf("%d ", a[i]);

    Two-pointer palindrome check

    Compare the first element with the last, the second with the second last, and keep moving towards the middle. One mismatch is enough to answer NO, so you can stop early.

    int ok = 1;
for(int i = 0; i < n / 2; i++)
    if(a[i] != a[n - 1 - i]) ok = 0;

    A string is a char array ending in '\0'

    scanf("%s", s) fills the array and adds the null character at the end, and it stops at the first space. So the array must have one slot more than the longest word you expect.

    char s[105];
scanf("%s", s);

    Counting a length by hand

    Before <string.h> (Module 11) you find a length by walking the array until the closing '\0' and counting the steps. That loop is all strlen does.

    int length = 0;
for(int i = 0; s[i] != '\0'; i++) length++;

    Character arithmetic

    Letters are stored as numbers (ASCII), and a capital letter is exactly 32 less than its small twin. So s[i] - 32 makes a letter capital and s[i] + 32 makes it small.

    if(c >= 'a' && c <= 'z') c = c - 32;

    Shortening long words

    When a word is too long, print its first letter, then how many letters sit in the middle (length - 2), then its last letter.

    printf("%c%d%c\n", s[0], length - 2, s[length - 1]);

    /*

F. Reversing
time limit per test: 1 second
memory limit per test: 64 megabytes

Given a number N and an array A of N numbers. Print the array in a reversed order.

Note:
*Don't use built-in-functions.

Input
First line contains a number N (1 <= N <= 10^3) number of elements.
Second line contains N numbers (0 <= Ai <= 10^9).

Output
Print the array in a reversed order.

Examples

input
4
5 1 3 2

output
2 3 1 5


input
5
1 2 3 4 5

output
5 4 3 2 1

*/

# include <stdio.h>

int main() {
    int n;
    scanf("%d", &n);

    /* N can be 1000, so 1005 slots are always enough. */
    int a[1005];

    for(int i = 0; i < n; i++){
        scanf("%d", &a[i]);
    }

    /* Nothing has to be swapped. We only print from the last index
       down to the first one, so the array itself stays as it is. */
    for(int i = n - 1; i >= 0; i--){
        printf("%d ", a[i]);
    }

    return 0;
}
    Input (stdin)
    4
5 1 3 2

    The first example from the statement: n = 4, then the four values.

    Output 
    2 3 1 5

    Reading the output. 2 3 1 5 — the input read right to left. The trailing space after the last number is fine; judges ignore spaces at the end of a line.

    How it works, step by step
    1. Read n, then fill a[0] … a[n-1] with scanf inside a loop.
    2. Start a second loop at i = n - 1, the last filled index, and run it down while i >= 0.
    3. Print a[i] followed by a space on each step, so the numbers come out last-to-first.
    4. The array itself is never changed: reversing the *printing* is enough, so no swapping and no second array are needed.
    Watch out. Size the array by the constraint, not by the sample. N can reach 1000, so a[1005] is declared once and works for every test.
    ✅ Check yourself: Why does the loop start at n - 1 instead of n?
    n values are stored at indices 0 to n-1, so a[n] is past the end. Starting at n - 1 prints the last value first.

G. Palindrome Array
time limit per test: 1 second
memory limit per test: 256 megabytes

Given a number N and an array A of N numbers. Determine if it's palindrome or not.

Note:
An array is called palindrome if it reads the same backward and forward, for example,
arrays { 1 } and { 1,2,3,2,1 } are palindromes, while arrays { 1,12 } and { 4,7,5,4 } are not.

Input
First line contains a number N (1 <= N <= 10^5) number of elements.
Second line contains N numbers (1 <= Ai <= 10^9).

Output
Print "YES" (without quotes) if A is a palindrome array, otherwise, print "NO" (without quotes).

Examples

input
5
1 3 2 3 1

output
YES


input
4
1 2 3 4

output
NO

*/

# include <stdio.h>

int main() {
    int n;
    scanf("%d", &n);

    /* N can be 100000, so 100005 slots are always enough. */
    int a[100005];

    for(int i = 0; i < n; i++){
        scanf("%d", &a[i]);
    }

    /* Walk from both ends at the same time: the first with the last,
       the second with the second last, and so on. One mismatch is enough
       to say NO, so we remember it in a flag. */
    int is_palindrome = 1;

    for(int i = 0; i < n / 2; i++){
        if(a[i] != a[n - 1 - i]){
            is_palindrome = 0;
            break;
        }
    }

    if(is_palindrome == 1){
        printf("YES");
    }
    else {
        printf("NO");
    }

    return 0;
}
    Input (stdin)
    5
1 3 2 3 1

    The first example: five values that mirror around the middle 2.

    Output 
    YES

    Reading the output. YES. The pairs (1,1) and (3,3) match and the middle 2 needs no partner. The second example 1 2 3 4 prints NO, because 1 and 4 differ immediately.

    How it works, step by step
    1. Read n and fill the array.
    2. Set a flag is_palindrome = 1, meaning "still a palindrome so far".
    3. Loop i from 0 while i < n / 2, comparing a[i] with its mirror a[n - 1 - i].
    4. On the first mismatch set the flag to 0 and break: no later pair can repair it.
    5. Print YES when the flag survived, otherwise NO.
    6. Stopping at n / 2 is enough because every pair is then checked once. With an odd n the middle element is skipped, and that is correct: it is its own mirror.
    Watch out. Print exactly YES or NO in capitals; a judge compares the text character by character, so Yes fails.
    ✅ Check yourself: With n = 7, how many comparisons does the loop make, and which element is never compared?
    Three: (0,6), (1,5) and (2,4). The middle element at index 3 is skipped, because it mirrors onto itself.

F. Way Too Long Words
time limit per test: 1 second
memory limit per test: 256 megabytes

Given a string S. Print the origin string if it's not too long otherwise, print the special abbreviation.

Note: The string is called too long, if its length is strictly more than 10 characters.
If the string is too long then you have to print the string in the following manner:

- Print the first character in the string.
- Print number of characters between the first and the last characters.
- Print the last character in the string.

For example: "localization" will be "l10n", and "internationalization" will be "i18n".

Input
The first line contains a number T (1 <= T <= 100) number of test cases.
Each of the T following lines contains a string S (1 <= |S| <= 100) where |S| is the length of the string.

It's guaranteed that S contains only lowercase Latin letters.

Output
For each test case, print the result string.

Example

input
4
word
localization
internationalization
pneumonoultramicroscopicsilicovolcanoconiosis

output
word
l10n
i18n
p43s

*/

# include <stdio.h>

int main() {
    int t;
    scanf("%d", &t);

    for(int test = 0; test < t; test++){
        /* |S| can be 100, so 105 slots hold the word and the '\0' at its end. */
        char s[105];
        scanf("%s", s);

        /* The length is counted by hand: walk until the '\0' that closes the string. */
        int length = 0;
        for(int i = 0; s[i] != '\0'; i++){
            length++;
        }

        if(length > 10){
            /* First character, then how many characters are hidden between
               the first and the last one, then the last character. */
            printf("%c%d%c\n", s[0], length - 2, s[length - 1]);
        }
        else {
            printf("%s\n", s);
        }
    }

    return 0;
}
    Input (stdin)
    4
word
localization
internationalization
pneumonoultramicroscopicsilicovolcanoconiosis

    The example from the statement: four words, one per line.

    Output 
    word
l10n
i18n
p43s

    Reading the output. word is short, so it is printed unchanged. localization has 12 letters, giving l + 10 + n = l10n; internationalization gives i18n; the 45-letter word gives p43s.

    How it works, step by step
    1. Read t, then repeat the whole job t times inside a loop.
    2. Read one word with scanf("%s", s), which stops at the space or newline and closes the word with '\0'.
    3. Count the length by walking the array until that '\0'.
    4. When the length is more than 10, print s[0], then length - 2, then s[length - 1].
    5. Otherwise print the word as it is. Either way end the line with \n, because each test case needs its own line.
    Watch out. "Too long" means strictly more than 10, so a word of exactly 10 characters is printed unchanged. Using >= here is the classic wrong answer.
    ✅ Check yourself: Why is the middle number length - 2 and not length?
    The first and last characters are printed as letters, so only the length - 2 characters between them are counted.

G. Conversion
time limit per test: 2 seconds
memory limit per test: 64 megabytes

Given a string S. Print the origin string after replacing the following:

- Replace every comma character ',' with a space character.
- Replace every capital character in S with its respective small character and Vice Versa.

Input
Only one line contains a string S (1 <= |S| <= 10^5) where |S| is the length of the string
and it consists of lower and upper English letters and comma character ','.

Output
Print the string after the conversion.

Example

input
happy,NewYear,enjoy

output
HAPPY nEWyEAR ENJOY

*/

# include <stdio.h>

int main() {
    /* |S| can be 100000, so 100005 slots hold the string and the '\0' at its end.
       The string never contains a space, so scanf with %s reads all of it. */
    char s[100005];
    scanf("%s", s);

    for(int i = 0; s[i] != '\0'; i++){
        if(s[i] == ','){
            printf(" ");
        }
        /* Letters are numbers underneath: 'a' is 32 more than 'A'.
           So subtracting 32 makes a small letter capital, and adding 32 does the opposite. */
        else if(s[i] >= 'a' && s[i] <= 'z'){
            printf("%c", s[i] - 32);
        }
        else {
            printf("%c", s[i] + 32);
        }
    }

    return 0;
}
    Input (stdin)
    happy,NewYear,enjoy

    The example from the statement: one line, letters and commas only.

    Output 
    HAPPY nEWyEAR ENJOY

    Reading the output. HAPPY nEWyEAR ENJOY — both commas became spaces, happy became capitals, and in NewYear each letter flipped the other way.

    How it works, step by step
    1. Read the string with scanf("%s", s). This is safe here because the input holds only letters and commas, never a space.
    2. Walk the array with a loop that runs while s[i] != '\0'.
    3. When the character is a comma, print a space instead.
    4. When it is between 'a' and 'z', print s[i] - 32, which is the same letter in capitals.
    5. Otherwise it is a capital letter, so print s[i] + 32 to make it small.
    6. Nothing is stored back into the array: each character is decided and printed as it is met.
    Watch out. scanf("%s", ...) stops at the first space, so it only works because this input has no spaces. The spaces appear in the *output*, which is printed one character at a time.
    ✅ Check yourself: Why does subtracting 32 turn 'a' into 'A'?
    In ASCII the capital letters sit 32 places before the small ones ('A' is 65, 'a' is 97), so the same shift works for every letter.

I. Palindrome
time limit per test: 1 second
memory limit per test: 256 megabytes

Given a string S. Determine whether S is Palindrome or not

Note: A string is said to be a palindrome if the reverse of the string is same as the string.
For example, "abba" is palindrome, but "abbc" is not palindrome.

Input
Only one line contains a string S (1 <= |S| <= 1000) where |S| is the length of the string
and it consists of lowercase letters only.

Output
Print "YES" if the string is palindrome, otherwise print "NO".

Examples

input
abba

output
YES


input
icpcassiut

output
NO


input
mam

output
YES

*/

# include <stdio.h>

int main() {
    /* |S| can be 1000, so 1005 slots hold the letters and the '\0' at the end. */
    char s[1005];
    scanf("%s", s);

    /* Count the length by walking the array until the closing '\0'. */
    int length = 0;
    for(int i = 0; s[i] != '\0'; i++){
        length++;
    }

    /* Same idea as the palindrome array, but with characters:
       compare the first letter with the last, the second with the second last,
       and stop at the middle. One mismatch is enough to answer NO. */
    int is_palindrome = 1;

    for(int i = 0; i < length / 2; i++){
        if(s[i] != s[length - 1 - i]){
            is_palindrome = 0;
            break;
        }
    }

    if(is_palindrome == 1){
        printf("YES");
    }
    else {
        printf("NO");
    }

    return 0;
}
    Input (stdin)
    abba

    The first example from the statement: one lowercase word on one line.

    Output 
    YES

    Reading the output. YES. The pairs (a,a) and (b,b) match. The second example icpcassiut prints NO, because i and t differ at once, and mam prints YES.

    How it works, step by step
    1. Read the word with scanf("%s", s), which closes it with '\0'.
    2. Count the length by walking the array until that '\0', because strlen belongs to Module 11.
    3. Set a flag is_palindrome = 1 and loop i from 0 while i < length / 2.
    4. Compare s[i] with its mirror s[length - 1 - i]; on the first mismatch clear the flag and break.
    5. Print YES when the flag survived, otherwise NO. With an odd length the middle letter is skipped, which is right: it mirrors onto itself.
    Watch out. The answer must be capital YES or NO. Also note scanf("%s", ...) would stop at a space — safe here, because the statement guarantees lowercase letters only.
    ✅ Check yourself: Why is comparing up to length / 2 enough instead of the whole word?
    Every pair is seen once by then. Going further would compare the same pairs again, in the other order.

D. Strings
time limit per test: 2 seconds
memory limit per test: 64 megabytes

Given two strings A and B. Print three lines contain the following:

- The size of the string A and size of the string B separated by a space
- The string produced by concatenating A and B (A + B).
- The two strings separated by a single space respectively, after swapping their first character.

For more clarification see the example below.

Input
The first line contains a string A (1 <= |A| <= 10) where |A| is the length of A.
The second line contains a string B (1 <= |B| <= 10) where |B| is the length of B.

Output
Print the answer required above.

Example

input
abcd
ef

output
4 2
abcdef
ebcd af

*/

# include <stdio.h>

int main() {
    /* Each string is at most 10 characters, so 15 slots are enough
       for the characters and the '\0' at the end. */
    char a[15];
    char b[15];

    scanf("%s", a);
    scanf("%s", b);

    /* Count both lengths by hand, by walking until the closing '\0'. */
    int length_a = 0;
    for(int i = 0; a[i] != '\0'; i++){
        length_a++;
    }

    int length_b = 0;
    for(int i = 0; b[i] != '\0'; i++){
        length_b++;
    }

    printf("%d %d\n", length_a, length_b);

    /* Line 2: printing A and then B, with nothing in between,
       is the same as printing A + B. */
    printf("%s%s\n", a, b);

    /* Line 3: swap the two first characters through a temporary box,
       then print the strings again. */
    char temp = a[0];
    a[0] = b[0];
    b[0] = temp;

    printf("%s %s", a, b);

    return 0;
}
    Input (stdin)
    abcd
ef

    The example from the statement: A on the first line, B on the second.

    Output 
    4 2
abcdef
ebcd af

    Reading the output. 4 2 are the two lengths; abcdef is the join; ebcd af is the pair after the first letters traded places — abcd starts with e and ef starts with a.

    How it works, step by step
    1. Read both words into a and b with scanf("%s", ...).
    2. Count each length with its own loop that stops at '\0', then print them separated by a space.
    3. For the join, print a and then b with nothing in between: printf("%s%s\n", a, b) gives A + B without building a third array.
    4. Swap the first characters through a temporary variable: keep a[0] in temp, copy b[0] into a[0], then put temp into b[0].
    5. Print both words again, now separated by a single space.
    Watch out. The swap needs the temporary variable. Writing a[0] = b[0] first would overwrite a[0], and b[0] would then be given its own value back.
    ✅ Check yourself: Why can the second line be printed without making a new array?
    Concatenation only matters for what is shown. Printing a immediately followed by b puts the same characters on the line, in the same order.

    📌 Remember

    • Reverse output needs no swapping: just loop from n-1 down to 0.
    • A palindrome check compares matching pairs from both ends and stops at the middle.
    • Strings are char arrays that end with '\0'; before Module 10 is over you count a length with a loop, not with strlen.
    • Characters are small numbers: a capital letter is 32 less than its small twin.
    • Swapping two values always needs a temporary variable.
    • Read the output format closely: spaces, new lines and case all matter on a judge.
