    Practice day: arrays and strings

    Module 10 has no code of its own. It is a practice day that brings together the two tools you have just learned, arrays and strings, and asks you to use them on small judge problems. The problems train you to walk an array from both ends, to treat a string as a character array, and to check characters one by one.

    💡 Key ideas

    Walking an array backwards

    To print or copy an array in reverse, start the loop at the last index n-1 and go down to 0. Nothing needs to move in memory.

    for(int i = n - 1; i >= 0; i--) printf("%d ", a[i]);

    Two-pointer palindrome check

    Put one index i at the start and another j at the end. Compare a[i] with a[j], then move both towards the middle. One mismatch is enough to say NO.

    int ok = 1;
for(int i = 0, j = n - 1; i < j; i++, j--)
    if(a[i] != a[j]) ok = 0;

    A string is a char array ending in '\0'

    scanf("%s", s) fills the array and adds the null character at the end. strlen(s) counts the characters before it.

    Character arithmetic

    Letters are stored as numbers (ASCII). 'a' to 'z' are in a row, so c - 'a' gives 0 to 25 and c - 32 turns a lowercase letter into its uppercase form.

    if(c >= 'a' && c <= 'z') c = c - 'a' + 'A';

    Shortening long words

    When a word is too long, print its first letter, then how many letters sit in the middle (len - 2), then its last letter.

    printf("%c%d%c\n", s[0], len - 2, s[len - 1]);

    📌 Remember

    • Reverse output needs no swapping: just loop from n-1 down to 0.
    • A palindrome check compares matching pairs from both ends and stops at the middle.
    • Strings are char arrays that end with '\0'; strlen stops there.
    • Characters are small numbers, so you can compare and shift them with + and -.
    • Read the output format closely: spaces, new lines and case all matter on a judge.
