    💡 Key ideas

    Pick the type by the constraints

    Values up to 10^9 fit in int, up to 10^18 need long long, and fractions need double. Always read the constraints first.

    %.2lf rounding

    printf("%.2lf", 23.5675) rounds to two decimals and prints 23.57.

    Leading space before %c

    scanf(" %c", &ch) skips the newline left over from earlier reads. The other specifiers skip whitespace on their own.

    for loop N times

    for (int i = 0; i < N; i++) runs exactly N times. Start at 1 with <= when you need the numbers 1 to N themselves.

    Divisibility test

    i % 5 == 0 is true when i is a multiple of 5.

    #include <stdio.h>
#include <string.h>
#include <math.h>
#include <stdlib.h>

/* 

Problem Statement

You've learned about variables, right? Now its time to practice them. 
You need to take an integer A, a very big integer B, a floating value C and 
a character D as input and output them serially.

Input Format

First line will contain A
Second line will contain B
Third line will contain C
Fourth line will contain D
Constraints

-10^9 <= A <= 10^9
-10^18 <= B <= 10^18
-10^9 <= C <= 10^9
Output Format

Output them serially and put a new line after each value. Output the floating value 2 points after decimal.
Sample Input 0

100
1234567891234567
23.5675
A
Sample Output 0

100
1234567891234567
23.57
A

*/
int main() {
    int A;
    long long B;
    double C;
    char D;

    scanf("%d", &A); // Input the integer A
    scanf("%lld", &B); // Input the long long integer B
    scanf("%lf", &C); // Input the floating value C
    scanf(" %c", &D); // Input the character D (Note: This will read the newline character left by previous scanf, so we need to consume it first)
    /*
    The leading space tells scanf to skip any whitespace (spaces, tabs, newlines) 
    before reading the character. This is a classic C beginner trap, and it only 
    affects %c, the other format specifiers (%d, %lld, %lf) automatically skip 
    leading whitespace.
    */

    printf("%d\n", A); // Output the integer A
    printf("%lld\n", B); // Output the long long integer B
    printf("%.2lf\n", C); // Output the floating value C with 2 decimal places
    /*
    lf (Specifier): Stands for long float (used for double). In modern 
    C (C99 and later), both %f and %lf behave identically inside 
    printf because float arguments are automatically promoted to double, 
    but %lf explicitly signals that the variable is a double.
    */
    
    printf("%c\n", D); // Output the character D

    return 0;
}
    Input (stdin)
    100
1234567891234567
23.5675
A

    Four lines: int, big integer, decimal number, character (this is the task's own sample).

    Output 
    100
1234567891234567
23.57
A

    Reading the output. Each value appears on its own line. 23.5675 becomes 23.57 because %.2lf rounds it.

    How it works, step by step
    1. Read A with %d, B with %lld, and C with %lf.
    2. Read D with " %c". The space skips the newline left after the number.
    3. Print them in order, using %.2lf for C.
    ✅ Check yourself: What would D contain if you used "%c" without the space?
    The newline character left over from reading C, not the letter A.

    /*

Problem Statement

I know and you also know that you love practice day so much. So this task is for you. You will be given a positive integer N, you need to print "I Love Practice" N times.

Here positive integer means those integers that are greater than 0.

Input Format

You will be given a positive integer N.
Constraints

1 <= N <= 1000
Output Format

Output "I Love Practice" N times. Don't forget to put a new line after every line.
Sample Input 0

5
Sample Output 0

I Love Practice
I Love Practice
I Love Practice
I Love Practice
I Love Practice
Sample Input 1

2
Sample Output 1

I Love Practice
I Love Practice

*/

#include <stdio.h>
#include <string.h>
#include <math.h>
#include <stdlib.h>

int main() {
    int N;
    scanf("%d", &N); // Input the positive integer N

    for(int i=0; i<N; i++){
        printf("I Love Practice\n"); // Output "I Love Practice
    }

    return 0;
}
    Input (stdin)
    3

    A positive integer N.

    Output 
    I Love Practice
I Love Practice
I Love Practice

    Reading the output. Three identical lines, one for each loop round.

    How it works, step by step
    1. Read N.
    2. for (int i = 0; i < N; i++) repeats N times.
    3. Each round prints the sentence and a newline.
    ✅ Check yourself: How many times does for (int i = 0; i < N; i++) run?
    Exactly N times (i = 0 to N-1).

    /*

Problem Statement

You will be given a positive integer N, you need to print from 1 to N and besides the value, print Yes or No. Print Yes if the value is divisible by 5 and print No otherwise.

Input Format

Input will contain a positive integer N.
Constraints

1 <= N <= 1000
Output Format

Output as mentioned in the question. See the sample input output for more clarifications. Put a new line after every line.
Sample Input 0

10
Sample Output 0

1 No
2 No
3 No
4 No
5 Yes
6 No
7 No
8 No
9 No
10 Yes
Sample Input 1

5
Sample Output 1

1 No
2 No
3 No
4 No
5 Yes

*/



#include <stdio.h>
#include <string.h>
#include <math.h>
#include <stdlib.h>

int main() {
    int N;
    scanf("%d", &N); // Input the positive integer N

    for(int i=1; i<=N; i++){
        if(i % 5 == 0){
            printf("%d Yes\n", i); // Output the value and "Yes" if it's divisible by 5
        } else {
            printf("%d No\n", i); // Output the value and "No" otherwise
        }
    }

    return 0;
}
    Input (stdin)
    12

    A positive integer N.

    Output 
    1 No

    Reading the output. Only lines 5 and 10 say Yes, because they are the only multiples of 5 up to 12.

    How it works, step by step
    1. Read N.
    2. Loop i from 1 to N (inclusive).
    3. If i % 5 == 0, print i Yes. Otherwise print i No.
    ✅ Check yourself: How would you change the program to say Yes for multiples of 3 or 5?
    Use the condition i % 3 == 0 || i % 5 == 0.

    📌 Remember

    • Read the constraints first, then choose int, long long or double.
    • Use %.2lf to print a double with two decimals.
    • Use " %c" to read a character after numbers.
    • i < N starting at 0 runs N times; i <= N starting at 1 gives you the numbers 1 to N.
