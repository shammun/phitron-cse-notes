    💡 Key ideas

    Splitting digits

    For a two-digit n, n / 10 is the tens digit and n % 10 is the units digit.

    int first = n / 10, second = n % 10;

    Wrap-around with %

    (ch - 'a' + 1) % 26 + 'a' moves one letter forward, and 'z' wraps back to 'a'.

    Divisors

    i divides n when n % i == 0. Checking every i from 1 to n lists all divisors.

    Flag variable

    Start with flag = false and set it to true when something happens. After the loop, the flag tells you whether it ever happened.

    Nested loops for patterns

    The outer loop picks the row and the inner loop prints that row's items. Write the item count as a formula in i, such as i, n-i+1 or 2*i-1.

    Characters from numbers

    'A' + i - 1 gives the i-th capital letter.

// Given a character, print the next alphabet

// First way to do it

// int main() {
//     char ch;

//     int ch_val;
    
//     if (ch >= 'a' && ch <= 'z') {

// Second way to do it

int main() {
    char ch;
    scanf("%c", &ch);
    
    if (ch >= 'a' && ch <= 'z') {
        printf("%c", ((ch - 'a' + 1) % 26) + 'a');
    }

    return 0;
}
    Input (stdin)
    z

    One lowercase letter.

    Output 
    a

    Reading the output. For z the output is a: (25 + 1) % 26 = 0, which is 'a'.

    How it works, step by step
    1. Read ch.
    2. ch - 'a' turns the letter into a position from 0 to 25.
    3. Add 1, take % 26 so that 26 wraps to 0, then add 'a' to get a letter back.
    4. Print it with %c.

    #include <stdio.h>

// A number of two digits is lucky if one of its digits is divisible by the other.

// For example, 39, 82, and 55 are lucky, while 79 and 43 are not.

// Given a number between 10 and 99, determine whether it is lucky or not.


int main() {
    int n;
    scanf("%d", &n);
    int first = n / 10;
    int second = n % 10;

    if(first % second == 0 || second % first == 0){
        printf("YES");
    } else {
        printf("NO");
    }

    return 0;
}
    Input (stdin)
    39

    A number from 10 to 99.

    Output 
    YES

    Reading the output. For 39, 9 % 3 = 0, so the output is YES.

    How it works, step by step
    1. first = n / 10 and second = n % 10.
    2. If first % second == 0 or second % first == 0, print YES.
    3. Otherwise print NO.
    Watch out. For numbers like 10, 20 or 30, second is 0, and first % second divides by zero, which crashes the program. Fix: check second == 0 || first. Since 0 is divisible by any digit, those numbers are lucky.
    ✅ Check yourself: Why can first never be 0 here?
    n is between 10 and 99, so its tens digit is at least 1.

    #include<stdio.h>

// Find if d can be achieved by either addition, subtraction or multiplication
// between a, b and class

int main(){
    long long a, b, c, d;
    scanf("%lld %lld %lld %lld", &a, &b, &c, &d);

    if(a + b + c == d || a + b - c == d || a + b * c == d || 
    a - b + c == d || a - b - c == d || a - b * c == d ||
    a * b + c == d || a * b - c == d || a - b * c == d) {
        printf("YES");
    } else {
        printf("NO");
    }
    
    return 0;
}
    Input (stdin)
    3 4 5 23

    Four integers a b c d.

    Output 
    YES

    Reading the output. 3 + 4*5 = 23, so the output is YES.

    How it works, step by step
    1. Read a, b, c, d as long long, since products can be large.
    2. Test each combination with ||: a+b+c, a+b-c, a+b*c, a-b+c, and so on.
    3. Print YES if any combination equals d, otherwise NO.
    Watch out. a - b * c is listed twice and a * b * c is missing, so an input like 2 3 4 24 wrongly prints NO. Fix: replace the repeated check with a * b * c == d.
    ✅ Check yourself: How many operator combinations are there for two slots with three operators?
    3 × 3 = 9.

#include <stdbool.h>

// Given a number N. Print all even numbers between 1 and N inclusive in separate lines

int main() {

    int n;
    scanf("%d", &n);
    bool flag = false;
    for(int i = 1; i <= n; i++){
        if(i % 2 == 0){
            flag=true;
            printf("%d\n", i);
        }
    }
    if(flag==false){
        printf("-1");
    }
}

    // Write a program to print the given pattern.

/*

N = 5

       *
     * * *
   * * * * *
 * * * * * * *
* * * * * * * * *


 */

#include <stdio.h>

int main() {
    int n;
    scanf("%d", &n);

    for(int i = 1; i <= n; i++){
        for(int j = 1; j <= 2* (n - i); j++){
            printf(" ");
        }

        for(int k = 1; k <= 2 * i - 1; k++){
            printf("* ");
        }

         printf("\n");
    }

    return 0;
}
    Input (stdin)
    4

    N.

    Output 
          * 
    * * * 
  * * * * * 
* * * * * * *

    Reading the output. The rows have 1, 3, 5 and 7 stars and are centred. The top row starts after 6 spaces.

    How it works, step by step
    1. The outer loop runs i from 1 to n.
    2. Print 2*(n-i) spaces. The count is doubled because every star takes two characters (* ).
    3. Print 2*i-1 copies of * .
    4. End the row with a newline.
    ✅ Check yourself: How many stars are on the last row for n = 10?
    2·10 − 1 = 19.

    📌 Remember

    • Use / 10 and % 10 to split off digits.
    • Use % 26 to wrap around the alphabet.
    • A flag remembers whether something happened inside a loop.
    • For patterns, write each row's space and item counts as formulas in i.
    • Never use % with a value that might be 0.

    ✅ Check yourself

    Which loops print this pattern for n=3: ***, **, *?
    for (i = n; i >= 1; i--) { for (j = 1; j <= i; j++) printf("*"); printf("\n"); }
    What is (24 + 3) % 26, and what does it mean for letters?
    1. Moving 3 letters forward from 'y' gives 'b'.
    Why does pattern4 print 2*(n-i) spaces instead of n-i?
    Each star is printed as two characters (* ), so the gap has to be twice as wide to keep the pyramid centred.
