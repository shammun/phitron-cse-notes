    Assignment: vectors, prefix sums & patterns

    💡 Key ideas

    Sort to find duplicates

    After sorting, equal values sit next to each other, so one pass comparing A[i] with A[i-1] finds any duplicate.

    sort(A.begin(), A.end());

    Prefix sums need long long

    Values up to 10^9 add up past the int limit quickly, so the running sum must be long long.

    vector<long long> pre(n);

    Sorted check

    An array is sorted ascending if no element is smaller than the one before it. One broken pair is enough to answer NO.

    if(A[j] < A[j-1]) flag = false;

    vector::insert at a position

    A.insert(A.begin() + X, value) puts a value at index X and shifts the rest right. Increase X after each insert to keep the inserted block in order.

    Pattern printing by counting spaces

    For each row, work out how many spaces come before, between and after the characters, and how those counts change from row to row.

    Multiple test cases

    Read T first, then repeat the whole read-solve-print routine T times, resetting variables inside the loop.

    /*

Problem Statement

You will be given an array A of size N. Print "YES" if there is any duplicate value in 
the array, "NO" otherwise.

Input Format

First line will contain N.
Second line will contain the array A.
Constraints

1 <= N <= 100000
0 <= A[i] <= 10^9; Where 0 <= i < N
Output Format

Output "YES" or "NO" without the quotation marks according to the problem statement.
Sample Input 0

5
1 2 3 4 5
Sample Output 0

NO
Sample Input 1

6
2 1 3 5 2 1 
Sample Output 1

YES

*/

#include <iostream>
#include <vector>
#include <algorithm>
#include <string>
using namespace std;

int main() {
    int n;
    cin >> n;

    vector<int> A(n);
    for(int i=0; i<n; i++){
        cin >> A[i];
    }

    sort(A.begin(), A.end());

    for(int i=1; i<n; i++){
        if(A[i] == A[i-1]){
            cout << "YES" << endl;
            return 0;
        }
    }

    cout << "NO" << endl;
    return 0;
}
    Input (stdin)
    6
2 1 3 5 2 1

    n, then n numbers.

    Output 
    YES

    Reading the output. YES: after sorting (1 1 2 2 3 5) the first two values are equal.

    How it works, step by step
    1. Read n and the vector A.
    2. sort it so equal values become neighbours.
    3. For i from 1, if A[i] == A[i-1], print YES and exit.
    4. If the loop ends, print NO.
    ✅ Check yourself: Why is a frequency array a bad idea here?
    Values go up to 10^9, far too large for an array index.

    /*

Problem Statement

You will be given an integer array A of size N. You need to print the prefix sum array 
of the array A in reverse order.

Input Format

First line will contain N.
Next line of contain the array A.
Constraints

1 <= N <= 10^5
1 <= A[i] <= 10^9; Where 0 <= i < N
Output Format

Output the prefix sum array in reverse order.
Sample Input 0

5
2 4 1 5 3
Sample Output 0

15 12 7 6 2 
Explanation 0

The prefix sum of the given array is: 2 6 7 12 15.
The reverse order is: 15 12 7 6 2.
Sample Input 1

3
1000000000 1000000000 1000000000

Sample Output 1

3000000000 2000000000 1000000000 

*/

#include <iostream>
#include <vector>
#include <algorithm>
#include <string>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<long long> nums(n);

    for(int i=0; i<n; i++){
        cin >> nums[i];
    }

    vector<long long>runningSum(n);
    runningSum[0] = nums[0];

    for(int i=1; i<n; i++){
        runningSum[i] = runningSum[i-1] + nums[i];
    }

    for(int i=n-1; i>=0; i--){
        cout << runningSum[i] << " ";
    }

    cout << endl;

    return 0;
}
    Input (stdin)
    3
1000000000 1000000000 1000000000

    n, then n numbers (this case tests overflow).

    Output 
    3000000000 2000000000 1000000000

    Reading the output. 3000000000 2000000000 1000000000: the totals are larger than an int can hold, and they print correctly because of long long.

    How it works, step by step
    1. Read the values into vector<long long> nums.
    2. runningSum[0] = nums[0], then runningSum[i] = runningSum[i-1] + nums[i].
    3. Print runningSum from index n-1 down to 0.
    ✅ Check yourself: What would this sample print if the sums were int?
    Wrong, overflowed (negative) numbers for 3000000000 and 2000000000.

    /*

Sorted

Problem Statement

You will given an array A of size N. You need to tell if the array is already sorted or 
not. If the array is sorted in ascending order print "YES", otherwise print "NO".

Input Format

First line will contain T, the number of test cases.
The first line of each test case will contain N.
The second line of each test case will contain the array A.
Constraints

1 <= T <= 1000
1 <= N <= 1000
0 <= A[i] <= 1000; Where 0 <= i < N
Output Format

Output "YES" or "NO" without the quotation marks according to the problem statement.
Sample Input 0

3
5
2 4 6 7 10
8
1 100 101 120 120 121 1000 1000
4
100 1 102 12
Sample Output 0

YES
YES
NO

*/

#include <iostream>
#include <vector>
#include <algorithm>
#include <string>
using namespace std;

int main() {
    int T;
    cin >> T;

    for(int i=0; i<T; i++){
        int N;
        cin >> N;
        vector<int> A(N);
        for(int j=0; j<N; j++){
            cin >> A[j];
        }

        bool flag = true;
        for(int j=1; j<N; j++){
            if(A[j] < A[j-1]){
                flag = false;
                break;
            }
        }

        if(flag){
            cout << "YES" << endl;
        }
        else{
            cout << "NO" << endl;
        }
    }

    return 0;
}
    Input (stdin)
    3
5
2 4 6 7 10
4
1 1 2 2
4
100 1 102 12

    T, then for each test: N and the array.

    Output 
    YES
YES
NO

    Reading the output. YES (strictly rising), YES (equal neighbours are allowed), NO (1 comes after 100).

    How it works, step by step
    1. Read T.
    2. For each test, read N and A.
    3. Start flag = true; if any A[j] < A[j-1], set it false and break.
    4. Print YES or NO.
    ✅ Check yourself: Why use < and not <= in the comparison?
    Equal neighbours still count as sorted ascending, so only a strict drop breaks the order.

    /*

Insert it

Problem Statement

You will given an integer array A of size N and another array B of size M. Also you will 
be given an index X. You need to insert the whole array B to the index X of array A.

Input Format

First line will contain N.
Second line will contain array A.
Third line will contain M.
Fourth line will contain array B.
The last line will contain X.
Constraints

1 <= N, M <= 10^3
1 <= A[i], B[j] <= 10^3; Where 0 <= i < N and 0 <= j < M
0 <= X <= N
Output Format

Output the final array A.
Sample Input 0

5
2 3 4 5 6
3
10 20 30
3
Sample Output 0

2 3 4 10 20 30 5 6 
Sample Input 1

5
2 3 4 5 6
3
10 20 30
0
Sample Output 1

10 20 30 2 3 4 5 6 
Sample Input 2

4
3 4 5 6
3
10 20 30
4
Sample Output 2

3 4 5 6 10 20 30 

*/

#include <iostream>
#include <vector>
#include <algorithm>
#include <string>
using namespace std;

int main() {
    int N;
    cin >> N;

    vector<int> A(N);
    for(int i=0; i<N; i++){
        cin >> A[i];
    }

    int M;
    cin >> M;

    vector<int> B(M);
    for(int i=0; i<M; i++){
        cin >> B[i];
    }

    int X;
    cin >> X;

    for(int i=0; i<M; i++){
        A.insert(A.begin() + X, B[i]);
        X++;
    }

    for(int i=0; i<N+M; i++){
        cout << A[i] << " ";
    }

    return 0;
}
    Input (stdin)
    5
2 3 4 5 6
3
10 20 30
3

    N, A, M, B, then X.

    Output 
    2 3 4 10 20 30 5 6

    Reading the output. 2 3 4 10 20 30 5 6: B sits in the middle, starting at index 3.

    How it works, step by step
    1. Read A (size N), B (size M) and X.
    2. For each B[i], call A.insert(A.begin() + X, B[i]).
    3. Then X++, so the next element goes right after the one just inserted.
    4. Print all N + M elements.
    Watch out. Without X++, B would end up reversed (30 20 10). One call A.insert(A.begin() + X, B.begin(), B.end()); does the whole job in O(N + M).
    ✅ Check yourself: What does the program print for X = 0 with the same arrays?
    10 20 30 2 3 4 5 6.

    /*

Printing X

Problem Statement

You will be given an positive odd integer N, you need to print the pattern for it. See sample 
input and output for understanding the pattern.

Input Format

Input will contain only N.
Constraints

1 <= N <= 20 and N is odd.
Output Format

Output the pattern.
Sample Input 0

5
Sample Output 0

\   /
 \ / 
  X  
 / \ 
/   \
Sample Input 1

7
Sample Output 1

\     /
 \   / 
  \ /  
   X   
  / \  
 /   \ 
/     \
Sample Input 2

3
Sample Output 2

\ /
 X 
/ \
Sample Input 3

1
Sample Output 3

X

*/

#include <iostream>
#include <vector>
#include <algorithm>
#include <string>
using namespace std;

int main() {
    int N;
    cin >> N;

    if(N == 1){
        cout << "X" << endl;
        return 0;
    }

    int spaces = N - 2;

    for(int i=0; i < N/2; i++){
        for(int j=0; j <i; j++){
            cout << " ";
        }
        cout << "\\";

        for(int j=0; j< spaces; j++){
            cout << " ";
        }
        cout << "/";

        for(int k=0; k<i; k++){
            cout << " ";
        }
        cout << endl;

        spaces -= 2;
    }

    for(int i=0; i<N/2; i++){
        cout << " ";
    }
    cout << "X" << endl;

    int space_before_after = N/2 - 1;
    int space_between = 1;
    for(int i=N/2 + 1; i < N; i++){
        for(int j=0; j<space_before_after; j++){
            cout << " ";
        }
        cout << "/";

        for(int k=0; k<space_between; k++){
            cout << " ";
        } 
        cout << "\\";

        for(int l=0; l<space_before_after; l++){
            cout << " ";
        }
        cout << endl;
        space_before_after--;
        space_between += 2;
    }

    return 0;
}
    Input (stdin)
    7

    A single odd N.

    Output 
    \     /
 \   / 
  \ /  
   X
  / \  
 /   \ 
/     \

    Reading the output. A 7-line X: the arms meet at the X in row 4. In the top half the gap between \ and / shrinks 5, 3, 1; in the bottom half it grows 1, 3, 5.

    How it works, step by step
    1. Special case: N == 1 prints just X.
    2. Top half (N/2 rows): row i has i spaces, \, spaces gaps, /, and i spaces. spaces starts at N-2 and drops by 2 each row.
    3. Middle row: N/2 spaces then X.
    4. Bottom half: space_before_after starts at N/2 - 1 and shrinks by 1; space_between starts at 1 and grows by 2; each row prints /, the gap, \.
    Watch out. The middle row has no trailing spaces while the other rows do. Most judges ignore trailing spaces, but a strict checker would not. Remember \ in a C++ string prints one backslash.
    ✅ Check yourself: How many spaces are between the slashes on the first row when N = 9?
    7 (N - 2).

    📌 Remember

    • Sort first when you need to spot equal values.
    • Use long long for any running total of large numbers.
    • An array is sorted if no neighbour pair goes down.
    • Increase the insert position after each insert to keep the inserted block's order.
    • Pattern problems: write down the space counts per row, then find how they change.

    ✅ Check yourself

    How can you check for duplicates in O(n) average time without sorting?
    Insert values into an unordered_set and report YES when an insert finds the value already present.
    What is the time complexity of inserting M elements one by one at the front of a vector of size N?
    O(M * (N + M)), because each insert shifts every element after it.
