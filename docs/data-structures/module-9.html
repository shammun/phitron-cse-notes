    Doubly linked list: build, print, insert, delete

    A doubly linked list gives every node two links: next to the node after it and prev to the node before it. This module builds one by hand, prints it both ways, and writes insert and delete at the head, the tail and any index. The extra prev link makes tail deletion O(1) and backward walks easy, but every operation now has two links to keep correct.

    💡 Key ideas

    Node with two links

    Each node stores val, next and prev. The constructor sets both links to NULL so a new node is not connected to anything yet.

    class Node { public: int val; Node* next; Node* prev; };

    Head and tail

    head->prev and tail->next are both NULL. Keeping a tail pointer lets you start at either end.

    Print forward and backward

    Forward: start at head and follow next. Backward: start at tail and follow prev. No recursion needed.

    for(Node* t = tail; t; t = t->prev) cout << t->val << " ";

    Every link has a partner

    If A->next == B, then B->prev must be A. Each insert or delete must fix both directions, or forward and backward prints will disagree.

    Insert in the middle: four links

    To put newNode after tmp: point newNode->next at tmp->next, point tmp->next->prev back at newNode, then tmp->next = newNode and newNode->prev = tmp.

    newNode->next = tmp->next;
tmp->next->prev = newNode;
tmp->next = newNode;
newNode->prev = tmp;

    O(1) tail delete

    Thanks to prev, the new tail is simply tail->prev; no walk from the head is needed.

    tail = tail->prev; delete tail->next; tail->next = NULL;

    Edge cases decide correctness

    Index 0 is a head operation; the last position is a tail operation; a one-node list must set both head and tail to NULL when emptied.

class Node {
    public:
        int val;     
        Node* next;
        Node* prev;

    Node(int val) {
        this->val = val; 
        this->next = NULL;
        this->prev = NULL;

void print_forward(Node* head){
    Node* tmp = head;
    while(tmp != NULL){
        cout << tmp->val << " ";
        tmp = tmp->next;

    cout << endl;
}

void print_backward(Node* tail){
    Node* tmp = tail;
    while(tmp != NULL){
        cout << tmp->val << " ";
        tmp = tmp->prev;
    }
    cout << endl;
}

    Node* tail = new Node(30);

    head->next = a;
    a->prev = head;

    a->next = tail;
    tail->prev = a;

    print_backward(tail);
    
    return 0;

    📌 Remember

    • A doubly node has next and prev; set both to NULL in the constructor.
    • Every change must keep A->next == B and B->prev == A true.
    • Head and tail insert/delete are all O(1); any-index operations are O(n) because of the walk.
    • Reuse the head/tail functions for index 0 and the last index.
    • When the list becomes empty, set both head and tail to NULL.

    ✅ Check yourself

    Which operation gets faster when you move from a singly to a doubly linked list with a tail pointer?
    Deleting the tail: O(n) becomes O(1).
    How can you quickly test that all prev links are correct?
    Print the list forward and backward; the backward line should be the exact reverse of the forward line.
    What does a doubly linked list cost in exchange for these benefits?
    An extra pointer in every node (more memory) and more links to update in every operation.
