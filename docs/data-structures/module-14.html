    🧭 Start here

    Stand in a line at a ticket counter. You arrive and join at the back. The person being served is at the front, and when they are done they leave and everyone shifts up one. Nobody who arrived after you is served before you.

    That is a queue: first in, first out — FIFO. It is the opposite habit to the pile of plates in Module 13. A stack hands back the newest value; a queue hands back the oldest one.

    front                                 back
  v                                     v
[ 10 ] [ 20 ] [ 30 ]   <- new joins here
  ^
served and removed here

    A queue has two ends that matter, so it has six small operations: push (join at the back), pop (leave from the front), front and back to read the two ends, plus size and empty. As with the stack, every one of them is O(1).

    Follow a short line with real values. Watch how front and back move independently of each other. With the STL that whole trace is five lines of code.

    queue<int> q;
q.push(10); q.push(20); q.push(30);
cout << q.front() << " " << q.back();  // 10 30
q.pop();
cout << q.front();                     // 20
    push 10    [ 10 ]          front 10  back 10
push 20    [ 10 20 ]       front 10  back 20
push 30    [ 10 20 30 ]    front 10  back 30
pop        [ 20 30 ]       front 20  back 30
push 40    [ 20 30 40 ]    front 20  back 40
pop        [ 30 40 ]       front 30  back 40

    Which end goes where. Building a queue on a singly linked list is the part that catches people. Add at the tail and remove at the head, and both are O(1). Do it the other way round and pop would have to find the node *before* the tail, which means walking the whole list — O(n) for every value removed. The choice of ends is not a matter of taste; one of them is 100000 times slower on a long queue.

    There is one more detail the module keeps coming back to. When the last value leaves, head becomes NULL, and tail must be set to NULL as well. Forget it and tail still points at memory you have just freed, so the next push links a new node onto a deleted node.

    The module also builds the queue on a doubly linked list and on the STL list — push_back to join, pop_front to leave — before using the ready-made queue<int>. Same six operations every time, different storage underneath.

    Why have both a stack and a queue? Because of one difference, and the practice problems on this page are mostly that difference in disguise. Put the same values into each, then take them all out:

    put in       10  20  30  40  50
stack gives  50  40  30  20  10   (reversed)
queue gives  10  20  30  40  50   (same order)

    So a stack in the middle of a pipeline reverses, and a queue keeps the order. That is the whole method behind reversing a queue: pour it into a stack, then pour the stack back. Reversing only the first k values is the same trick applied to a prefix, followed by rotating the rest round to the back.

    When you want a stack. Whenever the thing to deal with next is the most recent one still unresolved: matching brackets, applying backspaces to typed text, cancelling adjacent equal letters. When you want a queue. Whenever fairness of arrival matters, or work must be processed in the order it was created.

    💡 Key ideas

    FIFO

    A queue is a line at a counter: new people join at the back, service happens at the front. The first value pushed is the first popped.

    Queue operations

    push (join the back), pop (leave the front), front, back, size, empty — all O(1).

    queue<int> q;
q.push(1); q.push(2);
cout << q.front();  // 1
q.pop();
cout << q.front();  // 2

    Which end is which

    With a singly linked list, remove at the head (O(1)) and add at the tail (O(1) with a tail pointer). Removing at the tail would need the previous node.

    Stack reverses, queue keeps order

    Pouring values through a stack reverses them; through a queue they stay in order. Many problems (reverse a queue, reverse first K) are just this idea.

    Stack for matching

    When the latest unmatched item must be handled first — brackets, backspaces, adjacent duplicates — a stack is the natural tool.

    Auxiliary min stack

    A second stack that only stores 'new minimum so far' values gives getMin in O(1). Push on <= so duplicates of the minimum are counted.

    Building one structure from another

    A stack can be made from a queue and a queue from a stack by moving elements between helper containers. One operation becomes O(n), the rest stay O(1).

    Judge-only files

    LeetCode and Code360 files contain only a class or function; the judge supplies main, includes and ListNode/Node. The page shows a small test driver that does that job so the code can run.

    /*
Take two stacks of size N and M as input and check if both of them are the same or not. 
Don’t use STL stack to solve this problem.
*/

#include <iostream>
#include <vector>
#include <algorithm>
#include <string>
#include <list>
using namespace std; 

class Node {
    public:
        int val;     
        Node* next;
        Node* prev;

    Node(int val) {
        this->val = val; 
        this->next = NULL;
        this->prev = NULL;
    }
};

class myStack{
    public:
        Node* head = NULL;
        Node* tail = NULL;
        int sz = 0;

        void push(int val){ // O(1)
            sz++;
            Node* newNode = new Node(val);
            if(head == NULL){
                head = newNode;
                tail = newNode;
                return;
            }
            tail->next = newNode;
            newNode->prev = tail;
            tail = newNode;
        }

        void pop(){ // O(1)
            sz--;
            Node* deleteNode = tail;
            tail = tail->prev;
            delete deleteNode; 
            if(tail==NULL){
                head=NULL;
                return;
            }
            tail->next = NULL;
        }

        int top(){

public:
    void reverse(ListNode* &head, ListNode* tmp){
        if(tmp->next == NULL){
            head = tmp;
            return;

        tmp->next->next = tmp;
        tmp->next = NULL;

        ListNode* newNode = new ListNode(val);

            head = newNode;
            tail = newNode;
            return;

        tail->next = newNode;
        tail = newNode;

            if(tmp->val != tmp2->val){
                return false;

            tmp = tmp->next;
            tmp2 = tmp2->next;

/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    ListNode* removeNthFromEnd(ListNode* head, int n) {
        int length = 0;
        ListNode* currentNode = head; 
        while(currentNode){
            length++;
            currentNode = currentNode->next;
        }

        if(n == length){
            ListNode* toDel = head;
            head = head->next;
            delete toDel;
            return head;
        }

        ListNode* tmp = head;
        int index = length - n;
        for(int i=1; i<index; i++){
            tmp = tmp->next;
        }
        ListNode* toDelete = tmp->next;
        tmp->next = tmp->next->next;
        delete toDelete;

        return head;
    }
};

    How it works, step by step
    1. Count nodes into length.

class Solution {
public:
    void reverse(ListNode* &head, ListNode* tmp){
        if(tmp->next == NULL){
            head = tmp;
            return;
        }
        reverse(head, tmp->next);
        tmp->next->next = tmp;
        tmp->next = NULL;
    }
    ListNode* reverseList(ListNode* head) {
        if(head == NULL){
            return head;
        }
        reverse(head, head);
        return head;
    }
};

/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    ListNode* swapNodes(ListNode* head, int k) {
        int length = 0;
        ListNode* currentNode = head;
        while(currentNode){
            length++;
            currentNode = currentNode->next;
        }

        // set the front node
        ListNode* frontNode = head;
        for(int i=1; i< k; i++){
            frontNode = frontNode->next;
        }

        // set the end node
        ListNode* endNode = head;
        for(int i=1; i<= length-k; i++){
            endNode = endNode->next;
        }

        swap(frontNode->val, endNode->val);
        return head;
    }
};
