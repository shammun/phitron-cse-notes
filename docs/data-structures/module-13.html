    Basic Data Structures · Module 13

    Stack: build it three ways, then use the STL

    A stack is Last-In-First-Out: the last value you push is the first one you get back. This module builds a stack class on top of a vector, a hand-made doubly linked list and the STL list, then shows the ready-made stack<int>. It also starts a queue on a singly linked list. The goal is to see that the same five operations — push, pop, top, size, empty — can sit on different storage, all in O(1).

    💡 Key ideas

    LIFO

    Think of a pile of plates: you add to the top and take from the top. Values come out in the reverse of the order they went in.

    The five stack operations

    push(x) adds on top, pop() removes the top, top() reads it, size() counts, empty() tells if nothing is left. All are O(1).

    stack<int> st;
st.push(10);
cout << st.top();  // 10
st.pop();
if(st.empty()) cout << "empty";

    Stack on a vector

    The back of the vector is the top: push_back, pop_back and back() do all the work.

    Stack on a linked list

    Keep a tail pointer and treat the tail as the top. With a doubly linked list, pop can step back with tail->prev in O(1).

    Check empty() before top()/pop()

    Calling top() or pop() on an empty stack is undefined behaviour (often a crash). Always guard: while(!st.empty()).

    Queue preview (FIFO)

    A queue adds at the tail and removes from the head, so the first value in is the first out. A singly linked list with head and tail pointers gives O(1) for both.

    Name clashes in a class

    A class cannot have a data member and a member function with the same name. int size = 0; plus int size() is a compile error — rename the counter (for example sz).

    #include <iostream>
#include <vector>
#include <algorithm>
#include <string>
#include <list>

using namespace std;


class myStack{
    public:
        vector<int> v;

        void push(int val){
            v.push_back(val);
        }

        void pop(){
            v.pop_back();
        }

        int top(){
            return v.back();
        }

        int size(){
            return v.size();
        }

        bool empty(){
            return v.empty();
        }
};

int main(){
    myStack s;

    s.push(10);
    s.push(20);
    s.push(30);
    s.push(40);
    s.push(50);
    s.push(60);

    cout << s.top() << endl;
    s.pop();
    cout << s.top() << endl;

    if(s.empty() == false){
        cout << s.top() << endl;
    }

    // Before doing top and pop, first check 
    // whether the stack is empty or not
    if(!s.empty()){
        cout << s.top() << endl;
        s.pop();
    }

    // print the stack
    while(!s.empty()){
        cout << s.top() << endl;
        s.pop();
    }

    return 0;
}

    How it works, step by step
    1. push → v.push_back(val); pop → v.pop_back(); top → v.back().
    2. size and empty just forward to the vector.
    3. main pushes 10..60, prints the top (60), pops, prints the new top (50).
    4. It prints the top again after checking empty(), then prints-and-pops once more.
    5. Finally it empties the stack in a while(!s.empty()) loop, printing each top.
    ✅ Check yourself: Why is the end of the vector used as the top, not the front?
    Adding/removing at the back is O(1); at the front every element would have to shift, O(n).

    #include <iostream>
#include <vector>
#include <algorithm>
#include <string>
#include <list>
using namespace std; 

class Node {
    public:
        int val;     
        Node* next;
        Node* prev;

    Node(int val) {
        this->val = val; 
        this->next = NULL;
        this->prev = NULL;
    }
};

class myStack{
    public:
        Node* head = NULL;
        Node* tail = NULL;
        int size = 0;

        void push(int val){ // O(1)
            size++;
            Node* newNode = new Node(val);
            if(head == NULL){
                head = newNode;
                tail = newNode;
                return;
            }
            tail->next = newNode;
            newNode->prev = tail;
            tail = newNode;
        }

        void pop(){ // O(1)
            size--;
            Node* deleteNode = tail;
            tail = tail->prev;
            delete deleteNode; 
            if(tail==NULL){
                head=NULL;
                return;
            }
            tail->next = NULL;
        }

        int top(){
            return tail->val; // O(1)
        }

        int size(){
            return size; // O(1)
        }

        bool empty(){
            return size==0; // O(1)
            // return head==NULL; // O(1)
        }
};


int main(){
    myStack s;

    // get the input for stack
    int n;
    cin >> n;
    for(int i=0; i<n; i++){
        int x;
        cin >> x;
        s.push(x);
    }

    // print the stack
    while(s.empty() == false){
        cout << s.top() << endl;
        s.pop();
    }

    return 0;    
}

    How it works, step by step
    1. push: create a node; if the list is empty it becomes both head and tail, otherwise link it after tail and move tail.
    2. pop: remember tail, step tail = tail->prev, delete the old node.
    3. If tail became NULL, the stack is empty, so set head = NULL too; otherwise cut tail->next.
    4. top returns tail->val; size counts pushes minus pops.
    5. main reads n values and prints them by popping.
    Watch out. Compile error: the class has both int size = 0; and int size(). Fix: rename the counter to sz (as done later in Module 14's practice_problem_1_same_stacks.cpp).
    ✅ Check yourself: Why does pop need the prev pointer?
    After removing the tail, the stack must find the new tail in O(1); tail->prev gives it directly. A singly linked list would need a full walk.

    #include <iostream>
#include <vector>
#include <algorithm>
#include <string>
#include <stack>


using namespace std;


class Node{
    public:
        int val;
        Node* next;

        Node(int val){
            this->val = val;
            this->next = next;
        }
};

class myQueue{
    public:
        Node* head = NULL;
        Node* tail = NULL;
        int size = 0;

    void push(int val){
        size++;
        Node* newNode = new Node(val);
        if(head == NULL){
            head = newNode;
            tail = newNode;
            return;
        }
        tail->next = newNode;
        tail = newNode;
    }    

    void pop(){
        size--;
        Node* deleteNode = head;
        head = head->next;
        delete deleteNode;
        if(head == NULL){
            tail = NULL;
        }
    }

    int front(){
        return head->val;
    }

    int back(){
        return tail->val;
    }

    int size(){
        return size;
    }

    bool empty(){
        return head == NULL;
    }
};

int main(){
    myQueue q;
    int n;
    cin >> n;
    for(int i=0; i<n; i++){
        int x;
        cin >> x;
        q.push(x);
    }

    return 0;
}

    How it works, step by step
    1. push: link a new node after tail (or make it head and tail if empty).
    2. pop: delete head and move head forward; if the queue became empty, reset tail to NULL.
    3. front reads head->val, back reads tail->val.
    4. main only reads n values and pushes them; nothing is printed yet.
    Watch out. Two mistakes: int size clashes with int size() (rename the counter), and the Node constructor does this->next = next; which copies the uninitialised member onto itself — it should be this->next = NULL;.
    ✅ Check yourself: Why must pop set tail = NULL when the last node is removed?
    Otherwise tail still points to deleted memory, and the next push would write through that dangling pointer.

    📌 Remember

    • Stack = LIFO; queue = FIFO.
    • push / pop / top / size / empty are all O(1) on vector, linked list or STL.
    • The 'top' is the end where you can add and remove cheaply (vector back, list tail).
    • Always check empty() before top() or pop().
    • A class member variable and method cannot share a name.

    1.
    Why is a vector a poor base for a queue but fine for a stack?
    A queue removes from the front, which is O(n) in a vector; a stack only touches the back, which is O(1).
    In the doubly linked list stack, what two pointers must be fixed when the last node is popped?
    tail becomes NULL and head must also be set to NULL.
