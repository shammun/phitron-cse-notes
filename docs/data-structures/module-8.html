    Basic Data Structures · Module 8

    Singly linked list assignment problems

    This module is solving time: assignment problems that must be done with a singly linked list. Each one mixes the basic moves — build with insert_at_tail, walk with a tmp pointer, delete by relinking — into a small task: max minus min, search for an index, compare two lists, handle insert/delete queries and remove duplicates. Revising these shows how far the few core operations can take you.

    🧭 Start here

    Nothing new is taught today. This is the assignment day for singly linked lists, and every problem on it is built from four moves you already have.

    Build. Read values until -1 and append each one with insert_at_tail(head, tail, v). Walk. Put a tmp on head and step tmp = tmp->next until NULL, updating one running value as you go. Count while you walk. Keep an index that starts at 0 and goes up one per step. Delete. Stand one node before the victim, bend the arrow past it, free it.

    If those four are in your fingers, the five problems here are just different things to put inside the walk.

    for(Node* t = head; t != NULL; t = t->next){
    // one running value lives out here
}

    One worked example, because the rest are variations of it. The first problem asks for the largest value minus the smallest. Take the list 12 3 45 7 20. Start max at a value smaller than anything real and walk once, keeping the best so far:

    The answer is 45 − 3 = 42. The page does this with two separate walks, one for max and one for min, but both running values could sit in the same loop — that is worth trying yourself.

    Now change only what you keep. Keep a counter instead of a maximum and stop at the first node equal to X: that is the search problem, and the counter is the index. Keep nothing and just count the steps: that is get_size. Same walk, different passenger.

    node seen   12   3   45   7   20
max so far  12  12   45  45   45
min so far  12   3    3   3    3

    Two lists at once. To ask whether two lists are identical, compare the sizes first, then move tmp1 and tmp2 one step together and stop at the first place they differ. The size check is not politeness: without it one pointer reaches NULL while the other still has nodes, and reading ->val from NULL crashes.

    Two pointers on one list. Removing duplicates uses an outer node and an inner pointer that scans everything after it, unlinking each later node with the same value. On 2 5 2 3 5 5 1:

    The first copy of each value stays, so the original order survives. One trap: after you unlink a node, do not move inner forward. Its new next is a node you have not looked at yet, and skipping it can leave two equal values sitting side by side.

    start        2 5 2 3 5 5 1
outer = 2 -> 2 5 3 5 5 1   (later 2 gone)
outer = 5 -> 2 5 3 1       (both later 5s gone)
outer = 3 -> 2 5 3 1       (nothing to do)
outer = 1 -> 2 5 3 1

    What to watch for, since this is where marks are lost. Declare head and tail inside the test-case loop, or case two quietly adds onto case one's list. A delete index is valid only when 0 <= idx < size: writing idx > size instead of idx >= size lets idx == size through, and the walk then reads past the end of the list. When a delete removes the last node, tail has to move back too, otherwise the next insert_at_tail writes onto a freed box. And a pointer only moves with j = j->next; a bare j->next reads the address and throws it away, so the loop spins forever.

    💡 Key ideas

    Read until a sentinel

    The input lists end with -1. A while(true) loop reads a value, breaks on -1, and otherwise appends it to the list.

    while(true){ cin >> v; if(v == -1) break; insert_at_tail(head, tail, v); }

    One walk, one answer

    Max, min, size and search all use the same pattern: a tmp pointer from head to NULL, updating a running value (or a running index) at each node.

    for(Node* t = head; t != NULL; t = t->next) { ... }

    0-based index while walking

    Keep a counter that starts at 0 and goes up by one each time tmp moves; when the value matches, the counter is the index.

    Walk two lists together

    To compare two lists, check the sizes first, then move tmp1 and tmp2 one step at a time and stop at the first different value.

    Guard the index before deleting

    An index is valid only when 0 <= idx < size. Index 0 is the head case, and when the removed node was the last one, tail must be moved back.

    if(head == NULL || idx >= get_size(head)) return;

    Remove duplicates with two pointers

    For each outer node, an inner pointer scans the rest of the list and unlinks every later node with the same value. The first occurrence of each value stays, so the order is kept.

Problem Statement

You need to take a singly linked list of integer value as input and print the difference between 
the maximum and minimum value of the singly linked list.

Note: You must use singly linked list to solve this problem, otherwise you will not get marks.

Input Format

Input will contain the values of the singly linked list, and will terminate with -1.
Constraints

1 <= N <= 10^5; Here N is the maximum number of nodes of the linked list.
-10^9 <= V <= 10^9; Here V is the value of each node.
Output Format

Output the difference between the maximum and minimum value.
Sample Input 0

2 4 1 5 3 6 -1
Sample Output 0

5
Sample Input 1

2 -1
Sample Output 1

0

#include <iostream>
#include <vector>
#include <algorithm>
#include <string>
#include <limits.h>
#include <climits>
using namespace std; // Allows us to avoid prefixing standard library objects with `std::`.


class Node {
    public:
        int val;     // Value stored in the node (data).
        Node* next;  // Pointer to the next node in the linked list.

        // Constructor for the Node class to initialize 'val' and set 'next' to NULL.
        Node(int val) {
            this->val = val;  // Assign the provided value to the 'val' member.
            this->next = NULL; // Initialize 'next' to NULL, meaning no next node by default.
        }
};

void insert_at_tail(Node* &head, Node* &tail, int val){
    Node* newNode = new Node(val);
    if(head == NULL){
        head = newNode;
        tail = newNode;
        return;
    }
    
    tail->next = newNode;
    tail = newNode; // or tail = tail->next
}

int find_max(Node* head){
    if(head == NULL){
        return -1;
    }
    Node* tmp = head;
    int max = INT_MIN;

    while(tmp!=NULL){
        if(tmp->val > max){
            max = tmp->val;
        }
        tmp = tmp->next;
    }
    return max;
}

int find_min(Node* head){
    if(head == NULL){
        return -1;
    }
    Node* tmp = head;
    int min = INT_MAX;

    while(tmp!=NULL){
        if(tmp->val < min){
            min = tmp->val;
        }
        tmp = tmp->next;
    }
    return min;
}

int main(){
    Node* head = NULL;
    Node* tail = NULL;
    
    int val;
    while(true){
        cin >> val;
        if(val == -1){
            break;
        }
        insert_at_tail(head, tail, val);
    }

    int max = find_max(head);
    int min = find_min(head);

    int diff = max - min;

    cout << diff << endl;

    return 0;
}

    12 3 45 7 20 -1

    Values ended by -1.

    Output 
    42

    Reading the output. 42 = 45 (max) − 3 (min).

    How it works, step by step
    1. Build the list until -1.
    2. find_max walks the list with max starting at INT_MIN.
    3. find_min walks it again with min starting at INT_MAX.
    4. Print max - min.
    ✅ Check yourself: Could max and min be found in one walk?
    Yes — update both running values inside the same loop.

void remove_duplicate(Node* &head){
    Node* outer = head;

    while(outer != NULL){
        Node* inner = outer;
        while(inner->next != NULL){
            if(outer->val != inner->next->val){
                inner = inner->next;
            } else{
                Node* duplicate = inner->next;
                inner->next = inner->next->next;
                delete duplicate;
            }
        }
        outer = outer->next;
    }
}

    Reading the output. 2 5 3 1 — the later 2 and both later 5s were removed; the order of first occurrences is kept.

    How it works, step by step
    1. outer walks the list one node at a time.
    2. For each outer, inner starts at outer and looks at inner->next.
    3. If inner->next->val equals outer->val, unlink and delete that node — and do NOT move inner, because the new inner->next still needs checking.
    4. Otherwise move inner forward.
    5. When inner reaches the end, move outer forward.
    Watch out. This insert_at_tail walks the whole list for every value, so reading input is O(n²) even though tail is available. Using tail->next = newNode makes it O(1).
    ✅ Check yourself: Why does inner not move after a deletion?
    Its new next is an unchecked node; moving on would skip it and could leave two equal values side by side.

    Why do the query solutions check head == NULL before deleting?
    An empty list has no node to remove, and walking from a NULL head would crash.
    In duplicate removal, which occurrence of each value is kept?
    The first one; only later copies are unlinked.
    What does find_index return for a value that appears twice?
    The index of its first appearance, because it returns as soon as it finds a match.
