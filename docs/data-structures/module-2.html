    STL vector: basics and built-in functions

    This module introduces vector, the resizable array from the C++ Standard Template Library. You learn how to create, fill, read, grow, shrink and search a vector, and how capacity differs from size. The practice set uses vectors for typical array problems: reversing, replacing values, counting, frequency arrays and range sums.

    🧭 Start here

    In C you wrote int a[100]; and hoped 100 was enough. In C++ Module 2 you did better: read n first, then int *a = new int[n];. But when that array had to grow, every part of the job was yours - ask for a bigger block, copy each element across, delete[] the old block, and keep your own variable saying how many values are inside.

    Three things to hold in your head by hand: the memory, the size, and the cleanup. A vector is an array that holds all three itself.

    #include <vector>
vector<int> v;          // empty, no size given
v.push_back(10);        // now {10}
v.push_back(20);        // now {10, 20}
cout << v.size();       // 2
cout << v[1];           // 20, indexed like an array

    Look at push_back closely, because that is where the growing happens. A vector keeps two numbers: size(), how many values you have put in, and capacity(), how many fit in the block it owns at the moment. Push into a full block and it asks for a block twice as big, copies the old values across and frees the old one - exactly the juggling you used to do yourself.

    Why double, instead of adding one? If the block grew by one element every time, each push would copy everything already stored, and n pushes would cost about n^2/2 copies. Doubling makes the copying rare enough that push_back costs O(1) on average. Module 1 gave you the words to say that.

    call            size  capacity  copying?
(start)            0         0
push_back(10)      1         1   yes
push_back(20)      2         2   yes
push_back(30)      3         4   yes
push_back(40)      4         4   no
push_back(50)      5         8   yes

    What is new. Until now the length of an array was fixed at the moment you created it, and you carried it around in a separate n. Here the container grows itself, always knows its own length, and frees its memory when it goes out of scope without a delete[] from you.

    Everything else you know still works. v[i] is one step, O(1), just like a[i], and a loop over a vector is the loop you always wrote with v.size() in place of n:

    int n;
cin >> n;
vector<int> v(n);            // n zeros, no new/delete
for(int i = 0; i < n; i++) cin >> v[i];
for(int i = 0; i < v.size(); i++) cout << v[i] << " ";

    A second example. The tally from the C course becomes one line: vector<int> freq(26, 0) makes 26 counters already set to zero, and freq[ch - 'a']++ ticks the box for a letter. There is no first loop to clear the array.

    A third example. vector<string> names; holds whole lines read with getline, and names.push_back(line) adds one more however many there turn out to be. You no longer need to know the count before you start reading.

    Where it does not help. A vector is still an array inside. insert and erase in the middle shift every element after the hole, so they are O(n), not O(1). And answering many range-sum questions by looping over v[l] to v[r] each time is still O(n) per question, which is slow for 100000 questions - the last practice problem here shows that slow version, and the next module fixes it.

    The programs below take the tools one at a time: the ways to create a vector, reading input into one, size against capacity, element access, iterators, the modifiers (assign, pop_back, insert, erase, find), resize, clear and empty. After that the practice problems use them on ordinary array work - reversing, replacing values, counting, letter frequencies and range sums.

    💡 Key ideas

    Vector vs array

    A vector is an array that can change its size while the program runs. It still gives O(1) access by index, and it knows its own size().

    vector<int> v(5, 10); // {10,10,10,10,10}

    Ways to create a vector

    Empty, with a size (filled with 0), with a size and a value, as a copy of another vector, from an array range, or from a list in braces.

    vector<int> v4(a, a+5);
vector<int> v5 = {1, 2, 3};

    Size vs capacity

    size() is how many elements are stored; capacity() is how many fit before the vector must grow. When full, the vector usually doubles its capacity and copies the elements over, so push_back is O(1) on average.

    Adding and removing

    push_back adds at the end and pop_back removes the last element, both O(1). insert and erase in the middle must shift elements, so they are O(n).

    v.insert(v.begin() + 3, 2, 40);
v.erase(v.begin() + 3, v.begin() + 5);

    Accessing elements

    Use v[i] (no check), v.at(i) (throws on a bad index), v.front() and v.back(). All are O(1).

    Iterators

    An iterator is a pointer-like object. v.begin() points at the first element and v.end() points just past the last one. Algorithms such as find, replace and sort take iterator ranges.

    auto it = find(v.begin(), v.end(), 100);

    Frequency array

    To count letters, make vector<int> freq(26, 0) and increase freq[ch - 'a']. Index 0 stands for 'a', 1 for 'b', and so on.

    freq[ch - 'a']++;

    Brute-force range sums

    Adding up a[l..r] again for every query costs O(n) per query, so O(n*q) in total. That is too slow for large inputs; the next module fixes it with prefix sums.

Vectors in C++ STL

We will learn how to initialize a vector in C++.

#include <iostream>
#include <vector>
using namespace std;

int main() {
    // Initializing a vector
    vector<int> v;
    cout << "Size: " << v.size() << endl; // 0

    // Construct a vector of size n
    vector<int> v1(5);
    cout << "Size: " << v.size() << endl; // prints 5

    // Construct a vector of size n with all elements initialized to 10
    vector<int> v2(5, 10); // {10, 10, 10, 10, 10}
    for(int i=0; i<v.size(); i++){
        cout << v[i] << endl;
    }

    // Construct a vector with elements of another vector
    vector<int> v3(v2); // {10, 10, 10, 10, 10}

    // We can also create a vector by following the content of an array
    int a[5] = {1, 2, 3, 4, 5};
    vector<int> v4(a, a+5); // {10, 10, 10, 10, 10}
    for(int i=0; i<v4.size(); i++){
        cout << v4[i] << endl;
    }

    // Creating a vector
    vector<int> v5 = {1, 2, 3, 4, 5};
    for(int i=0; i<v5.size(); i++){
        cout << v5[i] << endl;
    }


    return 0;
}

    /*

In this tutorial, we will learn about vector input.

*/

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    // The vector input is the same as the array input

    // First way to input the vector
    // It is not necessary to declare the size of the vector
    vector<int> v;
    int n;
    cin >> n;
    for(int i=0; i<n; i++){
        int x;
        cin >> x;
        v.push_back(x); 
        // push_back() function is used to add elements to the vector
        // by increasing the size and adding the elements at the end
    }

    for(int i=0; i<v.size(); i++){
        cout << v[i] << " ";
    }

    cout << endl;

    // Second way to input the vector
    // declare an array of size n
    vector<int> v2(n); // vector of size n with all elements initialized to 0
    for(int i=0; i<n; i++){
        cin >> v2[i];
    }

    for(int i=0; i<v.size(); i++){
        cout << v[i] << " ";
    }

    cout << endl;


    return  0;
}
    Input (stdin)
    3
4 5 6
7 8 9

    n, then n numbers for the first vector, then n more for the second.

    Output 
    4 5 6 
4 5 6

    Reading the output. Both lines show 4 5 6. The second line should have shown 7 8 9, the values read into v2.

    How it works, step by step
    1. Read n.
    2. Way 1: for each of the n values, read x and call v.push_back(x); the vector grows by one each time.
    3. Print v.
    4. Way 2: make vector<int> v2(n) (n zeros) and read straight into v2[i].
    5. Print again.
    Watch out. The second print loop prints v instead of v2, so the second set of values is read but never shown. Change v[i] to v2[i] in the last loop.
    ✅ Check yourself: Why can you write cin >> v2[i] but not cin >> v[i] for the empty vector v?
    v2 was created with size n, so index i exists. v is empty, so v[i] is outside the vector; you must push_back instead.

    #include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v;
    cout << v.capacity() << endl; // prints 0
    // When we will store value, it will increase the capacity of the vector

    // Add element to the vector
    v.push_back(10);
    cout << v.capacity() << endl; // prints 1

    // Add element to the vector
    v.push_back(20);
    cout << v.capacity() << endl; // prints 2

    // Add element to the vector
    v.push_back(30);
    cout << v.capacity() << endl; // prints 4

    // When we will store value, when increasing capacity,
    // it will increase the capacity of the vector by a factor of 2

    // Add element to the vector
    v.push_back(40);
    cout << v.capacity() << endl; // prints 4

    v.push_back(50); // this is the fift value and so the capacity 4 will be doubled to 8
    cout << v.capacity() << endl; // prints 8

    return 0;
}

    Reading the output. The six lines 0 1 2 4 4 8 are the capacity after 0, 1, 2, 3, 4 and 5 insertions. Notice the doubling.

    How it works, step by step
    1. A new empty vector has capacity 0.
    2. After the 1st push, capacity is 1; after the 2nd, 2.
    3. The 3rd push does not fit, so capacity doubles to 4; the 4th fits.
    4. The 5th push doubles capacity again to 8.
    5. Each time it grows, the vector copies its elements into a bigger block, but that happens rarely enough that push_back is O(1) on average.
    Watch out. The exact growth rule depends on the compiler. GCC doubles; other libraries (MSVC) grow by 1.5x, so the numbers can differ.
    ✅ Check yourself: After 9 push_back calls on GCC, what is the capacity?
    16 (1, 2, 4, 8, then 16 once the 9th element does not fit).

    /*

In this tutorial, we will learn about vector element access.

*/

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> v = {1,2,3,4,5,3,25};

    // Accessing the elements of the vector using the [] operator
    // O(1) operation
    cout << v[0] << endl; // 1
    cout << v[1] << endl; // 2
    cout << v[2] << endl; // 3
    cout << v[3] << endl; // 4

    // Accessing the elements of the vector using the at() function
    cout << v.at(0) << endl; // 1
    cout << v.at(1) << endl; // 2
    cout << v.at(2) << endl; // 3
    cout << v.at(3) << endl; // 4

    // Accessing the first element of the vector using the front() function
    // O(1) operation
    cout << v.front() << endl; // 1

    // Anothr way to access the first element of the vector
    cout << v[0] << endl; // 1

    // Accessing the last element of the vector using the back() function
    // O(1) operation
    cout << v.back() << endl; // 25

    // Another way to access the last element of the vector
    cout << v[v.size()-1] << endl; // 25

    return 0;
}

    How it works, step by step
    1. v[i] reads index i directly with no bounds check.

    /*

In this tutorial, we will learn about vector iterators.

*/

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> v = {1,2,3,4,5,3,25};

    // Using iterator, we can access the elements of the vector
    for(vector<int>::iterator it = v.begin(); it != v.end(); it++){
        cout << *it << " ";
    }

    // We can also use auto keyword to declare the iterator
    for(auto it = v.begin(); it != v.end(); it++){
        cout << *it << " ";
    }


    return 0;
}

    How it works, step by step
    1. it starts at v.begin(), the first element.
    2. The loop runs while it != v.end(); end() is one past the last element.
    3. *it gives the value the iterator points to.
    4. auto lets the compiler work out the long iterator type for you.

    It points one position past the last element, so there is no value there.

    /*

We will learn about vector modifiers in this tutorial.

*/

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> v = {1,2,3,4,5};
    vector<int> v2;
    
    // Assigning values to the vector v2 using = operator
    v2 = v;

    for(int i=0; i<v2.size(); i++){
        cout << v2[i] << " ";
    }

    // When we do not need index, we can use this shortcut loop
    for(int x : v2){
        cout << x << " ";
    }

    // Assigning values to the vector v2 using assign() function
    v2.assign(v.begin(), v.end());

    // pop_back() function removes the last element from the vector
    v2.pop_back();
    // Now, the vector v2 will be {1, 2, 3, 4}
    for(int x : v2){
        cout << x << " ";
    }

    // insert(position, value) function inserts the element at the specified position
    v2.insert(v2.begin(), 10);
    // Now, the vector v2 will be {10, 1, 2, 3, 4}
    for(int x : v2){
        cout << x << " ";
    }

    // insert at the last position
    v2.insert(v2.end(), 20);
    // Now, the vector v2 will be {10, 1, 2, 3, 4, 20}
    for(int x : v2){
        cout << x << " ";
    }

    // insert multiple elements at the last position
    v2.insert(v2.end(), 3, 30);
    // Now, the vector v2 will be {10, 1, 2, 3, 4, 20, 30, 30, 30}
    for(int x : v2){
        cout << x << " ";
    }

    // insert multiple elements at the specified position
    v2.insert(v2.begin() + 3, 2, 40); 
    // here, we are inserting 2 elements with value 40 at position 3
    // Now, the vector v2 will be {10, 1, 2, 40, 40, 3, 4, 20, 30, 30, 30}

    // insert at position 5
    v2.insert(v2.begin() + 5, 50);
    // Now, the vector v2 will be {10, 1, 2, 40, 40, 50, 3, 4, 20, 30, 30, 30}
    for(int x : v2){
        cout << x << " ";
    }

    // erase(position) function removes the element at the specified position
    v2.erase(v2.begin() + 5); // here, we are removing the element at position 5 with value 50
    // Now, the vector v2 will be {10, 1, 2, 40, 40, 3, 4, 20, 30, 30, 30}
    for(int x : v2){
        cout << x << " ";
    }

    // erase(start, end) function removes the elements in the range [start, end)
    v2.erase(v2.begin() + 3, v2.begin() + 5); 
    // here, we are removing the elements in the range [3, 5)
    // So, it will remove the elements at position 3 and 4 with values 40 and 40
    // Now, the vector v2 will be {10, 1, 2, 3, 4, 20, 30, 30, 30}

    // Now, we will use some more functions that are not under vector class

    // replace(position, value) function replaces the element at the specified 
    // position with the given value
    // replace(start_position, end_position, value_to_be_replaced, new_value)
    // This replaces all the occurrences of the value_to_be_replaced with new_value
    
    // Suppose, we want to replace all the 30s with 100
    replace(v2.begin(), v2.end(), 30, 100);
    // Now, the vector v2 will be {10, 1, 2, 3, 4, 20, 100, 100, 100}
    for(int x : v2){
        cout << x << " ";
    }

    // find(start, end, value) function returns the iterator to the first occurrence of the value
    // If the value is not found, it returns the end iterator
    // So, we can use this function to check if a value is present in the vector or not
    // Is value 100 present in the vector v2?
    if(find(v2.begin(), v2.end(), 100) != v2.end()){
        cout << "100 is present in the vector" << endl;
    }
    else{
        cout << "100 is not present in the vector" << endl;
    }

    // find position of 100 in the vector v2
    // vector<int>::iterator it = find(v2.begin(), v2.end(), 100);
    // Instead of vector<int>::iterator it. we can just write auto it
    auto it = find(v2.begin(), v2.end(), 100); // this is a pointer to the first occurrence of 100 in the vector v2
    // as it is a pointer, we can use *it to access the value at that position
    cout << *it << endl; // prints 6 as it is at position 6 in the vector v2
    // Now, it will point to the first occurrence of 100 in the vector v2
    // So, we can use it to access the value at that position
    cout << "The first occurrence of 100 is at position " << distance(v2.begin(), it) << endl;
    // distance() function returns the distance between two iterators
    // it will return the vakue 3 because 100 is at position 6 in the vector v2

    return 0;
}

    /*

Range sum query

time limit per test: 1.5 seconds
memory limit per test: 256 megabytes

Given 2 numbers N and Q, an array A  of N number and Q  number of pairs L, R. For each 
query Q print a single line that contains the summation of all numbers from index L to 
index R.

Input
First line contains two numbers N, Q (1≤N,Q≤10^5) where N is number of elements in A and 
Q is number of query pairs.

Second line contains N numbers(1≤Ai≤10^9).

Next Q lines contains L,R (1≤L≤R≤N).

Output
For each query Q print a single line that contains the summation of all numbers from 
index L to index R.

Examples
Input
6 3
6 4 2 7 2 7
1 3
3 6
1 6
Output
12
18
28

Input
4 3
5 5 2 3
1 3
2 3
1 4
Output
12
7
15

*/

#include <iostream>
#include <vector>
#include <algorithm>
#include <string>
using namespace std;

int main() {
    int n, q;
    cin >> n >> q;
    vector<int> a(n);

    for(int i=0; i<n; i++){
        cin >> a[i];
    }

    vector<int> results(q);

    // Run loops for q times
    for(int i=0; i<q; i++){
        int l, r;
        cin >> l >> r;

        int sum = 0;
        for(int j=l-1; j<= r-1; j++){
            sum += a[j];
        }

        results[i] = sum;
    }

    for(int i=0; i<q; i++){
        cout << results[i] << endl;
    }

    return 0;
}
    Input (stdin)
    6 3
6 4 2 7 2 7
1 3
3 6
1 6

    n q, the array, then q lines of l r (1-based).

    Output 
    12
18
28

    Reading the output. 12, 18, 28, the judge's expected answers: 6+4+2, 2+7+2+7, and the whole array.

    How it works, step by step
    1. Read n, q and the array (0-based).
    2. For each query read 1-based l and r.
    3. Sum from index l-1 to r-1 and store it in results.
    4. Print all results at the end.
    Watch out. Two problems for big tests: O(n*q) = 10^10 operations gets Time Limit Exceeded, and int sum overflows because values go up to 10^9. Module 3 fixes both with a long long prefix sum.
    ✅ Check yourself: Why does this solution get TLE when n and q are both 10^5?
    Each query may scan the whole array, so the total work is about 10^10 steps.

    📌 Remember

    • A vector is a growable array: O(1) index access and O(1) average push_back.
    • size() counts elements; capacity() counts reserved slots and usually doubles.
    • insert and erase in the middle shift elements, so they are O(n).
    • Iterator ranges are half-open: [begin, end).
    • find returns end() when the value is missing; always compare before using the result.
    • Use vector<int> freq(26, 0) with ch - 'a' to count letters.

    ✅ Check yourself

    What is the difference between resize(n) and clear()?
    resize(n) sets the size to n, adding zeros or cutting elements; clear() sets the size to 0.
    Why is push_back O(1) on average even though growing copies all elements?
    Capacity doubles, so copies are rare; the total copying over n pushes is less than 2n, which averages to O(1) per push.
    What does distance(v.begin(), find(v.begin(), v.end(), x)) return when x is not in v?
    v.size(), because find returns end().
