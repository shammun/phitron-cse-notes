    This is the final exam of the course, and the hard part is not writing the code. It is reading a question and deciding, inside a minute, which container answers it. The whole course points at that one decision, so here is the map:

    the question asks for        reach for
---------------------------  ------------------
sorted, no duplicates        set
how many times, or which     map
  word or value wins
the smallest or biggest one  priority_queue
  right now, while items
  keep arriving and leaving
the answer for a position,   prefix sums
  from sums of the rest
first in first out / last    queue / stack
  in first out
search by comparing, and     BST
  in-order comes out sorted

    The pattern that comes up most is counting with a map and then picking the best count, so trace it once before the exam. Read the words with getline and a stringstream, tick a box per word, and keep track of the best as you go.

    The trap is the tie. If the question wants the first word to reach the highest count, update the answer only when the new count is strictly greater than the best so far. Using >= would let a later word steal the place on a tie:

    map<string,int> freq;
string best = "";
int bestCount = 0;
string w;
while(ss >> w){
    freq[w]++;
    if(freq[w] > bestCount){   // strictly greater, not >=
        bestCount = freq[w];
        best = w;
    }
}
    sentence: bat cat bat cat dog

word   its count   best so far
bat        1        bat 1
cat        1        bat 1
bat        2        bat 2
cat        2        bat 2   (tie: no change)
dog        1        bat 2

answer: bat 2

    The second pattern is a pile that changes while you are being asked about it. Keep the numbers in a min-heap and the current smallest is always top(), whatever has been added or removed since. Nothing is re-sorted, and each command costs O(log n):

    start with 7 3 9      min-heap top = 3
insert 5           -> top 3
ask for the min    -> 3
delete the min     -> 5 is now on top
delete the min     -> 7 is now on top
delete the min     -> 9 is now on top
delete the min     -> nothing left: Empty

    Watch that last line. A delete question asks for the minimum after the deletion, so the heap can be empty by the time you print. Check empty() before every top() and pop(), and check again after popping, or the program prints rubbish on the last query.

    Three more things that cost marks rather than ideas. After cin >> T the newline is still sitting in the input, so cin.ignore() must come before the first getline. In a priority queue comparator with two keys, compare the main key and only fall through to the second when the first ties, and remember that returning true means the left item comes out later. And counting words in a vector of pairs works, but each word is an O(n) search through it, so a long input runs out of time where a map at O(log n) does not.

    💡 Key ideas

    Pick the container from the question

    'Sorted and unique' means set. 'How many times' means map. 'Current min/max while items come and go' means priority_queue.

    Comparator with two keys

    Compare the main key first; only when it ties, compare the second key. In a priority queue, return true when the left item should come out later.

    if(l.name != r.name) return l.name > r.name; return l.val < r.val;

    Reading a number, then whole lines

    After cin >> T, the newline is still waiting in the input. cin.ignore() throws it away so the next getline reads the real sentence.

    cin >> T; cin.ignore(); getline(cin, S);

    First word to reach the maximum

    Update the answer only when a count becomes strictly greater than the best so far. A later word that only ties does not replace it.

    if(freq[w] > best){ best = freq[w]; ans = w; }

    Guard every heap access

    Before top() or pop(), check empty() and print Empty instead. After a pop, check again before printing the new top.

    map vs. vector of pairs for counting

    A map finds a word in O(log n). Searching a vector of pairs is O(n) per word, which can be too slow for long inputs.

Problem Statement

You will be given a list A of type pairs. Each pair will contain one string S and

#include <bits/stdc++.h>

using namespace std;



class Pair{
    public:
        string name;
        int val;

        Pair(string name, int val){
            this->name = name;
            this->val = val;
        }
};


class cmp{
    public:
        bool operator()(Pair &l, Pair &r){
            if(l.name > r.name){
                return true;
            } else if(l.name < r.name){
                return false;
            } else {
                return l.val < r.val;
            } 
        }
};

int main(){
    priority_queue<Pair, vector<Pair>, cmp> pq;
    int N;
    cin >> N;

    for(int i=0; i<N; i++){
        string name;
        int val;
        cin >> name >> val;
        Pair obj(name, val);
        pq.push(obj);
    }

    while(!pq.empty()){
        cout << pq.top().name << " " << pq.top().val << endl;
        pq.pop();
    }

}

    How it works, step by step
    1. Pair holds a name and a val.
    2. In cmp, l.name > r.name returns true, so later names sink and the alphabetically smallest name comes out first.
    3. For equal names, l.val < r.val returns true, so the larger value comes out first.
    4. Push all N pairs, then print top() and pop() until empty.
    Watch out. main has no return 0;. That is allowed in C++ (main returns 0 by default), but add it for consistency.

    /*

Count Me

Problem Statement

You will be given a sentence  that contains words with lowercase and uppercase English alphabets separated by spaces. You need to determine which word occurs the most times and also provide the count of that word.

Note: If there are multiple words that occur the most, print the first word that reaches the maximum count before others.

Input Format

First line will contain , the number of test cases.
Each test case will contain the sentence .
Constraints

, Here  means the length of .
Output Format

Output the word and the count that occurs the most.
Sample Input 0

1
Ratul loves to play football when he gets time but Ratul is not a good player so his teacher asked Ratul if he can play with him so that Ratul can progress
Sample Output 0

Ratul 4
Sample Input 1

2
ratul piyush fohad shuvo rafi piyush fohad ratul 
jony jony yes papa eating sugar no papa telling lies no papa open your mouth ha ha ha 
Sample Output 1

piyush 2
papa 3

*/





#include <bits/stdc++.h>

using namespace std;



int main()
{
    // Write your code here
    int T;
    cin >> T;
    cin.ignore();
    
    while(T--){
        string S;
        getline(cin, S);
        
        vector<pair<string, int>> word_freq;
        stringstream ss(S);
        string word;
        
        string result = "";
        int count_max = 0;
        
        while(ss >> word){
            bool flag = false;
            for(auto it=word_freq.begin(); it!=word_freq.end(); it++){
                if(it->first == word){
                    it->second = it->second + 1;
                    
                    if(it->second > count_max){
                        result = it->first;
                        count_max = it->second;
                    }
                    flag = true;
                    break;
                }
            }
            if(flag == false){
                word_freq.push_back({word, 1});
            }
        }

        
        for(auto it=word_freq.begin(); it!=word_freq.end(); it++){
            if(it->second > count_max){
                result = it->first;
                count_max = it->second;
            }
        }
        
        cout << result << " " << count_max << endl;
    }

    return 0;
}
    Input (stdin)
    2
ratul piyush fohad shuvo rafi piyush fohad ratul
a b c

    T, then T sentences, one per line.

    Output 
    piyush 2
a 1

    Reading the output. piyush 2: piyush, fohad and ratul all reach 2, but piyush gets there first. a 1: all words appear once, so the final loop picks the first one.

    How it works, step by step
    1. cin.ignore() after reading T removes the leftover newline so getline reads the sentence.
    2. For each word, a loop searches word_freq; if found, its count goes up, and the answer changes only when the count beats count_max.
    3. A new word is pushed with count 1 without touching the answer.
    4. After the sentence, a final loop picks the first word whose count beats count_max. This only matters when every word appears once (count_max is still 0), and then it picks the first word.
    5. Print the word and its count.
    Watch out. The search through the vector is linear for every word, so long sentences get slow. The map version fixes this.
    ✅ Check yourself: In the first sentence, why is the answer not ratul, even though it appears first?
    The rule is the first word to reach the top count; ratul's second copy is the last word, after piyush has already reached 2.

Problem Statement

You will be given a sentence S that contains words with lowercase and uppercase 
English alphabets separated by spaces. You need to determine which word occurs the 
most times and also provide the count of that word.

Note: If there are multiple words that occur the most, print the first word that 
reaches the maximum count before others.

Input Format
- First line will contain T, the number of test cases.
- Each test case will contain the sentence .

Constraints
1. 1 <= T <= 10^3
2. 1 <= |S| <= 10^4, Here |S| means the length of S.

Output Format
- Output the word and the count that occurs the most.

Sample Input 0
1
Ratul loves to play football when he gets time but Ratul is not a good player so his teacher asked Ratul if he can play with him so that Ratul can progress

Sample Output 0

Sample Input 1
2

Sample Output 1

#include <bits/stdc++.h>

using namespace std;



int main()
{
    // Write your code here
    int T;
    cin >> T;
    cin.ignore();
    
    while(T--){
        string S;
        getline(cin, S);
        stringstream ss(S);
        
        map<string, int> word_freq;
        
        string result;
        int count_max = 0;
        string word;
        
        while(ss >> word){
            word_freq[word] = word_freq[word] + 1;
            if(word_freq[word] > count_max){
                result = word; 
                count_max = word_freq[word];
            }
        }
        
        cout << result << " " << count_max << endl;
    }

    return 0;
}

    How it works, step by step
    1. Read T, then cin.ignore(), then each sentence with getline.
    2. word_freq[word] = word_freq[word] + 1 counts the word (a new word starts at 0).
    3. If the new count is greater than count_max, save this word as result.
    4. Because the check is strict (>), a word that only ties never replaces the earlier one.
    5. Print result and count_max.
    Watch out. Without cin.ignore(), the first getline would read an empty line and print a blank answer.

#include <bits/stdc++.h>

using namespace std;



class Student{
    public:
        string name;
        int roll;
        int marks;

        Student(string name, int roll, int marks){
            this->name = name;
            this->roll = roll;
            this->marks = marks;
        }
};


class cmp{
    public:
        bool operator()(Student &l, Student &r){
            if(l.marks < r.marks){
                return true;
            } else if(l.marks > r.marks){
                return false;
            } else {
                return l.roll > r.roll;
            } 
        }
};

int main(){
    priority_queue<Student, vector<Student>, cmp> pq;
    int N;
    cin >> N;

    for(int i=0; i<N; i++){
        string name;
        int roll, marks;
        cin >> name >> roll >> marks;
        Student obj(name, roll, marks);
        pq.push(obj);
    }
    
    int Q;
    cin >> Q;
    
    for(int i=0; i<Q; i++){
        int x;
        cin >> x;
        
        if(x == 0){
            string name2;
            int roll2, marks2;
            cin >> name2 >> roll2 >> marks2;
            Student obj2(name2, roll2, marks2);
            pq.push(obj2);
            cout << pq.top().name << " " << pq.top().roll << " " << pq.top().marks << endl;
        }
        if(x == 1){
            if(!pq.empty()){
                cout << pq.top().name << " " << pq.top().roll << " " << pq.top().marks << endl;
            } else {
                cout << "Empty" << endl;
            }
            
        }
        if(x == 2){
            if(pq.empty()){
                cout << "Empty" << endl;
                continue;
            }
            
            pq.pop();
            if(pq.empty()){
                cout << "Empty" << endl;
            } else {
                cout << pq.top().name << " " << pq.top().roll << " " << pq.top().marks << endl;
            }       
        }
    }


    return 0;
}

    How it works, step by step
    1. cmp returns true when l.marks < r.marks, so the highest marks rise to the top.
    2. On equal marks, l.roll > r.roll returns true, so the smaller roll is on top.

    📌 Remember

    • Sorted and unique → set; counting → map; changing min/max → priority_queue.
    • Multi-key comparator: compare the main key, and use the second key only on a tie.
    • cin.ignore() between cin >> and getline.
    • 'First to reach the max' means updating only on a strictly greater count.
    • Check empty() before every top() and pop(), and again after popping.
    • Don't forget using namespace std; when you don't use bits/stdc++.h.
