    Assignment: binary tree problems from level-order input

    This is the binary tree assignment. Every program first builds a tree from level-order input (-1 means no child), then answers one question: sum of non-leaf nodes, leaves in descending order, is the tree perfect, the nodes on level X, and the outer side of the tree. Revising it is a good way to practise the two tools you use for every tree problem: BFS with a queue and recursive DFS.

    🧭 Start here

    Five problems, and every one of them begins the same way: a run of numbers comes in, you turn it into a real tree, and only then answer the question. So the first tool of the day is the reader itself, the one from Module 18.

    Read the first number as the root and push it into a queue. Then pop a node and read the next two numbers as its left and right child, where -1 means no child, pushing the real children so that their children are read later. Here is the line the assignment uses and the tree it describes:

    10 20 30 40 50 -1 60 -1 -1 -1 -1 -1 -1

        10
       /  \
     20    30
     / \     \
   40   50    60

    Read the numbers in pairs after the root and it is easy to follow: 20 30 are the children of 10, 40 50 the children of 20, -1 60 says 30 has no left child and 60 on the right, and the last three pairs are the -1 -1 of the leaves 40, 50 and 60.

    Watch the edges here more than anywhere else. An empty tree is the single number -1, and the builder must return NULL without reading anything further. A one-node tree is 5 -1 -1. Every node that comes off the queue reads exactly two numbers, leaves included, so input that is one pair short leaves cin waiting and the program looks like it has hung.

    The second tool is the leaf test, !node->left && !node->right. Two problems are only a filter on it: problem 1 adds up the nodes that are not leaves, here 10 + 20 + 30 = 60, and problem 2 collects the leaves and prints them largest first, 60 50 40.

    The third tool is the pair of recursions from Module 18, both stopping at NULL: count(root) = count(left) + count(right) + 1, which gives 6 here, and depth(root) = max(depth(left), depth(right)) + 1, which gives 3 with the root at depth 1. Problem 3 uses both at once: a perfect tree has every level completely full, and a full tree of depth d holds exactly 2^d - 1 nodes. Here 6 is not 2^3 - 1 = 7, so the answer is NO, and the missing left child of 30 is the gap.

    The fourth tool is Module 19's queue of {node, level} pairs, used whenever the question mentions a level. Problem 4 reads the tree, then a number X, and prints the nodes on level X.

    This assignment counts the root as level 0. Other judges start at 1, so read the samples before you trust a level number. If nothing was collected the level does not exist and the answer is the word Invalid rather than an empty line.

    X = 0  ->  10
X = 1  ->  20 30
X = 2  ->  40 50 60
X = 3  ->  Invalid

    The fifth tool is a walk rather than a traversal. For the outer side of the tree you go down the left edge, taking the left child when there is one and the right child otherwise, and print that chain from the bottom up; then the root; then the right edge from the top down. On the tree above that is 40 20 10 30 60.

    Three attempts at this one are on the page, and the two failures are the useful part. One solves the textbook boundary traversal, which prints every leaf in the middle and answers a different question. The other reads collected levels backwards with an unsigned index and i >= 0, a test that is never false, so the index wraps round to a huge number and the program crashes. Count down with a plain int.

    Nothing here is new: it is Module 18's builder and counts and Module 19's two shapes, used five times in a row. The programs below give each problem with its input, its output and the traps inside it.

    💡 Key ideas

    Building a tree from level order

    Read the root, push it into a queue, then for each popped node read two numbers: its left and right child (-1 = none). New children are pushed so their children are read later, in the same order.

    cin >> l >> r;
p->left = (l == -1) ? NULL : new Node(l);

    Leaf vs internal node

    A leaf has no children (!left && !right). An internal node has at least one child. Many questions just filter on this test.

    Counting nodes and depth recursively

    count(root) = count(left) + count(right) + 1 and depth(root) = max(depth(left), depth(right)) + 1, both with 0 for NULL.

    Perfect binary tree formula

    A tree of depth d (root at depth 1) is perfect exactly when it has 2^d - 1 nodes, because every level is completely full.

    Levels in BFS

    Store {node, level} in the queue to know each node's level, then collect nodes whose level equals X.

    Outer side (left chain + right chain)

    Walk down the left edge (go left if possible, else right) and print it bottom-up, print the root, then walk down the right edge (go right if possible, else left) top-down.

Sum without leaf

Problem Statement

You will be given a binary tree as input in level order. You need to output the sum of all node's values in that tree except the leaf nodes.

For example

The output for the above tree will be: 60

Input Format

Input will contain the binary tree in level order. -1 means there is no node
available.

Constraints

1. 1<= Maximum number of nodes<= 10^5
2. 1<= Node's value <= 1000

Output Format

Output the total sum of that tree except the leaf nodes.

Sample Input 0

10 20 30 40 50 -1 60 -1 -1 -1 -1 -1 -1

Sample Output 0

60

The sample tree:
            10
           /  \
         20    30
        /  \     \
      40    50    60

*/

#include <iostream>     // cin and cout
#include <vector>       // not used here
#include <algorithm>    // not used here
#include <string>       // not used here
#include <queue>        // STL queue, for level order

using namespace std;    // write cout, queue ... without std::

// A binary tree node: a value and two child pointers (NULL = no child).
class Node {
    public:
        int val;        // the value stored here
        Node* left;     // address of the left child
        Node* right;    // address of the right child

    // Constructor, runs on `new Node(x)`: store x, no children yet.
    Node(int val) {
        this->val = val;        // this->val = member, val = parameter
        this->left = NULL;
        this->right = NULL;
    }
};

// Reads the tree in level order, the Module 18 way: first the root, then for
// every real node (in the order a queue hands them out) its left and right
// child, with -1 meaning "no child".
Node* input_tree(){
    int val;
    cin >> val;                  // the root (or -1 for an empty tree)
    Node* root;
    if(val == -1){
        root = NULL;
    } else {
        root = new Node(val);    // `new` builds the node on the heap and returns its address
    }

    // Nodes whose two children have not been read yet.
    queue<Node*> q;
    if(root){                    // a pointer is "true" when it is not NULL
        q.push(root);
    }

    // One pass reads one node's two children; stops when no node is waiting.
    while(!q.empty()){
        Node* p = q.front();     // oldest node still waiting for its children
        q.pop();

        int l, r;
        cin >> l >> r;           // its left and right child values
        Node* myLeft;
        Node* myRight;
        if(l == -1){
            myLeft = NULL;
        } else {
            myLeft = new Node(l);
        }

        if(r==-1){
            myRight = NULL;
        } else {
            myRight = new Node(r);
        }

        p->left = myLeft;        // attach the children (-> = member through a pointer)
        p->right = myRight;

        // Only real children wait in the queue for their own pair of values.
        if(p->left){
            q.push(p->left);
        }
        if(p->right){
            q.push(p->right);
        }

    }

    return root;
}

/*
 * Sum without leaf: add up every node that has at least one child.
 *
 * The idea: visit every node once with a level-order walk (queue). A node is
 * NOT a leaf when it has a left child or a right child, so only then is its
 * value added. Example (sample): 10, 20 and 30 have children, 40 50 60 do not,
 * so the answer is 10 + 20 + 30 = 60.
 *
 * int is enough: at most 10^5 nodes * 1000 = 10^8, below int's limit (~2.1 * 10^9).
 */
int sum_without_leaf(Node* root){
    if(!root){                   // empty tree: the sum is 0 (!root is true when root is NULL)
        return 0;
    }

    queue<Node*> q;              // nodes waiting to be checked
    q.push(root);

    int sum = 0;                 // running total of non-leaf values
    // One pass checks one node; stops when every node has been checked.
    while(!q.empty()){
        Node* parent = q.front();
        q.pop();

        // At least one child -> not a leaf -> count it.
        if(parent->left || parent->right){
            sum += parent->val;
        }

        // Queue the children so every node gets checked.
        if(parent->left){
            q.push(parent->left);
        }
        if(parent->right){
            q.push(parent->right);
        }
    }

    return sum;
}

int main()
{
    // Write your code here
    Node* root = input_tree();                 // build the tree from the input
    cout << sum_without_leaf(root) << endl;    // print the answer (endl = newline + flush)
    return 0;                                  // program finished normally
}
    Input (stdin)
    10 20 30 40 50 -1 60 -1 -1 -1 -1 -1 -1

    Tree in level order: 10 has children 20 and 30; 20 has 40 and 50; 30 has only a right child 60; the four leaves have -1 -1.

    Output 
    60

    Reading the output. Prints 60: the internal nodes are 10, 20 and 30, and 10 + 20 + 30 = 60. The leaves 40, 50, 60 are skipped.

    How it works, step by step
    1. input_tree() reads the root, then uses a queue to read two children for every node (-1 means none).
    2. sum_without_leaf runs a BFS starting at the root.
    3. For each popped parent, if parent->left || parent->right it is not a leaf, so add parent->val to sum.
    4. Push the existing children and keep going until the queue is empty.
    5. main prints the sum.
    Watch out. An empty tree (input -1) returns 0 thanks to the if(!root) check at the top.

/*
 * Leaf nodes in descending order.
 *
 * The idea: a recursive DFS collects every leaf (no left and no right child)
 * into the vector v, which is passed by reference so all calls fill the same
 * vector. Then main sorts it from big to small with greater<int>().
 * Example (sample): leaves 40 50 60 are found, printed as 60 50 40.
 *
 * Base case: NULL adds nothing. The recursive calls trust all_leaf_nodes to
 * add every leaf of that subtree to v.
 */
vector<int> all_leaf_nodes(Node* root, vector<int> &v){
    if(root == NULL){            // empty subtree: nothing to add
        return v;
    }
    // A leaf: store its value.
    if(root->left == NULL && root->right == NULL){
        v.push_back(root->val);  // push_back adds at the end of the vector
    }
    // Look for leaves on both sides (for a leaf both calls return at once).
    // Their return values (copies) are ignored; the real work is done in v.
    all_leaf_nodes(root->left, v);
    all_leaf_nodes(root->right, v);
    return v;                    // a copy of the filled vector
}


int main()
{
    // Write your code here
    Node* root = input_tree();                  // build the tree

    vector<int> v;                              // empty; the function fills it
    vector<int> ans = all_leaf_nodes(root, v);  // ans gets a copy of the leaves
    // greater<int>() puts the biggest value first (descending order).
    // Without it, sort would put the smallest first.
    sort(ans.begin(), ans.end(), greater<int>());

    // i walks over every index of ans; print each value followed by a space.
    for(int i=0; i<ans.size(); i++){
        cout << ans[i] << " ";
    }

    return 0;                                   // program finished normally
}

 * The idea is the formula from the statement: a perfect tree of depth d has
 * exactly 2^d - 1 nodes (1 + 2 + 4 + ... + 2^(d-1)). Any gap makes the real

// Number of nodes = left count + right count + 1 (this node).
// Base case NULL -> 0; each call trusts count_nodes(child) for that subtree.
int count_nodes(Node* root){
    if(root == NULL){
        return 0;
    }
    int l = count_nodes(root->left);
    int r = count_nodes(root->right);
    return l + r + 1;
}

// Depth counted in nodes: 1 + the deeper of the two sides (0 for NULL).
int max_depth(Node* root){
    if(root == NULL){
        return 0;
    }

    int l = max_depth(root->left);      // depth of the left subtree
    int r = max_depth(root->right);     // depth of the right subtree

    return max(l, r) + 1;               // max(a, b) = the larger one; + 1 for this node
}

// True if the tree is perfect.
bool is_perfect(Node* root){
    if(root == NULL){
        return true;                    // an empty tree has no gaps
    }
    int total_nodes = count_nodes(root);        // how many nodes there are
    int max_depth_of_tree = max_depth(root);    // how many levels there are

    // How many nodes a perfect tree with that many levels must have.
    // pow(2, d) returns a double (2.0^d); assigning it to an int keeps the
    // whole number (exact for the small depths a real perfect tree can have).
    // Careful: a very tall, thin tree (depth near 10^5) makes pow return a
    // number far too big for int, and converting it to int is undefined
    // behaviour. (A perfect tree with 10^5 nodes has depth at most 17, so
    // checking "depth > 17 -> NO" first would make this safe.)
    int total_nodes_for_perfect_tree = pow(2, max_depth_of_tree) - 1;

    // Perfect exactly when nothing is missing.
    return total_nodes == total_nodes_for_perfect_tree;
}

/*
 * Level nodes: print the values on level X, left to right (the root is
 * level 0 in this problem), or "Invalid" if the tree has no level X.
 *
 * The idea: a level-order walk where each node travels with its level as a
 * pair {node, level}; children get level + 1. Every node whose level equals X
 * is collected. The queue hands out each level left to right, so the values
 * come out in the right order.
 * If nothing was collected, the special value -999 is returned as a signal
 * for "no such level" (safe, because real values are at least 1).
 */
vector<int> level_nodes(Node* root, int X) {
    vector<int> ans;                 // values found on level X
    queue<pair<Node*, int>> q;       // {node, its level}; .first = node, .second = level
    if(root){
        q.push({root, 0});       // the root is on level 0 ({a, b} builds the pair)
    }

    // One pass handles one node; the whole tree is walked.
    while(!q.empty()){
        pair<Node*, int> parent = q.front();    // oldest waiting entry
        q.pop();

        Node* node = parent.first;      // the node
        int level = parent.second;      // its level

        // On the wanted level: keep it.
        if(level == X){
            ans.push_back(node->val);   // push_back adds at the end of the vector
        }

        // Children are one level deeper.
        if(node->left){
            q.push({node->left, level + 1});
        }

        if(node->right){
            q.push({node->right, level + 1});
        }
    }
    // No node on level X: send back the "invalid" signal.
    if(ans.empty()){
        ans.push_back(-999);
    }
    return ans;
}

    // is no right child.

        right_boundary(root->right, v);
    } else if(root->left){
        right_boundary(root->left, v);
    }

// Function to collect left boundary
// Walks down the left edge (left child if any, else right child), storing
// each node top-down and stopping BEFORE the leaf at the bottom.
// Sample 0 from 20: stores 20, 40 and stops at the leaf 90.
void leftBoundaryNodes(Node* root, vector<int>& res) {
