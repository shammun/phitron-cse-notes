Revising it is a good way to practise the two tools you use for every tree problem: BFS with a queue and recursive DFS.7 programsModule 21Binary search trees: search, insert, build from a sorted arrayThis module introduces the binary search tree (BST): a binary tree where everything on the left is smaller than the node and everything on the right is bigger. That one rule lets you throw away half the tree at every step, so search and insert take time proportional to the height, not the number of nodes. You also learn how to build a balanced BST from a sorted array by always picking the middle element as the root.5 programsModule 22Heaps: insert and delete, plus BST practiceThis module introduces the binary heap: a complete binary tree stored in a plain array, where every parent is bigger (max heap) or smaller (min heap) than its children. You learn how to insert by bubbling a value up and how to delete the root by moving the last value to the top and pushing it down.
