    Basic Data Structures · Module 22

    Heaps: insert and delete, plus BST practice

    This module introduces the binary heap: a complete binary tree stored in a plain array, where every parent is bigger (max heap) or smaller (min heap) than its children. You learn how to insert by bubbling a value up and how to delete the root by moving the last value to the top and pushing it down. The practice problems apply BST ideas (in-order is sorted, the BST rule lets you skip branches) and a simple top-two scan.

    💡 Key ideas

    Heap as an array

    A heap is a complete tree, so it fits in an array with no gaps. For index i, the children are at 2*i + 1 and 2*i + 2, and the parent is at (i - 1) / 2.

    int par_idx = (cur_idx - 1) / 2;
int left_idx = 2 * cur_idx + 1;
int right_idx = 2 * cur_idx + 2;

    Max heap vs min heap

    In a max heap every parent is at least as big as its children, so the largest value sits at index 0. A min heap is the mirror: the smallest value is at the top.

    Insert = push back, then bubble up

    Add the value at the end of the array, then keep swapping it with its parent while it beats the parent. It stops at the root or when the parent is already better.

    Delete root = move last to top, then push down

    Copy the last element into index 0 and remove the last slot. Then swap the top with its better child (bigger for max heap, smaller for min heap) until neither child beats it.

    O(log n) operations

    A complete tree with n nodes has height about log2(n), and bubbling up or down moves one level per swap, so both operations are O(log n).

    BST in-order is sorted

    Several problems here rely on it: the closest pair of values in a BST is always adjacent in in-order, and relinking nodes in in-order gives an increasing chain.

    #include<iostream>
#include <vector>

using namespace std;

int main(){
    int n;
    cin >> n;
    vector<int> v(n);

    for(int i=0; i<n; i++){
        cin >> v[i];
    }

    int val;
    cin >> val;
    v.push_back(val);
    int cur_idx = v.size() - 1;
    while(cur_idx != 0){
        int par_idx = (cur_idx - 1) / 2;
        if(v[cur_idx] > v[par_idx]){
            swap(v[cur_idx], v[par_idx]);
            cur_idx = par_idx;
        } else{
            break;
        }
    }

    for(int x : v){
        cout << x << " ";
    }
    cout << endl;

    return 0;
}

    Output 
    60 40 55 10 30 20 50

    Reading the output. 60 40 55 10 30 20 50: 55 started at index 6, beat its parent 50 at index 2 and swapped, then stopped under 60 because 55 < 60.

    How it works, step by step
    1. Read n and the heap into v, then read val and push_back it.
    2. cur_idx starts at the last index, where the new value sits.
    3. Compute par_idx = (cur_idx - 1) / 2. If v[cur_idx] > v[par_idx], swap them and move cur_idx up to the parent.
    4. Stop when the value is not bigger than its parent, or when it reaches index 0.
    5. Print the array: it is still a valid max heap.
    Watch out. The input array must already be a heap; the program does not build one from arbitrary values.

TreeNode<int>* insertionInBST(TreeNode<int>* root, int val)
{
    // Write your code here.
    if (root == NULL) {
        return new TreeNode<int>(val);
    }

    if (val < root->val) {
        root->left = insertionInBST(root->left, val);
    } else {
        root->right = insertionInBST(root->right, val);
    }

    return root;
}

Range sum of BST

Given the root node of a binary search tree and two integers low and high, return the sum of values of all nodes with a value in the inclusive range [low, high].

Example 1
Input: root = [10,5,15,3,7,null,18], low = 7, high = 15
Output: 32
Explanation: Nodes 7, 10, and 15 are in the range [7, 15]. 7 + 10 + 15 = 32.

Example 2
Input: root = [10,5,15,3,7,13,18,1,null,6], low = 6, high = 10
Output: 23
Explanation: Nodes 6, 7, and 10 are in the range [6, 10]. 6 + 7 + 10 = 23.



*/


/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    int rangeSumBST(TreeNode* root, int low, int high) {
        if(root == NULL){
            return 0;
        }

        if(low > root->val){
            return rangeSumBST(root->right, low, high);
        }

        if(high < root->val){
            return rangeSumBST(root->left, low, high);
        }

        return root->val + rangeSumBST(root->left, low, high) + rangeSumBST(root->right, low, high);
    }
};

/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:

    TreeNode* prev = NULL;
    int min_diff = INT_MAX;

    void inorderTraversal(TreeNode* node){
        if(!node){
            return;
        }

        inorderTraversal(node->left);

        if(prev){
            min_diff = min(min_diff, abs(node->val - prev->val));
        }

        prev = node;

        inorderTraversal(node->right);
    }

    int getMinimumDifference(TreeNode* root) {
        inorderTraversal(root);
        return min_diff;
    }
};

/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
private:
    void inorder(TreeNode* node, TreeNode* &current) {
        if (!node){
            return;
        }

        inorder(node->left, current);

        node->left = NULL;
        current->right = node;
        current = node;    

        inorder(node->right, current);
    }
    
public:
    TreeNode* increasingBST(TreeNode* root) {
        TreeNode* start = new TreeNode(999);
        TreeNode* current = start;
        
        inorder(root, current);
        
        return start->right;
    }
};

Maximum Product of Two Elements in an Array

Given the array of integers nums, you will choose two different indices i and j of 
that array. Return the maximum value of (nums[i]-1)*(nums[j]-1).
 

Example 1:

Input: nums = [3,4,5,2]
Output: 12 
Explanation: If you choose the indices i=1 and j=2 (indexed from 0), you will get the 
maximum value, that is, (nums[1]-1)*(nums[2]-1) = (4-1)*(5-1) = 3*4 = 12. 
Example 2:

Input: nums = [1,5,4,5]
Output: 16
Explanation: Choosing the indices i=1 and j=3 (indexed from 0), you will get the 
maximum value of (5-1)*(5-1) = 16.


*/

class Solution {
public:
    int maxProduct(vector<int>& nums) {
        int max_first = 0;
        int max_second = 0;

        for(int num : nums){
            if(num > max_first){
                max_second = max_first;
                max_first = num;
            } else if(num > max_second){
                max_second = num;
            }
        }

        return (max_first - 1) * (max_second - 1);
    }
};

    📌 Remember

    • A heap is a complete binary tree stored in an array: children at 2i+1, 2i+2, parent at (i-1)/2.
    • Insert: append, then bubble up while the value beats its parent.
    • Delete root: move the last value to the top, then push it down towards the better child.
    • Both heap operations are O(log n).
    • In-order traversal of a BST gives sorted values; many BST problems build on that.

    ✅ Check yourself

    In a heap array, what is the parent index of index 9 and the children of index 4?
    Parent of 9 is (9 - 1) / 2 = 4. Children of 4 are 9 and 10.
    Is the array 50 30 40 35 10 a valid max heap?
    No. Index 3 (value 35) has parent index 1 (value 30), and 35 > 30.
    Why can't we just delete v[0] with erase in a heap?
    Shifting every element left scrambles the parent-child positions, so the heap rule breaks and the cost is O(n). Moving the last element up and pushing it down keeps the shape and costs O(log n).
