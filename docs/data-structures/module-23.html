    Basic Data Structures · Module 23

    STL map, set, priority queue & review problems

    This module gives you three ready-made STL containers built on trees and heaps: map (a sorted key-value store), set (sorted unique values) and priority_queue (a heap that always shows the biggest or smallest item). You also learn to write a compare class so a priority queue can order your own objects. The practice day reviews linked lists, prefix sums and trees with LeetCode problems.

    🧭 Start here

    Three containers arrive in this module, and the easiest way to keep them apart is by the question each one answers: have I seen this before, how many times, and who is next by priority.

    Start with the middle one, because you have already solved it once. In Module 13 of the C course you counted marks with a frequency array: the value itself picked the box, so f[3]++ meant one more student with 3. One pass over the data, then every count is one step away.

    Now try the same trick on a sentence. Count how often each word appears, and the frequency array has nothing to offer. There is no box number for banana. The same wall appears with numbers too: if the marks were ID numbers up to 1,000,000,000 you would need an array of a billion ints, about 4 GB, to hold a handful of counts.

    A map is the tally sheet where the label on a box can be anything, and boxes only exist once something is put in them. Counting the words of a sentence becomes the same one-liner you already know, with a string in the brackets instead of a number:

    map<string,int> mp;
string line, word;
getline(cin, line);
stringstream ss(line);
while(ss >> word) mp[word]++;   // the word picks the slot
for(auto it = mp.begin(); it != mp.end(); it++)
    cout << it->first << " " << it->second << endl;
    input:  to be or not to be

read "to"   mp: to 1
read "be"   mp: be 1, to 1
read "or"   mp: be 1, or 1, to 1
read "not"  mp: be 1, not 1, or 1, to 1
read "to"   mp: be 1, not 1, or 1, to 2
read "be"   mp: be 2, not 1, or 1, to 2

printed in alphabetical order, not arrival order

    Look at that last line, because it tells you what a map really is. The keys came out sorted without anyone sorting them, which is the in-order traversal of Module 21: inside, a map is a balanced binary search tree of the keys. That is also the price. A frequency array answered in one step; a map follows a path down the tree, so every insert, lookup and erase costs O(log n). For 100000 different words that is about 17 comparisons, which is nothing, but it is not one.

    The "have I seen it" question is the same tree with the values thrown away: that is a set. It keeps unique values in ascending order, so insert 3, 10, 0, 6, 9, 10, 10 and it holds 0, 3, 6, 9, 10. Sorting and removing duplicates, in one container, while you read the input. One trap comes with the map: writing mp[k] for a key that is not there quietly creates it with value 0, so when you only want to ask, use mp.count(k).

    The third question, who is next by priority, is Module 22 with the code already written for you. A priority_queue is a heap: push and pop cost O(log n), top() is one step, and by default the top is the largest value. Push 10, 5, 30 and top() is 30; pop it and top() becomes 10. Write priority_queue<int, vector<int>, greater<int>> mn; and the smallest sits on top instead.

    For your own objects you hand it a compare class, and this is where people lose marks. operator()(l, r) returns true when l should sit lower, meaning come out later. So to serve the highest marks first you write return l.marks < r.marks;, which looks backwards next to the comparator you wrote for sort in Module 7 of the C++ course. Read it as "l loses to r" and it stops feeling strange.

    So the choice, in one breath: small whole numbers in a known range keep using a frequency array, because it is one step; any other key, or counts you want printed in order, use a map; unique and sorted, use a set; a changing pile where you only ever want the current best, use a priority_queue.

    💡 Key ideas

    map<key, value>

    Stores pairs sorted by key, like a dictionary. Insert, find and erase are O(log n) because it is a balanced BST inside.

    map<string,int> mp; mp["abc"] = 10;

    mp[key] creates missing keys

    Reading mp[k] for a key that is not there quietly inserts it with value 0. Use mp.count(k) when you only want to ask whether it exists.

    if(mp.count(k)) { ... }

    set<T>

    Keeps only unique values, always in ascending order. Great for 'sort and remove duplicates' in one go.

    set<int> s; s.insert(x);

    priority_queue

    A heap. By default top() is the largest value; with greater<int> it becomes a min-heap. push and pop are O(log n), top is O(1).

    priority_queue<int, vector<int>, greater<int>> mn;

    Custom compare class

    operator()(l, r) returns true when l should sit lower than r (come out later). So l.marks < r.marks makes the highest marks come out first. This feels reversed compared with sort.

    bool operator()(Student l, Student r){ return l.marks < r.marks; }

    Splitting a line into words

    Read the whole line with getline, wrap it in a stringstream, then ss >> word gives one word at a time.

    stringstream ss(s); while(ss >> word) mp[word]++;

    Prefix sums without an array

    Keep a running left sum; the right sum is total - left - nums[i]. This turns an O(n^2) check into O(n).

    /*

This file contains many examples of map in C++ STL.

map in STL is very similar to a dictionary in python.

In map, key and values are stored in key-value pair.

Insertion complexity is O(logn) and search complexity is O(logn).

Print complexity for one element is O(logn).
Complexity for printing n values is O(nlogn).



*/


#include<iostream>
#include <vector>
#include <queue>
#include <algorithm>
#include <string>
#include <map>

using namespace std;

int main(){
    // key, value pair
    map<int, int> mp; // key, value pair, Here key is int and value is int
    // key and values can be of any type
    mp[1] = 10; // 1 is key and 10 is value
    mp[2] = 20; // 2 is key and 20 is value
    mp[3] = 30; // 3 is key and 30 is value
    mp[4] = 40;
    mp[5] = 50;

    // print the map with keys and values

    // first way
    for(auto it = mp.begin(); it != mp.end(); it++){
        cout << it->first << " " << it->second << endl; // it->first is key and it->second is value
    }

    // second way
    for(auto &pair : mp){ // &pair to avoid copying -- this creates a refrence to each pair
        cout << pair.first << " " << pair.second << endl; // pair.first is key and pair.second is value
    }

    // map with key of string and value of int
    map<string, int> mp2;
    mp2["abc"] = 10;
    mp2["def"] = 20;
    mp2["ghi"] = 30;
    mp2["jkl"] = 40;
    mp2["mno"] = 50;

    cout << mp2["abc"] << endl;
    
    // if a key is not present in the map, and we want to access it,
    // it will give 0
    // if there is no key in the map, it will create a new key with value 0
    cout << mp2["xyz"] << endl;

    // How to understand if a key is present in the map or not?
    if(mp2.count("sjhgnkjdng")){
        cout << "Key is present" << endl;
    } else {
        cout << "Key is not present" << endl;
    }

    return 0;
}

    Reading the output. Keys 1-5 with their values appear twice (once per loop), then 10, then 0 for the missing key, then Key is not present.

    How it works, step by step
    1. map<int,int> mp gets keys 1..5 with values 10..50 using mp[key] = value.
    2. The first print loop uses an iterator: it->first is the key, it->second the value.
    3. The second print loop uses for(auto &pair : mp); the & avoids copying each pair.
    4. map<string,int> mp2 shows keys can be strings; mp2["abc"] prints 10.
    5. mp2["xyz"] prints 0 and, as a side effect, adds key xyz to the map.
    6. mp2.count(...) returns 1 or 0, so it is the safe way to check presence.
    Watch out. Using mp[k] just to check a key adds that key. Use count or find for checks.
    ✅ Check yourself: After cout << mp2["xyz"], what is mp2.size()?

    /*

This is about set in C++ STL.

Set is a container that stores unique elements in a specific order.

It has O(logn) time complexity for insertion, deletion and search.

It maintains a balanced BST and so the operations are O(logn).

It uses BST internally. Uses inorder traversal to print elements in sorted order.

*/

#include<iostream>
#include <vector>
#include <queue>
#include <algorithm>
#include <string>
#include <map>
#include <set>

using namespace std;

int main(){
    set<int> s;
    int n;
    cin >> n;
    for(int i=0; i<n; i++){
        int x;
        cin >> x;
        s.insert(x);
    }

    // print the set in ascending order without duplicates
    for(auto it = s.begin(); it != s.end(); it++){
        cout << *it << " ";
    }

    // We can't reverse the order of elements in set
    // If we really have to, we can put it in vector and print it in reverse order

    vector<int> v;
    for(auto it = s.begin(); it != s.end(); it++){
        v.push_back(*it);
    }
    reverse(v.begin(), v.end());
    
    for(int x : v){
        cout << x << " ";
    }

    // Is an element present?
    // Is 4 present in the set?

    if(s.count(4)){
        cout << "4 is present" << endl;
    } else {
        cout << "4 is not present" << endl;
    }

    return 0;
}
    Input (stdin)
    7
5 2 8 2 4 5 1

    n, then n numbers (duplicates allowed).

    Output 
    1 2 4 5 8 8 5 4 2 1 4 is present

    Reading the output. All on one line: 1 2 4 5 8 (sorted, duplicates gone), then 8 5 4 2 1 (reversed), then 4 is present.

    How it works, step by step
    1. Each s.insert(x) ignores values already in the set.
    2. Walking from s.begin() to s.end() gives ascending order (an in-order walk of the BST inside).
    3. To get descending order, the values are copied into vector v and reversed.
    4. s.count(4) is 1 if 4 is in the set, otherwise 0.
    Watch out. No newline is printed between the parts, so the three results run together. Add cout << endl; after each loop. (A set can also be walked backwards with rbegin()/rend(), no vector needed.)
    ✅ Check yourself: With input 3 and 9 9 9, what does the first loop print?
    Just 9, because a set keeps one copy.

    /*

Priority Queue in C++

*/

#include<iostream>
#include <vector>
#include <queue>



using namespace std;

int main(){
    
    // Maximum Priority Queue

    priority_queue<int> pq;
    pq.push(10);
    pq.push(5);
    pq.push(30);

    cout << pq.top() << endl; // 30
    pq.pop();
    cout << pq.top() << endl; // 10

    pq.push(100);
    cout << pq.top() << endl; // 100

    pq.push(21);
    cout << pq.top() << endl; // 100 -- it is still 100

    cout << pq.empty() << endl; // 0

    // Minimum Priority Queue

    priority_queue<int, vector<int>, greater<int>> pq2;
    pq2.push(10);
    pq2.push(5);
    pq2.push(30);

    cout << pq2.top() << endl; // 5
    pq2.pop();
    cout << pq2.top() << endl; // 10

    pq2.push(100);
    cout << pq2.top() << endl; // 5

    pq2.push(21);
    cout << pq2.top() << endl; // 5

    pq2.push(3);
    cout << pq2.top() << endl; // 3

    cout << pq.empty() << endl; // 0

    return 0;
}

    Reading the output. Lines 1-5 (30 10 100 100 0) come from the max-heap; lines 6-11 (5 10 10 10 3 0) come from the min-heap.

    How it works, step by step
    1. priority_queue<int> pq: after pushing 10, 5, 30 the top is 30.
    2. pop() removes 30, so the top becomes 10; pushing 100 makes it 100; pushing 21 does not change it.

    4. priority_queue<int, vector<int>, greater<int>> pq2 keeps the smallest on top: 5, then 10 after a pop.
    5. Pushing 100 and 21 leaves 10 on top; pushing 3 makes 3 the top.
    Watch out. The comments in the file say the min-heap top is 5 after pushing 100 and 21, but 5 was already popped, so the real output is 10. The last line checks pq.empty() again instead of pq2.empty().

    #include<iostream>
#include <vector>
#include <queue>
#include <algorithm>
#include <string>

using namespace std;

class Student{
    public:
        string name;
        int roll;
        int marks;

        Student(string name, int roll, int marks){
            this->name = name;
            this->roll = roll;
            this->marks = marks;
        }
};


class cmp{
    public:
        bool operator()(Student l, Student r){
            if(l.marks < r.marks){ // Descending order here not ascending order -- higher marks will come first
                return true;
            } else if(l.marks > r.marks){
                return false;
            } else {
                return l.roll > r.roll; // Ascending order, smaller rolls will come first
            } 
        }
};
int main(){
    priority_queue<Student, vector<Student>, cmp> pq;
    int n;
    cin >> n;

    for(int i=0; i<n; i++){
        string name;
        int roll, marks;
        cin >> name >> roll >> marks;
        Student obj(name, roll, marks);
        pq.push(obj);
    }

    while(!pq.empty()){
        cout << pq.top().name << " " << pq.top().roll << " " << pq.top().marks << endl;
        pq.pop();
    }

}
    Input (stdin)
    4
rafi 3 85
mina 1 92
sakib 2 85
tuli 4 70

    n, then n lines of name roll marks.

    Output 
    mina 1 92
sakib 2 85
rafi 3 85
tuli 4 70

    Reading the output. mina 1 92 comes first (highest marks); sakib 2 85 beats rafi 3 85 on the smaller roll; tuli 4 70 is last.

    How it works, step by step
    1. Student holds name, roll and marks.
    2. cmp::operator()(l, r) returns true when l should come out after r.
    3. l.marks < r.marks returns true, so lower marks sink and higher marks rise to the top.
    4. When marks are equal, l.roll > r.roll makes the larger roll sink, so the smaller roll comes out first.
    5. The main loop prints top() and pops until the queue is empty.
    Watch out. The comparator reads the opposite way from sort: for sort, a < b means ascending; for a priority queue it means the biggest comes out first.
    ✅ Check yourself: What single change makes the lowest marks come out first?
    Change the first comparison to l.marks > r.marks returning true.

    /*

https://leetcode.com/problems/middle-of-the-linked-list/description/

Middle of the Linked List

*/

class Solution {
public:
    int get_size(ListNode* head){
        int size = 0;  
        ListNode* temp = head;
        while(temp != NULL){
            size++;
            temp = temp->next;
        }
        return size;      
    }
    ListNode* middleNode(ListNode* head) {
        int size = get_size(head);
        int idx = size / 2;
        ListNode* temp = head;
        for(int i=0; i<idx; i++){
            temp = temp->next;
        }
        return temp;
    }
};

    int val;
    ListNode *next;

    ListNode(int x, ListNode *next) : val(x), next(next) {}

    int n; cin >> n;
    ListNode dummy; ListNode* tail = &dummy;
    for (int i = 0; i < n; i++) { int x; cin >> x; tail->next = new ListNode(x); tail = tail->next; }
    ListNode* mid = Solution().middleNode(dummy.next);
    cout << "middle node = " << mid->val << endl;
    cout << "list from middle:";
    for (ListNode* t = mid; t; t = t->next) cout << " " << t->val;
    cout << endl;
}

    Reading the output. middle node = 4 and list from middle: 4 5 6, matching LeetCode's expected answer [4,5,6]. With 6 nodes, idx = 3, so the second of the two middles is returned.

    How it works, step by step
    1. get_size walks the list once and counts nodes.
    2. idx = size / 2 is the middle position (0-based).
    3. A second walk moves temp forward idx times and returns it.
    Watch out. A single pass with a slow pointer (1 step) and a fast pointer (2 steps) finds the middle without counting first.
    ✅ Check yourself: For a list of 6 nodes, which node (1-based) is returned?
    The 4th, because idx = 6/2 = 3 steps from the head.

Design linked list

class Node{
    public: 
        int val;
        Node* next;
        Node* prev;

    Node(int val){
        this->val = val;
        this->next = NULL;
        this->prev = NULL;
    }

};

class MyLinkedList {
public:
    Node* head;
    Node* tail;
    int size;

    MyLinkedList() {
        head = NULL;
        tail = NULL;
        size = 0;
    }
    
    int get(int index) {
        if(index < 0 || index >= size){
            return -1;
        }
        Node* tmp = head;
        for(int i=0; i<index; i++){
            tmp = tmp->next;
        }
        return tmp->val;
    }
    
    void addAtHead(int val) {
        Node* newNode = new Node(val);
        if(head == NULL){
            head = tail = newNode;
        } else{
            newNode->next = head;
            head->prev = newNode;
            head = newNode;
        }
        size++;
    }
    
    void addAtTail(int val) {
        Node* newNode = new Node(val);
        if(tail == NULL){
            head = tail = newNode;
        } else {
            tail->next = newNode;
            newNode->prev = tail;
            tail = newNode;
        }
        size++;
    }
    
    void addAtIndex(int index, int val) {
        if(index < 0 || index > size){
            return;
        }

        if(index == 0){
            addAtHead(val);
            return;
        }

        if(index == size){
            addAtTail(val);
            return;
        }

        Node* tmp = head;
        for(int i=1; i<index; i++){
            tmp = tmp->next;
        }

        Node* newNode = new Node(val);
        newNode->next = tmp->next;
        tmp->next->prev = newNode;
        newNode->prev = tmp;
        tmp->next = newNode;

        size++;
    }
    
    void deleteAtIndex(int index) {
        if(index < 0 || index >= size || size == 0){
            return;
        }

        if(size == 1){
            delete head;
            head = tail = NULL;
        }

        else if(index == 0){
            Node* temp = head;
            head = head->next;
            head->prev = NULL;
            delete temp;
        }

        else if(index == size-1){
            Node* temp = tail;
            tail = tail->prev;
            tail->next = NULL;
            delete temp;
        }

        else{
            Node* curr = head;
            for(int i=0; i<index; i++){
                curr = curr->next;
            }
            curr->prev->next = curr->next;
            curr->next->prev = curr->prev;
            delete curr;
        }        

        size--;
    }
};

/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    ListNode* mergeNodes(ListNode* head) {
        ListNode* modify = head->next;
        ListNode* nextSum = modify;

        while(nextSum){
            int sum = 0;
            while(nextSum->val != 0){
                sum = sum + nextSum->val;
                nextSum = nextSum->next;
            }

            modify->val = sum;
            nextSum = nextSum->next;
            modify->next = nextSum;
            modify = modify->next;
        }
        return head->next;
    }
};

class Solution {
public:
    int pivotIndex(vector<int>& nums) {
        int total = 0;
        for(int num : nums){
            total += num;
        }

        int leftSum = 0;
        for(int i=0; i< nums.size(); i++){
            int rightSum = total - leftSum - nums[i];
            if(leftSum == rightSum){
                return i;
            }
            leftSum += nums[i];
        }

        return -1;
    }
};

class Solution {
public:
    vector<int> leftRightDifference(vector<int>& nums) {
        vector<int> leftSum;
        vector<int> rightSum;

        leftSum.push_back(0);
        leftSum.push_back(nums[0]);
        int sum1 = nums[0];

        for(int i=1; i<nums.size()-1; i++){
            sum1 += nums[i];
            leftSum.push_back(sum1);
        }


        for(int i=1; i<nums.size(); i++){
            int sum2 = nums[i];
            for(int j =i+1; j<nums.size(); j++){
                sum2 += nums[j];
            }
            rightSum.push_back(sum2);
        }
        rightSum.push_back(0);

        vector<int> result;
        
        for(int i=0; i<nums.size(); i++){
            result.push_back(abs(leftSum[i] - rightSum[i]));
        }
        

        return result;
    }
};

    How it works, step by step
    1. leftSum starts with 0 (nothing is left of index 0), then grows with running sums up to index n-2.
    2. For every i from 1, an inner loop adds nums[i..n-1] to get the right sum of position i-1.

    4. result[i] = abs(leftSum[i] - rightSum[i]).
    Watch out. The right sums are recomputed from scratch each time, which is O(n^2). Use right = total - left - nums[i] for O(n), as in the pivot-index problem.

/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    int maxDepth(TreeNode* root) {
        if(root == NULL){
            return 0;
        }

        int l = maxDepth(root->left);
        int r = maxDepth(root->right);
        return max(l, r) + 1;
    }
};
