    Assignment: stack & queue problems

    This module is an assignment that puts stacks and queues to work. You compare the pop order of a stack and a queue (once with the STL, once with your own linked-list classes), cancel pairs of characters with a stack, and simulate a ticket line with a queue. The big lesson: pick the container whose removal order matches the problem.

    💡 Key ideas

    LIFO vs FIFO

    A stack gives back the last value you pushed (LIFO). A queue gives back the first value you pushed (FIFO). So pushing the same list into both gives opposite removal orders.

    st.top();  // newest
q.front(); // oldest

    Compare while popping

    To check if two containers remove items in the same order, look at top() and front() together, compare, then pop both. Stop at the first mismatch.

    Stack as a cancel machine

    When a new character can cancel the one just before it, keep the not-yet-cancelled characters on a stack. The top is always the 'previous available' character. If the stack is empty at the end, everything cancelled.

    if(!st.empty() && st.top()=='0' && c=='1') st.pop();
else st.push(c);

    Queue as a waiting line

    A ticket line is a queue: join at the back with push, leave from the front with front() + pop(). Always check empty() before reading the front.

    Building your own stack/queue

    A doubly linked list with a tail pointer gives O(1) push/pop at the tail (a stack). A singly linked list with head and tail gives O(1) push at the tail and pop at the head (a queue).

    Early size check

    If the two lists have different lengths, they can never be the same, so print NO right away. Read all input first, then decide.

int main(){
    int n, m;
    cin >> n >> m;
    stack<int> st;
    queue<int> q;

    for(int i=0; i<n; i++){
        int val;
        cin >> val;
        st.push(val);

    for(int i=0; i<m; i++){
        int val;
        cin >> val;
        q.push(val);

    if(n != m){
        cout << "NO" << endl;
        return 0;

    while(!st.empty()){
        if(st.top() != q.front()){
            cout << "NO" << endl;
            return 0;
        } 
        st.pop();
        q.pop();
    }

    cout << "YES" << endl;

    return 0;

Problem Statement

There is a list of  values that were inserted into a stack and a list of  values that were inserted into a queue. You need to determine whether the stack and queue are the same or not based on the order in which the elements are removed.

Note: You cannot use any  here. You need to implement the stack and queue by yourself. You can use linked list or array as you want.

Input Format

First line will contain  and .
Second line will contain stack  with  values.
Third line will contain queue  with  values.
Constraints

Output Format

Output YES if they were same, otherwise NO.
Sample Input 0

5 5
10 20 30 40 50
50 40 30 20 10
Sample Output 0

YES
Sample Input 1

4 4
10 20 30 40
10 20 30 40
Sample Output 1

NO
Sample Input 2

5 4
1 2 3 4 5
5 4 3 2
Sample Output 2

NO

*/


#include <iostream>
#include <vector>
#include <algorithm>    
#include <string>
using namespace std;

class Node {
    public:
        int val;     
        Node* next;
        Node* prev;

    Node(int val) {
        this->val = val; 
        this->next = NULL;
        this->prev = NULL;
    }
};

class myStack{
    public:
        Node* head = NULL;
        Node* tail = NULL;
        int size1 = 0;

        void push(int val){ // O(1)
            size1++;
            Node* newNode = new Node(val);
            if(head == NULL){
                head = newNode;
                tail = newNode;
                return;
            }
            tail->next = newNode;
            newNode->prev = tail;
            tail = newNode;
        }

        void pop(){ // O(1)
            size1--;
            Node* deleteNode = tail;
            tail = tail->prev;
            delete deleteNode; 
            if(tail==NULL){
                head=NULL;
                return;
            }
            tail->next = NULL;
        }

        int top(){
            return tail->val; // O(1)
        }

        int size(){
            return size1; // O(1)
        }

        bool empty(){
            return size1==0; // O(1)
            // return head==NULL; // O(1)
        }
};

class myQueue{
    public:
        Node* head = NULL;
        Node* tail = NULL;
        int size2 = 0;

        void push(int val){ // O(1)
            size2++;
            Node* newNode = new Node(val);
            if(head == NULL){
                head = newNode;
                tail = newNode;
                return;
            }
            tail->next = newNode;
            tail = newNode;
        }

        void pop(){ // O(1)
            size2--;
            Node* deleteNode = head;
            head = head->next;
            delete deleteNode;
            if(head==NULL){
                tail = NULL;
            }
        }

        int front(){ // O(1)
            return head->val;
        }

        int back(){ // O(1)
            return tail->val;
        }

        int size(){ // O(1)
            return size2;
        }

        bool empty(){ // O(1)
            return head == NULL;
            // return size == 0;
        }
};

int main(){
    int n, m;
    cin >> n >> m;

    myStack st;
    myQueue q;

    for(int i=0; i<n; i++){
        int val;
        cin >> val;
        st.push(val);
    }

    for(int i=0; i<m; i++){
        int val;
        cin >> val;
        q.push(val);
    }

    if(n != m){
        cout << "NO" << endl;
        return 0;
    }

    while(!st.empty()){
        if(st.top() != q.front()){
            cout << "NO" << endl;
            return 0;
        } 
        st.pop();
        q.pop();
    }

    cout << "YES" << endl;

    return 0;
}
    Input (stdin)
    4 4
1 2 3 4
4 3 1 2

    First line n and m, then the stack values, then the queue values.

    Output 
    NO

    Reading the output. NO: the first two pairs match (4 with 4, 3 with 3), but then the stack gives 2 while the queue gives 1.

    How it works, step by step
    1. Node holds val, next and prev.
    2. myStack::push adds at tail; pop deletes tail and moves tail back with prev; top returns tail->val.
    3. myQueue::push adds at tail; pop deletes head and moves head forward; front returns head->val.
    4. Both reset the other end to NULL when the list becomes empty, so the next push starts fresh.
    5. main is the same as problem 1: read, check sizes, compare top() with front() while popping.
    Watch out. myStack::pop has no empty check. Calling it on an empty stack dereferences NULL. Here it is safe because main only pops while !st.empty().
    ✅ Check yourself: Why does the stack need a prev pointer but the queue does not?
    The stack removes from the tail, so after deleting it must step back to the previous node. The queue removes from the head and only ever moves forward with next.

#include <iostream>
#include <vector>
#include <algorithm>    
#include <string>
#include <stack>

using namespace std;

int main(){
    int t;
    cin >> t;

    while(t--){
        string s;
        cin >> s;

        stack<char> st;

        for(char c : s){
            if(st.empty()){
                st.push(c);
            } else{
                if(c == '0' && st.top() == '1'){
                    st.pop();
                } else if(c == '1' && st.top() == '0'){
                    st.pop();
                } else{
                    st.push(c);
                }
            }
        }

        if(st.empty()){
            cout << "YES" << endl;
        } else {
            cout << "NO" << endl;
        }
    }

    return 0;
}

    Reading the output. YES YES NO (one per line). In 0001 the three 0s pile up and only one of them is cancelled by the final 1.

    How it works, step by step
    1. Read t test cases; for each, read the string s and start an empty stack<char>.
    2. For every character c: if the stack is empty, push it.
    3. Otherwise, if c and st.top() are different digits, they cancel, so pop.
    4. If they are the same digit, push c.
    5. After the loop, an empty stack means YES, else NO.
    Watch out. Because any different pair cancels, the answer is simply 'the number of 0s equals the number of 1s'. The stack still shows the general pattern.
    ✅ Check yourself: Trace 0110: what does the stack hold after each character?

Problem Statement

You will be given a binary string  (A binary string is a string which contains only 0 and 1) in which every  will eliminate its previously adjacent  and itself. After an elimination, if another elimination is possible, it will continue until no further eliminations can be made.

For example, if the sequence is , then the  and  elements, as well as the  and  elements, will be eliminated, resulting in the string  (10 01 1 01 10 - Bold values are eliminated). After that, the 2nd and 3rd elements will be eliminated, resulting in the string 110 (1 01 10 - Bold values are eliminated). After that, no further eliminations can occur.

You need to determine whether the string will be empty after all eliminations.

Note: You need to solve it using STL Stack or Queue only.

Each test case will contain the string .

#include <iostream>
#include <vector>
#include <algorithm>    
#include <string>
#include <stack>

using namespace std;

int main() {
    int n;
    cin >> n;

    while(n--){
        stack<char> st;
        string s;
        cin >> s;
        
        for(char c : s){
            if(st.empty()){
                st.push(c);
                continue;
            }

            if(st.top() == '0' && c == '1'){
                st.pop();
            } else {
                st.push(c);
            }
        }

        if(st.empty()){
            cout << "YES" << endl;
        } else {
            cout << "NO" << endl;
        }
    }

    

    return 0;
}

    3

10
010011

    First line t, then one binary string per line.

    Output 
    YES
NO
YES

    Reading the output. YES, NO, YES. 10 stays because a 0 cannot remove the 1 before it.

    How it works, step by step
    1. For each test, read s and start an empty stack<char>.
    2. If the stack is empty, push c and move on.
    3. If st.top() == '0' and c == '1', the pair 01 disappears, so pop.
    4. Otherwise push c (this includes a 0 after a 1, which does not cancel).
    5. Empty stack at the end → YES, else NO.
    Watch out. Compare with problem 3: there both 01 and 10 cancel. Here only 01 does, so the order of characters matters, not just the counts.
    ✅ Check yourself: Does 0101 become empty? Show the stack.
    Yes. 0 → [0]; 1 pops → []; 0 → [0]; 1 pops → [].

    📌 Remember

    • Stack = last in, first out; queue = first in, first out.
    • To compare two containers, check the fronts/tops together and pop both.
    • A stack is the natural tool for 'cancel with the previous available item' problems, including chain reactions.
    • Always check empty() before top(), front() or pop().
    • A hand-made stack and queue are just linked lists with the right end pointers.

    ✅ Check yourself

    You push 1 2 3 into a stack and 3 2 1 into a queue. Are they 'same'?
    Yes. The stack pops 3 2 1 and the queue removes 3 2 1.
    Why does a stack handle chained eliminations like 0011 without extra loops?
    After a pair is removed, the new top is the character that now sits just before the next one, so the next comparison is automatically against it.
    What is the time cost of push and pop in the linked-list stack and queue?
    O(1) each, because they only touch the head or tail pointer.
