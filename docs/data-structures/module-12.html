    💡 Key ideas

    Read until a sentinel

    Several questions end the input with -1 (or the word end). Read in a while(true) loop and break when you see it, instead of reading a count first.

    while(true){
    cin >> val;
    if(val == -1) break;
    l.push_back(val);
}

    STL list helpers

    sort() orders a list in place and unique() removes neighbouring equal values. Sort first, then unique(), and every duplicate is gone.

    Insert at any index (doubly linked)

    Valid indexes are 0..size. Index 0 is insert-at-head, index size is insert-at-tail, anything in between needs the node before the position and four pointer updates.

    Print both directions

    Forward printing follows next from head; backward printing follows prev from tail. If the backward line looks wrong, a prev link was forgotten.

    Two-pointer palindrome

    With a doubly linked list, start i at the head and j at the tail and walk them toward each other, comparing values. Stop when they meet (odd length) or cross (even length).

    Iterators on list

    A list has no []. To reach index X, start at l.begin() and do it++ X times; next(it, k) does the same in one call. l.insert(it, v) puts v before it; l.erase(it) removes it.

    Mixed cin and getline

    After cin >> Q, a newline is still waiting. Call cin.ignore() before the first getline, or the first line you read will be empty.

Problem Statement

You will be given a linked list of integer values as input. You need to remove duplicate 
values from the linked list and finally print the linked list in ascending order.

Note: You need to solve this using STL List, otherwise you will not get marks.

Input Format

First line will contain the values of the linked list, and will terminate with -1.
Constraints

1 <= N <= 1000; Here N is the maximum number of nodes of the linked list.
0 <= V <= 1000; Here V is the value of each node.
Output Format

Output the final linked list where there will be no duplicate values.
Sample Input 0

1 2 3 4 5 -1
Sample Output 0

1 2 3 4 5 
Sample Input 1

1 2 4 2 3 5 1 4 5 2 6 1 -1
Sample Output 1

1 2 3 4 5 6 
Sample Input 2

5 5 1 1 2 4 2 4 1 3 5 0 -1
Sample Output 2

0 1 2 3 4 5 
Sample Input 3

10 10 10 20 20 20 10 20 -1
Sample Output 3

10 20 

*/

#include <iostream>
#include <list>
using namespace std;

int main(){
    list<int> l;

    int val;
    while(true){
        cin >> val;
        if(val == -1){
            break;
        }
        l.push_back(val);
    }

    l.sort();
    l.unique();

    for(int val: l){
        cout << val << " ";
    }

    cout << endl;

    return 0;
}
    Input (stdin)
    5 5 1 1 2 4 2 4 1 3 5 0 -1

    Values on one line, ending with -1 (which is not part of the list).

    Output 
    0 1 2 3 4 5

    Reading the output. 0 1 2 3 4 5 — sorted, each value once.

    How it works, step by step
    1. Read values in a while(true) loop and push_back each one; stop at -1.
    2. l.sort() puts equal values next to each other.
    3. l.unique() deletes each value that equals the one just before it.
    4. Print the list with a range-based for.
    Watch out. unique() without sort() only removes neighbouring copies: 1 2 1 would stay 1 2 1.
    ✅ Check yourself: Why must sort() come before unique()?
    unique() only removes consecutive equal elements; sorting makes all copies consecutive.

#include <iostream>
#include <vector>
#include <algorithm>
#include <string>
using namespace std; 

class Node {
    public:
        int val;     
        Node* next;
        Node* prev;

    Node(int val) {
        this->val = val; 
        this->next = NULL;
        this->prev = NULL;
    }
};

void print_forward(Node* head){
    cout << "L -> ";
    Node* tmp = head;
    while(tmp != NULL){
        cout << tmp->val << " ";
        tmp = tmp->next;
    }
    cout << endl;
}

void print_backward(Node* tail){
    cout << "R -> ";
    Node* tmp = tail;
    while(tmp != NULL){
        cout << tmp->val << " ";
        tmp = tmp->prev;
    }
    cout << endl;
}

int get_size(Node* head){
    int size = 0;
    Node* tmp = head;
    while(tmp!=NULL){
        tmp = tmp->next;
        size++;
    }
    return size;
}

void insert_at_head(Node* &head, Node* &tail, int val){
    Node* newNode = new Node(val);
    if(head==NULL){
        head = newNode;
        tail = newNode;
        return;
    }
    newNode->next = head;
    head->prev = newNode;
    head = newNode;
}

void insert_at_tail(Node* &head, Node* &tail, int val){
    Node* newNode = new Node(val);
    if(head==NULL){
        head = newNode;
        tail = newNode;
        return;
    }
    tail->next = newNode;
    newNode->prev = tail;
    tail = newNode;
}

void insert_at_any_position(Node* &head, Node* &tail, int pos, int val){
    int size = get_size(head);
    if(pos > size || pos < 0){
        cout << "Invalid" << endl;
        return;
    }

    if(pos==0){
        insert_at_head(head, tail, val);
        print_forward(head);
        print_backward(tail);
        return;
    }

    if(pos == size){
        insert_at_tail(head, tail, val);
        print_forward(head);
        print_backward(tail);
        return;
    }

    Node* tmp = head;
    for(int i=1; i<pos; i++){
        tmp = tmp->next;
    }
    
    Node* newNode = new Node(val);
    newNode->next = tmp->next;
    tmp->next->prev = newNode;
    tmp->next = newNode;
    newNode->prev = tmp;
    print_forward(head);
    print_backward(tail);
}


int main(){
    int Q;
    cin >> Q;

    Node* head = NULL;
    Node* tail = NULL;

    while(Q--){
        int X, V;
        cin >> X >> V;
        insert_at_any_position(head, tail, X, V);
    }

    return 0;
}

    Reading the output. The first query fails (Invalid, index 1 on an empty list). Then the list grows 10 → 10 20 → 5 10 20 → 5 7 10 20; every R -> line is the exact mirror of the L -> line, which proves the prev links are right.

    How it works, step by step
    1. get_size counts the nodes so we know the valid range 0..size.
    2. If pos < 0 or pos > size, print Invalid and stop this query.
    3. pos == 0 uses insert_at_head; pos == size uses insert_at_tail.
    4. Otherwise walk tmp to the node at index pos-1.
    5. Link the new node: newNode->next = tmp->next, tmp->next->prev = newNode, tmp->next = newNode, newNode->prev = tmp.
    6. After each successful insert, print_forward(head) and print_backward(tail).
    Watch out. The size check must allow pos == size (append at the end) but reject pos > size.
    ✅ Check yourself: For the list 5 10 20, which node does tmp stop on for query 2 99?
    The node at index 1 (10), because the loop runs pos-1 = 1 step; 99 is linked right after it.

void print_forward(list<int> &l){
    cout << "L -> ";
    for(auto it=l.begin(); it!=l.end(); it++){

void print_backward(list<int> &l){
    cout << "R -> ";
    if(l.empty()){
        cout << endl;
        return;
    }
    
    auto it = next(l.begin(), l.size()-1);
    while(true){

#include <iostream>
#include <vector>
#include <algorithm>
#include <string>
using namespace std; 

class Node {
    public:
        int val;     
        Node* next;
        Node* prev;

    Node(int val) {
        this->val = val; 
        this->next = NULL;
        this->prev = NULL;
    }
};


void insert_at_tail(Node* &head, Node* &tail, int val){
    Node* newNode = new Node(val);
    if(head==NULL){
        head = newNode;
        tail = newNode;
        return;
    }
    tail->next = newNode;
    newNode->prev = tail;
    tail = newNode;
}

bool is_palindrome(Node* head, Node* tail){
    bool flag = true;
    for(Node *i=head, *j=tail; i!=j && i->prev != j; i=i->next, j=j->prev){
        if(i->val != j->val){
            flag = false;
            break;
        }
    }
    return flag;
}

    Node* tail1 = NULL;

        cin >> val;
        if(val==-1){
            break;

    bool result = is_palindrome(head1, tail1);

    if(result){
        cout << "YES" << endl;
    }

    }

    How it works, step by step
    1. Build the list with insert_at_tail so head and tail are both known.
    2. Start i = head, j = tail.
    3. Continue while i != j (odd length: they meet) and i->prev != j (even length: they crossed).

#include <iostream>
#include <string>
#include <list>
#include <sstream>
using namespace std;

void browse_history(list<string> &Web, string* curr){
    string line;
    getline(cin, line);
    stringstream ss(line);
    string command;
    ss >> command;

    if(command == "visit"){
        string address;
        ss >> address;
        bool found = false;
        
        for(string s: Web){
            if(s == address){
                found = true;
                *curr = s;
                break;
            }
        }

        if(found){
            cout << *curr << endl;
        } else{
            cout << "Not Available" << endl;
        }
    
    } else if(command == "next"){
        
        bool previous_word_found = false;

        for(string s: Web){
            if(previous_word_found){
                *curr = s; // set the current pointer to this new next word after the previous current word
                cout << *curr << endl;
                return;
            }
            // current word is the same as the previous word and so set the previous word found to be true
            if(s == *curr){
                previous_word_found = true;
            }
        }
        cout << "Not Available" << endl;
    
    } else if(command == "prev"){
        
        string prev = Web.front();
        if(*curr == prev){
            cout << "Not Available" << endl;
            return;
        }

        for(string s: Web){
            if(s != *curr){
                // update the previous word to the next word as it has not matched the current word yet
                prev = s;
            } else{
                // if the current word is found, then set the previous word to the current word
                *curr = prev;
                cout << *curr << endl;
                return;
            }
        }
    }
}

            break;
        }
        Web.push_back(s);

    int Q;
    cin >> Q;
    cin.ignore();

    string curr = Web.front();

    while(Q--){
        browse_history(Web, &curr);
    }

    return 0;

#include <iostream>
#include <list>
using namespace std;

void print_forward(list<int> &l){
    cout << "L -> ";
    for(auto it=l.begin(); it!=l.end(); it++){
        cout << *it << " ";
    }
    cout << endl;
}

void print_backward(list<int> &l){
    cout << "R -> ";
    if(l.empty()){
        cout << endl;
        return;
    }
    
    // at the last element of the list
    auto it = next(l.begin(), l.size()-1);

    while(true){
        cout << *it << " ";
        if(it == l.begin()){
            break;
        }
        it--;
    }
    cout << endl;
}

void different_queries(list<int> &l, int X, int V){
    if(X == 0){
        l.push_front(V);
    }
    if(X == 1){
        l.push_back(V);
    }
    if(X == 2){
        if(V >= 0 && V < l.size()){
            auto it = l.begin();
            for(int i=0; i<V; i++){
                it++;
            }
            l.erase(it);
        }
    }

    print_forward(l);
    print_backward(l);
}

int main(){
    int Q;
    cin >> Q;
    list<int> l;

    while(Q--){
        int X, V;
        cin >> X >> V;

        different_queries(l, X, V);
    }

    return 0;
}

    How it works, step by step
    1. X == 0 → l.push_front(V); X == 1 → l.push_back(V).
    2. X == 2 → only if 0 <= V < l.size(), move an iterator V steps and l.erase(it).
    3. print_forward walks from begin() to end().
    4. print_backward handles the empty list first, then starts at the last element and walks with it-- until begin().
    5. Printing happens even if the delete was invalid.
    Watch out. On an empty list, next(l.begin(), l.size()-1) would be invalid (size()-1 wraps around), which is why print_backward checks l.empty() first. l.rbegin()..l.rend() is the simpler way to print backward.

    📌 Remember

    • Sentinel input (-1, end) → while(true) + break.
    • list::sort() then list::unique() removes all duplicates.
    • Valid insert indexes are 0..size; the ends are special cases.
    • Print backward from tail to prove your prev links are correct.
    • Two pointers from both ends check a palindrome in one pass.
    • Use cin.ignore() between cin >> and getline.
