    🧭 Start here

    LeetCode hands you one thing: a pointer called head. Not the length, not the tail, no way to step backwards. It is like reading a book where each page tells you the number of the next page and you may not turn back — to answer anything you start at page one.

    That one restriction is why the problems on this page, which look like eight different questions, are really four moves in different clothes: count first, then walk; two pointers at different speeds; relink next to jump over a node; and build a new chain when changing the old one is too fiddly to get right.

    Count first, then walk. "Return the middle node" sounds impossible when nobody tells you the length. So find the length: walk once and add one per node. The middle is then an ordinary index, and a second walk reaches it.

    1 -> 2 -> 3 -> 4 -> 5 -> NULL

walk 1   count the nodes      size = 5
         idx = size / 2      idx  = 2
walk 2   start at node 1
         step 1 -> node 2
         step 2 -> node 3    answer: node 3

    Two walks over n nodes is 2n steps, still O(n), so the cost of counting is nothing. The same move solves "swap the k-th node from the start with the k-th from the end": count to get the length, walk k-1 steps for the first node, walk length-k steps for the second, swap the two values.

    Two pointers at different speeds. slow one node per step, fast two. On a list with a cycle they must meet, which is the cycle question from the last module. Stop instead when fast runs out of list and slow is sitting on the middle — the one-walk alternative to the counting above, though the file here uses the counting version.

    Two pointers over two lists is the other flavour. To find the node where two lists join, compare a == b, the addresses, not a->val == b->val. Two different nodes are perfectly allowed to hold the same number; only the same address means the same node.

    Relink next to jump over a node. Deleting from a linked list is never really deleting; it is making an arrow skip. Removing duplicates from a sorted list is exactly that: if this node and the next hold the same value, point this node past the next one.

    Look at which branch moves temp. After a cut you must stay where you are: with 1 1 1 the node you are standing on still has a duplicate in front of it, and moving on would walk straight past it.

    ListNode* temp = head;
while(temp != NULL && temp->next != NULL){
    if(temp->val == temp->next->val){
        temp->next = temp->next->next;  // jump over the copy
    } else {
        temp = temp->next;              // move only if nothing was cut
    }
}

    Build a new chain when the in-place version is painful. The palindrome solution here does not reverse the list you were given: it copies every value into a fresh list, reverses the copy, then walks the two together comparing values. That costs an extra n nodes, but it is hard to get wrong.

    One repair belongs with the skipping move. It needs a node in front of the one being removed, which fails for exactly one node: the head itself. The standard fix is a throwaway node in front of the list — ListNode* dummy = new ListNode(0); dummy->next = head; — then walk and relink from dummy as usual and finish with return dummy->next;, whatever the list starts with by then. It removes the special case instead of writing an if for it.

    Two small things to watch. Before following temp->next->next, check that temp->next exists, or you read through a NULL. And when you are given only the node to delete, with no head anywhere, you cannot unlink it: copy the next node's value into it and skip that next node, which works for every node but the last.

    💡 Key ideas

    LeetCode's ListNode

    LeetCode gives you a ready-made node struct with val, next and three constructors. You only write the method inside class Solution; the judge builds the list and calls it.

    struct ListNode {
    int val;
    ListNode *next;
    ListNode(int x) : val(x), next(nullptr) {}
};

    Count first, then walk

    Many problems become easy once you know the length. Walk the list once to count size, then walk again exactly the number of steps you need (for example size/2 for the middle).

    Fast & slow pointers

    Move slow one step and fast two steps each turn. If there is a loop, fast eventually laps slow and they meet; if there is no loop, fast falls off the end (hits NULL).

    while(fast != NULL && fast->next != NULL){
    slow = slow->next;
    fast = fast->next->next;
    if(slow == fast) return true;
}

    Skipping a node

    To remove the node after temp, point temp->next past it: temp->next = temp->next->next. Nothing else in the list has to move.

    Recursive reverse

    Recurse to the last node and make it the new head. On the way back, each node makes its next node point back to it (tmp->next->next = tmp) and cuts its own forward link (tmp->next = NULL).

    Compare by address, not value

    Two lists intersect when they share the same node in memory. So compare pointers (tempA == tempB), not val — two different nodes can hold the same number.

    Delete with only the node pointer

    If you can't reach the previous node, copy the next node's value into the current node and skip the next node. The list looks as if the current node was removed. It cannot work for the tail.

https://leetcode.com/problems/middle-of-the-linked-list/description/

*/

#include <iostream>
using namespace std;

struct ListNode{
    int val;
    ListNode* next;
    // Default constructor
    ListNode(): val(0), next(nullptr){}
    // Constructor with a value
    ListNode(int x): val(x), next(nullptr){}
    // Constructor with a value and a pointer to the next node
    ListNode(int x, ListNode* next): val(x), next(next){}
};

class Solution {
    public:
        int get_size(ListNode* head){
            int size = 0;
            ListNode* temp = head;
            while(temp != NULL){
                size++;
                temp = temp->next;
            }
            return size;
        }

        ListNode* middleNode(ListNode* head){
            int size = get_size(head);
            int idx = size / 2;
            ListNode* temp = head;
            for(int i=0; i<idx; i++){
                temp = temp->next;
            }
            return temp;
        }

};

int main(){
    ListNode* n1 = new ListNode(1);
    ListNode* n2 = new ListNode(2);
    ListNode* n3 = new ListNode(3);
    ListNode* n4 = new ListNode(4);
    ListNode* n5 = new ListNode(5);

    // Link the nodes
    n1->next = n2;
    n2->next = n3;
    n3->next = n4;
    n4->next = n5;

    // Instantiate the solution and get the middle node
    Solution sol;
    ListNode* middle = sol.middleNode(n1);

    // Print the value of the middle node
    cout << middle->val << endl;

    // Clean up the memory
    delete n1;
    delete n2;
    delete n3;
    delete n4;
    delete n5;

    return 0;
}
    Input

    This program reads no input.

    Output 
    3

    Reading the output. With 5 nodes, idx = 5/2 = 2, so we step twice from 1 and print 3. With 6 nodes, idx would be 3 and you would get the 4th node (the second middle).

    How it works, step by step
    1. get_size walks from head to NULL and counts the nodes.
    2. middleNode computes idx = size / 2 (integer division).
    3. A for loop moves temp forward idx times, starting at head.
    4. temp now sits on the middle node, so it is returned.
    5. main builds 1 -> 2 -> 3 -> 4 -> 5 by hand and prints the middle node's value.
    Watch out. Integer division decides which middle you get. size/2 gives the second middle for even lengths, which is what LeetCode wants.
    ✅ Check yourself: For the list 10 20 30 40, which value does middleNode return?
    size = 4, idx = 2, so it steps twice and returns 30.

https://leetcode.com/problems/linked-list-cycle/

#include <iostream>
using namespace std;

// Definition for singly-linked list.
struct ListNode {
    int val;
    ListNode *next;
    // Default constructor.
    ListNode() : val(0), next(nullptr) {}
    // Constructor with a value.
    ListNode(int x) : val(x), next(nullptr) {}
    // Constructor with a value and a pointer to the next node.
    ListNode(int x, ListNode *next) : val(x), next(next) {}
};

class Solution {
public:
    bool hasCycle(ListNode *head) {
        ListNode* slow = head;
        ListNode* fast = head;
        bool flag = false;

        while(fast != NULL && fast->next != NULL){
            slow = slow->next;
            fast = fast->next->next;
            if(slow == fast){
                flag = true;
                break;
            }
        }
        return flag;
    }
};

int main() {
    // Create a linked list: 1 -> 2 -> 3 -> 4 -> 5 (no cycle)
    ListNode* n1 = new ListNode(1);
    ListNode* n2 = new ListNode(2);
    ListNode* n3 = new ListNode(3);
    ListNode* n4 = new ListNode(4);
    ListNode* n5 = new ListNode(5);

    // Linking nodes to form the list: 1 -> 2 -> 3 -> 4 -> 5
    n1->next = n2;
    n2->next = n3;
    n3->next = n4;
    n4->next = n5;

    Solution sol;

    // Test the list without a cycle.
    bool noCycle = sol.hasCycle(n1);
    cout << "List has cycle? " << (noCycle ? "Yes" : "No") << endl;

    // Create a cycle: make the last node (n5) point back to n3.
    n5->next = n3;

    // Test the list with a cycle.
    bool hasCycle = sol.hasCycle(n1);
    cout << "List has cycle? " << (hasCycle ? "Yes" : "No") << endl;

    // Note: In a real application, you'd need to free the allocated memory.
    // However, with a cycle present, cleaning up nodes requires extra care.
    // For simplicity, we're not deallocating memory in this example.

    return 0;
}
    Input

    This program reads no input.

    Output 
    List has cycle? No
List has cycle? Yes

    Reading the output. First line No for the straight list 1..5. Second line Yes after the tail was pointed back to node 3.

    How it works, step by step
    1. slow and fast both start at head.
    2. While fast and fast->next are not NULL, move slow one step and fast two steps.
    3. If they ever point to the same node, set flag = true and stop: there is a loop.
    4. If fast reaches the end, the loop ends and flag stays false.
    5. main tests a normal list, then links n5->next = n3 to make a cycle and tests again.
    Watch out. Check fast != NULL before fast->next != NULL; the order matters because && stops early and protects you from reading NULL->next.
    ✅ Check yourself: Why can't we just walk until NULL to detect a cycle?
    In a cyclic list you never reach NULL, so the loop would run forever. Two pointers at different speeds are guaranteed to meet inside the cycle instead.

https://leetcode.com/problems/remove-duplicates-from-sorted-list/description/

#include <iostream>
using namespace std;

// Definition for singly-linked list.
struct ListNode {
    int val;
    ListNode *next;
    // Default constructor.
    ListNode() : val(0), next(nullptr) {}
    // Constructor with a value.
    ListNode(int x) : val(x), next(nullptr) {}
    // Constructor with a value and a pointer to the next node.
    ListNode(int x, ListNode *next) : val(x), next(next) {}
};

class Solution {
public:
    ListNode* deleteDuplicates(ListNode* head) {
        ListNode* temp = head;
        while(temp!=NULL && temp->next !=NULL){
            if(temp->val == temp->next->val){
                temp->next = temp->next->next;
            } else{
                temp = temp->next;
            }
        }
        return head;
    }
};

int main() {
    // Create a sample sorted linked list with duplicates: 1 -> 1 -> 2 -> 3 -> 3
    ListNode* n1 = new ListNode(1);
    ListNode* n2 = new ListNode(1);
    ListNode* n3 = new ListNode(2);
    ListNode* n4 = new ListNode(3);
    ListNode* n5 = new ListNode(3);

    // Link the nodes together.
    n1->next = n2;
    n2->next = n3;
    n3->next = n4;
    n4->next = n5;

    // Print the original list.
    cout << "Original list: ";
    ListNode* current = n1;
    while(current != nullptr) {
        cout << current->val << " ";
        current = current->next;
    }
    cout << endl;

    // Call the solution.
    Solution sol;
    ListNode* newHead = sol.deleteDuplicates(n1);

    // Print the list after removing duplicates.
    cout << "List after removing duplicates: ";
    current = newHead;
    while(current != nullptr) {
        cout << current->val << " ";
        current = current->next;
    }
    cout << endl;

    // Clean up the allocated memory.
    current = newHead;
    while(current != nullptr) {
        ListNode* temp = current;
        current = current->next;
        delete temp;
    }

    return 0;
}
    Input

    This program reads no input.

    Output 
    Original list: 1 1 2 3 3 
List after removing duplicates: 1 2 3

    Reading the output. Original list: 1 1 2 3 3 then List after removing duplicates: 1 2 3.

    How it works, step by step
    1. temp starts at head.
    2. While temp and temp->next exist, compare temp->val with temp->next->val.
    3. If equal, unlink the duplicate: temp->next = temp->next->next (and stay on temp — there may be more copies).
    4. If different, move on: temp = temp->next.
    5. Return the same head; main prints the list before and after.
    Watch out. Only move temp forward when the values differ. If you always advanced, 1 1 1 would keep one extra 1. (The skipped nodes are also never deleted here — fine for LeetCode, a small leak in real code.)
    ✅ Check yourself: Would this code work on the unsorted list 1 2 1?
    No. It only compares neighbours, so the two 1s (not adjacent) both stay.

    #include <iostream>
using namespace std;

// Definition for singly-linked list.
struct ListNode {
    int val;
    ListNode *next;
    // Default constructor.
    ListNode() : val(0), next(nullptr) {}
    // Constructor with a value.
    ListNode(int x) : val(x), next(nullptr) {}
    // Constructor with a value and a pointer to the next node.
    ListNode(int x, ListNode *next) : val(x), next(next) {}
};

class Solution {
public:
    // Recursive helper function that reverses the list.
    // 'head' is passed by reference so that it can be updated when we reach the last node.
    // 'tmp' is the current node in the recursion.
    void reverse(ListNode* &head, ListNode* tmp){
        if(tmp->next == NULL){
            head = tmp;
            return;
        }
        reverse(head, tmp->next);
        tmp->next->next = tmp;
        tmp->next = NULL;
    }
    
    // Main function to reverse a linked list.
    ListNode* reverseList(ListNode* head) {
        if(head == NULL){
            return head;
        }
        reverse(head, head);
        return head;
    }
};

// Helper function to print the linked list.
void printList(ListNode* head) {
    ListNode* current = head;
    while(current != nullptr) {
        cout << current->val << " ";
        current = current->next;
    }
    cout << endl;
}

int main() {
    // Create a linked list: 1 -> 2 -> 3 -> 4 -> 5
    ListNode* n1 = new ListNode(1);
    ListNode* n2 = new ListNode(2);
    ListNode* n3 = new ListNode(3);
    ListNode* n4 = new ListNode(4);
    ListNode* n5 = new ListNode(5);
    
    n1->next = n2;
    n2->next = n3;
    n3->next = n4;
    n4->next = n5;
    
    cout << "Original list: ";
    printList(n1);
    
    Solution sol;
    ListNode* reversedHead = sol.reverseList(n1);
    
    cout << "Reversed list: ";
    printList(reversedHead);
    
    // Free the allocated memory.
    ListNode* current = reversedHead;
    while(current != nullptr) {
        ListNode* temp = current;
        current = current->next;
        delete temp;
    }
    
    return 0;
}
    Input

    This program reads no input.

    Output 
    Original list: 1 2 3 4 5 
Reversed list: 5 4 3 2 1

    Reading the output. Original list: 1 2 3 4 5 and Reversed list: 5 4 3 2 1.

    How it works, step by step
    1. reverseList returns right away for an empty list.
    2. reverse(head, tmp) takes head by reference so it can change the caller's head.
    3. Base case: when tmp->next == NULL, tmp is the last node, so head = tmp.
    4. Otherwise recurse on tmp->next first.
    5. After the call returns, tmp->next->next = tmp makes the next node point back, and tmp->next = NULL cuts the old forward link.
    6. main prints 1 2 3 4 5 then the reversed list.
    Watch out. Forgetting tmp->next = NULL leaves the old head pointing to the second node, which creates a 2-node cycle at the end of the reversed list.
    ✅ Check yourself: Why is head passed as ListNode* &head?
    So the base case can overwrite the caller's pointer with the last node; with a plain copy the new head would be lost.

#include <iostream>
using namespace std;

// Definition for singly-linked list.
struct ListNode {
    int val;
    ListNode *next;
    // Default constructor.
    ListNode() : val(0), next(nullptr) {}
    // Constructor with a value.
    ListNode(int x) : val(x), next(nullptr) {}
    // Constructor with a value and a pointer to the next node.
    ListNode(int x, ListNode *next) : val(x), next(next) {}
};

class Solution {
public:
    // Recursively reverse the linked list.
    // 'head' is passed by reference so that when we reach the last node,
    // we can update the original head pointer.
    // 'tmp' is used to traverse the list.
    void reverse(ListNode* &head, ListNode* tmp){
        if(tmp->next == NULL){
            head = tmp;
            return;
        }
        reverse(head, tmp->next);
        tmp->next->next = tmp;
        tmp->next = NULL;
    }

    // Inserts a new node with value 'val' at the tail of the list.
    // Both 'head' and 'tail' are passed by reference to update them if needed.
    void insert_at_tail(ListNode* &head, ListNode* &tail, int val){
        ListNode* newNode = new ListNode(val);
        if(head == NULL){
            head = newNode;
            tail = newNode;
            return;
        }
        tail->next = newNode;
        tail = newNode;
    }

    // Checks if the linked list is a palindrome.
    // This function creates a copy of the original list, reverses the copy,
    // and then compares node values one by one.
    bool isPalindrome(ListNode* head){
        ListNode* newHead = NULL;
        ListNode* newTail = NULL;

        ListNode* tmp = head;
        while(tmp != NULL){
            insert_at_tail(newHead, newTail, tmp->val);
            tmp = tmp->next;
        }
        // Reverse the copied list.
        reverse(newHead, newHead);

        // Compare the original list and the reversed copy.
        tmp = head;
        ListNode* tmp2 = newHead;
        while(tmp != NULL){
            if(tmp->val != tmp2->val){
                return false;
            }
            tmp = tmp->next;
            tmp2 = tmp2->next;
        }
        return true;
    }
};

int main(){
    // Build a sample linked list.
    // Let's create a palindrome list: 1 -> 2 -> 3 -> 2 -> 1
    ListNode* head = NULL;
    ListNode* tail = NULL;
    Solution sol;
    
    sol.insert_at_tail(head, tail, 1);
    sol.insert_at_tail(head, tail, 2);
    sol.insert_at_tail(head, tail, 3);
    sol.insert_at_tail(head, tail, 2);
    sol.insert_at_tail(head, tail, 1);

    // Test if the list is a palindrome.
    bool result = sol.isPalindrome(head);
    cout << "Is the list a palindrome? " << (result ? "Yes" : "No") << endl;

    // Clean up the allocated memory for the original list.
    ListNode* curr = head;
    while(curr != nullptr) {
        ListNode* temp = curr;
        curr = curr->next;
        delete temp;
    }
    // Note: The reversed copy inside isPalindrome is not freed in this example.
    // In production code, you should free all allocated memory.

    return 0;
}

    This program reads no input.

    Output 
    Is the list a palindrome? Yes

    Reading the output. Is the list a palindrome? Yes — the list reads the same backward.

    How it works, step by step
    1. insert_at_tail adds a new node after tail (and sets both head and tail for the first node).
    2. isPalindrome walks the original and pushes each val into a new list newHead.
    3. reverse(newHead, newHead) flips the copy with the recursive helper.
    4. Two pointers tmp (original) and tmp2 (reversed copy) move together; any different pair means false.
    5. If the walk finishes without a mismatch, return true.
    Watch out. You must copy before reversing. Reversing the original list itself would destroy the order you want to compare against.
    ✅ Check yourself: Why does the method copy the list instead of reversing the original?
    Reversing in place changes the original, so there would be nothing left to compare the reversed order with.

#include <iostream>
using namespace std;

// Definition for singly-linked list.
struct ListNode {
    int val;
    ListNode *next;
    // Default constructor.
    ListNode() : val(0), next(nullptr) {}
    // Constructor with a value.
    ListNode(int x) : val(x), next(nullptr) {}
    // Constructor with a value and a pointer to the next node.
    ListNode(int x, ListNode *next) : val(x), next(next) {}
};

class Solution {
public:
    // Deletes a node (except the tail) from the linked list.
    // This function copies the value from the next node into the current node
    // and then bypasses the next node.
    void deleteNode(ListNode* node) {
        node->val = node->next->val;
        node->next = node->next->next;
    }
};

// Helper function to print the linked list.
void printList(ListNode* head) {
    while (head != nullptr) {
        cout << head->val << " ";
        head = head->next;
    }
    cout << endl;
}

int main() {
    // Create a linked list: 4 -> 5 -> 1 -> 9
    // For the LeetCode problem, we're given only a pointer to the node to delete,
    // and it's guaranteed that the node is not the tail.
    ListNode* n1 = new ListNode(4);
    ListNode* n2 = new ListNode(5);
    ListNode* n3 = new ListNode(1);
    ListNode* n4 = new ListNode(9);
    
    n1->next = n2;
    n2->next = n3;
    n3->next = n4;
    
    cout << "Original list: ";
    printList(n1);
    
    // Suppose we want to delete the node with value 5.
    // In this approach, we are given only a pointer to the node to be deleted (n2).
    Solution sol;
    sol.deleteNode(n2);
    
    // After deletion, the list should become: 4 -> 1 -> 9
    cout << "List after deletion: ";
    printList(n1);
    
    // Cleanup:
    // Note: In the LeetCode problem, we do not worry about freeing memory.
    // However, in this demonstration, we have an orphaned node (originally n3)
    // whose memory is not directly accessible after deletion because its value
    // and pointer have been copied into n2.
    // For simplicity, we'll free the nodes that are still accessible.
    delete n1; // Node with value 4.
    delete n2; // Node now holding value 1 (copied from n3).
    delete n4; // Node with value 9.
    
    return 0;
}
    Input

    This program reads no input.

    Output 
    Original list: 4 5 1 9 
List after deletion: 4 1 9

    Reading the output. Original list: 4 5 1 9 then List after deletion: 4 1 9. The node that held 5 now holds 1.

    How it works, step by step
    1. node->val = node->next->val — the node takes its neighbour's value.
    2. node->next = node->next->next — the neighbour is unlinked.
    3. The list now looks exactly as if node had been removed.
    4. main builds 4 5 1 9, deletes the node holding 5, and prints before/after.
    Watch out. This trick cannot delete the tail (there is no next node to copy). The node that really disappears (old n3) is never freed in main.
    ✅ Check yourself: Which physical node is actually removed from the chain when you 'delete' 5 in 4 5 1 9?
    The node that held 1 (the next one). The 5 node stays but its value becomes 1.

https://leetcode.com/problems/intersection-of-two-linked-lists/

#include <iostream>
using namespace std;

// Definition for singly-linked list.
struct ListNode {
    int val;
    ListNode *next;
    // Default constructor.
    ListNode() : val(0), next(nullptr) {}
    // Constructor with a value.
    ListNode(int x) : val(x), next(nullptr) {}
    // Constructor with a value and a pointer to the next node.
    ListNode(int x, ListNode *next) : val(x), next(next) {}
};

class Solution {
public:
    ListNode *getIntersectionNode(ListNode *headA, ListNode *headB) {
        ListNode* tempA = headA;
        while(tempA != NULL){
            ListNode* tempB = headB;
            while(tempB != NULL){
                if(tempA == tempB){
                    return tempA;
                }
                tempB = tempB->next;
            }
            tempA = tempA->next;
        }
        return NULL;
    }
};

// Helper function to print a linked list.
void printList(ListNode* head) {
    while (head != nullptr) {
        cout << head->val << " -> ";
        head = head->next;
    }
    cout << "NULL" << endl;
}

int main() {
    // Create common nodes that will serve as the intersection part:
    // Intersection list: 8 -> 4 -> 5
    ListNode* common1 = new ListNode(8);
    ListNode* common2 = new ListNode(4);
    ListNode* common3 = new ListNode(5);
    common1->next = common2;
    common2->next = common3;
    
    // Create list A: 4 -> 1 -> 8 -> 4 -> 5
    ListNode* A1 = new ListNode(4);
    ListNode* A2 = new ListNode(1);
    A1->next = A2;
    A2->next = common1;  // Link to intersection
    
    // Create list B: 5 -> 6 -> 1 -> 8 -> 4 -> 5
    ListNode* B1 = new ListNode(5);
    ListNode* B2 = new ListNode(6);
    ListNode* B3 = new ListNode(1);
    B1->next = B2;
    B2->next = B3;
    B3->next = common1;  // Link to intersection

    // Print both lists.
    cout << "List A: ";
    printList(A1);
    cout << "List B: ";
    printList(B1);
    
    // Find the intersection.
    Solution sol;
    ListNode* intersection = sol.getIntersectionNode(A1, B1);
    
    if(intersection != nullptr) {
        cout << "Intersection at node with value: " << intersection->val << endl;
    } else {
        cout << "No intersection found." << endl;
    }
    
    // Clean up allocated memory.
    // Note: Since the intersection nodes are shared, they must be deleted only once.
    delete A1;
    delete A2;
    delete B1;
    delete B2;
    delete B3;
    delete common1;  // This also deletes common2 and common3 by following the chain.
    // (In a production system you might need a more sophisticated cleanup to avoid double-deletion.)
    
    return 0;
}
    Input

    This program reads no input.

    Output 
    List A: 4 -> 1 -> 8 -> 4 -> 5 -> NULL
List B: 5 -> 6 -> 1 -> 8 -> 4 -> 5 -> NULL
Intersection at node with value: 8

    Reading the output. Both lists are printed, then Intersection at node with value: 8 — the first shared node. Note the 1 in both lists is not the answer: they are different nodes with equal values.

    How it works, step by step
    1. Outer loop: tempA visits each node of list A.
    2. Inner loop: tempB restarts at headB and visits each node of B.
    3. If tempA == tempB (same address), that node is where the lists join — return it.
    4. If no pair matches, return NULL.
    5. main builds A = 4 1 [8 4 5] and B = 5 6 1 [8 4 5] where the bracketed part is shared.
    Watch out. The cleanup comment is wrong: delete common1 frees only that one node, not common2/common3 (they leak). Faster idea to try: two pointers that switch to the other list's head at the end meet at the intersection in O(n+m).
    ✅ Check yourself: Why is tempA->val == tempB->val the wrong test here?
    Different nodes can hold the same value (both lists contain a 1). Only the same address means the lists really share the node.

    /*

https://leetcode.com/problems/swapping-nodes-in-a-linked-list/

Swap the k-th node from the beginning of the list with the k-th node from the end,
and return the head.

The idea: a singly linked list only goes forward, so "the k-th from the end" cannot be
reached by walking backwards. Turn it into a distance from the head instead. In a list of
`length` nodes, the k-th node from the end is the (length - k + 1)-th from the start,
which is `length - k` steps away from the head. So: count the nodes once, then walk twice.

And the second trick: the problem only cares about the values, so swap the two `val`
fields instead of re-linking nodes. Swapping nodes properly would mean fixing the two
nodes before them as well, with special cases when the two are neighbours or one is the
head - much more code for the same visible result.

*/

#include <iostream>
#include <utility> // for std::swap
using namespace std;

// Definition for singly-linked list.
struct ListNode {
    int val;
    ListNode *next;
    // Default constructor.
    ListNode() : val(0), next(nullptr) {}
    // Constructor with a value.
    ListNode(int x) : val(x), next(nullptr) {}
    // Constructor with a value and a pointer to the next node.
    ListNode(int x, ListNode *next) : val(x), next(next) {}
};

class Solution {
public:
    ListNode* swapNodes(ListNode* head, int k) {
        // Pass 1: count the nodes. `while(currentNode)` is the short way of writing
        // `while(currentNode != NULL)` - a pointer counts as true unless it is null.
        int length = 0;
        ListNode* currentNode = head;
        while(currentNode){
            length++;
            currentNode = currentNode->next;
        }

        // Pass 2: the k-th node counting from the front, where the head is the 1st.
        // Starting i at 1 and stopping at i < k makes exactly k-1 steps, so k = 1 takes
        // no step at all and frontNode stays on the head.
        ListNode* frontNode = head;
        for(int i=1; i<k; i++){
            frontNode = frontNode->next;
        }

        // Pass 3: the k-th node counting from the back. That is length - k steps from the
        // head. Check it on the example: length = 5, k = 2, so 3 steps from node 1 lands
        // on node 4 - and 4 really is the 2nd node from the end.
        // The loop shape is different here (i <= length-k) but the effect is the same
        // count: length - k steps.
        ListNode* backNode = head;
        for(int i=1; i<=length-k; i++){
            backNode = backNode->next;
        }

        // Exchange only the numbers inside the two nodes. Every `next` pointer in the
        // list is untouched, so the list's shape is exactly as before.
        // (If k > length this would have walked off the end; LeetCode guarantees
        // 1 <= k <= length, so the code does not check.)
        swap(frontNode->val, backNode->val);

        // The head node itself never moves, so the same pointer is returned. Returning it
        // anyway is LeetCode's convention for list problems, where the head sometimes
        // does change.
        return head;
    }
    // Cost: three walks over the list, so O(n) time, and only a few pointers, O(1) space.
};

// Helper function to print the linked list.
// It is safe to move `head` itself here because the parameter is a copy of the caller's
// pointer (no `&`), so the caller's head is not disturbed.
void printList(ListNode* head) {
    while(head) {
        cout << head->val;
        // Print the arrow only between values, never after the last one.
        if(head->next) cout << " -> ";
        head = head->next;
    }
    cout << endl;
}

int main() {
    // Create a sample linked list: 1 -> 2 -> 3 -> 4 -> 5
    ListNode* n1 = new ListNode(1);
    ListNode* n2 = new ListNode(2);
    ListNode* n3 = new ListNode(3);
    ListNode* n4 = new ListNode(4);
    ListNode* n5 = new ListNode(5);

    n1->next = n2;
    n2->next = n3;
    n3->next = n4;
    n4->next = n5;

    cout << "Original list: ";
    printList(n1);

    // For example, let's swap the 2nd node from the beginning and the 2nd node from the end.
    // 2nd from the front is the node holding 2; 2nd from the end is the node holding 4.
    // So the printed list becomes 1 -> 4 -> 3 -> 2 -> 5.
    int k = 2;
    // LeetCode's method lives inside a class, so an object is needed to call it. On the
    // judge this `main` does not exist - only `class Solution` is submitted.
    Solution sol;
    ListNode* swappedHead = sol.swapNodes(n1, k);

    cout << "List after swapping kth nodes (k = " << k << "): ";
    printList(swappedHead);

    // Free allocated memory. Every `new` above has a matching `delete` here, and the
    // nodes are still reachable through n1..n5 because only values were swapped, not
    // links. Deleting is done after the last print - touching a node after `delete` is
    // undefined behaviour.
    delete n1;
    delete n2;
    delete n3;
    delete n4;
    delete n5;

    return 0;
}
    Input

    This program reads no input.

    Output 
    Original list: 1 -> 2 -> 3 -> 4 -> 5
List after swapping kth nodes (k = 2): 1 -> 4 -> 3 -> 2 -> 5

    Reading the output. 1 -> 2 -> 3 -> 4 -> 5 becomes 1 -> 4 -> 3 -> 2 -> 5: the 2nd from the front (2) and 2nd from the back (4) switched.

    How it works, step by step
    1. Count the nodes into length.
    2. frontNode starts at head and moves k-1 steps: the k-th node from the start.
    3. backNode starts at head and moves length-k steps: the k-th node from the end.
    4. swap(frontNode->val, backNode->val) exchanges only the values; links stay the same.
    5. main uses 1 2 3 4 5 with k = 2.
    ✅ Check yourself: For a list of length 7 and k = 3, how many steps does backNode take from the head?
    length - k = 4 steps, landing on the 5th node, which is the 3rd from the end.
