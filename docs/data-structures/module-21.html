    Basic Data Structures · Module 21

    Binary search trees: search, insert, build from a sorted array

    This module introduces the binary search tree (BST): a binary tree where everything on the left is smaller than the node and everything on the right is bigger. That one rule lets you throw away half the tree at every step, so search and insert take time proportional to the height, not the number of nodes. You also learn how to build a balanced BST from a sorted array by always picking the middle element as the root.

    💡 Key ideas

    BST rule

    For every node, all values in its left subtree are smaller and all values in its right subtree are bigger. The rule must hold for the whole subtree, not just the direct children.

    Search by comparing

    Compare the target with the current node. Equal means found; smaller means go left; bigger means go right. Reaching NULL means the value is not in the tree.

    if (val < root->val) return search(root->left, val);
else return search(root->right, val);

    Insert walks the same path as search

    A new value always becomes a leaf. Follow the search path until the child you need is NULL, then hang the new node there.

    Height decides speed

    Search and insert cost O(h). A balanced tree has h about log2(n); a tree built from sorted inserts becomes a chain with h = n.

    Sorted array to balanced BST

    Take the middle element as root, build the left half into the left subtree and the right half into the right subtree. Both halves have about the same size, so the tree stays balanced.

    int mid = (start + end) / 2;
root->left = convert(a, start, mid - 1);
root->right = convert(a, mid + 1, end);

    In-order of a BST is sorted

    Visiting left, node, right in a BST prints the values in increasing order. This is a quick way to check that a tree really is a BST.

    #include <iostream>
#include <queue>
#include <utility>
#include <vector>
using namespace std;

class Node{
    public:
        int val;
        Node* left;
        Node* right;

    Node(int val){
        this->val;
        this->left = NULL;
        this->right = NULL;
    }
};

Node* input_tree(){
    int val;
    cin >> val;
    Node* root;

    if(val == -1){
        root = NULL;
    } else{
        root = new Node(val);
    }

    queue<Node*> q;
    if(root){
        q.push(root);
    }

    while(!q.empty()){
        Node* p = q.front();
        q.pop();

        int l, r;
        cin >> l >> r;

        Node* myLeft;
        Node* myRight;

        if(l == -1){
            myLeft = NULL;
        } else{
            myLeft = new Node(l);
        }

        if(r == -1){
            myRight = NULL;
        } else{
            myRight = new Node(r);
        }

        p->left = myLeft;
        p->right = myRight;

        if(p->left){
            q.push(p->left);
        }
        if(p->right){
            q.push(p->right);
        }
    }
    return root;
}

bool search(Node* root, int val){
    if(root == NULL){
        return false;
    }
    if(root->val == val){
        return true;
    }

    if(val < root->val){
        return search(root->left, val);
    } else{
        return search(root->right, val);
    }
}

int main(){
    Node* root = input_tree();
    int val;
    cin >> val;

    if(search(root, val)){
        cout << "Found\n";
    } else{
        cout << "Not Found\n";
    }

    return 0;
}
    Input (stdin)
    20 10 30 5 15 25 40 -1 -1 -1 -1 -1 -1 -1 -1
15

    The tree in level order: root 20, children 10 and 30, then 5 15 25 40, then eight -1s for the empty children of the leaves. Last line: the value to look for (15).

    Output 
    Not Found

    Reading the output. You will see Not Found even though 15 is in the tree. That is the constructor bug described below, not a problem with the search logic.

    How it works, step by step
    1. input_tree reads the root, then uses a queue: for each node taken out it reads the left and right child values and creates nodes for the ones that are not -1.
    2. search(root, val) returns false when it falls off the tree (root == NULL).
    3. If root->val == val it returns true.
    4. Otherwise it goes left when val is smaller and right when it is bigger, so only one branch is explored per level.
    5. main prints Found or Not Found based on the result.
    Watch out. The constructor writes this->val; instead of this->val = val;, so every node keeps a garbage value and the search almost never matches. Fix: change that line to this->val = val; and the sample prints Found.
    ✅ Check yourself: Searching for 27 in this tree, which nodes are visited?
    20 (27 is bigger, go right), 30 (27 is smaller, go left), 25 (27 is bigger, go right), then NULL, so the answer is Not Found.

void level_order(Node* root){
    queue<Node *> q; // Create a queue to store nodes in level order traversal order
    q.push(root); // Push the root node into the queue

    while(!q.empty()){ 
        Node* f = q.front(); 
        q.pop();
        cout << f->val << " "; // Print the value of the current node
        if(f->left){
            q.push(f->left);
        }
        if(f->right){
            q.push(f->right);
        }
    }
}

void insert(Node* & root, int val){
    if(root == NULL){
        root = new Node(val);
    }
    if(val < root->val){
        if(root->left == NULL){
            root->left = new Node(val);
        } else{
            insert(root->left, val);
        }
    }

    if(val > root->val){
        if(root->right == NULL){
            root->right = new Node(val);
        } else {
            insert(root->right, val);
        }
    }
}

    insert(root, val);
    level_order(root);
}

    20 10 30 5 15 25 40 -1 -1 -1 -1 -1 -1 -1 -1
13

    The same 7-node BST as the search program, then the value 13 to insert.

    Output 
    20 10 30 5 15 25 40 13

    Reading the output. 20 10 30 5 15 25 40 13: the tree is printed level by level. 13 appears last because it went 20 -> left to 10 -> right to 15 -> left, making it a new node on the fourth level.

    How it works, step by step
    1. insert(Node* &root, int val) takes the root by reference so it can create the root when the tree is empty.
    2. If val is smaller than root->val: if the left child is empty, put a new node there; otherwise recurse into the left child.
    3. If val is bigger: do the same on the right side.
    4. Equal values fall through both checks, so duplicates are simply ignored.
    5. level_order prints the tree with a queue so you can see where the new node landed.
    Watch out. level_order pushes root without checking for NULL, so an empty tree (-1 as the first number) would crash while printing.
    ✅ Check yourself: Why is root passed as Node* &?
    So that when the tree is empty the function can make root point to the new node and the caller sees the change.

Node* convert(int a[], int size, int start, int end){
    if(start > end){
        return NULL;
    }
    int mid = (start + end) / 2;
    Node* root = new Node(a[mid]);
    Node* leftroot = convert(a, size, start, mid-1);
    Node* rightroot = convert(a, size, mid+1, end);
    root->left = leftroot;
    root->right = rightroot;
    return root;
}

    7
1 2 3 4 5 6 7

    n, then n values in increasing order.

    Output 
    4 2 6 1 3 5 7

    Reading the output. 4 2 6 1 3 5 7: 4 is the middle of the whole array, 2 and 6 are the middles of the two halves, and 1 3 5 7 are the leaves. A perfectly balanced tree of height 3.

    How it works, step by step
    1. convert(a, size, start, end) works on the part a[start..end]; if start > end the part is empty and it returns NULL.
    2. It picks mid = (start + end) / 2 and makes a[mid] the root of this part.
    3. The left half start..mid-1 becomes the left subtree and the right half mid+1..end becomes the right subtree, both built recursively.
    4. Because the array is sorted, everything on the left is smaller and everything on the right is bigger, so the BST rule holds automatically.
    5. main calls convert(a, n, 0, n-1) and prints the result with level_order.
    Watch out. The input must already be sorted; the code does not sort it. An unsorted array gives a tree that breaks the BST rule.
    ✅ Check yourself: For the array 1 2 3 4, which value becomes the root and why?
    2, because mid = (0 + 3) / 2 = 1 and a[1] = 2.

Convert Sorted Array to Binary Search Tree

Given an integer array nums where the elements are sorted in ascending order, convert 
it to a height-balanced binary search tree.

Example 1:
Input: nums = [-10,-3,0,5,9]
Output: [0,-3,9,-10,null,5]
Explanation: [0,-10,5,null,-3,null,9] is also accepted:

Example 2:
Input: nums = [1,3]
Output: [3,1]
Explanation: [1,null,3] and [3,1] are both height-balanced BSTs.

Constraints:

- 1 <= nums.length <= 10^4
- -10^4 <= nums[i] <= 10^4
- nums is sorted in a strictly increasing order.

*/

/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    TreeNode* array_to_BST(vector<int>& nums, int start, int end) {
        if(start > end){
            return NULL;
        }
        int mid = (start + end) / 2;
        TreeNode* root = new TreeNode(nums[mid]);
        TreeNode* leftroot = array_to_BST(nums, start, mid-1);
        TreeNode* rightroot = array_to_BST(nums, mid+1, end);
        root->left = leftroot;
        root->right = rightroot;
        return root;
    }

    TreeNode* sortedArrayToBST(vector<int>& nums) {
        TreeNode* root = array_to_BST(nums, 0, nums.size() - 1);
        return root;
    }
};

https://leetcode.com/problems/search-in-a-binary-search-tree/

Search in a Binary Search Tree

You are given the root of a binary search tree (BST) and an integer val.

Find the node in the BST that the node's value equals val and return the subtree 
rooted with that node. If such a node does not exist, return null.

Input: root = [4,2,7,1,3], val = 2
Output: [2,1,3]

Input: root = [4,2,7,1,3], val = 5
Output: []
 

Constraints:

The number of nodes in the tree is in the range [1, 5000].
- 1 <= Node.val <= 10^7
- root is a binary search tree.
- 1 <= val <= 10^7

*/



/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:

    TreeNode* search(TreeNode* root, int val){
        if(root == NULL){
            return NULL;
        }
        if(root->val == val){
            return root;
        }

        if(val < root->val){
            return search(root->left, val);
        } else{
            return search(root->right, val);
        }
    }

    TreeNode* sub_tree(TreeNode* node){
        if(node == NULL){
            return NULL;
        }
        TreeNode* leftNode = sub_tree(node->left);
        TreeNode* rightNode = sub_tree(node->right);
        node->left = leftNode;
        node->right = rightNode;
        return node;
    }

    TreeNode* searchBST(TreeNode* root, int val) {
        TreeNode* node_found = search(root, val);
        TreeNode* tree = sub_tree(node_found);
        return tree;
    }
};

    queue<TreeNode*> q; q.push(root);
    while (!q.empty()) {
        TreeNode* cur = q.front(); q.pop();
        int l, r; cin >> l >> r;
        if (l != -1) { cur->left = new TreeNode(l); q.push(cur->left); }
        if (r != -1) { cur->right = new TreeNode(r); q.push(cur->right); }
    }
    return root;
}
void printLevels(TreeNode* root) {   // one line per level
    if (!root) { cout << "(empty tree)" << endl; return; }
    queue<TreeNode*> q; q.push(root);
    while (!q.empty()) {
        int k = q.size();
        for (int i = 0; i < k; i++) {
            TreeNode* t = q.front(); q.pop();
            cout << t->val << " ";
            if (t->left) q.push(t->left);
            if (t->right) q.push(t->right);
        }
        cout << endl;
    }
}
int main() {
    TreeNode* root = readTree();
    int t; cin >> t;
    while (t--) {
        int val; cin >> val;
        cout << "searchBST(" << val << "):" << endl;
        printLevels(Solution().searchBST(root, val));
    }
}

    Reading the output. searchBST(2) prints the subtree 2 / 1 3, matching LeetCode's [2,1,3]. searchBST(5) prints (empty tree) because 5 is not in the BST, matching [].

    How it works, step by step
    1. search is the usual BST search, but it returns the node pointer instead of true/false, and NULL when not found.
    2. sub_tree walks the whole subtree and re-assigns each child to itself; it changes nothing, it just returns node.
    3. searchBST returns the found node, which LeetCode prints together with everything below it.
    Watch out. sub_tree is unnecessary: a node pointer already carries its whole subtree. return search(root, val); is enough.
    ✅ Check yourself: Why doesn't returning the node lose its children?
    The node still holds its left and right pointers, so whoever receives it can reach the whole subtree.

    📌 Remember

    • BST: left subtree smaller, right subtree bigger, for every node.
    • Search and insert follow one path down, so they cost O(height).
    • A new value is always inserted as a leaf.
    • Middle element as root turns a sorted array into a balanced BST.
    • In-order traversal of a BST gives the values in sorted order.

    ✅ Check yourself

    You insert 1, 2, 3, 4, 5 in this order into an empty BST. What does the tree look like and what is the search cost?
    A chain going right (1 -> 2 -> 3 -> 4 -> 5). Height is 5, so search is O(n) instead of O(log n).
    Is a tree with root 10, left child 5, and 5's right child 12 a valid BST?
    No. 12 is in the left subtree of 10 but is bigger than 10.
    How many comparisons at most does it take to search a balanced BST with 1023 nodes?
    About 10, because the height of a balanced tree with 1023 nodes is 10.
