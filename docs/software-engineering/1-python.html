    First steps in Python

    This is the first folder of the Software Engineering Track and a first Python program. After months of C, Python feels very light: there is no main, no #include, no semicolons and no compiling. You write a line and the interpreter runs it from top to bottom.

    💡 Key ideas

    Interpreted, top to bottom

    Python reads the file and runs each line in order. There is no compile step and no main() function you must write.

    print()

    print writes its arguments and then adds a newline by itself, so you don't need to type \n as you do in C's printf.

    print("Hello World")

    Strings in quotes

    Text goes inside single or double quotes. Both kinds work the same way.

    print('Hi')
print("Hi")

    Running a script

    From a terminal, type python first.py. The output shows up right away.

    Reading the output. You should see exactly one line: Hello World.

    How it works, step by step
    1. print("Hello World") is the only line in the file.
    2. Python passes the string to print, which writes it and then a newline.
    3. The script ends when there are no more lines. There is no return 0.
    Watch out. Python 3 needs the brackets: print "Hello" (without them) is Python 2 syntax and raises a SyntaxError.
    ✅ Check yourself: What is the C line that does the same thing, and what does Python add for you?
    printf("Hello World\n");. Python's print adds the newline for you.

    📌 Remember

    • Python runs the file from top to bottom. There is no main and no compiling.
    • print() adds a newline at the end by itself.
    • Strings can use single or double quotes.
    • Run a script with python file.py.

    ✅ Check yourself

    Name two things a C Hello World needs that the Python one does not.
    Any two of these: #include <stdio.h>, a main function, semicolons, return 0, a compile step.
    How many lines does print("a"); print("b") print?
    Two, because each print ends with its own newline.
