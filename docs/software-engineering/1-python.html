    First steps in Python

    This is the first folder of the Software Engineering Track and a first Python program. After months of C, Python feels very light: there is no main, no #include, no semicolons and no compiling. You write a line and the interpreter runs it from top to bottom.

    🧭 Start here

    You have spent a year with C and then C++: headers, a main, a type for every variable, a semicolon on every line, braces round every block, and a compiler that refuses to build the program until all of that is right.

    Python drops nearly all of it. Here is the same program - print one line of text - in both languages, side by side.

    C                          Python
-------------------------  --------------------
#include <stdio.h>
int main(){
  printf("Hello World\n"); print("Hello World")
  return 0;
}

    Four lines become one, and nothing is missing. There is no header to include, because print is always there. There is no main: Python starts at the first line of the file and runs down to the last one. There is no return 0 and no build step - you type python first.py and it runs.

    print is not printf. It has no format specifiers: you hand it the things you want printed and it works out how to show them. It also adds the newline for you, which is why the \n disappeared.

    Variables need no type. You do not write int n; - you write n = 5, and Python decides that n is a whole number. Write n = "five" on the next line and it is now text. Nothing has to be declared before it is used.

    n = 5
name = "Rafi"
print(name, "has", n, "books")
# Rafi has 5 books

    Braces are gone too, and this is the one change that trips people up. In C, indentation was politeness and { } decided what belonged to the if. In Python, indentation is the syntax. A line ending in a colon opens a block, and everything indented under it belongs to that block.

    Four spaces is the usual step. Mixing tabs and spaces, or indenting by different amounts inside one block, is an error and not a matter of taste.

    for i in range(1, 6):
    if i % 2 == 0:
        print(i, "is even")
    else:
        print(i, "is odd")

    Input works differently in a way worth learning on day one. scanf("%d", &n) told C that the next thing is a number. input() makes no such promise: it reads one line and gives you text, always. If you want a number, you convert it yourself with int() or float().

    Forget the conversion and nothing crashes - you get a wrong answer, which is worse. With the two lines 3 and 4 typed in:

    a = input()        a = int(input())
b = input()        b = int(input())
print(a + b)       print(a + b)

34                 7
(text joined)      (numbers added)

    One caution to carry over from C. In C, 7 / 2 with two ints gave 3, because division between whole numbers threw the remainder away. In Python, / always produces a decimal: 7 / 2 is 3.5, and 6 / 2 is 3.0, not 3. The C-style division is spelled //, so 7 // 2 is 3. Use // whenever you want a whole number - counting halves, splitting into groups, taking a middle index. One more difference: // rounds down, so -7 // 2 is -4, while C's / gave -3.

    Why any of this is worth your time: the same idea takes a third of the lines, there is no compile step, so testing a thought costs seconds. The price is that the compiler no longer checks your types - a mistake that C would have refused to build now waits quietly until that line runs.

    The file below is a one-line Hello World. Run it, see the output, and you know your Python installation works.

    💡 Key ideas

    Interpreted, top to bottom

    Python reads the file and runs each line in order. There is no compile step and no main() function you must write.

    print()

    print writes its arguments and then adds a newline by itself, so you don't need to type \n as you do in C's printf.

    print("Hello World")

    Strings in quotes

    Text goes inside single or double quotes. Both kinds work the same way.

    print('Hi')
print("Hi")

    Running a script

    From a terminal, type python first.py. The output shows up right away.

    # The first Python program, after a year of C and C++.
#
# This is the whole file. Compare it with the C version you have written many times:
#
#     #include <stdio.h>          <- Python has no #include here. print is always there.
#     int main(){                 <- Python has no main. The file itself is the program,
#                                    and the interpreter runs it from the first line to
#                                    the last, in order.
#         printf("Hello World\n");
#         return 0;               <- Python has no return 0. The script ends when the
#     }                              lines run out.
#
# Three more things that have quietly disappeared:
#   * No semicolons. The end of the line ends the statement.
#   * No braces and no types. Nothing here needs to be declared before it is used.
#   * No compiling. There is no gcc step and no .exe; you run the source file directly
#     with `python first.py` and the output appears at once. Python reads and executes,
#     which is why it is called an interpreted language.
#
# The one line below:
#   print   - a function that is built into the language, so no header is needed.
#   ( ... ) - the brackets are how you call it, and in Python 3 they are required.
#             `print "Hello World"` is old Python 2 syntax and is a SyntaxError now.
#   " ... " - a string. Single quotes work exactly the same: 'Hello World'.
#
# And one difference that is easy to miss: there is no \n in the text. printf prints
# exactly what you give it, so in C you had to add the newline yourself. Python's print
# adds a newline after every call, so two prints already give two lines.
print("Hello World")

    This program reads no input.

    Output 
    Hello World

    Reading the output. You should see exactly one line: Hello World.

    How it works, step by step
    1. print("Hello World") is the only line in the file.
    2. Python passes the string to print, which writes it and then a newline.
    3. The script ends when there are no more lines. There is no return 0.
    Watch out. Python 3 needs the brackets: print "Hello" (without them) is Python 2 syntax and raises a SyntaxError.
    ✅ Check yourself: What is the C line that does the same thing, and what does Python add for you?
    printf("Hello World\n");. Python's print adds the newline for you.

    📌 Remember

    • Python runs the file from top to bottom. There is no main and no compiling.
    • print() adds a newline at the end by itself.
    • Strings can use single or double quotes.
    • Run a script with python file.py.

    How many lines does print("a"); print("b") print?
