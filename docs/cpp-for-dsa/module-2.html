    Introduction to C++ for DSA · Module 2

    Dynamic memory: new, delete and heap arrays

    Module 2 practises basic C++ on judge problems and then introduces the heap. You learn why a local variable dies with its function, how new keeps memory alive, how to return an array from a function, and how to "resize" an array by copying.

    12 programs5 practice linksFolder on GitHub ↗

    🧭 Start here

    Picture a sheet of paper on which you must write the marks of a class, and nobody has told you yet how many students there are. You can rule a thousand lines and waste the page, or rule thirty and run out halfway. What you want is to hear the number first and cut the paper to size after that.

    You have met this in C. int a[5]; fixes the size while you are still typing the program, so the size has to be a guess. malloc was the way out: read n first, then ask for room for exactly n numbers. Module 2 is that same idea in C++ clothes, and it also makes plain what C left vague: where the room comes from, and who takes it back.

    The memory your program uses is split in two. Ordinary variables live in the stack: int x = 10; and int a[5]; are both there. The stack is automatic. Room is taken when the variable is created and handed back the moment the function it lives in ends. You never ask for it and you never get a say.

    The other area is the heap. Nothing is taken there unless you ask, and nothing is given back unless you say so. new is how you ask, delete is how you give back:

    int x = 10;          // a box on the stack, named x
int *p = new int;    // a box on the heap, no name
*p = 100;            // write 100 into that box
cout << *p << endl;  // 100
delete p;            // hand the box back

    It is worth drawing, because the heap box has no name of its own. The only way back to it is the address kept in p, and p itself is an ordinary stack variable:

    stack                   heap
------------            ----------------
x = 10
p = 0x1a2b40 ---------> 0x1a2b40:  100
                        this box has no name;
                        p is the only way to it

    So p is 0x1a2b40, an address, and *p is 100, the thing at that address. That part you know already. **What is new is the pair new and delete.** No size in bytes to work out, no cast to write: new int means one int, new int[n] means n of them, delete p gives back one, delete[] p gives back an array.

    If you never say delete, the box is never given back, not even after you have lost the address that led to it. That is a memory leak: memory your program still holds but can no longer reach or use. One leaked int costs 4 bytes and nobody notices; a leak inside a loop that runs a million times eats 4 megabytes and keeps going.

    The second use of the heap is the one that makes it worth having. A stack variable dies with its function. If a function stores 10 in a local x and hands out &x, the address survives but the box does not, and reading through it afterwards means reading memory that is no longer yours. It often still prints 10, so the bug hides. Put the value on the heap and the box is simply still there:

    fun():  int x = 10;   p = &x;
fun ends -> x's box is handed back
main:   *p  reads a box that is not ours

fun():  int *x = new int;  *x = 10;  p = x;
fun ends -> the heap box is untouched
main:   *p  is 10

    The same rule decides how a function hands an array back to main. A local int a[5] cannot be returned, because it dies with the function; int *p = new int[5] can, because it does not. A third use: no array can be made bigger after it exists. What you can do is ask for a bigger one, copy the old values across and carry on with the new one — three values in a 3-box array become those three plus two more in a 5-box array. The copying costs as many steps as the array is long, which is why you grow in jumps and not one element at a time.

    The first five programs below are ordinary practice written with cin and cout. After them come the memory programs: a dynamic variable, a static array beside a dynamic one, the dying-local trap and its fix, returning an array, and growing one by copying.

    💡 Key ideas

    Stack memory

    Local variables live in the function's stack frame and disappear when it returns.

    Heap memory with new

    new reserves memory that stays until you delete it.

    int *p = new int;

    Dynamic arrays

    new int[n] gives an array on the heap; free it with delete[].

    int *a = new int[n]; /* ... */ delete[] a;

    Dangling pointer

    A pointer to memory that has already been freed; reading it is undefined behaviour.

    Returning arrays

    Return a pointer to a heap array, never the address of a local array.

    Resizing by copying

    Make a bigger array, copy old items, add new ones, delete the old one.

Simple Calculator
time limit per test: 1 second
memory limit per test: 256 megabytes
Given two numbers X and Y. Print the summation and multiplication and subtraction of these 2 numbers.

Input
Only one line containing two separated numbers X, Y (1  ≤  X, Y  ≤  105).

Output
Print 3 lines that contain the following in the same order:

"X + Y = summation result" without quotes.
"X * Y = multiplication result" without quotes.
"X - Y = subtraction result" without quotes.

Example
Input
5 10
Output
5 + 10 = 15
5 * 10 = 50
5 - 10 = -5
Note
Be careful with spaces.

*/

using namespace std;

int main(){

    cin >> x >> y;

    cout << x << " + " << y << " = " << x + y << endl;
    cout << x << " * " << y << " = " << x * y << endl;
    cout << x << " - " << y << " = " << x - y << endl;

Capital or Small or Digit
time limit per test: 1 second
memory limit per test: 256 megabytes

Given a letter X. Determine whether X is Digit or Alphabet and if it is Alphabet determine if it is Capital Case or Small Case.

Note:

Digits in ASCII '0' = 48,'1' = 49 ....etc
Capital letters in ASCII 'A' = 65, 'B' = 66 ....etc
Small letters in ASCII 'a' = 97,'b' = 98 ....etc
Input
Only one line containing a character X which will be a capital or small letter or digit.

Output
Print a single line contains "IS DIGIT" if X is digit otherwise, print "ALPHA" in the first line followed by a new line that contains "IS CAPITAL" if X is a capital letter and "IS SMALL" if X is a small letter.

using namespace std;

int main(){
    char x;
    cin >> x;

    if(x >= '0' && x<= '9'){
        cout << "IS DIGIT" << endl;
    } else{
        cout << "ALPHA" << endl;
    }

    if(x >= 'A' && x <= 'Z'){
        cout << "IS CAPITAL" << endl;
    } else if(x >= 'a' && x <= 'z'){
        cout << "IS SMALL" << endl;
    }

    return 0;
}

    ✅ Check yourself: Why can you compare x >= 'a' directly?
    Characters are ASCII numbers, and the letters a-z are consecutive codes (97-122).

    /*

Max and Min
time limit per test: 0.25 seconds
memory limit per test: 64 megabytes
Given 3 numbers A, B and C, Print the minimum and the maximum numbers.

Input
Only one line containing 3 numbers A, B and C ( - 105 ≤ A, B, C ≤ 105)

Output
Print the minimum number followed by a single space then print the maximum number.

Examples
Input
1 2 3
Output
1 3
Input
-1 -2 -3
Output
-3 -1
Input
10 20 -5
Output
-5 20

*/

#include <iostream>
using namespace std;

int main(){
    int a, b, c;
    cin >> a >> b >> c;

    int min = a;
    if(b < min){
        min = b;
    }
    if(c < min){
        min = c;
    }

    int max = a;
    if(b > max){
        max = b;
    }
    if(c > max){
        max = c;
    }

    cout << min << " " << max << endl;

    return 0;
}
    Input (stdin)
    10 -4 7

    Three integers A B C.

    Output 
    -4 10

    Reading the output. With 10 -4 7 it prints -4 10.

    How it works, step by step
    1. Set min = a, then replace it if b or c is smaller.
    2. Set max = a, then replace it if b or c is larger.
    3. Print min max.
    ✅ Check yourself: How would you write this with the built-ins?
    cout << min({a,b,c}) << " " << max({a,b,c});

    /*

Max
time limit per test: 1 second
memory limit per test: 256 megabytes
Given a number N, and N numbers, find maximum number in these N numbers.

Input
First line contains a number N (1 ≤ N ≤ 103).

Second line contains N numbers Xi (0 ≤ Xi ≤ 109).

Output
Print the maximum number.

Example
Input
5
1 8 5 7 5
Output
8

*/

#include <iostream>
using namespace std;

int main(){
    int n;
    cin >> n;

    int arr[n];
    for(int i=0; i<n; i++){
        cin >> arr[i];
    }

    int max = arr[0];
    for(int i=1; i<n; i++){
        if(arr[i] > max){
            max = arr[i];
        }
    }

    cout << max << endl;

    return 0;
}
    Input (stdin)
    6
4 19 2 19 7 3

    First line N, then N numbers.

    Output 
    19

    Reading the output. For 4 19 2 19 7 3 it prints 19 (duplicates don't matter).

    How it works, step by step
    1. Read n and the array arr.
    2. Start with max = arr[0].
    3. For every later element, if it is bigger, update max.
    4. Print max.
    ✅ Check yourself: Why start max at arr[0] instead of 0?
    If all numbers were negative, 0 would be wrong; the first element is always a valid candidate.

    /*

Reversing
time limit per test: 1 second
memory limit per test: 64 megabytes
Given a number N and an array A of N numbers. Print the array in a reversed order.

Note:

*Don't use built-in-functions.

Input
First line contains a number N (1 ≤ N ≤ 103) number of elements.

Second line contains N numbers (0 ≤ Ai ≤ 109).

Output
Print the array in a reversed order.

Examples
Input
4
5 1 3 2
Output
2 3 1 5 

Input
5
1 2 3 4 5
Output
5 4 3 2 1 

 */

#include <iostream>
using namespace std;

int main(){
    int n;
    cin >> n;

    int arr[n];
    for(int i=0; i<n; i++){
        cin >> arr[i];
    }

    for(int i=n-1; i>=0; i--){
        cout << arr[i] << " ";
    }

    return 0;
}
    Input (stdin)
    5

    First line N, then N numbers.

    Output 
    7 2 8 1 9

    Reading the output. With 9 1 8 2 7 it prints 7 2 8 1 9 .

    How it works, step by step
    1. Read n and the array.
    2. Loop i from n-1 down to 0.
    3. Print arr[i] followed by a space.
    ✅ Check yourself: How would you reverse the array in place with swap?
    Swap arr[i] and arr[n-1-i] for i from 0 to n/2 - 1.

using namespace std; // Use the standard namespace to avoid prefixing std:: before standard functions

int main(){
    // Static array
    // Declare a static array 'a' of size 5. Static arrays are allocated on the stack.
    int a[5];
    // Use a for loop to take input for each element of the static array 'a'
    for(int i=0; i<5; i++){
        cin >> a[i]; // Read input from the user and store it in the array 'a'
    }
    // Use another for loop to print each element of the static array 'a'
    for(int i=0; i<5; i++){
        cout << a[i] << " "; // Print the value of each element in the array 'a'
    }

    cout << endl; // Print a newline character for better output formatting

    // Dynamic array
    // Declare a pointer 'p' and allocate memory for an array of 5 integers in the heap using the 'new' keyword
    int *p = new int[5];
    // Use a for loop to take input for each element of the dynamic array pointed to by 'p'
    for(int i=0; i<5; i++){
        cin >> p[i]; // Read input from the user and store it in the dynamic array
    }

    // Use another for loop to print each element of the dynamic array pointed to by 'p'
    for(int i=0; i<5; i++){
        cout << p[i] << " "; // Print the value of each element in the dynamic array
    }

    // Free the dynamically allocated memory to avoid memory leaks
    delete[] p;

    return 0; // Return 0 to indicate successful execution of the program
}
    Input (stdin)
    1 2 3 4 5
10 20 30 40 50

    Two lines of 5 integers: one for each array.

    Output 
    1 2 3 4 5 
10 20 30 40 50

    Reading the output. Line 1 1 2 3 4 5 from the static array, line 2 10 20 30 40 50 from the dynamic one.

    How it works, step by step
    1. int a[5]; is a fixed stack array; read 5 values and print them.
    2. int *p = new int[5]; makes a 5-int array on the heap.
    3. p[i] works exactly like a[i].
    4. delete[] p; gives the heap memory back.
    ✅ Check yourself: Which delete goes with new int[5]?
    delete[] p; (with brackets).

    #include <iostream> // Include the iostream library for input and output operations
using namespace std; // Use the standard namespace to avoid prefixing std:: before standard functions

int *p; // Declare a global pointer variable 'p' which can be accessed by all functions

// Define a function 'fun' which demonstrates the use of stack memory
void fun(){
    int x = 10; // Declare an integer variable 'x' in stack memory and initialize it to 10
    p = &x; // Assign the address of 'x' to the global pointer 'p'
    cout << "Fun -> " << x << endl; // Print the value of 'x' using cout
    return; // Return from the function
}

// Define the main function which is the entry point of the program
int main(){
    fun(); // Call the function 'fun'
    // Fun -> 10
    // The following line will print an undefined value or may cause a runtime error
    // because 'x' is a stack variable and its memory is deallocated after 'fun' returns
    cout << "Main -> " << *p << endl; // Dereference the pointer 'p' and print the value it points to
    // Main -> 10
    return 0; // Return 0 to indicate successful execution of the program
}
    Input

    This program reads no input.

    Output 
    Fun -> 10
Main -> 0

    Reading the output. Fun -> 10 is correct. Main -> 0 shows garbage: the old stack slot was reused. On another machine it may show 10 or crash.

    How it works, step by step
    1. fun() makes int x = 10 on its stack frame and stores &x in global p.
    2. fun() prints 10 and returns - its frame is freed.
    3. main reads *p, which now points to dead memory.
    Watch out. Never return or keep the address of a local variable. Use new (see the next file).
    ✅ Check yourself: Why is Main -> 0 not 10 here?
    x was a local variable; its memory was released when fun returned, so the value is no longer guaranteed.

    #include <iostream> // Include the iostream library for input and output operations
using namespace std; // Use the standard namespace to avoid prefixing std:: before standard functions

int *p; // Declare a global pointer variable 'p' which can be accessed by all functions

// Define a function 'fun' which demonstrates the use of dynamic memory allocation
void fun(){
    int *x = new int; // Dynamically allocate memory for an integer variable 'x' in the heap
    *x = 10; // Assign the value 10 to the memory location pointed to by 'x'
    p = x; // Assign the address of the dynamically allocated memory to the global pointer 'p'
    cout << "Fun -> " << *p << endl; // Print the value stored in the dynamically allocated memory using cout
    return; // Return from the function
}

// Define the main function which is the entry point of the program
int main(){
    fun(); // Call the function 'fun'
    // Fun -> 10
    // The following line will print the value stored in the dynamically allocated memory
    // because 'x' is a dynamic variable and its memory is not deallocated until we explicitly delete it
    cout << "Main -> " << *p << endl; // Dereference the pointer 'p' and print the value it points to
    // Main -> 10
    return 0; // Return 0 to indicate successful execution of the program
}
    Input

    This program reads no input.

    Output 
    Fun -> 10
Main -> 10

    Reading the output. Both lines show 10: Fun -> 10 and Main -> 10.

    How it works, step by step
    1. fun() does int *x = new int; *x = 10; p = x;.
    2. Heap memory is not freed when fun returns.
    3. main safely prints *p.
    ✅ Check yourself: When is this heap int freed?
    Only when someone calls delete p; (the program never does, so the OS frees it at exit).

    #include <stdio.h>
int *p;
void fun(void) {
    static int x = 10;  /* lives for the whole program */
    p = &x;
    printf("Fun -> %d\n", x);
}
int main(void) {
    fun();
    printf("Main -> %d\n", *p);
    return 0;
}
    Input

    Reading the output. The driver prints Fun -> 10 and Main -> 10: the static variable is still alive in main.

    How it works, step by step
    1. A static int x inside fun() is created once and kept for the whole program run.
    2. p = &x is therefore safe to use later in main.
    3. Unlike heap memory it needs no delete, but there is only one copy shared by all calls.
    Watch out. The source file is empty, so on its own it cannot become a program; the code under the test driver is only an illustration.

    It is created once and lives until the program ends, instead of dying when the function returns.

    int *y = dynamic_array(); // Call the function 'dynamic_array' and store the returned pointer

    #include <iostream> // Include the iostream library for input and output operations
using namespace std; // Use the standard namespace to avoid prefixing std:: before standard functions

int main(){
    // First we create a static array 'a' of size 3
    // Static arrays are allocated on the stack and have a fixed size
    int a[3];
    cout << "Enter the elements of the static array: " << endl;
    // Use a for loop to take input for each element of the static array 'a'
    for(int i=0; i<3; i++){
        cin >> a[i]; // Read input from the user and store it in the array 'a'
    }

    // Create another static array 'b' of size 5
    // This array is larger to accommodate additional elements
    int b[5];
    // Copy the elements of array 'a' into array 'b'
    for(int i=0; i<3; i++){
        b[i] = a[i]; // Copy each element from 'a' to 'b'
    }
    // Add additional elements to the new positions in array 'b'
    b[3] = 40;
    b[4] = 50;

    // Print the elements of the new static array 'b'
    cout << "The elements of the new array after using an array of size 5 are: " << endl;
    for(int i=0; i<5; i++){
        cout << b[i] << " "; // Print each element of the array 'b'
    }

    // Static arrays remain in the stack memory

    cout << endl; // Print a newline character for better output formatting

    // Now we create a dynamic array 'p' of size 3
    // Dynamic arrays are allocated on the heap and can be resized
    int *p = new int[3];
    cout << "Enter the elements of the dynamic array: " << endl;
    // Use a for loop to take input for each element of the dynamic array pointed to by 'p'
    for(int i=0; i<3; i++){
        cin >> p[i]; // Read input from the user and store it in the dynamic array
    }

    // Create another dynamic array 'q' of size 5
    // This array is larger to accommodate additional elements
    int *q = new int[5];
    // Copy the elements of the dynamic array 'p' into the new dynamic array 'q'
    for(int i=0; i<3; i++){
        q[i] = p[i]; // Copy each element from 'p' to 'q'
    }
    // Add additional elements to the new positions in array 'q'
    q[3] = 40;
    q[4] = 50;

    cout << endl; // Print a newline character for better output formatting
    // Print the elements of the new dynamic resized array 'q'
    cout << "The elements of the new dynamic resized array are: " << endl;
    for(int i=0; i<5; i++){
        cout << q[i] << " "; // Print each element of the dynamic array 'q'
    }

    // Free the dynamically allocated memory to avoid memory leaks
    delete[] p;

    return 0; // Return 0 to indicate successful execution of the program
}

    10 20 30
1 2 3

    Line 1: three numbers for the static array. Line 2: three numbers for the dynamic array.

    Output 
    Enter the elements of the static array: 
The elements of the new array after using an array of size 5 are: 
10 20 30 40 50 
Enter the elements of the dynamic array: 

The elements of the new dynamic resized array are: 
1 2 3 40 50

    Reading the output. The static part prints 10 20 30 40 50; the dynamic part prints 1 2 3 40 50. The prompts appear next to the results because all input is fed at once.

    How it works, step by step
    1. Read 3 values into a[3], copy them into b[5], set b[3]=40, b[4]=50.
    2. Do the same with heap arrays: p = new int[3], q = new int[5].
    3. Copy p into q, add 40 and 50, print q.
    4. delete[] p frees the old heap array.
    Watch out. q is never deleted; add delete[] q; before return 0;.
    ✅ Check yourself: Why is the heap version better for resizing?
    You can free the old array with delete[] and keep only the new one; a stack array stays until its scope ends.

    📌 Remember

    • Stack variables die with their function; heap variables live until delete.
    • new/delete for one value, new[]/delete[] for arrays.
    • Return heap arrays (pointers) from functions, never local arrays.
    • An array can't grow: allocate bigger, copy, free the old one.
    • Watch int overflow on products - use long long.
