    Headers, min/max/swap, line input and switch

    This folder continues Module 1 with handy built-ins (min, max, swap), reading full lines of text, fixing the leftover-newline trap with cin.ignore(), and making decisions with switch.

    7 programsFolder on GitHub ↗

    🧭 Start here

    Start with a decision you have written many times: which of two numbers is smaller? With a = 8 and b = 3 the answer is 3, and in C you wrote four lines of if and else to get it.

    C++ gives you two shorter ways to say the very same thing. Here is one decision in three forms:

    a = 8, b = 3   ->  smaller is 3

if (a < b) small = a;      // what you know
else       small = b;

small = a < b ? a : b;     // ternary

small = min(a, b);         // built in

    Read the middle one out loud in the order it is written: the condition, then ?, then what you want when it is true, then :, then what you want when it is false. a < b ? a : b is simply "if a < b take a, otherwise take b". Nothing new happens; it is the if-else you already write, folded onto one line.

    The catch is the reason it stays short: each side must be a single expression, not a block. As soon as a branch needs two statements, go back to if and else. On the previous page if_else.cpp uses this form for even and odd.

    The third line is shorter still, because somebody has already written that if-else for you. min and max come from <algorithm>, and with more than two values you put them inside curly braces:

    cin >> a >> b >> c;        // 8 3 5
cout << min(a, b);         // 3
cout << max(a, b);         // 8
cout << min({a, b, c});    // 3
cout << max({a, b, c});    // 8
swap(a, b);                // now a = 3, b = 8

    Look at that last line. Swapping two values in C meant a temp variable, or a function taking two addresses. swap(a, b) does it with no & and no temp, and this small saving shows up in every sorting program later.

    Which headers? In C you listed them one by one: stdio.h, string.h, math.h. #include <bits/stdc++.h> pulls in the whole standard library in a single line, which is why contest solutions all start with it. The price is that it only works on the GCC compiler and makes compiling a little slower. The first file on this page contains nothing but that one line.

    Now the old space problem. In the C course you found that scanf("%s", s) stops dead at the first space, so I love C plus plus gave you only I, and you reached for fgets to get the whole line. cin >> s has exactly the same habit, and the cure here is cin.getline(s, 100), which reads up to the end of the line, spaces and all, into a char s[100].

    There is one trap, and it is the same trap fgets had. After cin >> x reads a number, the Enter you pressed is still sitting in the input, waiting. getline sees that newline first and stops immediately, handing you an empty line. cin.ignore() throws away that one leftover character:

    you type:  5 <Enter>
           Hello Phitron world <Enter>

after cin >> x the input still holds:
   <newline>Hello Phitron world<newline>
   ^ getline stops here  ->  empty line

cin.ignore() eats that one newline, so
getline now reads:  Hello Phitron world

    Last, another way to choose. For "day 3 is Wednesday" you would write an else-if ladder testing day == 1, then day == 2, and so on down. switch(day) compares once and jumps straight to the matching case, which reads better when you are picking one of many fixed values.

    Two things to remember. Every case needs break, or the code runs on into the next case as well, and default catches everything you did not list. switch only works on whole-number types such as int and char, so it can test x % 2 or a letter, but never a whole word.

    The programs below show each of these: the one-header file, min_max_swap.cpp, string.cpp and string_after_int_problem.cpp for line input, and three switch programs - including one whose remainder trick quietly fails on negative numbers.

    💡 Key ideas

    bits/stdc++.h

    A GCC header that includes the whole standard library in one line; common in contests.

    #include <bits/stdc++.h>

    min / max / swap

    From <algorithm>. Use braces for more than two values.

    min({a, b, c})

    cin.getline

    Reads a whole line (with spaces) into a char array.

    cin.getline(s, 100);

    cin.ignore()

    Skips one leftover character, usually the newline after a number, before a line read.

    switch

    Jumps to the case equal to the value; break stops fall-through; default catches the rest.

    #include <iostream>
#include <algorithm> // This header file is used to use the min, max, and swap functions
using namespace std; // This line allows us to use names for objects and variables from the standard library without the 'std::' prefix

int main(){
    int a, b, c;
    cin >> a >> b >> c;

    /*
    In C++, min and max can be found using if else statements
    if(a <b){
        cout << a << endl;
    } else {
        cout << b << endl;
    }
    */

    // In C++, min and max can be found using built-in functions
    cout << min(a, b) << endl;
    cout << max(a, b) << endl;

    // min and max can find minimum and maximum among more than two numbers
    // In this case, the numbers have to be passed within second or curly braces
    cout << min({a, b, c}) << endl;
    cout << min({20, -100, 40, 65}) << endl;

    cout << max({a, b, c}) << endl;
    cout << max({20, -100, 40, 65}) << endl;

    cout << endl;

    // swap function swaps the values of two variables
    swap(a, b);
    cout << a << " " << b << endl;

    return 0;
}

    8 3 5

    Three integers a b c.

    Output 
    3
8
3
-100
8
65

3 8

    Reading the output. With 8 3 5: 3 and 8 (min/max of a,b), 3 (min of a,b,c), -100 (min of the fixed list), 8 and 65 (the two max values), a blank line, then 3 8 - a and b after the swap.

    How it works, step by step
    1. Read a, b, c.
    2. min(a, b) and max(a, b) compare two values.
    3. min({a, b, c}) and max({...}) take a list in curly braces for more than two values.
    4. swap(a, b) exchanges the two variables.

    #include <iostream> // This header file is used to perform input and output operations
using namespace std; // This line allows us to use names for objects and variables from the standard library without the 'std::' prefix

int main(){
    int x; // Declaring an integer variable x to store the user input
    cin >> x; // Taking input from the user and storing it in variable x

    // cin.ignore() is used to ignore the newline character left in the input buffer after reading the integer
    // This is necessary because the newline character would otherwise be read by the next input operation
    cin.ignore();

    char s[100]; // Declaring a character array s to store the string input
    // cin.getline() is used to read a line of text from the user, including spaces
    // The first argument is the character array to store the input
    // The second argument is the maximum number of characters to read
    cin.getline(s, 100);

    // Printing the integer and the string on separate lines
    // The endl manipulator is used to insert a newline character and flush the output buffer
    cout << x << endl << s << endl;

    // Another way to take string input with spaces
    // We don't need to use char array or cin.getline()
    string s2; // Declaring a string variable s2 to store the user input
    int y;
    cin >> y;
    cin >> s2; // Taking input from the user and storing it in variable s2

    cout << y << endl << s2 << endl; // Printing the string on a single line

    return 0; // return 0 indicates that the program ended successfully
}
    Input (stdin)
    5
Hello Phitron world
12 Dhaka

    An integer, a full line of text, then an integer and a word.

    Output 
    5
Hello Phitron world
12
Dhaka

    Reading the output. 5, Hello Phitron world, 12, Dhaka - each on its own line.

    How it works, step by step
    1. Read x with cin >> x.
    2. cin.ignore() throws away the leftover newline.
    3. cin.getline(s, 100) now reads the full sentence.
    4. Then y and s2 are read with plain cin >>.
    Watch out. The comment calls cin >> s2 a way to read strings with spaces, but cin >> still stops at the first space. Use getline(cin, s2) for a full line.
    ✅ Check yourself: What would getline read if you removed cin.ignore()?
    An empty string - it would read the leftover newline right after the number.

    #include <iostream> // This header file is used to perform input and output operations
using namespace std; // This line allows us to use names for objects and variables from the standard library without the 'std::' prefix

int main(){
    int day;
    cin >> day;

    switch(day){
        case 1:
            cout << "Monday\n";
            break;
        case 2:
            cout << "Tuesday\n";
            break;
        case 3:
            cout << "Wednesday\n";
            break;
        case 4:
            cout << "Thursday\n";
            break;
        case 5:
            cout << "Friday\n";
            break;
        case 6:
            cout << "Saturday\n";
            break;
        case 7:
            cout << "Sunday\n";
            break;
        default:
            cout << "Invalid day\n";
    }

    return 0;    
}
    Input (stdin)
    3

    A number (1-7 are valid).

    Output 
    Wednesday

    Reading the output. Input 3 prints Wednesday.

    How it works, step by step
    1. Read day.
    2. switch(day) jumps to the matching case.
    3. break stops it from falling into the next case.
    4. default handles invalid numbers.
    ✅ Check yourself: What happens if you forget break after case 3?
    It falls through and also prints Thursday (and continues until a break).

    #include <iostream> // This header file is used to perform input and output operations
using namespace std; // This line allows us to use names for objects and variables from the standard library without the 'std::' prefix

int main(){
    int x; // Declaring an integer variable x to store the user input
    cin >> x; // Taking input from the user and storing it in variable x

    // Using the switch statement to check if x is even or odd
    // The expression (x % 2) calculates the remainder when x is divided by 2
    // If the remainder is 0, it means x is even
    // If the remainder is 1, it means x is odd
    switch(x % 2){
        case 0: // If the remainder is 0, execute the following block
            cout << "Even\n"; // Print "Even" followed by a new line
            break; // Exit the switch statement
        case 1: // If the remainder is 1, execute the following block
            cout << "Odd\n"; // Print "Odd" followed by a new line
            break; // Exit the switch statement
    }

    return 0; // return 0 indicates that the program ended successfully
}
    Input (stdin)
    7

    One integer.

    Output 
    Odd

    Reading the output. Input 7 prints Odd.

    How it works, step by step
    1. Read x.
    2. switch(x % 2) gives 0 or 1 for non-negative numbers.
    3. Print Even or Odd.
    Watch out. For negative odd numbers x % 2 is -1, so nothing is printed. Add case -1: or use abs(x) % 2.
    ✅ Check yourself: What is -7 % 2 in C++?
    -1, so no case matches and nothing prints.

    #include <iostream> // This header file is used to perform input and output operations
using namespace std; // This line allows us to use names for objects and variables from the standard library without the 'std::' prefix

int main(){
    char ch;
    cin >> ch;

    /*
    In C, we can use if-else to check if a character is a vowel or consonant
    if(ch == 'a' || ch == 'e' || ch == 'i' || ch == 'o' || ch == 'u' || ch == 'A' || ch == 'E' || ch == 'I' || ch == 'O' || ch == 'U'){
        cout << "Vowel\n";
    } else {
        cout << "Consonant\n";
    }
    */
    switch(ch){
        case 'a':
            cout << "Vowel\n";
            break;
        case 'e':
            cout << "Vowel\n";
            break;
        case 'i':
            cout << "Vowel\n";
            break;
        case 'o':
            cout << "Vowel\n";
            break;
        case 'u':
            cout << "Vowel\n";
            break;
        case 'A':
            cout << "Vowel\n";
            break;
        case 'E':
            cout << "Vowel\n";
            break;
        case 'I':
            cout << "Vowel\n";
            break;
        case 'O':
            cout << "Vowel\n";
            break;
        case 'U':
            cout << "Vowel\n";
            break;
        default:
            cout << "Consonant\n";
    }

    return 0;
}

    E

    One letter.

    Output 
    Vowel

    Reading the output. Input E prints Vowel.

    How it works, step by step
    1. Read a char ch.
    2. switch(ch) compares it with 'a', 'e', ... 'U'.
    3. A match prints Vowel; default prints Consonant.
    Watch out. default also catches digits and symbols, so 5 would be called a consonant.
    ✅ Check yourself: How can you shorten the ten vowel cases?
    Stack the labels without break: case 'a': case 'e': ... cout << "Vowel"; break;

    📌 Remember

    • min({...})/max({...}) handle any number of values.
    • cin >> stops at spaces; use getline for full lines.
    • Call cin.ignore() between cin >> number and getline.
    • Always break inside switch cases unless you want fall-through.

    ✅ Check yourself

    Why is cin.ignore() needed after reading an int and before getline?
    The newline typed after the number is still in the buffer and getline would read it as an empty line.
    Can switch work on a string?
    No. It works on integer-like types (int, char, enums).
    What does swap(a, b) do?
    Exchanges the values of a and b.
