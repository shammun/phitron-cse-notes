    💡 Key ideas

    Pattern replace scan

    At each position, check if the pattern starts there; if yes, output a marker and jump past it.

    Word-by-word scan

    Build words between spaces and remember to check the last word after the loop.

    Mirror swap

    Swap element i with element n-1-i for i < n/2.

    Multi-key comparator

    Compare key 1; if equal key 2; if equal key 3.

    if (l.eng != r.eng) return l.eng > r.eng;
if (l.math != r.math) return l.math > r.math;
return l.id < r.id;

    /*

Problem Statement

You will be given two strings S and X. You need to replace all X from string S with a '#' sign.

Input Format

First line will contain T, the number of test cases.
Next T lines will contain a line with S and X.

Constraints

1. 1 <= T <= 1000
2. 1 <= |S|, |X| <= 1000
3. |X| <= |S|

Output Format

- For each test cases output the modified string S.

Sample Input 0

2
rahimisagoodguy good
canyoutellmewhereicanfindheriwillbegreatefultoyouifyoutellmetheanswer you

Sample Output 0

rahimisa#guy
can#tellmewhereicanfindheriwillbegreatefulto#if#tellmetheanswer

*/

#include <iostream>
#include <string>
using namespace std;

bool matching_location(string s1, string s2, int index){
    if(index + s2.size() > s1.size()){
        return false;
    }
    for(int i=0; i<s2.size(); i++){
        if(s1[index + i] != s2[i]){
            return false;
        }
    }
    return true;
}

int main(){
    int tests;
    cin >> tests;
    string results[1000];

    for(int i=0; i<tests; i++){
        string s1, s2;
        cin >> s1 >> s2;

        string result = "";

        int position = 0;
        while(position < s1.size()){
            if(matching_location(s1, s2, position)){
                result += '#';
                position += s2.size();
            } else{
                result += s1[position];
                position++;
            }
        }
        results[i] = result;
    }

    for(int i=0; i<tests; i++){
        cout << results[i] << endl;
    }

    return 0;
}
    Input (stdin)
    2
rahimisagoodguy good
aaaa aa

    T; then T lines S X.

    Output 
    rahimisa#guy
##

    Reading the output. rahimisagoodguy good gives rahimisa#guy. aaaa aa gives ## - matches don't overlap because the scan jumps past each one.

    How it works, step by step
    1. matching_location(s1, s2, index) checks that X fits and every character matches.
    2. position moves through s1.
    3. Match: append # and skip s2.size() characters.
    4. No match: append the character and move 1.
    5. Store results and print them at the end.
    Watch out. matching_location takes both strings by value, copying them on every call; const string& would be faster.
    ✅ Check yourself: Why does aaaa with X = aa give ## and not ###?
    After a match the scan skips the whole X, so matches never overlap.

    /*

Problem Statement

Write a program to determine if a given string contains the word "Jessica." If the word is present in the string, the program should output "YES," otherwise it should output "NO."

NOTE: You need to find only "Jessica"; not "jessica" or "JeSsica" or any other form. Words are separated by spaces.

Input Format

Input will contain a string S containing names. There is a space in between two names.
Constraints

1 <= |S| <= 1000; Here |S| means the length of the string.
Output Format

Output YES or NO according to the question.
Sample Input 0

Rahat Rifat Sakib Asif Sifat Jessica Ratul Munna
Sample Output 0

YES
Sample Input 1

Rahat Rifat Sakib Asif Sifat Ratul Munna
Sample Output 1

NO
Sample Input 2

Rahat Rifat Sakib Asif jessica Sifat Ratul Munna
Sample Output 2

NO
Sample Input 3

Rahat Rifat Sakib Asif Jessicarvai Sifat Ratul Munna
Sample Output 3

NO

*/

#include <iostream>
#include <string>
using namespace std;

int main(){
    string s;
    getline(cin, s);

    bool flag = false;
    string word = "";

    for(int i=0; i<s.size(); i++){
        if(s[i] != ' '){
            word += s[i];
        } else{
            if(word == "Jessica"){
                flag = true;
                break;
            }
            word = "";
        }
    }

    if(word == "Jessica"){
        flag = true;
    }

    if(flag){
        cout << "YES" << endl;
    } else{
        cout << "NO" << endl;
    }

    return 0;
}
    Input (stdin)
    Rahat Rifat Jessicarvai Asif Jessica

    One line of names.

    Output 
    YES

    Reading the output. Prints YES: Jessicarvai doesn't count, but the last word Jessica does - found by the check after the loop.

    How it works, step by step
    1. Read the whole line with getline.
    2. Add non-space characters to word.
    3. At a space, check word == "Jessica", then reset word.
    4. After the loop, check the last word too.
    ✅ Check yourself: Why is the check after the loop needed?
    The last word is not followed by a space, so it would never be checked inside the loop.

Problem Statement

You will be given two strings S and X. You need to replace all X from string S with a '#' sign.

Input Format

First line will contain T, the number of test cases.
Next T lines will contain a line with S and X.
Constraints

1 <= T <= 1000
1 <= |S|, |X| <= 1000
|X| <= |S|
Output Format

For each test cases output the modified string S.
Sample Input 0

2
rahimisagoodguy good
canyoutellmewhereicanfindheriwillbegreatefultoyouifyoutellmetheanswer you
Sample Output 0

rahimisa#guy

#include <iostream>
#include <string>
using namespace std;

class Student{
    public:
    string nm;
    int cls;
    char s;
    int id;
};

int main(){
    int n;
    cin >> n;

    Student a[n];

    for(int i=0; i<n; i++){
        cin >> a[i].nm;
        cin >> a[i].cls;
        cin >> a[i].s;
        cin >> a[i].id;
    }

    // reverse section by swapping the first half with the second half
    for(int i=0; i<n/2; i++){
        char temp = a[i].s;
        a[i].s = a[n-i-1].s;
        a[n-i-1].s = temp;
    }

    for(int i=0; i<n; i++){
        cout << a[i].nm << " " << a[i].cls << " " << a[i].s << " " << a[i].id << endl;
    }

    return 0;
}
    Input (stdin)
    4
Rahim 7 A 101
Karim 8 B 102
Sakib 9 C 103
Tamim 10 D 104

    N, then N lines name class section id.

    Output 
    Rahim 7 D 101
Karim 8 C 102
Sakib 9 B 103
Tamim 10 A 104

    Reading the output. Names, classes and ids stay; sections are reversed: A B C D becomes D C B A.

    How it works, step by step
    1. Read nm, cls, s, id for each student.
    2. For i < n/2, swap a[i].s with a[n-i-1].s.
    3. Print all students in the original order.
    Watch out. The comment at the top is a copy of the Replace Word statement and does not describe this program.
    ✅ Check yourself: What happens to the middle student when N is odd?
    Its section stays the same, because the loop stops before it.

Problem Statement

You will be given data for N students, where each student will have a name (nm), class (cls), section (s), student ID (id), math marks (math_marks), and English marks (eng_marks).

Your task is to sort the students data according to the total marks (sum of math_marks and eng_marks) in descending order. If multiple student have the same total marks then sort them according to the id in ascending order as the id will be unique.

Input Format

First line will contain N.
Next N lines will contain nm, cls, s, id, math_marks and eng_marks respectively.
Constraints

1 <= N <= 100
1 <= |nm| <= 100 and will contain only English alphabets.
1 <= cls <= 10
'A' <= s <= 'Z'
1 <= id <= 1000
0 <= math_marks, eng_marks <= 100
Output Format

Output the students data in descending order according to the total marks.

*/

#include <iostream> // Include the input/output stream library for using cout
#include <string> // Include the string library for std::string
#include <climits> // Include the climits library for INT_MAX and INT_MIN
#include <algorithm> // Include the algorithm library for sort function
using namespace std; // Use the standard namespace to avoid writing "std::" repeatedly

class Student{
    public:
    string nm;
    int cls;
    char s;
    int id;
    int math_marks;
    int eng_marks;
}; // Define a class named Student

bool dsc(Student l, Student r){
    if(l.math_marks + l.eng_marks > r.math_marks + r.eng_marks){
        return true;
    } else if(l.math_marks + l.eng_marks < r.math_marks + r.eng_marks){
        return false;
    } else{
        return l.id < r.id;
    }
}

int main(){
    int n;
    cin >> n;

    Student a[n];
    for(int i=0; i<n; i++){
        cin >> a[i].nm >> a[i].cls >> a[i].s >> a[i].id >> a[i].math_marks >> a[i].eng_marks;
    }

    sort(a, a+n, dsc);

    for(int i=0; i<n; i++){
        cout << a[i].nm << " " << a[i].cls << " " << a[i].s << " " << a[i].id << " " << a[i].math_marks << " " << a[i].eng_marks << endl;
    }

    return 0;
}
    Input (stdin)
    4
asif 9 A 3 80 70
rina 8 B 1 90 60
joy 10 C 2 75 90
moni 7 D 4 95 70

    N, then N lines name class section id math english.

    Output 
    joy 10 C 2 75 90
moni 7 D 4 95 70
rina 8 B 1 90 60
asif 9 A 3 80 70

    Reading the output. joy and moni both have 165 (ids 2 and 4), then rina and asif both have 150 (ids 1 and 3).

    How it works, step by step
    1. Read all six fields per student.
    2. dsc compares math_marks + eng_marks.
    3. On equal totals it returns l.id < r.id.
    4. Sort and print.
    ✅ Check yourself: How would you avoid writing the sum twice?
    Store int tl = l.math_marks + l.eng_marks (and the same for r) at the top of the comparator.

Problem Statement

You will be given data for N students, where each student will have a name (nm), class (cls), section (s), student ID (id), math marks (math_marks), and English marks (eng_marks).

Your task is to sort the students data according to the eng_marks in descending order. If multiple student have the same eng_marks then sort them according to the math_marks in 
descending order. If multiple student have the same math_marks then sort them accoding to the id in ascending order as the id will be unique.

Input Format

First line will contain N.
Next N lines will contain nm, cls, s, id, math_marks and eng_marks respectively.
Constraints

1 <= N <= 1000
1 <= |nm| <= 100 and will contain only English alphabets.
1 <= cls <= 10
'A' <= s <= 'Z'
1 <= id <= 10^9
0 <= math_marks, eng_marks <= 100
Output Format

Output the data in sorted order as instructed.

6
akib 2 R 1001 32 53
rakib 1 E 1002 93 97

bokib 3 Q 1004 93 58

6

rakib 1 E 1002 94 88

#include <iostream> // Include the input/output stream library for using cout
#include <string> // Include the string library for std::string
#include <climits> // Include the climits library for INT_MAX and INT_MIN
#include <algorithm> // Include the algorithm library for sort function
using namespace std; // Use the standard namespace to avoid writing "std::" repeatedly

class Student{
    public:
    string nm;
    int cls;
    char s;
    int id;
    int math_marks;
    int eng_marks;
}; // Define a class named Student

bool dsc(Student l, Student r){
    if(l.eng_marks > r.eng_marks){
        return true;
    } else if(l.eng_marks < r.eng_marks){
        return false;
    } else{
        if(l.math_marks > r.math_marks){
            return true;
        } else if(l.math_marks < r.math_marks){
            return false;
        } else{
            return l.id < r.id;
        }
    }
}

int main(){
    int n;
    cin >> n;

    Student a[n];
    for(int i=0; i<n; i++){
        cin >> a[i].nm >> a[i].cls >> a[i].s >> a[i].id >> a[i].math_marks >> a[i].eng_marks;
    }

    sort(a, a+n, dsc);

    for(int i=0; i<n; i++){
        cout << a[i].nm << " " << a[i].cls << " " << a[i].s << " " << a[i].id << " " << a[i].math_marks << " " << a[i].eng_marks << endl;
    }

    return 0;
}

    How it works, step by step
    1. Compare eng_marks first.
    2. If equal, compare math_marks.
    3. If still equal, the smaller id comes first.
    4. Sort and print.
    Watch out. id can be up to 10^9, which still fits in an int.
    ✅ Check yourself: With three keys, when is the id compared?
    Only when both English and math marks are equal.

    📌 Remember

    • Scan-and-jump avoids overlapping matches.
    • Always handle the last word after a split-by-space loop.
    • Mirror swaps stop at n/2.
    • Multi-key sorting: check each key in order, only moving on when equal.

    ✅ Check yourself

    Write the three-key comparator using != checks.
    if (l.e != r.e) return l.e > r.e; if (l.m != r.m) return l.m > r.m; return l.id < r.id;
    How could you find an exact word in a line more simply?
    Split the line with stringstream and compare each word with ==.

    false, because index + X.size() > S.size().
