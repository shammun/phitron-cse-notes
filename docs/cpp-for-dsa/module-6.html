    🧭 Start here

    Here is a strip of paper with letters written on it: BRITISHEGYPTGHANA. Before you learn a single function name, ask what you ever actually want to do with a strip like that. There are only four kinds of question, and every tool in this module answers one of them.

    What is inside it? Look at one letter with s[i], or walk over all of them. How long is it? s.size(). Can I take a piece out? s.substr(i, len) hands you the len letters starting at position i, as a new string of its own. Can I build a new one? Grow it with +=, or ask for one ready-made: string s(5, 'a') gives aaaaa, and string s3("Hello", 3) gives Hel.

    Grouped by the question they answer, there is nothing to memorise: you have a question, you reach for the tool.

    Now a real task from this page. Replace every EGYPT inside the strip with a single space, so BRITISHEGYPTGHANA becomes BRITISH GHANA.

    Do it by hand first. Put a finger at the left end, keep a clean sheet beside you, and at every position ask one question: do the next five letters spell EGYPT? If not, copy that single letter onto the clean sheet and step the finger on by one. If they do, write a space instead and jump five steps, past the whole word. When the finger runs off the end, the clean sheet is the answer. That is the program, exactly:

    string result = "";
int i = 0;
while (i < s.size()) {
    if (s.substr(i, 5) == "EGYPT") {
        result += ' ';      // write a space
        i += 5;             // jump over the word
    } else {
        result += s[i];     // copy one letter
        i++;
    }
}
    s = BRITISHEGYPTGHANA

i=0   substr(0,5)  = "BRITI"  no  -> take 'B'
i=1   substr(1,5)  = "RITIS"  no  -> take 'R'
...   (five more single letters)
i=7   substr(7,5)  = "EGYPT"  yes -> add ' ', i=12
i=12  substr(12,5) = "GHANA"  no  -> take 'G'
...   (four more single letters)

result:  B  BR  BRI ... BRITISH  BRITISH 
         ... BRITISH GHANA

    What is new, compared with Module 5? There you met the tools one at a time; here you decide which one a problem needs, and you cut a string apart and build a different one back up. Three tools are new too.

    for (char c : s) walks the whole string with no index at all, for when you do not care where you are, only what is there. reverse(s.begin(), s.end()) turns a string back to front in place, and the same function written as reverse(a, a+n) does it to a plain array of numbers.

    sort(s.begin(), s.end()) sorts the letters themselves, so banana becomes aaabnn. That looks pointless until you see what it buys you: two words are anagrams of each other exactly when their sorted forms are equal.

    A second example. Is a word a palindrome? One way is the two-pointer walk you know: left at the front, right at the back, compare, step inwards, stop at the first mismatch. The other is one line of thought: copy the string, reverse the copy, ask s == rev_s. With the string class == really compares the letters, so no strcmp is needed.

    A third example. How many times can you spell EGYPT out of the letters of a word? Every copy eats one e, one g, one y, one p and one t, so count those five letters; the answer is the smallest count:

    pemigdbeigyypetet

e 4    g 2    y 2    p 2    t 2
smallest is 2  ->  EGYPT can be made twice

    A fourth. Reverse every word of a line but keep the words in place. Read the line with getline and feed it to a stringstream, which hands you the words one at a time; reverse each as it comes out. Splitting on spaces would otherwise be twenty lines of code.

    The module also finishes the object work from Module 3. A function can live inside the class, so shammunul.hello() prints that student's own name and marks without being told which student. And copying a heap object means copying its field values (or *kohli3 = *dhoni3), never the pointer: after delete dhoni, reading dhoni->name is reading memory you have handed back, even if the letters still look right on screen.

    The programs below take these tools one at a time, then use them on real problems: palindromes, counting letters, replacing a word, reversing words, lucky tickets and balloons.

    💡 Key ideas

    String constructors

    Build a string from text, part of text, part of another string, or repeated characters.

    string s(5, 'a');

    Range-based for

    for (char c : s) loops over every element without an index.

    sort / reverse on strings

    Both take iterators from <algorithm>.

    reverse(s.begin(), s.end());

    Member functions

    Functions inside a class that work with that object's own fields.

    Letter counting

    s[i] - 'a' or s[i] - 'A' maps letters to array indices 0-25.

    Two pointers

    Compare from both ends toward the middle - the classic palindrome check.

    Deep copy of objects

    Copy field values (or *a = *b), not pointers; never read an object after delete.

    /*

Palindrome
time limit per test: 1 second
memory limit per test: 256 megabytes
Given a string S. Determine whether S is Palindrome or not

Note: A string is said to be a palindrome if the reverse of the string is same as the string. For example, "abba" is palindrome, but "abbc" is not palindrome.

Input
Only one line contains a string S (1 ≤ |S| ≤ 1000) where |S| is the length of the string and it consists of lowercase letters only.

Output
Print "YES" if the string is palindrome, otherwise print "NO".

Examples:

Input
abba
Output
YES

Input
icpcassiut
Output
NO

Input
mam
Output
YES

*/

#include <iostream> // Include the input/output stream library for using cout
#include <string>   // Include the string library for std::string
using namespace std; // Use the standard namespace to avoid writing "std::" repeatedly

bool isPalindrome(string s){
    int left = 0;
    int right = s.size() - 1;

    while(left < right){
        if(s[left] != s[right]){
            return false;
        }
        left++;
        right--;
    }

    return true;
}

int main(){
    string s;
    cin >> s;

    if(isPalindrome(s)){
        cout << "YES" << endl;
    } else {
        cout << "NO" << endl;
    }
}
    Input (stdin)
    racecar

    One lowercase word.

    Output 
    YES

    Reading the output. racecar prints YES.

    How it works, step by step
    1. left = 0, right = s.size() - 1.
    2. While left < right, compare s[left] and s[right].
    3. A mismatch means NO; otherwise move both inward.
    4. If the loop ends, it is a palindrome.
    ✅ Check yourself: Why is left < right enough (not <=)?
    When they meet at the middle character, it matches itself, so there is nothing left to check.

Given a string S. Determine whether S is Palindrome or not

Note: A string is said to be a palindrome if the reverse of the string is same as the string. For example, "abba" is palindrome, but "abbc" is not palindrome.

Input
Only one line contains a string S (1 ≤ |S| ≤ 1000) where |S| is the length of the string and it consists of lowercase letters only.

Print "YES" if the string is palindrome, otherwise print "NO".

Input

NO

#include <iostream> // Include the input/output stream library for using cout
#include <string>   // Include the string library for std::string
#include <algorithm> // Include the algorithm library for reverse function
using namespace std; // Use the standard namespace to avoid writing "std::" repeatedly

int main(){
    string s;
    cin >> s;

    string rev_s = s;
    reverse(rev_s.begin(), rev_s.end());

    if (s == rev_s){
        cout << "YES" << endl;
    } else {
        cout << "NO" << endl;
    }

    return 0; // Indicate that the program ended successfully
}

    NO

    Reading the output. abca reversed is acba, which differs, so NO.

    How it works, step by step
    1. Copy s into rev_s.
    2. reverse(rev_s.begin(), rev_s.end()).
    3. s == rev_s means palindrome.
    ✅ Check yourself: What extra cost does this version have over the two-pointer one?
    It uses O(n) extra memory for the reversed copy.

New Words
time limit per test: 1 second
memory limit per test: 256 megabytes
Given a string S
. Print number of times that "EGYPT" word can be formed from S's characters.

Note: Case of the letters doesn't matter. For example: "Egypt", "egypt" and "eGyPt" are the same.

Input
Only one line contains a string S(1≤|S|≤10^6) where |S| is the length of the string and it consists of lowercase and uppercase English letters.

Output
Print the answer required above.

Examples
Input
EgYpTaz
Output
1

Input
pemigdbeigyypetet
Output
2

*/

#include <iostream> // Include the input/output stream library for using cout
#include <string>   // Include the string library for std::string
using namespace std; // Use the standard namespace to avoid writing "std::" repeatedly

int main(){
    string s;
    cin >> s;

    // Convert the string to lowercase
    for(int i=0; i<s.size(); i++){
        if (s[i] >= 'A' && s[i] <= 'Z'){
            s[i] = char(s[i]) - 'A' + 'a';
        }
    }

    int cnt_e = 0, cnt_g = 0, cnt_y = 0, cnt_p = 0, cnt_t = 0;

    for(int i=0; i<s.size(); i++){
        if(s[i] == 'e'){
            cnt_e++;
        } else if(s[i] == 'g'){
            cnt_g++;
        } else if(s[i] == 'y'){
            cnt_y++;
        } else if(s[i] == 'p'){
            cnt_p++;
        } else if(s[i] == 't'){
            cnt_t++;
        }
    }

    int ans = cnt_e;
    if(cnt_g < ans){
        ans = cnt_g;
    }
    if(cnt_y < ans){
        ans = cnt_y;
    }
    if(cnt_p < ans){
        ans = cnt_p;
    }
    if(cnt_t < ans){
        ans = cnt_t;
    }

    cout << ans << endl;

    return 0;
}

    How it works, step by step
    1. Turn capital letters into small ones with s[i] - 'A' + 'a'.
    2. Count e, g, y, p, t.
    3. Each word needs one of each, so the answer is the minimum count.

Replace Word

Given a string S. Print S after replacing every sub-string that is equal to "EGYPT" with space.

Input
Only one line contains a string S (1≤|S|≤10^3) where |S| is the length of the string and it consists of only uppercase English letters.

#include <iostream> // Include the input/output stream library for using cout
#include <string>   // Include the string library for std::string

int main(){
    string s;
    cin >> s;

    string result = "";
    string word = "EGYPT";
    int target_length = 5;
    int i = 0;

    while(i < s.length()){
        if (i + target_length <= s.length() && s.substr(i, target_length) == word){
            result += ' ';
            i += target_length;

            result += s[i];
            i++;
        }
    }

}

    3. Match: add ' ' and i += 5.
    4. No match: add s[i] and i++.
    ✅ Check yourself: Why jump by 5 after a match?

    /*

Lucky?
time limit per test: 1 second
memory limit per test: 256 megabytes
A ticket is a string consisting of six digits. A ticket is considered lucky if the sum of the first three digits is equal to the sum of the last three digits. Given a ticket, output if it is lucky or not. Note that a ticket can have leading zeroes.

Input
The first line of the input contains an integer t (1≤t≤10^3) — the number of testcases.

The description of each test consists of one line containing one string consisting of six digits.

Output
Output t lines, each of which contains the answer to the corresponding test case. Output "YES" if the given ticket is lucky, and "NO" otherwise.

You can output the answer in any case (for example, the strings "yEs", "yes", "Yes" and "YES" will be recognized as a positive answer).

Example

Input
5
213132
973894
045207
000000
055776

Output
YES
NO
YES
YES
NO

Note
In the first test case, the sum of the first three digits is 2+1+3=6 and the sum of the last three digits is 
1+3+2=6, they are equal so the answer is "YES".

In the second test case, the sum of the first three digits is 9+7+3=19 and the sum of the last three digits 
is 8+9+4=21, they are not equal so the answer is "NO".

In the third test case, the sum of the first three digits is 0+4+5=9 and the sum of the last three digits is 
2+0+7=9, they are equal so the answer is "YES".

*/

#include <iostream> // Include the input/output stream library for using cout
#include <string>   // Include the string library for std::string
using namespace std; // Use the standard namespace to avoid writing "std::" repeatedly

bool isLuckyTicket(string num){
    int first_half_sum = (num[0] - '0') + (num[1] - '0') + (num[2] - '0');
    int second_half_sum = (num[3] - '0') + (num[4] - '0') + (num[5] - '0');
    return first_half_sum == second_half_sum;
}

int main() {
    int n;
    cin >> n;

    string results[1000]; // Array for storing results from different test cases

    // Read input and check if each ticket is lucky
    for(int i=0; i<n; i++){
        string ticket;
        cin >> ticket;
        results[i] = isLuckyTicket(ticket) ? "YES" : "NO";
    }

    // print results
    for(int i=0; i<n; i++){
        cout << results[i] << endl;
    }

    return 0; // Indicate that the program ended successfully
}
    Input (stdin)
    3
213132
973894
000000

    t, then t six-digit tickets.

    Output 
    YES
NO
YES

    Reading the output. 213132 gives YES (6 = 6), 973894 gives NO (19 vs 21), 000000 gives YES.

    How it works, step by step
    1. Read each ticket as a string so leading zeros stay.
    2. Turn each char into a digit with num[i] - '0'.
    3. Compare the two sums; store YES/NO and print all at the end.
    ✅ Check yourself: Why read the ticket as a string instead of an int?
    An int would lose leading zeros like in 045207, and digit access is easier on a string.

ICPC Balloons

In an ICPC contest, balloons are distributed as follows:

The second line of each test case contains a string s of length n consisting of uppercase English letters,

#include <string> // Include the string library for std::string
using namespace std; // Use the standard namespace to avoid writing "std::" repeatedly

int calculate_balloons(int n, string s){
    bool first_time[26] = {false};
    int total_balloons = 0;

    // count the number of balloons
    for(int i=0; i<n; i++){
        int problem_index = s[i] - 'A';

        total_balloons += 1;

        if(!first_time[problem_index]){
            total_balloons += 1;
            first_time[problem_index] = true;
        }

    }

    return total_balloons;
}

    for(int i=0; i<t; i++){
        int n;
        string s;
        cin >> n >> s;
        results[i] = calculate_balloons(n, s);
    }

    for(int i=0; i<t; i++){
        cout << results[i] << endl;
    }

    return 0;  // Indicate that the program ended successfully

    /*

K. I Love strings
time limit per test: 2 seconds
memory limit per test: 64 megabytes

Given two strings S and T. Print a new string that contains the following:

- The first letter of the string S followed by the first letter of the string T.
- The second letter of the string S followed by the second letter of the string T.
- and so on...

In other words, the new string should be ( S0 + T0 + S1 + T1 + .... ).

Note: If the length of S is greater than the length of T then you have to add the rest of
S letters at the end of the new string and vice versa.

Input
The first line contains a number N (1 <= N <= 50) the number of test cases.

Each of the N following lines contains two string S, T (1 <= |S|, |T| <= 50) consists of
lower and upper English letters.

Output
For each test case, print the required string.

Example

input
2
ipAsu ccsit
ey gpt

output
icpcAssiut
egypt

*/

#include <iostream>
#include <string>
using namespace std;

int main() {
    int n;
    cin >> n;

    while(n--) {
        string s, t;
        cin >> s >> t;

        /* The answer grows one letter at a time. In C this needed a fixed
           char array big enough for both words; a C++ string grows by itself,
           so `answer += c` is all that is needed. */
        string answer = "";

        /* Walk as far as the longer word. Each step adds the letter of S and
           the letter of T, but only if that word still has one at position i.
           That single guard is what handles words of different lengths. */
        int longer = s.size();
        if((int)t.size() > longer) {
            longer = t.size();
        }

        for(int i = 0; i < longer; i++) {
            if(i < (int)s.size()) {
                answer += s[i];
            }
            if(i < (int)t.size()) {
                answer += t[i];
            }
        }

        cout << answer << endl;
    }

    return 0;
}
    Input (stdin)
    2
ipAsu ccsit
ey gpt

    The two test cases from the statement.

    Output 
    icpcAssiut
egypt

    Reading the output. icpcAssiut and egypt, exactly as the statement expects.

    How it works, step by step
    1. Read the number of test cases and loop with while(n--).
    2. Read both words with cin >> s >> t.
    3. answer starts empty and grows with answer += s[i].
    4. Walk i as far as the longer of the two words.
    5. Add s[i] only while i is still inside s, and t[i] only while i is still inside t. Those two guards are what makes the leftover tail work without any extra code.
    Watch out. s.size() is unsigned, so it is cast to int before being compared with i. Comparing an int with an unsigned value can surprise you when the int is negative.
    ✅ Check yourself: Where do the leftover letters of the longer word come from in this loop?
    From the rounds where only one of the two guards is still true, so only that word contributes a letter.
