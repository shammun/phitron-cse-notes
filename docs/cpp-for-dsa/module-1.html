    Introduction to C++ for DSA · Module 1

    C++ basics: cout, cin, formatting and casting

    This module moves from C to C++ input and output. You print with cout, read with cin, format decimals with setprecision, see how characters map to ASCII numbers, and read input until it ends. These are the tools used in every later program.

    9 programsFolder on GitHub ↗

    🧭 Start here

    You have just finished a whole course in C. Nothing you learned there is thrown away. A for loop is the same loop, if and else decide the same way, arrays are the same boxes in a row, and '0' is still 48. C++ keeps all of it.

    What changes on the first day is small: the two lines at the top of the file, and the way you print and read. Here is the same tiny program - read a number, print its double - written both ways:

    C                        C++
----------------------   ---------------------
#include <stdio.h>       #include <iostream>
                         using namespace std;
int main(){              int main(){
  int n;                    int n;
  scanf("%d", &n);          cin >> n;
  printf("%d\n", n*2);      cout << n*2 << endl;
  return 0;                 return 0;
}                        }

    Look at what disappeared. There is no %d, and there is no &. You do not tell the computer what kind of value you are printing, because the variable already knows: cout << n prints an int as an int, and if n were a double the same line would print a double.

    That is why this is harder to get wrong. Think of the mistakes that cost you time in C: %d for a long long instead of %lld, %f where %lf was needed, a forgotten & in scanf that crashes the program, and the leading space before %c. None of those exist here. There are no format letters left to get wrong.

    using namespace std; is the line that lets you write cin and cout instead of std::cin and std::cout. Both spellings appear on this page, and they mean exactly the same thing.

    A second thing to watch: the line ending. In C the \n sat inside the format string, so you could hardly forget it. In C++ nothing ends the line by itself. endl does it, and so does "\n".

    This catches people once and then never again. In print_variable.cpp, x is 10 and the first print has no endl, so the next print carries on where it stopped and the screen shows 1010:

    int x = 10;
char c = 'A';
double d = 34.56;
cout << x;                       // no endl
cout << x << " " << c << " " << d << endl;
// screen:  1010 A 34.56

    A third example: decimals. printf("%.5lf", d) becomes cout << fixed << setprecision(5) << d, from the header <iomanip>. fixed means "count digits after the point", and setprecision(5) sets that count, so 23.45676 prints as 23.45676. Drop fixed and the 5 counts all the digits instead, giving 23.457.

    A fourth: characters. You already know a char holds a number. In C the format letter chose the view: %c showed the letter, %d showed the code. cout has no format letter, so it goes by the type, and when you want the other view you ask with a cast:

    char c = 'A';
cout << c;          ->  A
cout << (int)c;     ->  65

int y = 65;
cout << y;          ->  65
cout << (char)y;    ->  A

    The last piece is reading until the input stops. while (cin >> x) keeps going as long as another number arrives and ends when the input runs out, which saves you counting the values first.

    So the whole module is one trade. You give up the format letters, and with them you give up a family of silent mistakes; in exchange you must remember endl yourself and ask for a cast when you want a character shown as a number. Everything else you already know.

    The programs below take these one at a time, from hello_world.cpp up to eof.cpp, with if_else.cpp showing the ternary operator - a one-line if-else that the next page builds on.

    💡 Key ideas

    cout and <<

    cout is the output stream; << pushes values into it. No %d-style codes are needed.

    cout << x << " " << d << endl;

    cin and >>

    cin reads values separated by spaces or newlines into variables, in order.

    cin >> x >> c >> d;

    using namespace std

    Lets you write cin/cout instead of std::cin/std::cout.

    fixed + setprecision

    From <iomanip>; fixed << setprecision(k) prints exactly k digits after the decimal point.

    cout << fixed << setprecision(2) << 3.14159;

    ASCII and casting

    A char stores a number. (int)'A' is 65 and (char)65 is 'A'.

    Ternary operator

    cond ? a : b is a one-line if-else.

    Read until end of input

    while (cin >> x) loops as long as input keeps coming.

    #include <iostream>

int main(){
    int x = 10;
    // In C, printf("%d", x) is used to print a variable
    // In C++, cout << x is used to print a variable
    std::cout << x; // printf("%d", x) is equivalent to cout << x

    char c = 'A';
    double d = 34.56;
    std::cout << x << " " << c << " " << d << std::endl; // endl is used to print a new line
    // In C, printf("My favorite number is %d\n", x) is used to print a variable
    // In C++, cout << "My favorite number is " << x << std::endl; is used to print a variable
    std::cout << "My favorite number is " << x << std::endl;
    return 0;
}
    Input

    This program reads no input.

    Output 
    1010 A 34.56
My favorite number is 10

    Reading the output. The first line reads 1010 A 34.56: the first 10 comes from the lone cout << x (no newline), the second 10 starts the next print. Line two is My favorite number is 10.

    How it works, step by step
    1. x = 10 is printed alone with std::cout << x; (no newline).
    2. Then x, c and d are printed with " " between them and std::endl at the end.
    3. Finally a sentence and a number are printed together.
    Watch out. If you want each print on its own line, end it with endl or "\n".
    ✅ Check yourself: Why do you see 1010 instead of 10 on its own line?
    The first cout << x has no endl, so the next output continues on the same line.

    #include <iostream> // This is the header file that allows us to use input and output objects like std::cin and std::cout
using namespace std; // This line allows us to use names for objects and variables from the standard library without the 'std::' prefix

int main(){
    int x; // Declaring an integer variable x
    char c; // Declaring a character variable c
    double d; // Declaring a double (floating-point) variable d

    // Taking multiple inputs from the user and storing them in variables x, c, and d respectively
    // cin is used to take input from the user
    // The '>>' operator is used to extract the input values and store them in the respective variables
    cin >> x >> c >> d;

    // Printing the values of x, c, and d separated by spaces
    // cout is used to print output to the console
    // The '<<' operator is used to send the values of x, c, and d to the output stream
    // endl is used to print a new line
    cout << x << " " << c << " " << d << endl;

    return 0; // return 0 indicates that the program ended successfully
}
    Input (stdin)
    25 Z 3.75

    An integer, a character and a decimal number, separated by spaces.

    Output 
    25 Z 3.75

    Reading the output. Prints 25 Z 3.75 - the same three values in the same order.

    How it works, step by step
    1. Declare int x, char c, double d.
    2. cin >> x >> c >> d; reads them in order, skipping spaces between them.
    3. Print them back separated by spaces.
    ✅ Check yourself: With input 25 Z 3.75, which variable gets Z?
    c, because cin fills variables left to right and c is the second one.

    2. int ASCII_value = c; with c = 'A' stores 65.
    3. (int)c prints the same 65 by casting.
    4. (char)y with y = 65 prints the letter A.

    #include <iostream> // This header file is used to perform input and output operations
using namespace std; // This line allows us to use names for objects and variables from the standard library without the 'std::' prefix

int main(){
    int x = 6; // Initializing integer variable x with value 6

    // Using the ternary operator to check if x is even or odd
    // The condition (x % 2 == 0) checks if x is divisible by 2 with no remainder, which means x is even
    // If the condition is true, it executes the first part (cout << "Even\n"), which prints "Even" followed by a new line
    // If the condition is false, it executes the second part (cout << "Odd\n"), which prints "Odd" followed by a new line
    x % 2 == 0 ? cout << "Even\n" : cout << "Odd\n"; 
    // Works only when there is only one statement to execute inside if and one statement 
    // to execute inside else

    return 0; // return 0 indicates that the program ended successfully
}
    Input

    This program reads no input.

    Output 
    Even

    Reading the output. Prints Even because 6 % 2 is 0.

    How it works, step by step
    1. x % 2 == 0 is the condition.
    2. If true, the part before : runs (cout << "Even\n").
    3. Otherwise the part after : runs.
    4. Good only when each branch is a single expression.
    ✅ Check yourself: Rewrite x % 2 == 0 ? cout << "Even" : cout << "Odd"; as if-else.
    if (x % 2 == 0) cout << "Even"; else cout << "Odd";

    #include <iostream> // Include the iostream library to allow input/output operations
using namespace std; // Use the standard namespace to avoid prefixing 'std::' before cin, cout, etc.

int main() {
    int x; // Declare an integer variable 'x' to store input values

    // Start a while loop to continuously read input from the user
    // 'cin >> x' reads an integer from the standard input (keyboard) and stores it in 'x'
    // The loop runs as long as a valid integer is provided as input
    while (cin >> x) {
        // Output the value of 'x' using 'cout' and add a newline character
        // This prints the input number and moves to the next line
        cout << x << endl;

        // Explanation of different formatters:
        // - 'cin' is used to read input data from the user. It works by extracting the next input and storing it in the specified variable.
        // - 'cout' is used to display output to the user. Here, it outputs the value of 'x' followed by a newline ('endl').
        // Using these formatters ensures the program handles input and output in a structured way.
        // The loop enables continuous input handling, which stops when an invalid input (non-integer) is encountered or the user signals EOF (End of File, e.g., Ctrl+D or Ctrl+Z).
    }

    // Return 0 indicates that the program executed successfully
    return 0;
}
    Input (stdin)
    10
20
30

    Any number of integers; the program stops when input ends.

    Output 
    10
20
30

    Reading the output. Each input number is echoed: 10, 20, 30.

    How it works, step by step
    1. cin >> x gives true while a number was read.
    2. When input ends (end of file) or a non-number appears, it becomes false and the loop stops.
    3. Each read value is printed on its own line.
    ✅ Check yourself: How do you signal end of input when typing in a Windows terminal?
    Press Ctrl+Z then Enter (Ctrl+D on Linux/macOS).

    📌 Remember

    • cout << prints, cin >> reads - no format codes.
    • endl ends the line; without it output continues on the same line.
    • fixed << setprecision(k) gives k decimal places.
    • Characters are numbers underneath (ASCII).
    • while (cin >> x) is the standard read-until-end loop.
