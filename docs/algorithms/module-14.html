    Recursion and the first steps of dynamic programming

    The module starts with recursion: a function that solves a problem by calling itself on a smaller version. Plain recursive Fibonacci repeats the same work many times. Memoization (top-down DP) and a bottom-up loop remove that repeated work. The practice problems apply the same ideas to digits, factorials, reachability and Tribonacci.

    💡 Key ideas

    Base case + recursive case

    Every recursive function needs a stopping condition (base case) and a call that moves toward it. Without the base case it never stops and the stack overflows.

    int fact(int n) { if (n == 1) return 1; return n * fact(n - 1); }

    Work before vs after the call

    Printing before the recursive call prints in the order the calls are made (1..5). Printing after the call prints as the calls return (5..1).

    Overlapping subproblems

    fib(n) calls fib(n-1) and fib(n-2), and both of them call fib(n-3) again. The plain version takes about 2^n steps.

    Memoization (top-down DP)

    Keep a dp array filled with -1. Before computing, check whether the answer is already stored; after computing, store it. Each state is computed once.

    if (dp[n] != -1) return dp[n];
dp[n] = fib(n-1) + fib(n-2);

    Tabulation (bottom-up DP)

    Fill the table from the smallest cases upward with a loop. No recursion and no stack depth issues.

    for (i = 2; i <= n; i++) f[i] = f[i-1] + f[i-2];

    Choose the right integer type

    Factorials and Fibonacci numbers grow fast. 13! already overflows int; use long long (good up to 20!).

    Recursion visualiser

    Drawing the call tree helps you see repeated calls. The module links an online recursion visualiser for this.

    How it works, step by step
    1. If n is 0 or 1, return n.
    2. Otherwise return fib(n-1) + fib(n-2).
    3. The same values are recomputed again and again, so the call tree doubles at each level.

    #include <iostream>
#include <vector>
#include <algorithm>    
#include <string>

using namespace std;
int dp[1005];

int fib(int n){
    if(n < 2){ // or, we can also write if(n == 0 || n == 1)
        return n;
    }
    if(dp[n] != -1){
        return dp[n];
    }
    dp[n] = fib(n-1) + fib(n-2);
    return dp[n];
}

int main(){
    memset(dp, -1, sizeof(dp));
    int n;
    cin >> n;
    cout << fib(n) << endl;

    return 0;
}
    Input (stdin)
    40

    A single n (the answer fits in int up to n = 46).

    Output 
    102334155

    Reading the output. Prints 102334155 (fib(40)) instantly, while the plain recursive version takes noticeably long for n = 40.

    How it works, step by step
    1. memset(dp, -1, sizeof(dp)) marks every state as 'not computed'.
    2. Base case: n < 2 returns n.
    3. If dp[n] != -1, return the saved value at once.
    4. Otherwise compute fib(n-1) + fib(n-2), store it in dp[n], and return it.
    Watch out. Tip: on some compilers you need #include <cstring> for memset; this file relies on another header bringing it in.
    ✅ Check yourself: Why is -1 a safe 'empty' marker here?
    Fibonacci values are never negative, so -1 can never be a real stored answer.

    /*

https://leetcode.com/problems/climbing-stairs/

70. Climbing Stairs

You are climbing a staircase. It takes n steps to reach the top.

Each time you can either climb 1 or 2 steps. In how many distinct ways can you climb to 
the top?


Example 1:

Input: n = 2
Output: 2
Explanation: There are two ways to climb to the top.
1. 1 step + 1 step
2. 2 steps
Example 2:

Input: n = 3
Output: 3
Explanation: There are three ways to climb to the top.
1. 1 step + 1 step + 1 step
2. 1 step + 2 steps
3. 2 steps + 1 step
 

Constraints:

1 <= n <= 45


*/

class Solution {
    public:
        int dp[50];
        int fibo(int n){
            if(n<3){
                return n;
            }
            if(dp[n] != -1){
                return dp[n];
            }
            dp[n] = fibo(n-1) + fibo(n-2);
            return dp[n];
        }
        int climbStairs(int n) {
            memset(dp, -1, sizeof(dp));
            int ans = fibo(n);
            return ans;
        }
    };

Print Digits using Recursion

Given a number N. Print the digits of N separated by a space.

Note: Solve this problem using recursion.

Input
First line contains a number T (1 ≤ T ≤ 10) number of test cases.

Next T lines will contain a number N (0 ≤ N ≤ 10^9).

Output
For each test case print a single line contains the digits of the number separated by

Example
Input

121
39
123456

Output
1 2 1 
3 9 
1 2 3 4 5 6

#include <iostream>
using namespace std;

void printDigits(long long n){
    if(n < 10){
        cout << n;
        return;
    }

    printDigits(n/10);
    cout << " " << n % 10;
}

int main(){
    int t;
    cin >> t;

    while(t--){
        long long n;
        cin >> n;

        printDigits(n);
        cout << endl;
    }

    return 0;
}

    2. Otherwise call printDigits(n / 10) to print all digits except the last.
    3. Then print a space and n % 10.
    4. main repeats this for T numbers, ending each with a newline.

    /*

https://codeforces.com/group/MWSDmqGsZm/contest/223339/problem/W

Reach Value

Given a number N. Initially you have a value equal 1 and you can perform one of the 
following operation any number of times:

1. Multiply your current value by 10.
2. Multiply your current value by 20.

Determine if your value can reach N or not.

Note: Solve this problem using recursion.

Input
First line contains a number T (1≤T≤100) number of test cases.

Next T lines will contain a number N (1≤N≤10^12).

Output
For each test case print "YES" if your value can reach exactly N otherwise, print "NO".

Example
Input
5
1
2
10
25
200

Output
YES
NO
YES
NO
YES

*/

#include <iostream>
#include <set>

using namespace std;

set<long long> visited;

bool canReach(long long target){
    if(target == 1){
        return true;
    }
    if(target < 1){
        return false;
    }

    if(visited.find(target) != visited.end()){
        return false;
    }

    visited.insert(target);

    if(target % 10 == 0 && canReach(target / 10)){
        return true;
    }
    if(target % 20 == 0 && canReach(target / 20)){
        return true;
    }

    return false;
}

int main(){
    int t;
    cin >> t;

    while(t--){
        long long n;
        cin >> n;

        visited.clear();

        if(canReach(n)){
            cout << "YES" << endl;
        } else {
            cout << "NO" << endl;
        }
    }

    return 0;
}
    Input (stdin)
    5
1
2
10
25
200

    T, then T values of N. This is the judge's example.

    Output 
    YES
NO
YES
NO
YES

    Reading the output. YES NO YES NO YES on separate lines, matching the judge. 200 = 1 x 10 x 20, while 25 is not divisible by 10 or 20.

    How it works, step by step
    1. canReach(1) is true; anything below 1 is false.
    2. A visited set stops the search from checking the same number twice.
    3. If target % 10 == 0 and canReach(target / 10) succeeds, return true.
    4. Same with 20.
    5. Clear visited before each test case.
    ✅ Check yourself: Why go backwards (divide) instead of forwards (multiply)?
    Dividing only has an option when the number is divisible, so the search stays tiny and ends at 1 or a dead end. Multiplying forward has no natural stopping point except passing N.

    /*

https://leetcode.com/problems/fibonacci-number/description/

Fibonacci Number

The Fibonacci numbers, commonly denoted F(n) form a sequence, called the Fibonacci 
sequence, such that each number is the sum of the two preceding ones, starting from 0 
and 1. That is,

    F(0) = 0, F(1) = 1
    F(n) = F(n - 1) + F(n - 2), for n > 1.

    Given n, calculate F(n).

 

Example 1:

Input: n = 2
Output: 1
Explanation: F(2) = F(1) + F(0) = 1 + 0 = 1.
Example 2:

Input: n = 3
Output: 2
Explanation: F(3) = F(2) + F(1) = 1 + 1 = 2.
Example 3:

Input: n = 4
Output: 3
Explanation: F(4) = F(3) + F(2) = 2 + 1 = 3.
 

Constraints:

0 <= n <= 30


*/

class Solution {
    public:
        int fib(int n) {
            if(n == 0){
                return 0;
            }
            if(n == 1){
                return 1;
            }
    
            int dp[31];
            memset(dp, -1, sizeof(dp));
    
            dp[0] = 0;
            dp[1] = 1;
    
            for(int i=2; i<=n; i++){
                dp[i] = dp[i-1] + dp[i-2];
            }
    
            return dp[n];
        }
    };

    /*

https://leetcode.com/problems/n-th-tribonacci-number/description/

1137. N-th Tribonacci Number

The Tribonacci sequence Tn is defined as follows: 

T0 = 0, T1 = 1, T2 = 1, and Tn+3 = Tn + Tn+1 + Tn+2 for n >= 0.

Given n, return the value of Tn.

 

Example 1:

Input: n = 4
Output: 4
Explanation:
T_3 = 0 + 1 + 1 = 2
T_4 = 1 + 1 + 2 = 4
Example 2:

Input: n = 25
Output: 1389537
 

Constraints:

0 <= n <= 37
The answer is guaranteed to fit within a 32-bit integer, ie. answer <= 2^31 - 1.

*/

class Solution {
    public:
        int tribonacci(int n) {
            if(n == 0){
                return 0;
            }
            if(n == 1 || n == 2){
                return 1;
            }
    
            int dp[40] = {0};
            dp[0] = 0;
            dp[1] = 1;
            dp[2] = 1;
            
            for(int i=3; i<=n; i++){
                dp[i] = dp[i-1] + dp[i-2] + dp[i-3];
            }
            return dp[n];
        }
    };

    📌 Remember

    • Recursion = base case + a call on a smaller problem.
    • Code before the call runs on the way down; code after it runs on the way back up.
    • Repeated subproblems make plain recursion exponential; memoize them with a dp array.
    • Bottom-up loops fill the same table without recursion.
    • Pick long long when values grow fast, and include <cstring> when you use memset.

    What are the two ingredients a problem needs for DP to help?

    Top-down or bottom-up: which one can overflow the call stack for n = 10^6?
    Top-down, because it recurses about n levels deep. Bottom-up uses a loop.
    How many distinct states does memoized fib(n) compute?
    n + 1 (the values 0..n), each once.
