    Breadth-first search (BFS), levels and paths

    BFS explores a graph layer by layer from a source using a queue. Because it reaches nodes in order of distance, the same code also gives the shortest number of edges to every node (its level) and, with a parent array, the actual shortest path. These patterns come back in almost every later graph problem.

    🧭 Start here

    You are standing in town 0 and you want to reach town 5 using as few roads as possible. Here is the map:

          (1)-----(3)
     /           \
  (0)             (5)
     \           /
      (2)-----(4)

    Left to yourself you would not wander around. You would write down every town one road away: 1 and 2. Then every new town two roads away: 3 and 4. Then three roads away: 5. The moment 5 appears you stop, and you know the answer is 3 roads, because you had already finished with everything closer.

    That ring-by-ring sweep is breadth-first search, and you have done it before. In the binary tree module, level order printed the root, then the whole first level, then the whole second level, using a queue: pop a node, push its children. BFS is that same loop with adj_list[par] in place of left and right.

    What is new is one array. A tree has no way back to a node you already printed, so nothing could repeat. A graph does have a way back: standing on 1, one of its neighbours is 0, the town you came from. Push it again and 0 pushes 1 again, and the queue never empties. So every node gets marked in a visited array, and only unmarked neighbours are pushed.

    q.push(src); visited[src] = true;
while(!q.empty()){
    int par = q.front(); q.pop();
    for(int child : adj_list[par]){
        if(!visited[child]){
            q.push(child);
            visited[child] = true;   // mark when pushed
        }
    }
}

    Mark the node when you push it, not when you pop it. If you waited until the pop, node 5 would be pushed once by 3 and again by 4 before either push was noticed, and it would be handled twice.

    Run the loop on the map above, starting at 0, and keep a level next to each node, level[child] = level[par] + 1:

    pop   queue after   newly pushed   level set
 -     0             0              0 -> 0
 0     1 2           1, 2           1 -> 1, 2 -> 1
 1     2 3           3              3 -> 2
 2     3 4           4              4 -> 2
 3     4 5           5              5 -> 3
 4     5             -
 5     (empty)       -

    Read the last column: level[5] is 3, which is the answer you worked out by hand. And you did not only solve it for 5. One run of BFS filled in the distance to every town the source can reach, in O(V + E), because each node enters the queue once and each edge is looked at once.

    Why is that level really the shortest distance? Because the queue keeps the towns in the order they were found, so everything at distance 1 leaves the queue before anything at distance 2. The first time a node is reached, it is reached by the fewest edges, and after that it is marked and never reconsidered.

    That argument leans on one quiet assumption: every edge counts the same, one step. If one road took five minutes and another took two hours, a path with more roads could be quicker, and counting edges would give the wrong answer. Weighted graphs need a different algorithm, which comes later in the course.

    Two small additions make BFS answer two more questions. Which towns can I reach at all? After the run, visited[x] already says so, and a node in a separate piece of the graph keeps its level of -1.

    Which roads do I actually take? Store parent[child] = par at the moment the child is discovered, then walk backwards from the destination. On the trace above: 5 came from 3, 3 came from 1, 1 came from 0, and 0's parent is -1, so the walk stops. That gives 5 3 1 0; reverse it and you have the path 0 1 3 5.

    The programs below are these pieces one at a time: plain BFS, BFS with levels, a reachability check, path printing, and three practice problems that reuse them. Watch the resetting: every new BFS from a new source must clear visited and level first, or the old marks will stop it.

    💡 Key ideas

    Queue + visited

    Push the source, mark it visited. Repeatedly pop the front node and push every unvisited neighbour, marking it visited when it is pushed so it never enters the queue twice.

    q.push(src); vis[src] = true;
while(!q.empty()){
  int par = q.front(); q.pop();
  for(int c : adj[par]) if(!vis[c]){ q.push(c); vis[c] = true; }
}

    Level = shortest distance

    Set level[src] = 0 and level[child] = level[par] + 1. In an unweighted graph this is the fewest edges from the source.

    Parent array

    Store parent[child] = par when a child is discovered. Walking parent back from the destination gives the path in reverse.

    Reachability

    After one BFS, vis[x] tells whether x can be reached from the source at all.

    Resetting state

    memset(vis, false, ...) and memset(level, -1, ...) before each BFS; -1 means "not reached". memset needs <cstring>.

    BFS complexity

    Every node is pushed once and every edge is looked at once (twice when undirected): O(V + E).

using namespace std;

vector<int> adj_list[1005];
bool visited[1005];
int level[1005];
int parent[1005];

void bfs(int src){
    queue<int> q;
    q.push(src);
    visited[src] = true;
    level[src] = 0;
    // parent[src] = -1;

    while(!q.empty()){
        int par = q.front();
        q.pop();

        cout << par << " ";

        for(int child : adj_list[par]){
            if(!visited[child]){
                q.push(child);
                visited[child] = true;
                level[child] = level[par] + 1;
                parent[child] = par;
            }   
        }
    }
}


int main(){
    int n, e;
    cin >> n >> e;

    while(e--){
        int a, b;
        cin >> a >> b;
        adj_list[a].push_back(b);
        adj_list[b].push_back(a);
    }

    memset(visited, false, sizeof(visited));
    memset(level, -1, sizeof(level));
    memset(parent, -1, sizeof(parent));

    int src, dest;
    cin >> src >> dest;

    bfs(src);

    /*
    for(int i=0; i<n; i++){
        cout << i << " parent -> " << parent[i] << endl;
    }
    */

    // First way to print path -- prints in reverse order
    int node = dest;

    while(node != -1){
        cout << node << " ";
        node = parent[node];
    }

    // Second way to print path -- prints in correct order
    vector<int> path;
    int node2 = dest;
    while(node2 != -1){
        path.push_back(node2);
        node2 = parent[node2];
    }
    reverse(path.begin(), path.end());
    for(int x : path){
        cout << x << " ";
    }

    return 0;
}

        }
    }

841. Keys and Rooms

There are n rooms labeled from 0 to n - 1 and all the rooms are locked except for room 0. Your goal is to visit all the rooms. However, you cannot enter a locked room without having its key.

When you visit a room, you may find a set of distinct keys in it. Each key has a number on it, denoting which room it unlocks, and you can take all of them with you to unlock the other rooms.

Given an array rooms where rooms[i] is the set of keys that you can obtain if you visited room i, return true if you can visit all the rooms, or false otherwise.

 

Example 1:

Input: rooms = [[1],[2],[3],[]]
Output: true
Explanation: 
We visit room 0 and pick up key 1.
We then visit room 1 and pick up key 2.
We then visit room 2 and pick up key 3.
We then visit room 3.
Since we were able to visit every room, we return true.
Example 2:

Input: rooms = [[1,3],[3,0,1],[2],[0]]
Output: false
Explanation: We can not enter room number 2 since the only key that unlocks it is in that room.
 

Constraints:

n == rooms.length
2 <= n <= 1000
0 <= rooms[i].length <= 1000
1 <= sum(rooms[i].length) <= 3000
0 <= rooms[i][j] < n
All the values of rooms[i] are unique.

*/

class Solution {
public:
    bool vis[1005];

    void bfs(int src, vector<vector<int>>& rooms){
        queue<int> q;
        q.push(src);
        vis[src] = true;

        while(!q.empty()){
            int par = q.front();
            q.pop();

            for(int key : rooms[par]){
                if(!vis[key]){
                    q.push(key);
                    vis[key] = true;
                }
            }
        }
    }

    bool canVisitAllRooms(vector<vector<int>>& rooms) {
        memset(vis, false, sizeof(vis));
        bfs(0, rooms);

        for(int i=0; i<rooms.size(); i++){
            if(!vis[i]) return false;
        }

        return true;
    }
};

    /*

Message Route   (CSES 1667)

Syrjala has n computers and m connections between them. Every connection joins
two computers and can be used in both directions. Uolevi wants to send a
message from computer 1 to computer n, and he wants the message to pass
through as few computers as possible. Print how many computers the route
visits and the route itself. If computer n cannot be reached from computer 1
at all, print IMPOSSIBLE.

Every connection costs the same, so "fewest computers" is just "fewest edges",
and that is exactly what BFS measures. BFS gives the levels; a parent array
remembers which computer put each computer into the queue, so the route can be
walked backwards from n.

Input
The first line has two numbers n and m: the number of computers and the number
of connections. The computers are numbered 1, 2, ..., n.
Then m lines follow, each with two numbers a and b: there is a connection
between computers a and b.
Both n and m can be large (hundreds of thousands), so the graph is kept as an
adjacency list and BFS touches every computer and every connection once.

Output
If there is no route, print the single word IMPOSSIBLE.
Otherwise print on the first line k, the number of computers on the route, and
on the second line the k computers in order, starting with 1 and ending with n.

Examples

input
5 5
1 2
1 3
1 4
2 3
5 4

output
3
1 4 5

input
4 2
1 2
3 4

output
IMPOSSIBLE

*/

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;

    /* n can be in the hundreds of thousands, so the adjacency list is a
       vector of size n+1 instead of a fixed-size global array. Index 0 stays
       unused because the computers are numbered from 1. */
    vector<vector<int>> adj_list(n + 1);

    while(m--) {
        int a, b;
        cin >> a >> b;
        adj_list[a].push_back(b);
        adj_list[b].push_back(a);   // the connection works both ways
    }

    vector<bool> visited(n + 1, false);
    vector<int> level(n + 1, -1);
    /* parent[x] is the computer that first reached x. The source has no
       parent, so it is left at -1 and that is what stops the walk back. */
    vector<int> parent(n + 1, -1);

    queue<int> q;
    q.push(1);
    visited[1] = true;
    level[1] = 0;

    while(!q.empty()) {
        int par = q.front();
        q.pop();

        for(int child : adj_list[par]) {
            if(!visited[child]) {
                visited[child] = true;
                level[child] = level[par] + 1;
                parent[child] = par;
                q.push(child);
            }
        }
    }

    if(!visited[n]) {
        cout << "IMPOSSIBLE" << endl;
        return 0;
    }

    /* Walk back from n through the parents. That gives the route in reverse,
       so it is collected in a vector and turned around. */
    vector<int> path;
    int node = n;
    while(node != -1) {
        path.push_back(node);
        node = parent[node];
    }
    reverse(path.begin(), path.end());

    /* level[n] counts edges; the number of computers is one more than that,
       and it is also the size of the path we just built. */
    cout << path.size() << endl;
    for(int i = 0; i < (int)path.size(); i++) {
        if(i > 0) cout << " ";   // one space between computers, none at the end
        cout << path[i];
    }
    cout << endl;

    return 0;
}

    Reading the output. Prints 3 and then 1 4 5. The message goes 1 -> 4 -> 5, three computers in total. With the second sample in the file header (4 2, edges 1-2 and 3-4) it prints IMPOSSIBLE, because nothing joins the two halves.

    How it works, step by step
    1. Read the graph into vector<vector<int>> adj_list(n + 1) and push both directions, because a connection works both ways. A vector, not a fixed adj_list[1005]: here n can be in the hundreds of thousands.
    2. BFS from computer 1, filling level and parent as each computer is discovered.
    3. parent[child] = par records who put the child into the queue, so the route can be walked backwards later.
    4. If computer n was never visited, print IMPOSSIBLE and stop.
    5. Otherwise start at n and follow parent until it is -1. Computer 1 keeps parent -1, so that is what ends the walk.
    6. The collected route comes out from n back to 1, so reverse it before printing.
    7. Print path.size() first (the number of computers, one more than level[n]), then the route on the next line.
    Watch out. The count asked for is computers, not connections: it is level[n] + 1, not level[n]. And check visited[n] before touching the parents - walking back from a computer that was never reached gives nonsense.
    ✅ Check yourself: Why is plain BFS enough here, without any distances?
    Every connection counts the same, so the cheapest route is simply the one with the fewest connections, and BFS reaches every computer on its lowest level first.

    📌 Remember

    • BFS = queue + visited; mark when you push.
    • level[child] = level[par] + 1 gives shortest distance in unweighted graphs.
    • parent[child] = par lets you rebuild the path; reverse it at the end.
    • Reset vis/level before every new BFS.
    • BFS runs in O(V + E).

    ✅ Check yourself

    Why does BFS give shortest distances only when all edges have the same weight?
    It counts edges layer by layer; with different weights a path with more edges can be cheaper.
    A BFS from node 0 never reaches node 7. What are level[7] and parent[7]?
    Both stay at their start value, -1.
    What data structure turns BFS into DFS if you swap it in?
    A stack (LIFO) instead of a queue (FIFO).
