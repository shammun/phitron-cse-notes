    Introduction to Algorithms · Module 18

    Merge sort, LCS and Kruskal's MST

    Three classic algorithms close the course. Merge sort shows divide and conquer: split the array in half, sort each half, merge them. Longest common subsequence is a two-string DP. Kruskal's algorithm builds a minimum spanning tree by taking the cheapest edges that do not form a cycle, using DSU. The module's quiz material also contrasts substrings with subsequences.

    💡 Key ideas

    Divide and conquer

    Break the problem into halves, solve each half recursively, then combine. For merge sort the combining step is the merge.

    Merging two sorted arrays

    Keep one pointer in each array, copy the smaller front element, advance that pointer, and finally copy whatever is left.

    while (i < n && j < m) c[k++] = (a[i] < b[j]) ? a[i++] : b[j++];

    Merge sort cost

    log n levels of halving, and each level does O(n) merge work, so O(n log n) time with O(n) extra memory.

    Substring vs subsequence

    A substring is a contiguous block of characters. A subsequence keeps the order but may skip characters. ace is a subsequence of abcde, not a substring.

    LCS recurrence

    Compare the last characters: equal gives 1 + lcs of both shorter strings; different gives the better of dropping one character from either string.

    if (a[i] == b[j]) return 1 + lcs(i-1, j-1);
return max(lcs(i-1, j), lcs(i, j-1));

    Minimum spanning tree

    A set of n-1 edges that connects all nodes with the smallest total weight and no cycle.

    Kruskal's algorithm

    Sort edges by weight. Walk through them and keep an edge only if its ends are in different DSU groups; then union them.

#include <vector>
#include <algorithm>
#include <string>

using namespace std;

int main(){
    // First we will take the input for two arrays

    int n, m;
    cin >> n >> m;

    int a[n];
    for(int i=0; i<n; i++){
        cin >> a[i];
    }

    int b[m];
    for(int i=0; i<m; i++){
        cin >> b[i];
    }

    // Now, declare an array to store the result for the merging of two arrays
    int c[n+m];

    // Now, take the two pointers for the two arrays and pointer for the result array
    int i=0, j=0, curr=0;

    while(i < n && j < m){
        if(a[i] < b[j]){
            c[curr] = a[i];
            i++;
            curr++;
        } else{
            c[curr] = b[j];
            j++;
            curr++;
        }
    }

    while(i < n){
        c[curr] = a[i];
        i++;
        curr++;
    }

    while(j < m){
        c[curr] = b[j];
        j++;
        curr++;
    }

    for(int i=0; i<n+m; i++){
        cout << c[i] << " ";
    }

    return 0;
}
    Input (stdin)
    4 3
1 4 7 9
2 3 8

    n m, then the two arrays, each already sorted.

    Output 
    1 2 3 4 7 8 9

    Reading the output. Prints 1 2 3 4 7 8 9: every element of both arrays, in order.

    How it works, step by step
    1. Read sizes n, m and the two sorted arrays a, b.
    2. i, j point into a, b; curr points into the result c.
    3. While both have elements, copy the smaller front element into c and advance.
    4. Copy the rest of whichever array is not finished.
    5. Print c.
    Watch out. The inputs must already be sorted; merging unsorted arrays gives an unsorted result.
    ✅ Check yourself: How many comparisons can merging 4 and 3 elements need at most?
    6 (n + m - 1), because each comparison places one element and the last one needs no comparison.

    #include <iostream>
#include <vector>
#include <algorithm>
#include <string>

using namespace std;

void divide(int a[], int l, int r){
    if(l >= r){
        return;
    }
    int mid = (l+r)/2;
    divide(a, l, mid);
    divide(a, mid+1, r);

}

int main(){
    // First we will take the input for two arrays

    int n, m;
    cin >> n >> m;

    int a[n];
    for(int i=0; i<n; i++){
        cin >> a[i];
    }

    divide(a, 0, n-1);

    return 0;
}

    n and an unused m, then n values.

    (prints nothing)

    How it works, step by step
    1. divide(a, l, r) stops when l >= r (one element or none).
    2. Otherwise mid = (l + r) / 2.
    3. Recurse on the left half [l, mid] and the right half [mid+1, r].
    4. main reads n m (m is not used) and the array, then calls divide(a, 0, n-1).
    ✅ Check yourself: For n = 8, how many levels of splitting are there before ranges have size 1?
    3 (8 -> 4 -> 2 -> 1), which is log2 8.

    #include <iostream>
#include <vector>
#include <algorithm>
#include <string>

using namespace std;

void conquer(int c[], int l, int mid, int r){
    int n = mid - l + 1;
    int a[n];
    for(int i=0; i<n; i++){
        a[i] = c[l+i];
    }

    int m = r - mid;
    int b[m];
    for(int i=0; i<m; i++){
        b[i] = c[mid+1+i];
    }

    // Now, take the two pointers for the two arrays and pointer for the result array
    int i=0, j=0, curr=l;

    while(i < n && j < m){
        if(a[i] < b[j]){
            c[curr] = a[i];
            i++;
            curr++;
        } else{
            c[curr] = b[j];
            j++;
            curr++;
        }
    }

    while(i < n){
        c[curr] = a[i];
        i++;
        curr++;
    }

    while(j < m){
        c[curr] = b[j];
        j++;
        curr++;
    }
}

void divide(int a[], int l, int r){ // O(nlogn) -- this does the merge sort
    if(l >= r){
        return;
    }
    int mid = (l+r)/2;
    divide(a, l, mid); // merge sort the left half
    divide(a, mid+1, r); // merge sort the right half
    conquer(a, l, mid, r); // merge the two sorted arrays
}

int main(){
    // First we will take the input for two arrays

    int n, m;
    cin >> n >> m;

    int a[n];
    for(int i=0; i<n; i++){
        cin >> a[i];
    }

    divide(a, 0, n-1);

    for(int i=0; i<n; i++){
        cout << a[i] << " ";
    }

    return 0;
}
    Input (stdin)
    6 0
5 2 9 1 5 6

    n and an unused m, then n values (a duplicate 5 is included).

    Output 
    1 2 5 5 6 9

    Reading the output. Prints 1 2 5 5 6 9. Duplicates are kept.

    How it works, step by step
    1. divide(a, l, r): return if the range has one element.
    2. Sort [l, mid] and [mid+1, r] recursively.
    3. conquer copies the two halves into temporary arrays a and b.
    4. It merges them back into c[l..r] with the two-pointer method.
    5. main prints the sorted array.
    Watch out. main still reads an unused m, left over from conquer.cpp; the input must contain it. Using a[i] <= b[j] in the merge would make the sort stable (equal values keep their order).
    ✅ Check yourself: Why is merge sort always O(n log n), even on already-sorted input?
    It always splits in the middle and always merges, whatever the order of the values.

    // Longest common substring using recursion
// We will be given two strings a and b. We have to find the length of the 
// longest common substring of the two strings.
// We will use memoization to optimize the solution.


#include <iostream>
#include <vector>
#include <algorithm>
#include <string>

using namespace std;
string a, b;
int dp[1005][1005];

int lcs(int i, int j){
    if(i < 0 || j < 0){
        return 0;
    }

    if(dp[i][j] != -1){
        return dp[i][j];
    }

    if(a[i] == b[j]){
        dp[i][j] = lcs(i-1, j-1) + 1;
        return dp[i][j];
    } else{
        int op1 = lcs(i-1, j);
        int op2 = lcs(i, j-1);
        dp[i][j] = max(op1, op2);
        return dp[i][j];
    }
}

int main(){
    memset(dp, -1, sizeof(dp));
    cin >> a >> b;
    int n = a.size();
    int m = b.size();
    cout << lcs(n-1, m-1);

    return 0;
}
    Input (stdin)
    abcde
ace

    Two strings.

    Output 
    3

    Reading the output. Prints 3 (the common subsequence ace).

    How it works, step by step
    1. memset(dp, -1, ...) and read strings a, b.
    2. Base case: an empty prefix (i < 0 or j < 0) gives 0.
    3. If a[i] == b[j], the answer is lcs(i-1, j-1) + 1.
    4. Otherwise the best of skipping a[i] or skipping b[j].
    5. Print lcs(n-1, m-1).
    Watch out. The top comment says 'substring', but the code computes the longest common subsequence; a substring version would reset to 0 when characters differ. Tip: on some compilers you need #include <cstring> for memset; this file relies on another header bringing it in.
    ✅ Check yourself: What is the LCS length of abc and def?
    0, they share no characters.

    #include <iostream>
#include <vector>
#include <algorithm>
#include <string>

using namespace std;

int par[1005];
int group_size[1005];

class Edge{
    public:
        int a, b, c;
        Edge(int a, int b, int c){
            this->a = a;
            this->b = b;
            this->c = c;
        }
};

bool cmp(Edge l, Edge r){
    return l.c < r.c;
}

int find(int node){
    if(par[node] == -1){
        return node;
    }
    int leader = find(par[node]);
    par[node] = leader;
    return leader;
}

int dsu_union(int node1, int node2){
    int leader1 = find(node1);
    int leader2 = find(node2);

    if(group_size[leader1] >= group_size[leader2]){
        par[leader2] = leader1;
        group_size[leader1] += group_size[leader2];
    } else{
        par[leader1] = leader2;
        group_size[leader2] += group_size[leader1];
    }
}

int main(){
    memset(par, -1, sizeof(par));
    memset(group_size, 1, sizeof(group_size));

    int n, e;
    cin >> n >> e;
    vector<Edge> edge_list;

    while(e--){
        int a, b, c;
        cin >> a >> b >> c;
        edge_list.push_back(Edge(a, b, c));
    }

    sort(edge_list.begin(), edge_list.end(), cmp);

    /*
    for(auto edge : edge_list){
        cout << edge.a << " " << edge.b << " " << edge.c << endl;
    }
    */
    
    int total_cost = 0;

    // Check if the edges are connected or not
    for(auto edge : edge_list){
        int parA = find(edge.a);
        int parB = find(edge.b);
        if(parA != parB){
            dsu_union(edge.a, edge.b);
            total_cost += edge.c;
        }
    }

    cout << total_cost << endl;

    return 0;
}
    Input (stdin)
    4 5
1 2 1
2 3 4
1 3 3
3 4 2
1 4 5

    n e, then e edges a b weight.

    Output ended with exit code 0xc0000005
    (prints nothing)

    Reading the output. The program crashes before printing anything (status exit_0xc0000005, an access violation), and the compiler warns no return statement in function returning non-void. That missing return is the cause (see Watch out). With the fix it prints 6: edges 1-2 (1), 3-4 (2) and 1-3 (3).

    How it works, step by step
    1. Read the edges into edge_list as Edge(a, b, c).
    2. sort them with cmp, cheapest first.
    3. For each edge, find the leaders of both ends.
    4. Different leaders: dsu_union them and add the weight to total_cost.
    5. Same leader: skip it, it would form a cycle.
    6. Print total_cost.
    Watch out. dsu_union is declared to return int but never returns anything. In C++ that is undefined behaviour, and here it makes the program crash on the first union. Make it void dsu_union(...). Also, memset(group_size, 1, ...) fills bytes, not ints; set sizes with a loop. If the graph may be disconnected, also count kept edges and check that there are n-1. Tip: on some compilers you need #include <cstring> for memset.
    ✅ Check yourself: Why is it safe to skip an edge whose ends already share a leader?
    Its ends are already connected by cheaper (or equal) edges, so adding it would only create a cycle and raise the cost.

    📌 Remember

    • Merge sort = split in half, sort both halves, merge with two pointers: O(n log n).
    • Substring is contiguous; subsequence keeps order but may skip characters.
    • LCS: equal last characters add 1; otherwise take the better of dropping one side.
    • Kruskal = sort edges + DSU; keep an edge only when it joins two groups.
    • An MST of n nodes has exactly n-1 edges.

    ✅ Check yourself

    What is the longest common subsequence of ABCBDAB and BDCABA, in length?
    4 (for example BCBA).
    How many substrings does a string of length 4 have (counting repeats)?
    10 = 4 + 3 + 2 + 1.
    Why does Kruskal need the edges sorted?
    The greedy rule 'always take the cheapest safe edge' only gives the minimum total if edges are considered from cheapest to most expensive.
