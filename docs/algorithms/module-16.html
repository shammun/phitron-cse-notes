    Final exam: DP, BFS on numbers, knapsack, anagrams

    The course's final exam problems. Two ask for the same sequence in top-down and bottom-up style. One turns 'can I reach N?' into a BFS over numbers. One is a straight 0-1 knapsack with several test cases, and the last is an anagram check by sorting.

    💡 Key ideas

    Top-down vs bottom-up

    The same recurrence can be memoized recursion or a forward loop. Bottom-up avoids deep recursion and is natural when every smaller value is needed anyway.

    Tetranacci recurrence

    Each term is the sum of the previous four, starting with 0, 1, 1, 2. Four base cases are needed.

    T[n] = T[n-1] + T[n-2] + T[n-3] + T[n-4]

    Numbers as graph nodes

    In 'reach N from 1 by +3 or x2', each number is a node and each operation is an edge. BFS with a vis array explores every reachable number up to N once.

    Prune values above the target

    Both operations only increase the value, so anything bigger than N can never come back down. Don't push it.

    Reset state between test cases

    With many test cases, clear dp/vis before each one, for the full range the test uses.

    Anagram check by sorting

    Two words use the same letters exactly when their sorted forms are equal.

    sort(a.begin(), a.end()); sort(b.begin(), b.end()); return a == b;

Tetranacci Number 1

The Tetranacci sequence is an extension of the well-known Fibonacci sequence, incorporating four 
previous terms instead of two.

The Tetranacci sequence Tn is defined as follows:

- T0 = 0, T1 = 1, T2 = 1,T3 = 2
- For n >= 4, Tn = Tn-1 + Tn-2 + Tn-3 + Tn-4

Given an integer 𝑛, return the value of Tn

Note : You must solve this problem using Recursion. (Top Down)

Input Format

A single integer n representing the position in the Tetranacci sequence.

Constraints
- 0 <= n <= 30
- The result is guaranteed to fit within a 32-bit integer (<=2^31-1)

Output Format

Print a single integer, the value of Tn

Sample Input 0
4

Sample Output 0
4

Explanation 0

T4 = T3 + T2 + T1 + T0 = 2 + 1 + 1 + 0 = 4

Sample Input 1
5

Sample Output 1
8

Explanation 1
T5 = T4 + T3 + T2 + T1 = 4 + 2 + 1 + 1 = 8

*/

#include <iostream>
#include <vector>
#include <algorithm>
#include <cmath>
#include <cstdio>
#include <vector>  
#include <cstring>  
#include <string>

using namespace std;
int dp[35];

int tetranacci(int n){
    if(n <= 1){ // or, we can also write if(n == 0 || n == 1)
        return n;
    }
    if(n== 2){
        return 1;
    }
    if(n == 3){
        return 2;
    }
    if(dp[n] != -1){
        return dp[n];
    }
    dp[n] = tetranacci(n-1) + tetranacci(n-2) + tetranacci(n-3) + tetranacci(n-4);
    return dp[n];
}

int main(){
    memset(dp, -1, sizeof(dp));
    int n;
    cin >> n;
    cout << tetranacci(n) << endl;

    return 0;
}
    Input (stdin)
    10

    A single n (0 to 30).

    Output 
    208

    Reading the output. Prints 208. The sequence is 0, 1, 1, 2, 4, 8, 15, 29, 56, 108, 208.

    How it works, step by step
    1. memset(dp, -1, ...) marks every value as unknown.
    2. Base cases: n <= 1 returns n, n == 2 returns 1, n == 3 returns 2.
    3. If dp[n] is known, return it.
    4. Otherwise store the sum of the four previous terms.
    ✅ Check yourself: What is T(6)?
    15 = 8 + 4 + 2 + 1.

https://www.hackerrank.com/contests/final-exam-a-introduction-to-algorithms-a-batch-06/challenges/tetranacci-number

Tetranacci Number II

The Tetranacci sequence is an extension of the well-known Fibonacci sequence, incorporating four 
previous terms instead of two.

The Tetranacci sequence Tn is defined as follows:

- T0 = 0, T1 = 1, T2 = 1,T3 = 2
- For n >= 4, Tn = Tn-1 + Tn-2 + Tn-3 + Tn-4

Given an integer 𝑛, return the value of Tn

Note : You must solve this problem using Loop. (Bottom up)

Input Format
A single integer n representing the position in the Tetranacci sequence.

Constraints
- 0 <= n <= 60
- The result is guaranteed to fit within a 64-bit integer (<=2^63-1 )

Output Format
Print a single integer, the value of Tn

Sample Input 0
4

Sample Output 0
4

Explanation 0
T4 = T3 + T2 + T1 + T0 = 2 + 1 + 1 + 0 = 4

Sample Input 1
5

Sample Output 1
8

Explanation 1
T5 = T4 + T3 + T2 + T1 = 4 + 2 + 1 + 1 = 8

*/

#include <iostream>
#include <vector>
#include <algorithm>    
#include <string>

using namespace std;

int main(){
    int n;
    cin >> n;
    long long tetra[n+1];

    tetra[0] = 0;
    tetra[1] = 1;
    tetra[2] = 1;
    tetra[3] = 2;

    for(int i=4; i<=n; i++){
        tetra[i] = tetra[i-1] + tetra[i-2] + tetra[i-3] + tetra[i-4];
    }

    cout << tetra[n] << endl;
    return 0;
}
    Input (stdin)
    10

    A single n (0 to 60).

    Output 
    208

    Reading the output. Prints 208, the same as the top-down version.

    How it works, step by step
    1. Create long long tetra[n+1].
    2. Set the first four terms: 0, 1, 1, 2.
    3. For i = 4..n, add the four previous terms.
    4. Print tetra[n].
    Watch out. For n < 3 the array has fewer than 4 cells, yet the code writes tetra[3] (and tetra[2], tetra[1]), which is out of bounds. It may still print the right value by luck. Size the array max(n + 1, 4) or declare it with a fixed size like 65.
    ✅ Check yourself: Why is long long needed here but not in version I?
    Version I stops at n = 30, which fits in int. Terms near n = 60 are far larger than 2^31.

https://www.hackerrank.com/contests/final-exam-a-introduction-to-algorithms-a-batch-06/challenges/make-it-2

Make it

Problem Statement

You will be given a positive integer N. You will start from 1 and do some steps (possibly zero).

In each step you can choose one of the following:

1. Add 3 with the current value
2. Multiply by 2 with the current value

Can you tell if you can reach N by using any number of steps you want.

Input Format
- First line will contain , the number of test cases.
- In each test case you will be given .

Constraints
1. 1 <= T <= 10^3
2. 1 <= N <= 10^5

Output Format
- Print "YES" if you can reach , "NO" otherwise.

Sample Input 0
5
1
3
5
15
16

Sample Output 0
YES
NO
YES
NO
YES

*/

#include <iostream>
#include <vector>
#include <algorithm>    
#include <string>
#include <stack>
#include <queue>

using namespace std;

bool vis[100005];

bool make_it(int n){
    queue<int> q;
    q.push(1);

    vis[1] = true;

    while(!q.empty()){
        int par = q.front();
        q.pop();

        if(par == n){
            return true;
        }

        int option1 = par + 3;
        int option2 = par * 2;

        if(option1 <= n && vis[option1] == false){
            q.push(option1);
            vis[option1] = true;
        }

        if(option2 <= n && vis[option2] == false){
            q.push(option2);
            vis[option2] = true;
        }
    }

    return false;
}

int main(){
    int t;
    cin >> t;

    while(t--){
        int n;
        cin >> n;
        memset(vis, false, sizeof(vis));

        if(make_it(n)){
            cout << "YES" << endl;
        }
        else{
            cout << "NO" << endl;
        }
    }

    return 0;

}
    Input (stdin)
    5
1
3
5
15
16

    T, then T values of N. This is the judge's sample.

    Output 
    YES
NO
YES
NO
YES

    Reading the output. YES NO YES NO YES, one per line (for example 5 = 1 x 2 + 3, and 16 = 1 x 2 x 2 x 2 x 2).

    How it works, step by step
    1. Push 1 into the queue and mark vis[1].
    2. Pop a value par; if it equals n, return true.
    3. Try par + 3 and par * 2; push each one that is at most n and unvisited.
    4. If the queue empties, return false.
    5. Clear vis before each test case.
    Watch out. Clearing all 100005 cells of vis per test is wasteful with 1000 tests; clearing only vis[0..n] is enough. Tip: on some compilers you need #include <cstring> for memset; this file relies on another header bringing it in.
    ✅ Check yourself: Why can't 3 be reached?
    From 1 you can get 4 or 2; every later value is at least 4 or is 2 (which leads to 5 or 4). Nothing lands on 3.

https://www.hackerrank.com/contests/final-exam-a-introduction-to-algorithms-a-batch-06/challenges/adventure-1

Adventure

Problem Statement

Once upon a time, there was a treasure hunter who ventured into an ancient temple in search of a 
valuable artifact. The temple was filled with traps and obstacles, and the treasure hunter had to 
carry all of his equipment with him.

The treasure hunter had a backpack with a limited weight capacity, and he could only carry a 
certain amount of equipment with him. Each piece of equipment had its own weight and value, and 
the treasure hunter needed to choose which items to bring to maximize the total value while 
keeping the total weight under the limit.

Help the treasure hunter to choose which items to bring in his backpack to maximize their total 
value while keeping the total weight of his backpack under a certain limit. Each item can only be 
included once.

Input Format

- First line will contain T, the number of test cases.
- The first line of each test case will contain N(Number of items) and W(Total weight of backpack).
- Second line of each test case will contain an array w containing the weights of all items.
- Third line of each test case will contain an array v containting the values of all items.

Constraints
1. 1 <= T <= 10^3
2. 1 <= N <= 10^3
3. 1 <= W <= 10^3
4. 0 <= w[i] <= 10^3; Here 0 <= i < N
5. 0 <= v[i] <= 10^3; Here 0 <= i < N;

Output Format
- Output the maximum total value you can obtain in the backpack for each test case.

Sample Input 0
2
4 7
2 3 4 5
4 7 6 5
4 17
10 1 6 9
6 10 10 8

Sample Output 0
13
28

Explanation 0
In the first test case case, he can take 2nd and 3rd item which total weight is 3+4=7 and total 
value is 7+6=13 and its the maximum value possible.

*/

#include <iostream>
#include <vector>
#include <algorithm>
#include <string>
#include <cstring>

using namespace std;

int val[1005], weight[1005];
int dp[1005][1005];

int knapsack(int i, int max_weight){
    if(i < 0 || max_weight == 0){
        return 0;
    }

    if(dp[i][max_weight] != -1){
        return dp[i][max_weight];
    }

    if(weight[i] <= max_weight){
        int op1 = knapsack(i-1, max_weight - weight[i]) + val[i];
        int op2 = knapsack(i-1, max_weight);
        dp[i][max_weight] = max(op1, op2);
        return dp[i][max_weight];
    } else {
        dp[i][max_weight] = knapsack(i-1, max_weight);
        return dp[i][max_weight];
    }
}

int main(){
    int t;
    cin >> t;

    while(t--){
        int n, max_weight;
        cin >> n >> max_weight;

        for(int i=0; i<n; i++){
            cin >> weight[i];
        }

        for(int i=0; i<n; i++){
            cin >> val[i];
        }

        for(int i=0; i<n; i++){
            for(int j=0; j<=max_weight; j++){
                dp[i][j] = -1;
            }
        }

        cout << knapsack(n-1, max_weight) << endl;
    }
}
    Input (stdin)
    2
4 7
2 3 4 5
4 7 6 5
4 17
10 1 6 9
6 10 10 8

    T; each test: N W, the weights, the values. This is the judge's sample.

    Output 
    13
28

    Reading the output. Prints 13 and 28, matching the sample. In test 1, items of weight 3 and 4 give 7 + 6 = 13.

    How it works, step by step
    1. Read n, max_weight, then all weights, then all values.
    2. Reset dp[i][j] = -1 for j from 0 through max_weight.
    3. knapsack(i, w): 0 if no items or no capacity; memo check; take/skip choice.
    4. Print knapsack(n-1, max_weight).
    Watch out. Weights can be 0 here, and the base case is max_weight == 0. With capacity 0 a weight-0 item with value > 0 would be missed; if (i < 0) return 0; alone is the safer base case.
    ✅ Check yourself: What changed from the buggy Module 15 versions that makes this one correct?
    The reset loop uses j <= max_weight, so the starting state is really marked as unsolved.

https://www.hackerrank.com/contests/final-exam-a-introduction-to-algorithms-a-batch-06/challenges/pile-of-word-37-3

Pile of Word

Problem Statement

Pile of Word is a word formed by rearranging the letters of another word, using all the original 
letters exactly once. In other words, it involves creating a new word by rearranging the characters 
of a given word. It is possible that after rearranging it looks like the original one.

You will be given two strings S1 and S2. You need to determine if the strings are Pile of Word of each 
other.

Input Format

First line will contain T, the number of test cases.
Each line of the test case will contain S1 and S2 separated by a space. The string will contain Enlish 
small alphabets only.

Constraints
1. 1 <= T <= 10^3
2. 1 <= |S1|, |S2| <= 10^4. Here || means the length of string.

Output Format
- Ouptut YES if the strings are Pile of Word to each other, NO otherwise.

Sample Input 0
4
eat tea
madam madam
ball all
ant tan

Sample Output 0
YES
YES
NO
YES

*/

#include <iostream>
#include <string>
#include <algorithm>

using namespace std;

bool pileOfWord(string s1, string s2){
    sort(s1.begin(), s1.end());
    sort(s2.begin(), s2.end());

    if(s1.length() != s2.length()){
        return false;
    }

    for(int i = 0; i < s1.length(); i++){
        if(s1[i] != s2[i]){
            return false;
        }
    }

    return true;
}

int main(){
    int t;
    cin >> t;

    while(t--){
        string s1, s2;
        cin >> s1 >> s2;

        if(pileOfWord(s1, s2)){
            cout << "YES" << endl;
        } else {
            cout << "NO" << endl;
        }
    }

    return 0;
}
    Input (stdin)
    4
eat tea
madam madam
ball all
ant tan

    T, then T lines with two words. This is the judge's sample.

    Output 
    YES
YES
NO
YES

    Reading the output. Prints YES YES NO YES, matching the sample. ball and all differ in length.

    How it works, step by step
    1. Sort s1 and s2 (they are copies, so the originals are unchanged).
    2. Different lengths: return false.
    3. Compare each position; any difference means false.
    4. Otherwise return true and print YES.
    ✅ Check yourself: How could you check anagrams in O(L) instead?
    Count each letter in an array of 26: add for the first word, subtract for the second, and check that all counts are 0.

    📌 Remember

    • One recurrence, two styles: memoized recursion or a bottom-up loop.
    • Match the integer type to the constraints (n = 60 needs long long).
    • 'Can I reach N with these operations?' is a BFS over numbers.
    • Reset DP/visited arrays for every test case, over the full range.
    • Sorted strings are equal exactly when the words are anagrams.

    ✅ Check yourself

    In Make it, why is it safe to ignore values above N?
    Both operations only make the number bigger, so a value above N can never come back to N.
    How many base cases does a recurrence that uses the previous k terms need?
    k base cases (here 4 for Tetranacci).
    Is 10 reachable in Make it? Show a path.
    Yes: 1 -> 4 (+3) -> 7 (+3) -> 10 (+3).
