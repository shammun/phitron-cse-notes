    💡 Key ideas

    Linear search

    Scan from the left and return the first index where the value matches; return -1 if you reach the end.

    std::set

    Keeps unique elements in sorted order automatically, so inserting every character and then printing the set gives unique letters alphabetically.

    set<char> s(str.begin(), str.end());

    Reachable sums with 3 and 4

    3, 4, 6, 7, 8 are reachable, and since 6, 7, 8 are three consecutive values, adding 3 again covers every number from 6 upward. Only 1, 2 and 5 are impossible.

    Sort, then greedy with a falling cap

    To take distinct counts from bags, sort sizes from large to small and take min(size, previous - 1), never below 0.

    Balanced partition with a size rule

    Choose exactly n/2 items whose sum is as close as possible to half the total. A DP over (items used, sum) records which sums are reachable.

    /*

The Lost Book

Problem Statement

The central library of the city has a unique method of organizing its books. The books are arranged in an array 
of integers, where each integer represents a unique book code.

You are the head librarian and have received a request to locate a specific book. Given the array of book codes 
and the target book code, your task is to determine if the book is available. If the book is found, return the 
index of the book in the array (0-based). Otherwise, return -1 to indicate the book is not in the collection.

Can you help to find the lost book?

Input Format

- The first line contains an integer n, the number of books.
- The second line contains n space-separated integers, representing the book codes.
- The third line contains a single integer target, the book code you are searching for.

Constraints
1 <= n <= 2*10^5
1 <= alpha_i <= 1X10^9
1 <= target <= 1X10^9 

Output Format
Output the index(0 based) of the book if found else output -1.

Sample Input 0
5
10 20 5 6 3
3

Sample Output 0
4

Sample Input 1
6
10 20 5 6 3 66
99

Sample Output 1
-1

*/

#include <iostream>

using namespace std;

int lostBook(int arr[], int n, int target){
    for(int i=0; i<n; i++){
        if(arr[i] == target){
            return i;
        }
    }
    return -1;
}

int main(){
    int n;
    cin >> n;

    int arr[n];
    for(int i=0; i<n; i++){
        cin >> arr[i];
    }

    int target;
    cin >> target;

    cout << lostBook(arr, n, target) << endl;

    return 0;
}
    Input (stdin)
    5
10 20 5 6 3
3

    n, the book codes, then the target. This is the contest's first sample.

    Output 
    4

    Reading the output. Prints 4, because code 3 is at index 4 (counting from 0).

    How it works, step by step
    1. Read n, the array, and target.
    2. lostBook loops i from 0 to n-1 and returns i at the first match.
    3. If the loop ends, return -1.
    4. Print the result.
    Watch out. The array is not sorted, so binary search would be wrong here.
    ✅ Check yourself: What would the program print for target 99 with the same array?

    /*

Problem Statement

In a quiet town, a group of linguists is studying the structure of words. They are particularly interested in 
analyzing words to find all the unique letters and arranging them in alphabetical order to understand their 
composition better.

Given a string S consisting of lowercase English letters, your task is to extract all unique letters, sort them 
alphabetically and print the result.

Input Format
A single string S , consisting only of lowercase English letters.

Constraints
1≤∣S∣≤10^6

Output Format
Print a single string containing all unique letters from S, sorted in alphabetical order.

Sample Input 0
hello

Sample Output 0
ehlo

Explanation 0
- The unique letters in "hello" are h, e, l, o.
= Sorting them alphabetically gives "ehlo".

Sample Input 1
banana

Sample Output 1
abn

*/

#include <iostream>
#include <string>
#include <set>

using namespace std;

int main(){
    string S;
    cin >> S;

    set<char> unique_letters;

    for(char c : S){
        unique_letters.insert(c);
    }

    for(char c : unique_letters){
        cout << c;
    }

    cout << endl;

    return 0;
}
    Input (stdin)
    banana

    One lowercase string. This is the contest's second sample.

    Output 
    abn

    Reading the output. Prints abn: the letters b, a, n without repeats, in alphabetical order.

    How it works, step by step
    1. Read the string S.
    2. Insert each character into unique_letters.
    3. Loop over the set and print each character (already in alphabetical order).
    ✅ Check yourself: How could you do this without a set?
    Use a bool seen[26] array, mark each letter, then print the marked letters from a to z.

    /*

Problem Statement

You are given a target integer T. Initially, you start with a variable S=0. In each step, you can add 
either 3 or 4 to S. Your task is to determine whether it is possible to reach the target T by performing 
a series of such additions.

Input Format
A single integer T, representing the target sum.

Constraints
1 <= T <= 10^9

Output Format
Print "YES" if it is possible to reach the target T by adding 3 or 4 in each step.
Print "NO" otherwise.

Sample Input 0
10

Sample Output 0
YES

Explanation 0
- Start with S=0.
- Add 3: S=0+3=3.
- Add 4: S=3+4=7.
- Add 3: S=7+3=10.
- The target T=10 is achieved.

Sample Input 1
2

Sample Output 1
NO

Explanation 1
It is impossible to reach 2 by adding only 3 or 4.

*/

#include <iostream>
using namespace std;

int main(){
    int T;
    cin >> T;

    if(T < 3){
        cout << "NO" << endl;
    } else if(T == 3 || T == 4 || T == 6 || T == 7 || T == 8 || T == 9 || T == 10 || T == 11 || T >= 12){
        cout << "YES" << endl;
    } else{
        cout << "NO" << endl;
    }

    return 0;
}
    Input (stdin)
    5

    A single T. 5 is the interesting case: 3 + something never makes 5.

    Output 
    NO

    Reading the output. Prints NO. With T = 10 it prints YES (3 + 3 + 4).

    How it works, step by step
    1. T < 3: NO.
    2. T in {3, 4, 6, 7, 8, 9, 10, 11} or T >= 12: YES.
    3. Anything else (only 5 is left): NO.
    Watch out. The long condition works, but the rule is simply: NO for 1, 2 and 5, YES for everything else.
    ✅ Check yourself: Is 13 reachable? Give a split.
    Yes: 3 + 3 + 3 + 4.

Mina and Moni are two sisters who share a deep bond of love, and they extend this love even to their food. They have a habit of 
splitting everything equally between them. One fine day, their father gave them a total of  coins and asked them to divide it

    How it works, step by step
    1. Let total be the sum and k = n / 2 the size of the smaller group.
    2. Build can[c][s]: can exactly c coins sum to s? Start with can[0][0] = true.
    3. For each coin, go through c from high to low and mark can[c+1][s + coin] from can[c][s] (0-1 knapsack style).
    4. For every s with can[k][s], the difference is abs(total - 2*s); print the smallest.
    5. Use a bitset per count if the sums are large.
    Watch out. Only the statement was saved; there is no solution in this file. Plain subset sum is not enough: the group sizes are fixed, so the DP must also track how many coins are used.
    ✅ Check yourself: Why must the DP track the number of coins, not only the sum?
    Each sister must get exactly n/2 (or n/2 + 1) coins; a subset with the right sum but the wrong size is not allowed.

    📌 Remember

    • Unsorted data: linear search; do not binary search.
    • set gives unique + sorted in one step.
    • For 'sums of a and b' problems, find the small impossible values; beyond them everything works.
    • Sort descending and use a falling cap to make counts distinct.
    • Fixed group sizes turn subset sum into a DP over (count, sum).

    ✅ Check yourself

    What is the running time of inserting m characters into a set<char>?
    O(m log k), where k (at most 26) is the number of distinct letters, so effectively O(m).
