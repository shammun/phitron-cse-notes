    Assignment 1: graph & grid basics

    The first graded assignment. It checks that you can read a graph, look at adjacency lists directly, and run BFS on a grid to test reachability, count apartments (components) and measure their sizes. Each problem is a small twist on the Module 2-3 templates.

    5 programsFolder on GitHub ↗

    🧭 Start here

    This is the first graded assignment, so nothing on it is new. Every problem is one of the three tools from Modules 1 to 3 wearing a different hat. The hard part of an assignment day is not writing the code; it is reading a question and knowing within ten seconds which tool it is asking for.

    Start with the question that needs no search at all. If someone asks "is there a road straight from A to B, with no other town in between?", you do not walk anywhere. You look at A's neighbour list and check whether B is written in it. BFS would give the right answer too, but it answers a much bigger question than the one asked, and on 10^6 queries that costs you the time limit.

    // is there a single edge a -> b ?
for(int x : adj_list[a]){
    if(x == b) return true;
}
return false;

    Three of the five problems hand you a map instead of a list of edges, so it is worth saying once what a map and a graph have in common. A cell (i, j) is a node. Its neighbours are the four cells above, below, left and right of it.

    The only difference is where the edges live. In a graph you stored them yourself in adj_list. In a grid nobody stores them, because you can work them out: add one of the four direction pairs to (i, j), then let valid(i, j) tell you whether you have fallen off the map. So the BFS from Module 2 does not change at all. visited becomes two-dimensional, and "the neighbours of this node" becomes four additions.

                (i-1, j)
                |
  (i, j-1) -- (i, j) -- (i, j+1)
                |
            (i+1, j)

    Here is the pattern the grid problems share, on a map small enough to do by hand. # is a wall, . is floor, and you want the number of separate rooms.

    map            after the search from (0,1)
# . . #        #  1  1  #
# # . #        #  #  1  #
. . # #        .  .  #  #

next unvisited floor cell is (2,0)
               #  1  1  #
               #  #  1  #
               2  2  #  #

2 searches started  ->  2 apartments
sizes: 3 cells and 2 cells

    You walked over the cells in reading order. The first floor cell you met that was not yet visited started a search, and that search swallowed the whole room, so every other cell of that room was already marked when the outer loop reached it. The number of searches you started is therefore the number of apartments, and if the search counts the cells it marks, that count is the size of one apartment. Those two lines of bookkeeping are problems 4 and 5.

    BFS or DFS? For "can I get from A to B" and "how many rooms are there", both give the same answer, because both end up marking exactly the reachable cells. Choose BFS when the question mentions distance — fewest steps, shortest path, how many moves — because BFS finishes one level before starting the next, so the level on which a cell is found is its distance. Choose DFS when you only need to touch everything reachable and want shorter code, but remember that it recurses: on a 1000 x 1000 open map the recursion can go a million calls deep.

    Two details catch people on this assignment. First, the special cells: A and B are not ., so a search that walks only on . will refuse to step onto its own target. Note their row and column while you are reading the map, and let the search walk on anything that is not a wall. Second, direction: in the first problem the edges are one-way, so 0 1 can be YES while 1 0 is NO. Push b into adj_list[a] and nothing back.

    The five programs below are these ideas with the details filled in. Read each statement first, decide which of the three tools it wants, and only then look at the code.

    💡 Key ideas

    Direct edge check

    To know whether a → b is one edge, scan adj[a] for b. No search needed.

    Sorted neighbour list

    Sorting adj[x] with greater<int>() gives neighbours in descending order.

    Find special cells while reading

    Store the row/column of A and B as the grid is read, so BFS knows where to start and stop.

    Grid components

    Loop over all cells; each unvisited floor cell starts a BFS and adds one apartment.

    Component size from BFS

    Start a counter at 1 and add 1 every time a new cell is pushed; return it from bfs.

Problem Statement

You will be given a directed graph as input. Then you will receive Q queries. For each query, you will be 
given two nodes, A and B. You need to determine whether you can go from A to B directly without using any

#include <iostream>
#include <vector>

using namespace std;

vector<int> adj_list[1005];

bool direct_edge(int from, int to){
    if(from == to){
        return true;
    }
    for(int child : adj_list[from]){
        if(child == to){
            return true;
        }
    }
    return false;
}

int main(){
    int n, e;
    cin >> n >> e;

    for(int i=0; i<e; i++){
        int a, b;
        cin >> a >> b;
        adj_list[a].push_back(b);
    }

    int Q;
    cin >> Q;

    while(Q--){
        int from, to;
        cin >> from >> to;
        if(direct_edge(from, to)){
            cout << "YES" << endl;
        } else {
            cout << "NO" << endl;
        }
    }

    return 0;
}

    How it works, step by step
    1. Store the directed edges: only adj_list[a].push_back(b).
    2. direct_edge(from, to) returns true at once if from == to.
    3. Otherwise it scans adj_list[from] for to.
    4. Print YES or NO for each query.
    Watch out. With up to 10^6 edges and 10^6 queries, scanning a long list can be slow; an adjacency matrix (N <= 1000) gives O(1) answers.

    /*

Problem Statement

You are given an N X M sized 2D matrix that represents a map of a building. Each cell 
represents a wall, a floor or a room. You will be given two rooms A and B. You need to 
tell if you can go from room A to B by passing through the floors. You can walk left, 
right, up, and down through the floor cells. You can't pass through walls.

Input Format

- The first input line has two integers N and M: the height and width of the map.
- Then there are N lines of M characters describing the map. Each character is .(floor), 
#(wall), A or B (rooms).

Constraints

1. 1 <= N, M <= 1000

Output Format

- Output YES if you can go from room  to , NO otherwise.

Sample Input 0

5 8
########
#.A#...#
#.##.#B#
#......#
########

Sample Output 0

YES

*/

#include <iostream>
#include <vector>
#include <queue>

using namespace std;

char grid[1005][1005];
bool vis[1005][1005];
vector<pair<int, int>> direction = {{0, 1}, {0, -1}, {-1, 0}, {1, 0}};
int n, m;

bool valid(int i, int j){
    if(i < 0 || i >= n || j < 0 || j >= m){
        return false;
    }
    return true;
}

bool bfs(int Ai, int Aj, int Bi, int Bj){
    queue<pair<int, int>> q;
    q.push({Ai, Aj});
    vis[Ai][Aj] = true;

    while(!q.empty()){
        pair<int, int> par = q.front();
        q.pop();
        int par_i = par.first;
        int par_j = par.second;

        if(par_i == Bi && par_j == Bj){
            return true;
        }

        for(int i=0; i<4; i++){
            int ci = par_i + direction[i].first;
            int cj = par_j + direction[i].second;
            if(valid(ci, cj) && vis[ci][cj] == false && grid[ci][cj] != '#'){
                q.push({ci, cj});
                vis[ci][cj] = true;
            }
        }
    }
    return false;
}

int main(){
    cin >> n >> m;

    int Ai = -999, Aj = -999, Bi = -999, Bj = -999;

    for(int i=0; i < n; i++){
        for(int j=0; j<m; j++){
            cin >> grid[i][j];
            if(grid[i][j] == 'A'){
                Ai = i;
                Aj = j;
            } else if(grid[i][j] == 'B'){
                Bi = i;
                Bj = j;
            }
        }
    }

    memset(vis, false, sizeof(vis));
    bool result = bfs(Ai, Aj, Bi, Bj);

    if(result){
        cout << "YES" << endl;
    } else {
        cout << "NO" << endl;
    }
}

    5 8
########
#.A#...#
#.##.#B#
#......#
########

    N M, then the map with ., #, A, B (the sample from the statement).

    Output 
    YES

    Reading the output. Prints YES: A goes down the left corridor, along the bottom and up to B.

    How it works, step by step
    1. While reading, remember (Ai, Aj) and (Bi, Bj).
    2. BFS from A; a neighbour is allowed if valid, unvisited and not #.
    3. When the popped cell equals B, return true.
    4. If the queue empties, return false. Print YES/NO.
    Watch out. Tip: on some compilers you need #include <cstring> for memset; this file relies on another header bringing it in.
    ✅ Check yourself: Why does the BFS allow any cell that is not # instead of only .?
    So it can also step onto the target cell B (and start from A).

    /*

Problem Statement

You are given an N X M sized 2D matrix that represents a map of a building. Each cell represents a 
wall or a room. The connected rooms are called apartments. Your task is to count the number of 
apartments in that building. You can walk left, right, up, and down through the room cells. You 
can't pass through walls.

Input Format

The first input line has two integers  and : the height and width of the map.
Then there are  lines of  characters describing the map. Each character is either .(room) or 
#(wall).

Constraints

1. 1 <= N, M <= 1000

Output Format

Output the number of apartments

Sample Input 0

5 8
########
#..#...#
####.#.#
#..#...#
########

Sample Output 0

3

Sample Input 1

6 8
.#.#####
.#.###..
#..#...#
#.##....
..##.###
#.#.##.#

Sample Output 1

5

*/

#include <iostream>
#include <vector>
#include <queue>
#include <algorithm>

using namespace std;

char grid[1005][1005];
bool vis[1005][1005];
vector<pair<int, int>> direction = {{0, 1}, {0, -1}, {-1, 0}, {1, 0}};
int n, m;

bool valid(int i, int j){
    if(i < 0 || i >= n || j < 0 || j >= m){
        return false;
    }
    return true;
}

void bfs(int Ai, int Aj){
    queue<pair<int, int>> q;
    q.push({Ai, Aj});
    vis[Ai][Aj] = true;

    while(!q.empty()){
        pair<int, int> par = q.front();
        q.pop();
        int par_i = par.first;
        int par_j = par.second;

        for(int i=0; i<4; i++){
            int ci = par_i + direction[i].first;
            int cj = par_j + direction[i].second;

            if(valid(ci, cj) && !vis[ci][cj] && grid[ci][cj] == '.'){
                q.push({ci, cj});
                vis[ci][cj] = true;
            }
        }
    }
}

int main(){
    cin >> n >> m;

    for(int i=0; i<n; i++){
        for(int j=0; j<m; j++){
            cin >> grid[i][j];
        }
    }

    int count = 0;
    for(int i=0; i<n; i++){
        for(int j=0; j<m; j++){
            if(!vis[i][j] && grid[i][j] == '.'){
                bfs(i, j);
                count++;
            }
        }
    }

    cout << count << endl;

    return 0;
}

    2. Double loop over cells; if a cell is . and not visited, bfs(i, j) and count++.
    3. bfs only walks into . cells.

/*

Problem Statement

You are given an  sized 2D matrix that represents a map of a building. Each cell represents a wall or a room. The connected rooms are called apartments. Your task is to count the number of apartments in that building. You can walk left, right, up, and down through the room cells. You can't pass through walls.

Input Format

The first input line has two integers  and : the height and width of the map.
Then there are  lines of  characters describing the map. Each character is either .(room) or #(wall).

Output the number of apartments

#include <iostream>
#include <vector>
#include <queue>
#include <algorithm>

using namespace std;

char grid[1005][1005];
bool vis[1005][1005];
vector<pair<int, int>> direction = {{0, 1}, {0, -1}, {-1, 0}, {1, 0}};
int n, m;

bool valid(int i, int j){
    if(i < 0 || i >= n || j < 0 || j >= m){
        return false;
    }
    return true;
}

int bfs(int Ai, int Aj){
    queue<pair<int, int>> q;
    q.push({Ai, Aj});
    vis[Ai][Aj] = true;
    int room_count = 1;

    while(!q.empty()){
        pair<int, int> par = q.front();
        q.pop();
        int par_i = par.first;
        int par_j = par.second;

        for(int i=0; i<4; i++){
            int ci = par_i + direction[i].first;
            int cj = par_j + direction[i].second;

            if(valid(ci, cj) && !vis[ci][cj] && grid[ci][cj] == '.'){
                q.push({ci, cj});
                vis[ci][cj] = true;
                room_count++;
            }
        }
    }
    return room_count;
}

int main(){
    cin >> n >> m;

    for(int i=0; i<n; i++){
        for(int j=0; j<m; j++){
            cin >> grid[i][j];
        }
    }

    vector<int> apartments;
    for(int i=0; i<n; i++){
        for(int j=0; j<m; j++){
            if(!vis[i][j] && grid[i][j] == '.'){
                int room_count = bfs(i, j);
                apartments.push_back(room_count);
            }
        }
    }

    sort(apartments.begin(), apartments.end());

    if(apartments.size() == 0){
        cout << 0 << endl;
    } else {
        for(int i = 0; i<apartments.size(); i++){
            cout << apartments[i] << " ";
        }
        cout << endl;
    }

    return 0;
}

    How it works, step by step
    1. room_count starts at 1 for the start cell.
    2. Each newly pushed . cell adds 1.
    3. Store every returned size in apartments, then sort ascending.
    4. Print the sizes, or 0 if the vector is empty.
    ✅ Check yourself: Why does room_count start at 1, not 0?
    The start cell is part of the apartment but is pushed before the counting loop.
